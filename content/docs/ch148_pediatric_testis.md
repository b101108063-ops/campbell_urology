## 📖 導讀

**隱睪症**（cryptorchidism/undescended testis）是男孩最常見的性腺發育異常，足月新生兒發生率約2%–5%，早產兒更高。睪丸的正常下降需依賴**INSL3**（胰島素樣因子3）與**睪固酮**（testosterone）的調控，並透過**引帶**（gubernaculum）與**腹股溝管**（inguinal canal）的結構變化完成。延遲治療會導致**精原細胞**（spermatogonia）凋亡增加與不育風險。本章節涵蓋隱睪症的胚胎學、激素調控、診斷方法與治療時機，並特別討論**自發性下降**、**睪丸固定術**（orchiopexy）與**後天型隱睪症**的概念。

---

## 胚胎學與激素調控

### 睪丸發育的關鍵調控因子

| 調控因子 | 來源細胞 | 主要作用 |
|---|---|---|
| **SRY** | 原始性腺 | 觸發睪丸決定 |
| **SOX9** | 支持細胞（Sertoli cells）| 促進 Sertoli 細胞分化與增殖 |
| **AMH**（抗穆勒氏管激素）| Sertoli 細胞 | 誘導穆勒氏管退化 |
| **INSL3** | Leydig 細胞 | 調控**引帶**發育與睪丸下降（第一階段）|
| **睪固酮**（testosterone）| Leydig 細胞 | 維持Wolffian管、調控第二階段下降 |

### 睪丸下降的兩個階段

**第一階段（腹股溝前期）**：依賴**INSL3**與**睪固酮**，引帶增大並固定於腹股溝區域。**第二階段（經腹股溝與恥骨上下降）**：依賴**睪固酮**調控的腹股溝管關閉與引帶收縮，將睪丸拉入陰囊。

人類胎兒在**22週前**很少發生經腹股溝的睪丸下降，多數胎兒在**27週後**睪丸才完全進入陰囊。

> **臨床重點**
> - **INSL3**與**睪固酮**是睪丸下降的兩大關鍵激素：INSL3主管引帶與腹股溝前期下降，睪固酮負責腹股溝期與陰囊期的調控。
> - 臨床上隱睪症可分為**可觸及型**（palpable）與**不可觸及型**（nonpalpable）；約80%為可觸及型，多位於腹股溝外環附近。

## 青春期前正常睪丸發育與 Tanner 分期

嬰兒期與兒童期的睪丸發育較緩慢，直至青春期才快速增大。臨床上評估睪丸大小以**Prader睪丸測量器**（Prader orchidometer）或超聲波測量容積為標準：

| 年齡 | 平均睪丸容積 |
|---|---|
| 新生兒（足月）| 0.5–1 mL |
| 嬰兒期 | 1–2 mL |
| 兒童期（4–8歲）| 2–3 mL |
| 青春期初期（Tanner 2–3）| 4–6 mL |
| Tanner 4–5 | 15–25 mL（成人型）|

> **臨床重點**
> - 隱睪症合併**小睪丸**（testicular volume < 正常值2SD以下）應懷疑合併**性腺機能低下**或**染色體異常**（如Klinefelter syndrome，47,XXY）。
> - 隱睪症本身即為**男性不育症**的風險因子，研究顯示單側隱睪術後仍有約30%精液分析異常，雙側者更高達50%–70%。

## 診斷方法

### 理學檢查

理學檢查是診斷隱睪症的第一步，應在溫暖環境下以雙手檢查：
- **可觸及型**：腹股溝區或恥骨上可觸及移動性睪丸
- **不可觸及型**：需考慮**睪丸缺如**（anorchia）或腹腔內睪丸

### 影像學檢查

| 檢查 | 敏感性 | 建議使用情境 |
|---|---|---|
| **陰囊超聲波** | 中等 | 可觸及型，用於確認陰囊內無睪丸 |
| **腹股溝超聲波** | 中等 | 評估腹股溝管區域 |
| **MRI** | 高 | 不可觸及型，考虑腹腔內睪丸 |
| **腹腔鏡** | 最高 | 不可觸及型確診與治療（金標準）|

> **臨床重點**
> - 超聲波對**腹股溝區域**的睪丸定位敏感性尚可，但對**腹腔內睪丸**敏感性低；不可觸及型隱睪建議直接行**腹腔鏡檢查**（diagnostic laparoscopy）。
> - **腹腔鏡**同時具有診斷與治療雙重價值：若發現腹腔內睪丸，可同時進行腹腔鏡輔助睪丸固定術或分期 Fowler-Stephens 睪丸固定術。

## 自發性下降與後天型隱睪症

### 自發性下降（Spontaneous Descent）

出生時診斷為隱睪的嬰兒，約**50%–87%**於**3個月前**出現自發性下降（尤其常見於高 scrotal型）。早產兒自發性下降比例更高。少數病例在1–5歲間出現**再上升**（reascent），發生率約10%–22%。

### 後天型隱睪症（Acquired Cryptorchidism）

隱睪症的診斷不再被視為純粹的先天性异常：研究顯示部分男童在新生兒期確認睪丸已完全下降，卻在數月或數年後被診斷為隱睪，稱為**後天型隱睪症**。致病機制可能與**腹股溝管結構異常**或**引帶功能障礙**有關。

> **臨床重點**
> - 隱睪症的追蹤應持續至**至少1歲**，因仍有約10%–22%的「已下降」睪丸可能再上升。
> - 對青春期男孩的隱睪症更應積極處理，因為延遲至青春期後的睪丸固定術對**生育功能**的保護效果顯著下降。

## 睪丸固定術（Orchiopexy）

### 標準腹股溝睪丸固定術

適用於**可觸及型**隱睪。手術要點：
1. 腹股溝切口，游離精索
2. 充分游離精索，確保無張力將睪丸置入陰囊
3. 固定睪丸於陰囊肉膜層
4. 若腹股溝管需修補，則進行**外環重建**

### Fowler-Stephens 睪丸固定術

適用於**腹腔內 high-lying 睪丸**（睪丸位於腹腔內或內環上方），或精索長度不足以安全游離至陰囊者。原理為結扎睪丸主要血供（精索內血管），依賴**輸精管血管**（vasal vessels）與**引帶血管**（gubernacular vessels）的側枝循環供血。

分期 Fowler-Stephens（一期先行結扎，6–12個月後二期游離固定）可提高成功率，因側枝循環有足夠時間建立。

> **臨床重點**
> - **睪丸固定術的手術時機**建議為**6個月至1歲**：太早（< 6個月）自發性下降仍可能發生，太晚（> 1歲）則生殖細胞凋亡加劇，生育功能受损。
> - **分期 Fowler-Stephens** 適用於 high-lying 腹腔內睪丸，一期結扎後6–12個月的等待期是建立側枝循環的關鍵，**不應過早進行二期手術**。
