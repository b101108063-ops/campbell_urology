## 📖 導讀

**性發育差異（Disorders of Sex Development, DSD）**與**泄殖腔畸形（Cloacal Anomalies）**代表小兒泌尿生殖系統最複雜的先天異常之一。本章節涵蓋**先天性腎上腺增生（Congenital Adrenal Hyperplasia, CAH）**、**純粹泄殖腔（persistent cloaca）**、**無肛畸形（anorectal malformation）**的評估原則，以及這些疾病在外科重建過程中的倫理與技術考量。早期精確的解剖評估與多專科團隊合作是達到良好長期功能的關鍵。

## 性發育差異（DSD）概述

### 定義與分類

DSD 涵蓋所有出生時性腺、內生殖器或外生殖器表現型與核型不一致之情況。**尿生殖竇異常（Urogenital Sinus Anomalies）**可見於四種臨床情境：

| 臨床情境 |
|----------|
| 性腺性別模糊狀態（genital ambiguity states） |
| 純粹尿生殖竇（pure urogenital sinus） |
| 泄殖腔畸形伴直腸受累 |
| 女性膀胱外翻（female exstrophy） |

### 先天性腎上腺增生（CAH）

CAH 為**自體隱性遺傳疾病**，最常見的酶缺陷為 **21-羥化酶缺乏（21-hydroxylase deficiency）**，發生率約 1/15,000–16,000。90–95% 的案例為 **CYP21A2 基因（第 6 號染色體短臂）突變**。突變類型與酶活性決定了雄性化程度——CAH 被視為一個**光譜性疾病（spectrum disorder）**，從輕度非典型到嚴重模糊皆可見。

### 身體檢查要點

#### 外生殖器評估

- **陰蒂大小與陰唇融合程度**：評估雄性化程度
- **泌尿生殖竇開口位置**：從接近正常陰道口位置到陰蒂尖端皆有可能
- **唇囊皺褶色素沉著**：可見於 CAH（因黑色素細胞刺激素升高）
- **肛門位置**：泄殖腔異常時肛門通常前移

#### 性腺評估

- 觸診確認睪丸數量、位置與質地
- 若兩側性腺皆已下降，則發現 **46,XX 核型的機率極低**

> **臨床重點**
> - 對於陰莖發育不良之 ambiguous genitalia 案例，若兩側睪丸已下降幾乎可排除 46,XX 核型
> - CAH 嬰兒之唇囊皺褶及乳暈色素沉著是腎上腺皮質刺激素（ACTH）分泌增加的重要線索
> - 新生兒 ambiguous genitalia 應在多專科團隊（泌尿科、內分泌科、遺傳科、心理師）框架下進行評估

## 影像學與內視鏡評估

### 尿生殖竇異常的解剖評估

需定義以下關鍵解剖細節：
- **共同尿生殖竇的長度**
- **陰道匯合處位置及其與膀胱頸之距離**
- **陰道大小與數量（雙陰道？）**
- **宮頸是否存在**
- **膀胱與尿道解剖**

### 泄殖腔畸形之產前診斷

- **超聲波**：胎兒腹水伴雙葉或三葉狀盆腔囊性結構 + 雙側水腎 + 羊水過少
- 最早可在 **19 週胎兒**時診斷
- 胎兒腹水形成機制：出口阻塞導致尿液逆流至 子宮，經輸卵管進入腹腔

### 術前影像學

| 檢查 | 目的 |
|------|------|
| 腹部 X 光片 | 腸道氣體分布、鈣化性胎糞（尿逆流進入直腸所致） |
| 腹部超聲波 | 水腎（常見，多因hydrocolpos 壓迫膀胱出口）、腎臟評估 |
| 內視鏡檢查 | 最佳診斷工具，準確定義解剖結構 |

### 內視鏡檢查的關鍵發現

| 發現 | 臨床意義 |
|------|----------|
| 尿道多處微小開口 | 陰道未在 genitography 顯示時的特徵 |
| 輸尿管導管插入熒光透視 | 確認陰道位置與大小 |
| 嚴重雄性化 CAH 案例 | 可見男性樣外括約肌，陰道在近端進入類似精阜結構 |

> **臨床重點**
> - **內視鏡檢查**是手術重建前最關鍵的診斷工具，準確度優於 genitography
> - Genitography 對複雜泄殖腔異常的解剖定義準確率僅約 72%，且不影響手術決策

## 泄殖腔畸形（Cloacal Anomaly）

### 定義

泄殖腔畸形為直腸與泌尿生殖道共用一個**單一會陰孔（single perineal orifice）**的先天畸形。外生殖器表現從接近正常女性外觀到完全性別置換或所謂「娃娃樣（doll-like）」會陰皆有可能。

### 術前評估

泄殖腔畸形的術前評估需確認：
- **腎臟**：水腎評估（Hendren 報導 23 例中 14 例有腎臟異常，含 6 例孤立腎）
- **陰道**：60% 有某種程度的陰道與、子宮分隔（septation）
- **心臟**：13% 有心血管異常
- **脊椎**：骶骨異常常見
- **其他**：氣管食道瘻管（5%）、**VACTERL 關聯（Vertebral, Anal, Cardiac, Tracheoesophageal, Renal, Limb）**

### VACTERL 關聯

| VACTERL 組成 | 說明 |
|--------------|------|
| V – Vertebral | 脊椎異常 |
| A – Anal | 肛門閉鎖 |
| C – Cardiac | 心臟異常 |
| T – TEF | 氣管食道瘻/食道閉鎖 |
| R – Renal | 腎發育不全/發育不良 |
| L – Limb | 肢體缺陷 |

> **臨床重點**
> - 所有泄殖腔畸形新生兒均需接受**心臟超聲波**與**腎臟超聲波**篩檢
> - 泄殖腔畸形之高達 14/23 合併腎臟異常，術前必須排除

## 外科重建原則與倫理

### 手術時機之倫理爭議

DSD 手術的時機長期以來是醫學倫理的核心議題：

- 反對早期手術者認為：嬰兒無法給予知情同意，手術決策應留待患者成年後自行決定
- 支持早期手術者認為：早期重建可改善外觀、減少心理創傷，且現行技術可達到優異的美容效果

> **臨床重點**
> - **資訊不應對家屬或患者隱瞞**——保密（secrecy）在 DSD 照護中沒有立足之地
> - 應向家屬提供手術與觀察兩種選項的完整優缺點，且心理與同儕支持應同等提供給兩種選擇的家庭
> - 以 CAH 為例，研究顯示無論是否接受手術，CAH 女性患者對自身生殖器的滿意度均低於對照組

### 女性化陰道整形術（Feminizing Genitoplasty）

**陰道整形術（vaginoplasty）**、**陰蒂縮小術（clitoroplasty）**與**陰唇融合修復術（labioplasty）**可達到優異的美容效果。但需注意：

- 腦是主宰性取向的最主要器官
- 早期手術的長期結局需等患者成年後才能確認
- 手術不能「治癒」DSD
- 接受手術與未接受手術的 CAH 女性對其生殖器滿意度相仿

### 睪丸/卵巢活檢

如評估後仍無法確認診斷，可考慮性腺活檢（deep incision 取材，因 ovotestes 之卵巢組織可能完全包圍睪丸組織或分布於兩極）。此檢查應**僅在活檢結果會影響撫養性別決定時**才進行。
