## 📖 導讀

後尿道瓣膜（Posterior Urethral Valves, PUV）為男嬰最常見之嚴重下泌尿道阻塞病變，可導致**腎功能衰竭**、**膀胱功能障礙**乃至**肺部發育不全**。儘管cystoscopic 瓣膜切除術本身技術相對簡單，但胎兒期阻塞所造成之**膀胱功能障礙**、**腎發育不全**與**多尿**等後遺症，往往需終生追蹤與多專科整合照護。本章節從流行病學、病理生理學（含 Valve Bladder Syndrome）到產前後診斷與新生兒處理，進行全面系統整理。

---

## 分類與流行病學

### Young 分類（傳統分類）

| 類型 | 特徵 |
|---|---|
| **Type 1**（最常見）| 瓣膜葉自**精阜**（verumontanum）長出，向前融合於外尿道括約肌近端，為前後向之薄膜狀構造 |
| **Type 2** | 黏膜皺褶自精阜向膀胱頸延伸，現今多認為不具阻塞性 |
| **Type 3** | 先天性阻塞性膜，**通常於初次導尿時已自行穿孔** |

> **臨床重點**
> Type 1 瓣膜為最常見之類型，其病生理意義為造成**後尿道擴張**、**膀胱出口阻力增加**與**雙側輸尿管逆流/水腎**。Type 3 瓣膜可能於導尿後造成穿孔，使術中 cystoscopic 確認困難，需結合臨床與影像學綜合判斷。

### 發生率

| 統計指標 | 數值 |
|---|---|
| 總發生率 | 約 1.6–2.1/10,000 出生 |
| 每年的新病例數（美國）| 約 300–500 名 |
| 長期進展至終末期腎病之比例 | 約 1/3 |

## 病理生理學

### Valve Bladder Syndrome（Mitchell 1982）

後尿道瓣膜造成之膀胱出口阻塞，引發一系列連鎖性膀胱與上泌尿道病理變化。

#### 病程分期

| 階段 | 病理變化 | 臨床特徵 |
|---|---|---|
| **代償期** | 膀胱出口阻力增加 → 逼尿肌肥厚 | 排尿壓力高、膀胱壁增厚、排空良好 |
| **去代償期** | 多尿（腎發育不全相關）+ 逼尿肌疲乏 → 殘尿增加 | 排尿後餘尿上升、hydronephrosis 惡化 |

#### 惡性循環（Vicious Cycle）

```
阻塞 → 逼尿肌肥厚 → 高排尿壓
   ↑                      ↓
殘尿增加 ← 排空不良 ← 逼尿肌功能惡化
   ↓                      ↓
水腎惡化 ← 逆流增加 ← 膀胱高壓傳導至上泌尿道
```

### 腎發育不全之角色

傳統觀點認為腎功能損傷為阻塞之單純後果，但越來越多證據顯示**腎發育不全**可能與阻塞同步存在，而非僅為阻塞之結果。

| 機制 | 證據 |
|---|---|
| **ACEI/ATR 基因多形性** | PUV 患童之 ACE1 基因表現增加、ATR 基因表現減少，與其他發育不全及對照組有顯著差異 |
| **腎素-血管張力素系統** | 嚴重腎發育不全與 RAS 活性降低相關 |
| **TGF-β1、TNF-α** | 為腎纖維化與發炎之媒介因子，瓣膜切除術後可下降 |
| **ACEI 治療之潛力** | 動物實驗顯示可減少腎纖維化；臨床選擇性病例可考慮 |

> **臨床重點**
> **ACEI（血管緊張素轉換酶抑制劑）**在實驗模型中顯示可降低腎纖維化，並減少 TGF-β1 與 TNF-α 之表現，為 selected PUV 患童之輔助治療提供理論依據，但臨床應用仍需更多前瞻性研究支持。

## 產前診斷

### 超聲特徵

| 超聲發現 | 臨床意義 |
|---|---|
| 厚壁增大膀胱 | 高度敏感（~95%）|
| **Keyhole sign**（後尿道擴張）| 特異度 ~80% |
| 雙側水腎（hydroureter + pelvocaliectasis）| 提示雙側上泌尿受影響 |
| 腎臟回音增加 | 暗示腎實質損傷 |
| 羊水過少 | 胎兒尿液產量減少，預後不良指標 |

### 產前超聲之局限性

- 產前超聲區分 **PUV**、**尿道閉鎖**、**Prune-belly 症候群**與**高Grade VUR** 之準確率僅約 50%。
- 後尿道瓣膜之偽陽性率：文獻報告為 22–58%。

### 胎兒 MRI

胎兒 MRI 可提供高解剖解析度之軟組織對比，於以下方面有附加價值：
- 確認尿道擴張程度與膀胱大小
- 評估肺部發育不全程度
- 鑑別囊性腎病變與腎發育不全
- 部分研究顯示 MRI 可改變約 30% 之初步超聲診斷

## 產後診斷

### 排尿性膀胱尿道造影（VCUG）

VCUG 為確認後尿道瓣膜之**決定性放射學檢查**。

**典型影像學表現：**
- 膀胱頸升高（elevated bladder neck）
- 後尿道向心性擴張與漏斗化（funneling）
- 瓣膜處可見造影劑充盈之切跡（notching）

> **臨床重點**
> VCUG 應於腎臟與膀胱超聲完成後、新生兒生命徵象穩定時儘早執行。任何具有產前懷疑發現之男嬰，均應於**出院前**完成 VCUG，以避免延遲診斷導致不可逆腎功能惡化。

### 新生兒導尿之技術要點

後尿道瓣膜男嬰常因**膀胱頸肥厚升高**及**後尿道擴張**而使導尿困難。

| 技術建議 | 適應情況 |
|---|---|
| 使用 **coudé 導管** | 標準導管無法通過時 |
| 導管尖端 dorsal 彎曲（使用 stylet）| 後尿道路徑偏移時 |
| **避免氣囊過度充盈** | 以免造成進一步創傷 |

## 長期併發症

| 併發症 | 發生率/說明 |
|---|---|
| **終末期腎病**（ESRD）| 約 1/3 之 PUV 患童需長期透析或腎移植 |
| **膀胱功能障礙**（Valve bladder）| 逼尿肌活動過度與排空障礙之組合，長期影響生活品質 |
| **尿路感染**（UTI）| 與殘尿量直接相關 |
| **尿失禁** | 膀胱功能障礙之直接後果 |
| **膀胱輸尿管逆流**（VUR）| 通常為 valve-related reflux，患側腎臟功能多數不良 |

---

## 總結

後尿道瓣膜之臨床處理不能僅聚焦於瓣膜切除之微創技術，更需重視**胎兒期阻塞對膀胱與腎臟之永久性影響**。**Valve Bladder Syndrome** 描述了「阻塞-逼尿肌肥厚-殘尿增加-上泌尿高壓傳導-腎功能惡化」之惡性循環，成為理解 PUV 長期預後不佳之核心概念。早期診斷（產前及新生兒期）與適時外科介入，配合長期膀胱功能追蹤與必要時之 ACEI 輔助治療，是改善此類患童長期預後的多專科策略。
