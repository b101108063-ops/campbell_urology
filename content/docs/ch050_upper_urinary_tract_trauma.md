## 📖 導讀

腎臟創傷的處理從精確的分級與影像學評估開始。**美國創傷外科協會（AAST）器官損傷分級**是臨床決策與預後評估的基礎。Hemodynamically穩定的患者可採用非手術治療（NOM），但需嚴密監控；不穩定或符合絕對/相對適應症者則需及時手術探查。本章節涵蓋腎創傷分級、影像學適應症、各級治療原則及手術探查的技術要點。

---

## AAST 腎臟創傷分級（表50-1）

| 等級 | 損傷類型 | 臨床表現 |
|------|---------|---------|
| **I級** | 包膜下血腫（無擴大）、無實質撕裂 | 顯微或肉眼血尿，泌尿檢查正常 |
| **II級** | 無擴大之腎周血腫侷限於後腹膜；< 1 cm深之皮質實質裂傷，無尿液外滲 | |
| **III級** | > 1 cm皮質深度裂傷，未延伸至收集系統或尿液外滲 | |
| **IV級** | 實質裂傷延伸至皮質、髓質及收集系統；主腎动脉或靜脈損傷（出血受限） | |
| **V級** | 完全破碎腎臟；腎門撕脫導致去血管化 | |

> **臨床重點**
> - 雙側損傷：**提升一級**（最高至III級）
> - 分級的準確性依賴**對比增強CT**；臨床分級是預後的重要指標

## 腎臟影像學適應症

### 符合影像學檢查的標準

| 創傷類型 | 適應症 |
|---------|-------|
| **穿通傷** | 腹部、側腰或下胸入口/出口傷口，且血流動力學穩定可接受CT |
| **鈍傷** | 明顯加速/減速機轉（如高速車禍、 高處墜落）|
| **鈍傷** | 肉眼血尿 |
| **鈍傷** | 顯微血尿且低血壓（收縮壓 < 90 mmHg）|
| **兒童創傷** | 每高倍視野 > 5 RBCs |

> **臨床重點**
> - 所有穿透傷患者如有血流動力學穩定，CT較直接進入手術室更能完整評估
> - 超聲（FAST）在成人腎創傷患者特異性不足；主要用於立即腹部出血評估

## 影像學工具

### 對比增強電腦斷層（CECT）

| 項目 | 內容 |
|------|------|
| **首選檢查** | 腎創傷分級的金標準 |
| **時相** | 腎皮質期、腎實質期、排泄期（延遲顯影）|
| **腎血管損傷評估** | 腎动脉血栓：皮質邊緣徵象（皮質對比差）|

### 術中「單次」靜脈腎盂造影（One-shot IVP）

| 項目 | 內容 |
|------|------|
| **適應症** | 腹部探查中發現不明原因後腹膜血腫且先前無CT |
| **目的** | 確認對側功能性腎臟存在；評估患側尿液外滲 |
| **技術** | 單次注射 2 mL/kg 對比劑，10分鐘後拍片 |
| **判讀** | 正常 → 可避免探索患側；異常 → 需探索並重建 |

### 腎臟血管栓塞（Angiographic Embolization）

| 項目 | 內容 |
|------|------|
| **適應症** | 顯著腎出血可控制；創傷性假性動脈瘤或動靜脈瘻管 |
| **優點** | 非侵入性，避免不必要的手術及腎切除 |
| **初始失敗率** | 13%–88%；後續栓塞通常成功 |
| **注意事項** | 需專業團隊、立即可執行、且患者可於手術室/血管攝影室間轉移 |

> **臨床重點**
> - 栓塞失敗後再進行栓塞通常可成功；血栓溶解或支架置入仍有個案報告成功
> - 假性动脉瘤及動靜脈瘻管：栓塞治療成功率高

## 非手術治療（Nonoperative Management, NOM）

| 條件 | 內容 |
|------|------|
| **標準** | 血流動力學穩定且完整分期的 I–III 級腎創傷（不論致傷機轉）|
| **顯著腎創傷（II–V級）** | 僅占腎創傷總數的 5% |
| **支架/引流** | 输尿管支架或經皮腎造口引流可促進腎創傷癒合 |

### 需要引流/支架的情況

| 適應症 | 處置 |
|--------|------|
| 骨盆骨折導尿管裂傷、嚴重生殖器創傷無法經尿道置入輸尿管支架 | 經皮腎造口引流＋考虑順行性輸尿管支架 |
| 持久性腎周液體積聚（血腫、尿囊或膿場）| 經皮引流管放置 |

### 尿囊（Hurinoma）與血腫的影像學鑑別

| 類型 | CT密度（Hounsfield Units）| 對比增強 |
|------|--------------------------|---------|
| **尿囊** | 0–20 HU | 延遲顯影（靜脈注射對比劑後5-20分鐘）可見對比劑依賴性聚集 |
| **血腫** | > 30 HU | 無增強 |
| **膿場** | > 20 HU | 邊緣增強（rim enhancement）|

## 手術探查適應症

### 絕對適應症

| 適應症 | 說明 |
|--------|------|
| 血流動力學不穩定/休克 | 復甦無反應 |
| 擴大/搏動性腎血腫 | 通常表示腎动脉裂傷 |
| 疑似腎血管蒂撕脫（V級）| 腎門完全去血管化 |
| 腎盂輸尿管連接處（UPJ）中斷 | 完全性尿液阻斷 |

### 相對適應症

| 適應症 | 說明 |
|--------|------|
| 尿液外滲伴顯著腎實質去血管化 | 舊資料建議較高併發症率，但新資料顯示保守治療結果良好 |
| 腎創傷合併結腸/胰臟損傷 | 建議同期修復腎創傷以降低併發症 |
| 延遲診斷之动脉損傷 | 可能需延遲腎切除 |

> **臨床重點**
> - 尿囊 alone（單獨來自IV級皮質裂傷或盞部破裂）超過90%可自行緩解，非手術治療首選
> - 腎創傷合併尿囊/尿漏，若非存活組織超過25%，併發症風險大增，需考虑手術

## 手術技術

### 腹部（經腹膜）途徑

**步驟：**

1. **腎血管控制優先**：在切開Gerota筋膜前，先隔離並放置血管阻斷帶（vessel loops）在腎靜脈（先）及腎动脉上
2. 將小腸移出術野，顯露中後腹膜
3. 後腹膜切開：沿主動脈，腸系膜下动脉上方至Treitz韌帶
4. 顯露左腎靜脈（横跨主動脈前方），以 Deaver 牽開器向上牽開
5. 左右腎动脉位於靜脈下方，置於血管阻斷帶上
6. 打開Gerota筋膜，評估損傷程度並進行重建

> **臨床重點**
> - **經腹膜途徑** 可完整檢查所有腹部臟器，發現合併傷（穿透傷中可達94%）
> - **先控制腎血管** 是避免打開血腫時大量出血的關鍵
