## 📖 導讀

膀胱結石是下泌尿道結石的主要類型，與上泌尿道結石（如腎結石）在成因及處理上有所不同。本章節系統性探討膀胱結石的流行病學、風險因子（特別是**體內異物**及**神經性膀胱**）、診斷方法及多元化的治療選擇，包括化學溶解術、體外震波碎石術、微創手術取石等。臨床上，膀胱結石的治療不僅要移除結石本身，更需同時處理根本的尿路病理異常，以預防復發。了解不同族群（如脊髓損傷患者、器官移植受者）的特殊風險，對於制定個人化的預防及治療策略至關重要。

## 膀胱結石成因與風險因子

### 體內異物（Nidus Formation）

**體內異物**是膀胱結石形成最常見的原因，尤其在女性患者中更為普遍。異物提供結石附著的核心，使尿液中的礦物質易於沉積形成結石。

常見異物來源：

| 來源類型 | 範例 |
|----------|------|
| **醫源性** | 手術縫線（膀胱懸吊術、吊帶手術）、金屬夾、支架 |
| **避孕器** | 子宮內避孕器、骨盆底支持環 |
| **失禁手術材料** | 陰道懸吊術用網片、張力自由陰道 tape 手術 |
| **前列腺治療併發症** | 前列腺化學消融後的壞死組織、內支架 |
| **其他** | 陰道沖洗異物、糞便穿刺傷、骨折骨水泥 |

> **臨床重點**
> - 縫線 материал 可在術中未被發現，故術後膀胱鏡檢查不可或缺
> - 網片侵蝕進入膀胱是近年來失禁手術的已知併發症
> - 子宮內避孕器遷移至膀胱後可作為結石核心

### 攝護腺手術後結石

**根治性攝護腺切除術**後，**背側靜脈複合體**的絲線縫扎線（如絲線）侵蝕入膀胱可形成結石。此外，**近端尿道膀胱頸吻合處**的非吸收性外科夾若遷移至膀胱，亦可形成結石本。

### 長期導尿與膀胱引流

| 導尿類型 | 結石發生率 | 說明 |
|----------|-----------|------|
| 短期輸尿管支架 | 常見附著 | 長期留置風險增加 |
| 長期留置導尿管 | 0.07–2.2% | 慢性導尿患者 |
| 間歇性自行導尿 | 較低 | 相比長期導尿風險顯著降低 |

 Foley 氣球在膀胱內破裂後，殘留碎片常導致後續結石形成。

## 神經性膀胱與脊髓損傷

### 風險與流行病學

**神經性膀胱（neurogenic bladder）**患者因排尿功能障礙，膀胱結石風險顯著升高：

- 成人脊髓損傷後，結石發生**高峰期**在受傷後 **3 個月**
- **10 年內**約 **15–30%** 患者會形成至少一顆結石
- 一旦形成第一顆結石，後續結石形成的風險**增加四倍**

> **臨床重點**
> - 四肢癱瘓且完全性脊髓損傷患者因無法自行導尿，依賴長期導尿或照護者協助，風險較高
> - **間歇性自行導尿**者的年度結石風險僅 **0.2%**，顯著低於長期導尿者的 **4%**
> **清淨間歇性導尿是所有可行患者的首選膀胱管理方式**

### 導尿方式與結石預防

| 管理方式 | 年度結石風險 | 建議程度 |
|----------|-------------|----------|
| 清淨間歇性導尿 | 0.2% | 首選 |
| 長期留置導尿（經尿道） | 4% | 避免長期使用 |
| 長期留置導尿（恥骨上） | 相近 | 無顯著優勢 |
| 膀胱擴大術（未使用導管） | 5–8% | 兒童族群較低 |

## 移植患者族群

### 胰臟移植受者

膀胱結石是**胰臟移植**（膀胱引流型）的已知併發症，發生率 **0.5–10%**：

| 風險因子 | 說明 |
|----------|------|
| 非吸收性縫線或外科夾 | 結石核心 |
| 低血清 pH | 碳酸氫鹽流失 |
| 尿液滯留 | 糖尿病神經性膀胱病變 |
| 免疫抑制 | 菌尿症增加 |

### 腎臟移植受者

單獨腎移植後膀胱結石發生率約 **0–5%**，主要仍為縫線 материал 作為核心。

## 臨床表現

### 症狀

| 症狀 | 說明 |
|------|------|
| **終末血尿（terminal hematuria）** | 最常見的表現 |
| 排尿困難、頻尿、急尿 | 結石刺激膀胱黏膜 |
| 尿流減弱 | 大結石可能阻塞膀胱頸 |
| 失禁、下腹疼痛 | 活動加重（如走路） |
| 無症狀 | 大結石因活動受限較少引起症狀 |

> **臨床重點**
> - 大結石反而症狀可能較少，因為在膀胱內移動範圍受限
> - 典型症狀組合：終末血尿 + 排尿中斷 + 恥骨上疼痛

## 治療方式

### 非手術治療

#### 化學溶解術

| 結石類型 | 溶解劑 | 使用方式 |
|----------|--------|----------|
| **鳥糞石（struvite）/ 磷酸鈣結石** | Renacidin（枸橼酸氫鎂鉀） | 持續膀胱沖洗 |
| **尿酸結石** | 氫氧化鉀（口服）或鹼性溶液 | 口服或膀胱內灌注 |

**Renacidin** 需留置導尿管進行持續沖洗，或每日 intravesical 灌注 3–4 次，每次保留 30–45 分鐘。

> **臨床重點**
> - Renacidin 使用可能併發嚴重甚至致命的全身性感染
> - 必須確保導尿管通暢、患者無明顯感染徵兆
> - **腎功能不全患者禁用 Renacidin**

#### 其他藥物

- **醋酸羥胺酸（acetohydroxamic acid）**：減少長期導尿患者的導管附著
- **檸檬酸鉀（potassium citrate）**：尿酸結石的口服溶解治療

### 體外震波碎石術（ESWL）

| 優點 | 限制 |
|------|------|
| 非侵入性 | 對於大結石或硬結石效果有限 |
| 可門診執行 | 可能需要多次治療 |
| 恢復快速 | 有術後結石碎片滯留風險 |

### 內視鏡取石術

#### 經尿道膀胱鏡取石術

使用**膀胱鏡（cystoscope）**經尿道進入膀胱，以抓取器或碎石後沖洗取出：

| 適應症 | 說明 |
|--------|------|
| 小至中等結石 | 首選治療 |
| 無顯著膀胱出口阻塞 |  |

#### 經皮膀胱造口取石術（Percutaneous Cystolithotomy）

| 適應症 | 說明 |
|--------|------|
| 大結石（>4–5 公分） | 微創方式 |
| 小膀胱或尿道狹窄患者 | 避免尿道損傷 |
| 內視鏡取石失敗 | 補救選項 |

優於開放手術之處：住院時間短、導尿時間短、傷口美觀。

### 開放膀胱取石術（Open Cystolithotomy）

曾為治療金標準，但因微創技術進展而減少使用：

| 情況 | 考量 |
|------|------|
| 巨大結石（>8–10 公分） | 內視鏡難以處理 |
| 合併需要開放手術的膀胱病理 | 同期處理 |
| 內視鏡或微創方式失敗 | 最後手段 |

## 預防策略

| 族群 | 預防建議 |
|------|----------|
| 脊髓損傷患者 | 優先選擇清淨間歇性導尿 |
| 長期導尿患者 | 定期更換導尿管、維持個人衛生 |
| 移植患者 | 監測尿路感染、維持足夠水分攝取 |
| 復發性膀胱結石 | 完整尿路評估、代謝評估、處理根本病因 |

**關鍵原則**：治療結石時，必須同步處理根本的尿路病理異常，以降低復發風險。
