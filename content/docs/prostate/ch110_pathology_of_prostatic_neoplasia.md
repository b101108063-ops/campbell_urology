## 📖 導讀

攝護腺癌的病理診斷與分級是制定治療策略的基石。**Gleason 分級系統**是攝護腺癌最重要的預後預測因子，透過**組織架構圖案（Architectural Pattern）**而非細胞型態進行分級，分數範圍為 2-10。本章節詳細說明 Gleason Pattern 1-5 的組織學特徵、切片報告的標準化內容（包括陽性子彈數、腫瘤長度、格里森分數），以及根治性切除標本的病理評估要點。此外，本章涵蓋**攝護腺上皮內腫瘤（PIN）**、**非典型切片**等臨床常見診斷困境的處理原則。

## Gleason 分級系統

### 分級原則

Gleason 分級系統是基於**腺體的組織架構圖案**，而非細胞型態。分級範圍為 **Pattern 1（分化最佳）**到 **Pattern 5（未分化）**。

| Pattern | 組織學特徵 |
|---------|-----------|
| **Pattern 1** | 邊界清楚的結節，由緊密排列之腺體組成（最良性樣） |
| **Pattern 2** | 結節內腺體排列較鬆散 |
| **Pattern 3** | 小腺體呈浸潤性生長，穿插於良性腺體之間 |
| **Pattern 4** | 大而不規則之篩狀（Cribriform）腺體或融合腺體 |
| **Pattern 5** | 腫瘤細胞實性巢狀生長，伴中心性壞死（Comedonecrosis） |

### 2005 年修訂要點

| 項目 | 內容 |
|------|------|
| **切片上 Gleason Score** | 最常見 Pattern + 最高級 Pattern（兩者相加） |
| **單一 Pattern 腫瘤** | 兩個 Pattern 給予相同分數 |
| **切片診斷不建議使用 Gleason 2-4** | 再現性差、專家複查常升級、預後相關性不佳 |

> **臨床重點**
> - **Gleason 分數是切片上最強大的預後預測因子**，可用於預測：病理分期、術後進展、近接治療候選資格、放疗預後、主動監測標準、凍結治療/HIFU/局灶治療候選資格等
> - 切片上僅少量癌症病灶時，仍應給予完整 Gleason 分數，因為此類少量癌症之分級準確度與大病灶相當

## 切片病理報告要點

### 標準報告內容

| 項目 | 臨床意義 |
|------|---------|
| **陽性核心數** | 腫瘤範圍評估 |
| **每條核心之腫瘤長度（mm）** | 腫瘤量測量 |
| **每條核心之腫瘤百分比** | 腫瘤比例評估 |
| **Gleason 分數** | 惡性度分級 |
| **神經周圍侵犯（Perineural Invasion）** | 預後因子（切片上之周邊神經侵犯與體外放療預後相關） |
| **淋巴血管侵犯（LVI）** | 預後不良因子 |

> **臨床重點**
> - 切片上**神經周圍侵犯**與**包膜外侵犯（EPE）**發生率較高相關，但對近接治療預後影響較小
> - 萎縮及發炎與攝護腺致癌可能相關，但一旦在切片上出現萎縮，**並不增加後續切片發現癌症或 PIN 的風險**
> - 建議病理學家報告**陽性子彈數 + 另一種腫瘤範圍測量**（如總腫瘤長度）

## 非典型切片與 ASAP

### 非典型切片處置

約 **5%** 的切片呈現**非典型（ATYPICAL）**發現。此類情况：

| 建議做法 | 說明 |
|---------|------|
| 報告術語 | 「**非典型腺體病灶（Focus of Atypical Glands）**」 |
| 避免術語 | 「非典型增生」、「非典型小腺體增生（ASAP）」 |
| 後續癌症發現率 | **40-50%** |
| PSA 升高程度與 DRE 發現 | 與後續癌症發現**不相關** |
| 建議處置 | **無論 PSA 為何，均應在 6 個月內再次切片** |

> **臨床重點**
> - 非典型切片是**最容易被專家複查改變診斷**的類型
> - 建議將此類切片送外部諮詢，尝试在患者接受再次切片前確認診斷
> - 切片中混入**儲精囊組織**（基部模擬 PIN）或 **Cowper 腺**（尖端模擬癌症）是常見診斷陷阱

## 經尿道切除標本的分期

### T1a vs T1b 分期標準

**經尿道切除術（TUR）**標本中，**5%** 是區分 T1a 與 T1b 的分界線：

| 分期 | 標準 |
|------|------|
| **T1a** | 腫瘤佔標本 **≤ 5%** |
| **T1b** | 腫瘤佔標本 **> 5%** |

- 處理 **6-8 塊蠟塊**可偵測大多數 T1b 腫瘤
- 處理 **8-10 塊蠟塊**可偵測 **> 90%** 的 T1a 病灶
- 對於年輕患者（< 65 歲）考慮積極治療時，可全部檢查 TUR 組織

## 根治性切除標本評估

### 包膜外侵犯（EPE）

**包膜外侵犯（Extraprostatic Extension, EPE）**的切片預測因子包括：
- 更高的 Gleason 分數
- 腫瘤範圍更大
- **神經周圍侵犯**（切片上發現時）

### 腫瘤體積

| 發現 | 臨床意義 |
|------|---------|
| **切片預測準確性** | 切片上的有利發現（低 Gleason、小腫瘤範圍）通常預測切除標本亦為有利 |
| **切片取樣誤差** | 有利切片發現**不必然**保證切除標本亦為有利 |

> **臨床重點**
> - 建議病理學家報告某種客觀腫瘤體積測量（ISUP 建議）
> - **腫瘤體積本身不是獨立預後因子**，不會影響後續治療決策
> - 最簡單快速的方法（如 overall percentage 估算）已足夠

## 治療後腫瘤變化

### 荷爾蒙治療效果

| 變化 | 說明 |
|------|------|
| **切片型態** | 腫瘤 grade 可能**人為升高**，病理學家不應對有治療效果的腫瘤給予 Gleason 分數 |
| **非治療區域** | 若腫瘤其他區域無明顯治療效果，可給予 Gleason 分數 |
| **Finasteride** | 研究顯示不改變 BPH 或癌症的組織學外觀 |

### 血管/淋巴侵犯

| 項目 | 數據 |
|------|------|
| **根治切除標本中血管侵犯發生率** | 約 **7%**（小於 4 cc 的腫瘤） |
| **臨床意義** | 與其他不良因子（EPE、分級、邊緣、腫瘤體積）相關，但**仍提供獨立預後資訊** |
| **神經周圍侵犯** | 根治切除標本中常見，**不具預後意義**，不應列入病理報告 |

## 免疫組織化學輔助診斷

### 常用標記

| 標記 | 應用 |
|------|------|
| **高分子量細胞角蛋白（High-molecular-weight Cytokeratin, 34βE12）** | 正常/良性腺體（含基底細胞）呈陽性；癌症陰性 |
| **p63** | 與 34βE12 相似，標記基底細胞 |
| **α-甲基醯基-CoA 消旋酶（AMACR, P504S）** | 優先標記攝護腺癌及 HGPIN（但有假陽/假陰性） |
| **ERG（核內免疫反應）** | 作為 **TMPRSS2:ERG 基因融合**之替代指標（約 50% 攝護腺癌有此融合） |

> **臨床重點**
> - AMACR 的主要限制：在切片上少量癌症病灶之敏感度可能僅 **30-40%**
> - AMACR 陽性並不能排除 HGPIN（可能為假陽性）
> - 免疫組織化學是**輔助工具**，不能取代扎實的形態學評估
