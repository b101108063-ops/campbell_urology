# Chapter 121 Treatment of Castration-Resistant Prostate Cancer

## 臨床考量要點

> **關鍵要點：**
> - **治療前**需評估疾病範圍與侵襲性
> - 關鍵決定因子：**是否有影像學轉移、為生化或臨床進展、有無症狀（如疼痛）**
> - mCRPC 的臨床表現在**轉移分布**與 **PSA 動力學（如 PSADT）** 兩方面均具有異質性
> - 在開始細胞毒性化療前，應先考虑**次級荷爾蒙治療**，尤其對非轉移性 CRPC 或無症狀患者

---

## 疾病評估與預後考量

### 疾病狀態分類（Scher 臨床狀態系統）

CRPC 可分為不同的臨床狀態，有助於治療決策：

| 臨床狀態 | 定義 |
|---------|------|
| **M0 CRPC**（非轉移性 CRPC） | PSA 上升且去勢睪固酮水平，但無影像學可見轉移 |
| **M1 CRPC**（轉移性 CRPC） | 骨、淋巴結或內臟轉移 |

> **重要：** TNM 分期系統在復發或晚期攝護腺癌的管理中幫助有限；臨床狀態分類更能反映治療實踐與疾病自然史。

### 初始評估的關鍵組成

| 評估項目 | 臨床意義 |
|---------|---------|
| **疾病範圍（Extent of disease）** | 決定治療強度 |
| **進展模式與部位** | PSA 單獨升高？新骨轉移？內臟/淋巴結轉移？ |
| **症狀的有無** | 骨痛等症狀預後較差 |
| **先前內分泌治療的反應** | 治療持續時間與 PSA 反應程度 |

---

## 抗雄激素撤藥效應

> **臨床現象：** 停用抗雄激素（非類固醇或類固醇製劑）後，約 **20-30%** 的患者可出現短期臨床反應，表現為 PSA 下降、症狀改善，偶有軟組織或骨轉移的客觀緩解。

**建議步驟：**
1. 在 LHRH agonist 基礎上加用抗雄激素而出現進展時
2. **第一步：** 停用抗雄激素，觀察 4-8 週
3. 監測 PSA 變化
4. 若 PSA 持續上升，再考慮下一步治療

---

## 細胞毒性化學治療

### 療效評估的挑戰

| 問題 | 說明 |
|------|------|
| **骨轉移測量困難** | 骨轉移為 **blastic lesions**，難以用傳統方法測量 |
| **軟組織/內臟轉移常見嗎？** | 僅少數患者有可測量的軟組織病灶 |
| **「有效率」作為主要終點的問題** | 僅有骨轉移患者的客觀緩解難以評估 |

> **共識建議：** 在 mCRPC 臨床試驗中，**無進展存活（PFS）** 比「客觀緩解率」更能反映治療效果；在可行時，**整體存活（OS）** 是首選終點。

### 化療前預後模型的重要因子

| 預後因子 | 方向 |
|---------|------|
| **體能狀態（Performance status）** | 越差，預後越差 |
| **疼痛** | 有疼痛，預後較差 |
| **鹼性磷酸酶（ALP）** | 升高，預後較差 |
| **血紅蛋白（Hemoglobin）** | 降低，預後較差 |
| **PSA 水平** | 越高，預後越差 |
| **LDH** | 升高，預後較差 |
| **骨轉移範圍** | 越多，預後越差 |
| **內臟轉移** | 有，預後較差 |

## 化學治療藥物

### Docetaxel（多西他賽）

| 項目 | 內容 |
|------|------|
| **劑量** | 75 mg/m² 每 3 週一次 |
| **聯合用藥** | 口服 prednisone 5 mg bid |
| **主要毒性** | 嗜中性球減少、疲勞、週邊神經病變、指甲病變、體液瀦留 |

> **里程碑研究（TAX 327）：** 多西他賽每三週方案與 mitoxantrone + prednisone 相比，**中位整體存活改善 2.4 個月**（18.9 個月 vs. 16.5 個月，p=0.009）。

### Cabazitaxel

| 項目 | 內容 |
|------|------|
| **適應症** | Docetaxel 治療後進展的 mCRPC |
| **劑量** | 25 mg/m² 每 3 週一次 |
| **主要毒性** | 嗜中性球減少、腹瀉、噁心、嘔吐 |

> **TROPIC 研究：** Cabazitaxel 相比 mitoxantrone，在 docetaxel 治療後進展的 mCRPC 患者中，**中位 OS 延長 2.4 個月**（15.1 個月 vs. 12.7 個月）。

## 循環腫瘤細胞（CTC）計數

### CTC 作為預後生物標誌

| CTC 狀態 | 定義 | 預後意義 |
|---------|------|---------|
| **Favorable** | CTC < 5/7.5 mL | 較佳預後 |
| **Unfavorable** | CTC ≥ 5/7.5 mL | 較差預後 |

> **研究證據：** 治療前 CTC ≥ 5/7.5 mL 且化療後 CTC 未降至 < 5 的患者，中位 OS 顯著較短（de Bono 等，2008）。

## 常見併發症的管理

### 脊髓壓迫（Spinal Cord Compression）

> **腫瘤急症：** 攝護腺癌常見椎體轉移，因此脊髓壓迫的發生率特別高。

**警示症狀：** 背部疼痛、感覺異常、腿部無力、腸道/膀胱功能障礙

**處理原則：**
- 立即影像學評估（MRI）
- 高劑量類固醇（如 dexamethasone）
- 手術減壓（如可行）或放射治療

### 阻塞性尿路病變（Obstructive Uropathy）

**原因：** 原發病變或骨盆/腹膜後淋巴結病變壓迫輸尿管

**處理：**
- 內視鏡輸尿管支架置入
- 或經皮腎造口術（PCN）

> **重要：** 若计划使用細胞毒性化療，應先緩解腎功能障礙，因為許多化療藥物依賴腎臟排泄清除。

### 貧血與血小板減少

| 問題 | 可能原因 | 處理 |
|------|---------|------|
| **貧血** | 骨盆腔放射、骨髓化療、化療、腫瘤骨髓浸潤 | Erythropoietin（注意：可能增加死亡率）|
| **血小板減少** | 廣泛放射治療、化療 | 血小板輸注 |
| **血小板增多** | 副腫瘤現象 | 通常不需要治療 |

## 新型 AR 標靶治療

### Abiraterone Acetate（阿比特龍）

| 項目 | 內容 |
|------|------|
| **機制** | **CYP17 抑制劑**，阻斷睪固酮與腎上腺雄激素的合成 |
| **適應症** | mCRPC（化療前與化療後） |
| **用法** | 口服 1000 mg/day + prednisone 5 mg bid |
| **主要毒性** | 高血壓、低血鉀、水腫、肝功能異常 |

> **COU-AA-301 研究（化療後）：** Abiraterone + prednisone 相比安慰劑，**中位 OS 延長 4.6 個月**（15.8 個月 vs. 11.2 個月）。

### Enzalutamide（恩雜魯胺）

| 項目 | 內容 |
|------|------|
| **機制** | **雄激素受體（AR）抑制劑**，阻斷雄激素與 AR 的結合及 AR 核內轉位 |
| **適應症** | mCRPC（化療前與化療後） |
| **主要毒性** | 疲勞、癲癇（需注意）、熱潮紅 |

> **AFFIRM 研究：** Enzalutamide 相比安慰劑，中位 OS 延長 **4.8 個月**（18.4 個月 vs. 13.6 個月）。

---

## Ra-223（鐳-223）治療

| 項目 | 內容 |
|------|------|
| **機制** | **α 粒子發射體**，選擇性骨轉移灶內釋放高能輻射 |
| **適應症** | 有症狀性骨轉移且無已知內臟轉移的 mCRPC |
| **用法** | 靜脈注射，每 4 週一次，共 6 次 |
| **主要毒性** | 骨髓抑制（血小板減少、貧血） |

> **ALSYMPCA 研究：** Ra-223 相比安慰劑，**中位 OS 延長 3.6 個月**，並顯著延遲首次骨骼相關事件（SRE）時間。

---

## 治療順序與整合

### 典型治療路徑（mCRPC）

```
化學化生（如有必要）
    ↓
Abiraterone 或 Enzalutamide（化療前）
    ↓
Docetaxel + Prednisone（一線化療）
    ↓
Cabazitaxel（二線化療）
    ↓
Ra-223（若符合條件）
    ↓
臨床試驗 / 緩和治療
```

> **重要原則：** 所有患者應持續維持**睪固酮抑制（去勢水平）**，即使在後續化療期間也不應中斷 LHRH agonist 或手術去勢。

---

## 骨健康製劑（Denosumab 與 Zoledronic Acid）

| 藥物 | 機制 | 劑量 | 說明 |
|------|------|------|------|
| **Denosumab** | RANKL 抑制劑 | 120 mg 皮下注射，每 4 週 | 預防骨骼相關事件（SRE） |
| **Zoledronic Acid** | 雙磷酸鹽 | 4 mg 靜脈注射，每 3-4 週 | 預防 SRE |

> **注意：** 使用 denosumab 或 zoledronic acid 的患者，應在治療前和治療期間監測**血鈣水平**及**腎功能**。
