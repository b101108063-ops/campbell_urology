## 📖 導讀

後腹腔腫瘤（Retroperitoneal Tumors, RPTs）是指發生於後腹腔間質組織的良惡性腫瘤，病理類型多樣，其中**脂肪肉瘤（liposarcoma）**及**平滑肌肉瘤（leiomyosarcoma）**最為常見。由於後腹腔位置深在、症狀隱匿，許多患者確診時腫瘤已相當巨大。本章節重點說明後腹腔肉瘤的手術切除原則，包括**安全邊界（surgical margin）**的重要性，以及**術前切片（pretreatment biopsy）**在治療決策中的關鍵角色。值得注意的是，與上皮性腫瘤不同，後腹腔肉瘤的局部復發是主要死因，而非遠處轉移，因此的手術質量直接決定患者預後。

## 後腹腔間質細胞腫瘤分類

### 脂肪細胞腫瘤

| 腫瘤類型 | 惡性程度 | 特點 |
|----------|----------|------|
| **血管脂肪瘤（angiomyolipoma）** | 良性 | 由血管、平滑肌、脂肪組成 |
| **高分化脂肪肉瘤（well-differentiated liposarcoma）** | 低度惡性 | 局部復發為主，轉移少見 |
| **去分化脂肪肉瘤（de-differentiated liposarcoma）** | 高度惡性 | 可含其他間質細胞成分 |
| **圓形細胞脂肪肉瘤（round cell liposarcoma）** | 高度惡性 | 小圓細胞緊密排列，胞內脂肪稀少 |
| **多形性脂肪肉瘤（pleomorphic liposarcoma）** | 高度惡性 | 細胞多形性，含脂母細胞 |

### 脂肪肉瘤的分子特徵

- **myxoid 脂肪肉瘤**：染色體 12 與 16 的平衡易位 **t(12:16)(q13:p11)**，見於 90% 病例
- **高分化脂肪肉瘤**：典型 ring chromosome 12（亦可見於良性脂肪瘤）

> **臨床重點**
> - 影像學區分脂肪瘤與高分化脂肪肉瘤的準確率僅約 70%，需參考結節性、條索狀結構及腫瘤邊界
> - S-100 免疫染色可用於確診脂肪母細胞的存在
> - 高分化脂肪肉瘤長期預後主要受局部復發及所需大手術的併發症影響

### 其他間質細胞腫瘤

| 腫瘤類型 | 惡性程度 | 特點 |
|----------|----------|------|
| **平滑肌瘤（leiomyoma）** | 良性 | 梭形細胞，豐富嗜酸性細胞質 |
| **上皮樣平滑肌肉瘤（epithelioid leiomyosarcoma）** | 惡性 | 上皮樣細胞形態 |
| **惡性纖維組織細胞瘤（malignant fibrous histiocytoma, MFH）** | 惡性 | 現已知為纖維母細胞腫瘤，多形性顯著 |
| **孤立性纖維瘤（solitary fibrous tumor）** | 潛在惡性 | CD34 陽性 |
| **硬纖維瘤（aggressive fibromatosis）** | 中間型 | 非轉移但局部侵襲性生長 |

### 惡性纖維組織細胞瘤（MFH）

| MFH 亞型 | 預後 |
|----------|------|
| myxoid 亞型 | 較佳 |
| 其他亞型（storiform、giant cell、xanthomatous） | 侵襲性高，易轉移 |

MFH 與血液淋巴增生性疾病（包括白血病、何杰金氏及非何杰金淋巴瘤）之間存在關聯，機制不明。

## 病理學診斷要點

### 診斷困難之處

| 挑戰 | 說明 |
|------|------|
| 良性 vs. 惡性 | 即使嚴格顯微鏡檢查，區分高分化脂肪肉瘤與脂肪瘤仍有難度 |
| 形態學重疊 | 各亞型間可能有重疊特徵 |
| 取樣偏差 | 核心切片可能無法代表整體腫瘤 |

### 免疫組織化學

| 標記 | 腫瘤類型 |
|------|----------|
| **S-100** | 脂肪細胞腫瘤（脂肪瘤及脂肪肉瘤均陽性） |
| **Desmin, SMA** | 平滑肌腫瘤 |
| **CD34** | 孤立性纖維瘤 |
| **c-KIT** | GIST（胃腸道間質瘤） |

## 臨床表現與診斷

### 症狀

| 表現類型 | 說明 |
|----------|------|
| **無症狀腹部腫塊** | 許多患者的主要表現 |
| 腹部不適、腹脹 | 腫瘤壓迫鄰近器官 |
| 腰痛、側腹疼痛 | 常見主訴 |
| 血尿 | 腫瘤侵犯泌尿系統 |
| 噁心、嘔吐 | 胃腸道受壓 |
| 下肢水腫、IVC 症候群 | 大靜脈受侵犯 |

### 影像學評估

| 檢查方式 | 角色 |
|----------|------|
| **腹部超聲** | 初步篩檢，評估腫塊性質 |
| **CT** | 主要診斷工具，局部分期 |
| **MRI** | 軟組織分辨率佳，評估血管侵犯 |
| **胸部 CT** | 遠處轉移常規評估 |

> **臨床重點**
> 非實性病變（如囊腫、动脉瘤、膿腰大肌膿腫）可依據病史及影像特徵排除
> 影像檢查應評估：腫瘤大小、邊界、與鄰近器官關係、血管侵犯、淋巴結及遠處轉移

## 術前切片原則

### 切片適應症

| 情況 | 切片必要性 |
|------|------------|
| **疑似淋巴瘤** | 必要；淋巴瘤以化學治療為主，手術非首選 |
| 已知原發腫瘤的轉移 | 必要；可避免不必要的手術 |
| 影像學評估為無法切除 | 必要；切片可導引系統治療 |
| 疑似肉瘤且已有轉移 | 必要；切片可導引新輔助化學治療 |
| 可切除的肉瘤 | 建議；可確立診斷及分級 |

> **臨床重點**
> - 若影像學明確為**後腹腔脂肪肉瘤**且預期可切除，術前切片**非必要**
> - 切片應由經驗豐富的病理學家判讀，免疫組織化學染色通常必要
> - 冷凍切片對此類腫瘤的診斷**不可靠**，不應作為術中決策依據

### 切片技術

| 技術 | 優勢 | 劣勢 |
|------|------|------|
| **CT/超聲/ MRI 導引核心切片（14-16G）** | 首選；微創，避免種植 | 少量組織 |
| 開放切片 | 組織量大 | 創傷較大，可能污染手術 field |
| 細針抽吸（FNA） | 簡單 | 組織量不足，常無診斷性 |

**切片路徑選擇**：應選擇**後腹腔（retroperitoneal）**而非經腹腔的路徑，以避免理論上的腹膜種植風險。

## 肉瘤手術原則

### 手術核心理念

| 原則 | 說明 |
|------|------|
| **根治性切除** | 唯一可能根治的方式 |
| **en bloc 切除** | 懷疑侵犯的器官應與腫瘤一併整塊切除 |
| **陰性切緣** |顯微鏡下無腫瘤殘留是局部控制關鍵 |
| **多專科團隊** | 需要外科、腫瘤內科、放射科、病理科合作 |

> **臨床重點**
> - 與上皮性腫瘤不同，後腹腔肉瘤通常直接接觸而非侵犯鄰近結構，手術切除這些結構是必要的
> - **局部復發是低至中度惡性肉瘤的主要死因**，占所有肉瘤死因的首位
> 早期研究報告局部復發率約 50%（5 年無復發存活），近期報吿可達 **75–80%**，進步來自更積極的手術策略

### 器官切除策略

| 器官 | 切除原則 |
|------|----------|
| **腎臟** | 若腫瘤直接接觸，應一併切除（根治性腎切除） |
| **結腸** | 受侵犯段切除，端端吻合 |
| **胰臟尾部** | 可能需要胰體尾切除 |
| **脾臟** | 左側腫瘤可能需要脾切除 |
| **下腔靜脈（IVC）** | 若無法遊離，可能需要 IVC 切除及重建或置換 |

### 平衡切除範圍與發病率

| 考量 | 說明 |
|------|------|
| 切除積極性 | 確保陰性邊緣但避免不必要的重要器官切除 |
| 生命品質 | 大手術可能導致長期併發症 |
| 術前評估 | 多專科會議討論每例患者 |
