## 📖 導讀

上泌尿道泌尿上皮腫瘤（UTUC）泛指腎盞、腎盂及輸尿管來源的泌尿上皮癌，其生物行為與膀胱癌相似但更具侵襲性。本章節探討UTUC的復發模式、腎盞-腎盂與輸尿管腫瘤的差異、以及膀胱癌治療後上泌尿道復發的時序關係與風險因子。了解這些臨床模式對制訂合理的腫瘤監測策略至關重要。

---

## 上泌尿道泌尿上皮癌（UTUC）概述

### 疾病特性

| 項目 | 內容 |
|------|------|
| **主要組織型態** | 泌尿上皮癌（Transitional cell carcinoma）|
| **次要型態** | 鱗狀細胞癌、腺癌（少見）|
| **初診轉移率** | 高達 19% |
| **與膀胱癌比較** | 侵襲性更高、更多低分化腫瘤 |

> **臨床重點**
> - 儘管UTUC常被報導為較差預後，但與病理分級匹配的膀胱癌相比，癌症特定存活率相近
> - 膀胱癌與UTUC在根治性膀胱切除術或腎輸尿管切除術後，直接比對發現：T1/T4期時腫瘤位置影響存活

## 腎盞/腎盂 vs. 輸尿管腫瘤

### 解剖分布

| 位置 | 發生率 |
|------|--------|
| 遠端輸尿管 | ~70% |
| 中段輸尿管 | ~25% |
| 近端輸尿管 | ~5% |

此分布可能與**下游種植（downstream implantation）**現象有關。

### 預後影響因子

| 因子 | 對預後的影響 |
|------|------------|
| **腫瘤分期（T stage）** | 最重要的預後因子 |
| **腫瘤分级** | 重要 |
| **淋巴血管侵犯（LVI）** | 增加復發風險 |
| **淋巴結轉移** | 顯著降低存活 |
| **腫瘤位置（腎盂 vs. 輸尿管）** | 爭議性；但多數研究顯示分期分級>LVI>位置 |

### 5年存活率

| 分期 | 5年存活率 |
|------|----------|
| Ta / Tis | 100% |
| T1 | 91.7% |
| T2 | 72.6% |
| T3 | 40.5% |

> **臨床重點**
> - 腫瘤**位置**（腎盂 vs. 輸尿管）對癌症特定死亡的影響目前無共識
> - 建議在行腎輸尿管切除術時**完整切除整段輸尿管**，以避免輸尿管殘端腫瘤復發
> - 雙側病變（同步或異步）發生率約 1.6%–6.0%

## 泌尿上皮癌的時序關係

### 膀胱癌術後上泌尿道復發

| 研究數據 | 數值 |
|---------|------|
| UTUC發生率（傳統報導）| 2%–4% |
| UTUC發生率（高選擇族群）| 可達 25% |
| 復發間隔時間 | 17–170 個月 |

**增加術後上泌尿道復發風險的因子（Meta-analysis，27研究，13,185人）：**

| 風險因子 | 風險比（HR）|
|---------|------------|
| 原位癌（CIS）| 高 |
| 低惡性度腫瘤 | 高 |
| 多發性復發 | 高 |
| 多病灶腫瘤 | 高 |
| 既往UTUC病史 | 高 |
| 陽性輸尿管切緣 | 高 |
| T1 vs. Ta | 1.16 |
| 高惡性度膀胱癌 | 2.16 |
| 三角區或輸尿管口附近膀胱癌 | 1.76 |

> **臨床重點**
> - **CIS患者**接受膀胱切除術後上泌尿道復發率更高（21%–30%）
> - 高風險膀胱癌（T1或CIS）患者建議**每年至少一次上泌尿道影像學追蹤**
> - 復發多以**血尿**為表現，常發現時已屬晚期

### 上泌尿道復發的時序特徵

| 項目 | 內容 |
|------|------|
| 延遲復發 | 輸尿管比腎盂更常見（40 vs. 67 個月）|
| BCG治療後（CIS）| 約30%發生UTUC，多在遠端輸尿管（遠端、膀胱交界及壁內段）|

## 上泌尿道解剖學基礎

### 正常上泌尿道結構

| 結構 | 組織學特點 |
|------|-----------|
| **腎盞/腎盂** | 纖維結締組織＋兩層平滑肌；內襯轉化上皮（泌尿上皮）|
| **輸尿管** | 兩層連續平滑肌（內層疏螺旋、外層密螺旋）；遠端1/3增加第三層（外縱層）|

- 輸尿管肌肉層與膀胱三層肌肉（內縱、中環、外斜）相延續
- 肌肉層外為漿膜層（疏鬆結締組織）
- 上皮層從腎盞至遠端輸尿管**連續不間斷**

> **臨床重點**
> - 上泌尿道上皮與膀胱泌尿上皮雖然胚胎來源不同（前者為中胚層，後者為內胚層），但組織學上極為相似
> - 理論上泌尿上皮層可延伸至收集管，因此**收集管腎細胞癌**可能與泌尿上皮癌有發生學關聯

---

## 膀胱癌術後上泌尿道監測的臨床建議

| 患者類型 | 建議追蹤策略 |
|---------|-------------|
| 單純Ta/T1（非侵襲性乳頭狀癌）| 每1-2年上泌尿道影像學或細胞學檢查 |
| T1疾病 | 縮短追蹤間隔 |
| 高惡性度或CIS | 每年至少一次上泌尿道影像學 |
| 膀胱癌術後出現血尿 | 立即上泌尿道評估 |
| 有輸尿管口附近腫瘤或輸尿管逆流 | 提高警覺 |

## 重點摘要

| 主题 | 關鍵內容 |
|------|---------|
| **UTUC特性** | 侵襲性高、初診轉移率達19%；70%位於遠端輸尿管 |
| **預後因子** | 分期 > 分級 > LVI > 淋巴結轉移；位置影響仍有爭議 |
| **復發風險** | CIS、多發復發、陽性切緣、高惡性度皆增加上泌尿道復發 |
| **追蹤建議** | 高風險膀胱癌每年至少一次上泌尿道影像學 |
| **延遲復發** | 輸尿管復發較腎盂更早（40 vs. 67 個月）|
