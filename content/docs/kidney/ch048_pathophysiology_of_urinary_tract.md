## 📖 導讀

泌尿道阻塞是泌尿科常見的臨床問題，可由結石、腫瘤、發炎狹窄或外部壓迫等多種原因引起。由於臨床表徵變異性大，及時且精確的診斷高度依賴適當的影像學檢查。本章節系統回顧目前可用的影像學工具，包括腎臟超聲（含都卜勒）、核醫利尿劑腎圖、非對比CT、靜脈腎盂造影（IVP）及磁共振泌尿系造影（MRU），說明各項檢查的原理、診斷準確率及臨床限制。

---

## 腎臟超聲檢查（Renal Ultrasonography）

### 優勢與限制

| 優勢 | 限制 |
|------|------|
| 廣泛可及、費用低、無游離輻射 | 水腎為**解剖學發現**非功能診斷 |
| 無需靜脈注射對比劑（腎功能不佳或對比劑過敏者可安全執行） | 水腎可存在於無阻塞時（如膀胱輸尿管逆流） |
| 可偵測不透光結石 | 急性阻塞早期可能無明顯水腎；50%急性腎絞痛患者標準超聲可能正常 |
| 可評估腎臟大小、皮質厚度、腎竇脂肪 | 區分阻塞性與非阻塞性水腎困難，尤其當阻塞因素未被直接顯影 |

### 都卜勒超聲與阻力指數（Resistive Index, RI）

**阻力指數（RI）公式：**

```
RI =（收縮期最大流速 − 舒張末期流速）/ 收縮期最大流速
```

- 正常人 RI 上限約為 **0.70**
- 阻塞後，短期**前列腺素介導的血管擴張**隨即引發腎血流量減少及腎血管阻力增加

| 族群 | RI 正常值上限 |
|------|-------------|
| 成人 | 0.70 |
| 嬰兒（< 1歲） | 常超過0.70 |
| 兒童（< 4歲） | 可持續偏高 |
| 老年人 | 可超過0.70而無腎功能受損 |

**診斷準確率：**
- 單側 RI ≥ 0.70：敏感性 92%、特異性 88%
- 兩腎 RI 差值（δ RI）> 0.1：可提高診斷準確率

> **臨床重點**
> - RI 在輕度或部分阻塞患者常為正常
> - 顯影劑可誘發血管收縮並增加 RI；NSAID 可顯著降低急性阻塞腎臟的 RI，均可能干擾診斷

### 彩色都卜勒：輸尿管噴射（Ureteral Jets）分析

| 參數 | 阻塞側表現 |
|------|-----------|
| 噴射頻率 | 顯著降低（差異 > 1.5 jets/min）|
| 噴射持續時間 | 縮短（差異 > 2.5 秒）|
| 噴射最大速度 | 降低（差異 > 19.5 cm/sec）|

- **相對噴射頻率（RJF）**= 患側噴射頻率 / 兩側總和（5分鐘內）
- RJF < 25%：**敏感性 87%、特異性 96%** 可偵測兒童阻塞

> **臨床重點**
> - 噴射分析需要患者良好水化且需與正常對側比較
> - 超聲對結石的整體敏感性僅 45%、特異性 94%；無法取代CT

## 非對比電腦斷層（Noncontrast CT）

| 項目 | 內容 |
|------|------|
| **黃金標準** | 目前偵測腎結石的金標準 |
| **結石偵測敏感性** | > 95% |
| **限制** | 遊離輻射曝露；對功能性引流資訊有限 |
| **低劑量CT** | 適用於 follow-up；小於3 mm結石、輸尿管膀胱交界處阻塞及肥胖患者診斷準確率可能下降 |

## 核醫檢查：利尿劑腎圖（Diuretic Renography）

核醫檢查是**唯一**能提供動態腎功能資訊的影像學工具。

### 常用放射性藥物

| 藥物 | 特性 |
|------|------|
| **⁹⁹ᵐTc-MAG3** | 首選藥物；高腎臟萃取率（90%）、血漿蛋白結合率高；適用於腎功能受損患者 |
| **⁹⁹ᵐTc-DTPA** | 由腎絲球過濾；可用於測量GFR |

### 利尿劑腎圖的判讀

**F+20（furosemide challenge）：**
- 給予利尿劑後20分鐘時，若積存活性減少 < 50%：提示**阻塞**
- 主要評估**半排出時間（T₁/₂）**

| 結果 | 判讀 |
|------|------|
| T₁/₂ < 10分鐘 | 無顯著阻塞 |
| T₁/₂ 10–20分鐘 | 不確定，需結合臨床 |
| T₁/₂ > 20分鐘 | 很可能阻塞 |

> **臨床重點**
> - 利尿劑腎圖可區分阻塞性與非阻塞性腎積水（尤其在腎功能尚存時）
> - 對於嚴重腎功能受損患者，因腎臟萃取率下降，判讀需謹慎

## 磁共振泌尿系造影（MRU）

### 優勢與劣勢

| 優勢 | 劣勢 |
|------|------|
| 無游離輻射 | 費用高、可及性低 |
| 結合優異解剖資訊與功能性數據 | 腎結石顯現不佳（訊號缺失）|
| 對比排泄時間可評估功能 | 嚴重腎功能受損者有**腎源性全身纖維化（NSF）**風險 |
| 可顯現非功能性腎臟結構 | |
| 對比腎盞-輸尿管通過時間正常 ≤ 4 分鐘；阻塞 ≥ 8 分鐘 | |

### 腎源性全身纖維化（NSF）風險

- 與含 gadolinium 對比劑相關，2006年確認
- 主要發生於**嚴重腎功能受損（GFR < 30 mL/min/1.73 m²）**患者
- 風險族群發生率約 **3%**
- 目前建議嚴重腎功能受損者限制使用 gadolinium

> **臨床重點**
> - MRU 敏感性接近 **100%** 診斷上泌尿道阻塞
> - 在傳統影像檢查無法確定時（如胎兒水腎評估、腎功能不佳患者），MRU 特別有价值

## 排泄性泌尿道造影（Excretory Urography, IVP）

| 項目 | 內容 |
|------|------|
| **歷史地位** | 曾是評估泌尿道結石/阻塞的首選影像工具 |
| **現況** | 已被非對比CT大幅取代 |
| **殘留價值** | 可同時評估解剖結構與引流功能 |

---

## 各項檢查綜合比較

| 檢查 | 主要用途 | 敏感性 | 特異性 | 輻射 |
|------|---------|--------|--------|------|
| **腎臟超聲** | 初步篩檢、結石偵測 | 45%（結石） | 88–94% | 無 |
| **CT（無對比）** | 結石金標準 | > 95% | 高 | 有 |
| **利尿劑腎圖** | 功能性阻塞評估 | 依條件變異 | 依條件變異 | 有 |
| **MRU** | 複雜病例、解剖評估 | 接近100% | 高 | 無 |

---

## 重點摘要

| 主题 | 關鍵內容 |
|------|---------|
| **超聲** | 首選篩檢工具；水腎為解剖發現非功能診斷 |
| **阻力指數（RI）** | RI > 0.70 提示阻塞，但敏感性有限；NSAID及對比劑可影響結果 |
| **CT** | 結石偵測金標準；累積輻射劑量需注意 |
| **利尿劑腎圖** | 唯一可提供動態功能資訊的工具；T₁/₂ > 20分鐘提示阻塞 |
| **MRU** | 無輻射、結合解剖與功能；嚴重腎功能受損者禁用含gadolinium製劑 |
