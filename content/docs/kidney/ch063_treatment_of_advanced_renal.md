## 📖 導讀

晚期腎細胞癌（Advanced Renal Cell Carcinoma, RCC）的治療策略在過去二十年間經歷了從細胞激素時代到標靶治療時代的重大轉變。本章節系統整理預後風險分層模型、腫瘤細胞減滅手術（cytoreductive nephrectomy）的適應症與循證依據，以及轉移病灶切除術的臨床意義，為晚期腎癌的多學科治療提供決策框架。

---

## 預後因素與風險分層

### MSKCC 預後模型（化療/免疫治療時代）

**表63-1｜不良預後因素（Memorial Sloan Kettering Cancer Center 模型）**

| 不良預後因素 |
|------------|
| **Karnofsky 功能狀態評分 < 80%** |
| **乳酸去氫酶升高（> 正常上限 1.5 倍）** |
| **血紅蛋白降低（< 正常下限）** |
| **校正血鈣升高（> 10 mg/dL）** |
| **無先前腎切除術病史** |

| 風險分層 | 預後因素數 | 存活期 |
|---------|-----------|--------|
| 低風險 | 0 個 | 最長 |
| 中風險 | 1–2 個 | 中等 |
| 高風險 | 3–5 個 | 最短 |

### IMDC 預後模型（VEGF 標靶治療時代）

**表63-2｜VEGF 標靶治療族群之不良預後因素（International Metastatic Renal Cell Carcinoma Database Consortium）**

| 不良預後因素 |
|------------|
| **Karnofsky 功能狀態評分 < 80%** |
| **嗜中性球細胞增多症（> 正常上限）** |
| **血紅蛋白降低（< 正常下限）** |
| **校正血鈣升高（> 正常上限）** |
| **血小板增多症（> 正常上限）** |
| **確診至 VEGF 標靶治療間隔 < 1 年** |

| 風險分層 | 中位整體存活期 |
|---------|-------------|
| 0 個風險因素 | **43.2 個月** |
| 1–2 個風險因素 | **22.5 個月** |
| ≥3 個風險因素 | **7.8 個月** |

> **臨床重點**
> IMDC 模型證實嗜中性球細胞增多症與血小板增多症是獨立於 MSKCC 模型之外的不良預後指標；這兩個指標在臨床上容易取得，應常規納入晚期腎癌的風險評估。

## 腫瘤細胞減滅手術（Cytoreductive Nephrectomy）

### 理論基礎

晚期 RCC 患者接受細胞減滅腎切除術的動機包括：
1. 巨大原發腫瘤可能抑制關鍵免疫細胞功能（T 細胞抑制）
2. 偶爾文獻報導腎切除術後轉移病灶**自發性消退（spontaneous regression）**的罕見案例
3. 系統性藥物治療（尤其細胞激素）在大部分患者中對原發腎腫瘤難以達到顯著療效

### 隨機對照試驗結果

**表63-3｜干擾素 α-2b 單獨或合併細胞減滅腎切除術之隨機研究彙整**

| 研究 | 治療組 | 存活效益 |
|------|--------|---------|
| 研究一 | 手術 → IFN vs. IFN  alone | 手術組存活顯著更優 |
| 研究二 | 手術 → IFN vs. IFN  alone | 手術組存活顯著更優 |

> **臨床重點**
> 兩項隨機研究均顯示，經過高度選擇的晚期 RCC 患者接受細胞減滅腎切除術後再給予**干擾素 α（IFN-α）**治療，其存活優於單獨使用干擾素治療；然而此結論僅適用於細胞激素時代，目前標靶治療時代的角色仍待前瞻性研究證實。

### 誰不應接受細胞減滅手術？

以下患者族群預後不佳，應審慎評估或避免細胞減滅手術：
- **功能狀態差（Karnofsky < 80%）**
- **共病症嚴重**
- **疾病快速進展**
- **腦部轉移**

## 轉移病灶切除術（Metastasectomy）

### 臨床意義

大多數轉移性 RCC 患者無法以現有系統藥物達到根治或長期無病緩解。切除局限性轉移病灶在多個回溯性研究中顯示與長期無病間隔及總體存活改善相關。然而需注意：**轉移切除術從未被前瞻性隨機對照試驗系統性評估**，其良好療效可能反映患者選擇偏差與腫瘤生物學差異。

### 預後指標

**有利預後指標：**
- 完整切除所有轉移病灶（complete metastasectomy）
- 單一轉移病灶
- 年齡 < 60 歲
- **無病間隔 > 1 年**（從原發腫瘤確診至復發的時間）
- 僅有肺臟轉移
- 轉移腫瘤體積較小（< 4 cm）
- **異時性（metachronous）**病灶

### 存活資料

| 病灶特徵 | 5 年存活率 |
|---------|-----------|
| 完整切除（整體系列）| **35%–50%** |
| 完整切除（MSKCC, n=141）| **44%** |
| 不完整切除（MSKCC, n=70）| **14%** |

> **臨床重點**
> 完整轉移切除術即便在多發性轉移病灶患者中也顯示可行且與癌症專屬存活改善相關；然而在缺乏前瞻證據支持前，選擇患者時應综合考量年齡、無病間隔、轉移灶數量與位置等預後因子。

## 緩和性細胞減滅手術（Palliative Cytoreductive Nephrectomy）

細胞減滅腎切除術亦可作為**緩和醫療**手段，適用於以下臨床情況：
- **頑固性疼痛**
- **血尿（hematuria）**
- **全身性症狀（constitutional symptoms）**
- **副腫瘤症候群**（如高血鈣、紅血球增多症、續發性血小板增多症、高血壓）

需注意並非所有原發腫瘤切除均能帶來臨床獲益，例如高血鈣患者中僅約半數（7/12）可見有意義的血鈣下降。

### 非根治性轉移切除術的適應症

| 臨床情況 | 處理原則 |
|---------|---------|
| 單一腦轉移 | 手術切除 ± 放射治療 |
| 承重骨或關節轉移 | 手術切除 + 放射治療 |
| 脊椎轉移伴脊髓或神經根壓迫 | 緊急手術減壓 |

## 免疫治療在晚期腎細胞癌的角色

宿主免疫系統長期被認為在 RCC 的發生與控制中扮演重要角色。**自發性消退（spontaneous regression）**的報導提供免疫系統參與腎癌调控的最早證據。雖然免疫調節的詳細機制已超出本章範圍，但免疫治療在晚期 RCC 的歷史地位與新興檢查點抑制劑的發展，為未來治療提供了重要基礎。

---

> **臨床重點**
> - 預後風險模型（MSKCC 與 IMDC）是晚期 RCC 治療決策與臨床試驗設計的核心工具，應常規用於所有轉移性腎癌患者的初始評估
> - 細胞減滅腎切除術的適應症應严格筛选：功能狀態良好、疾病進展相對緩慢、無腦轉移的患者最可能從中獲益
> - 轉移病灶切除術的價值在於選擇性患者可獲得長期無病存活，但必須向患者說明此療效尚未經隨機試驗驗證
