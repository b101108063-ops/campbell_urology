## 📖 導讀

腎臟移植是末期腎病（ESRD）患者恢復正常生活品質的最佳治療方式。本章節系統說明移植候選者的術前評估流程，包括心血管疾病篩檢、感染疾病血清學及凝血功能檢測，同時涵蓋移植前常見泌尿科問題的處理原則（如膀胱出口阻塞、泌尿道改流及膀胱擴大術），以及捐贈者的類型與器官保存的病理生理基礎。

---

## 移植候選者術前評估

### 移植前評估項目

| 類別 | 評估內容 |
|------|---------|
| **心臟評估** | 冠狀動脈疾病發生率超過50%患者；心臟核醫檢查或心臟超聲波評估心肌灌注、射出分率、瓣膜功能 |
| **傳染病篩檢** | HIV、HBV、HCV、EBV、CMV、梅毒、結核病；愛滋病已可透過雞尾酒抗反轉錄病毒療法控制，特定條件下可考慮移植 |
| **凝血功能** | 血小板、凝血酶原時間（PT）、部分凝血活酶時間（PTT）、活化蛋白C抵抗比（因子V Leiden） |
| **惡性腫瘤篩檢** | 乳房攝影（大於40歲女性）、前列腺特異抗原（必要時）、膀胱癌評估 |
| **社會心理評估** | 物質濫用、戒菸評估、服藥順從性 |

> **臨床重點**
> - 冠狀动脉疾病是移植前最需注意的死亡風險因素；50歲以上有糖尿病、腎衰竭、腦血管疾病患者併發症風險約25%
> - HIV患者若無伺機性感染跡象、病毒量低且T淋巴球數量充足，可考慮移植
> - 血栓風險增加者：先前透析通路失敗、流產史、抗磷脂抗體症候群、高同半胱胺酸血症

## 移植前泌尿科處置

### 適應症與時機

**需要進行原生腎臟切除（Native Nephrectomy）的常見適應症：**

| 適應症 | 說明 |
|--------|------|
| 有症狀的腎結石（無法以微創處理） | 需移除以避免移植後併發感染 |
| 高惡性度腎腫瘤 | 無論是否為獲得性囊性腎病 |
| 自體顯性多囊腎（PKD） | 囊腫過大延伸至腸骨脊下方、反覆感染、出現實質腫瘤 |
| 持續性抗腎絲球基底膜抗體 | 避免移植後復發 |
| 嚴重蛋白尿 | 藥物無法控制 |
| 反覆腎盂腎炎 | 感染控制不佳 |
| 第4-5級膀胱輸尿管逆流（VUR） | 合併泌尿道感染 |

> **臨床重點**
> - 移植前原生腎切除的理想時機：活體腎移植前**至少6週**
> - 自體顯性多囊腎患者如囊腫未延伸至腸骨脊下方，通常有足夠空間容納移植腎

### 膀胱出口阻塞的處理

- **藥物治療**：α-腎上腺素阻斷劑（如tamsulosin）為首選；5α-還原酶抑制劑（如finasteride）可作為輔助
- **手術治療**：經尿道前列腺切除（TURP）或雷射氣化；無尿患者接受TURP需注意術後膀胱頸攣縮或前列腺窩狹窄的高風險

### 泌尿道改流與膀胱擴大術

| 方式 | 考量 |
|------|------|
| **原位新膀胱（Orthotopic neobladder）** | 為首選，可維持正常排尿方式 |
| **自體導管式改流（Continent catheterizable pouch）** | 適用於膀胱功能嚴重受損者 |
| **輸尿管皮膚造口** | 不建議，狹窄與感染風險高 |

## 捐贈者類型

### 腦死捐贈者（DBD）與心死捐贈者（DCD）

| 類型 | 定義 |
|------|------|
| **腦死捐贈者（DBD）** | 符合腦死判定標準，捐贈前已確認腦死 |
| **心死捐贈者（DCD）** | 不符合腦死標準但昏迷且依賴呼吸器；家屬同意在心跳停止後捐贈；撤除維生治療至器官復取前約需5分鐘無自發呼吸及持續心静止 |

DCD捐贈器官會經歷不同程度的**溫暖缺血**，需特別注意保存。

> **臨床重點**
> - 捐贈前應進行全面器官評估，包含器官大小、病變檢查及組織相容性檢測
> - 捐贈者年齡、器官冷缺血時間、捐贈者類型（DBD vs. DCD）均會影響移植預後

## 器官保存的病理生理

### 缺血性損傷機制

缺血會導致：

```
ATP耗竭 → 鈉鉀幫浦功能失常 → 細胞內鉀、鎂流失
       → 細胞內鈣增加
       → 無氧醣解（乳酸堆積）
       → 溶小體酶活化
       → 細胞水腫
       → 急性腎小管壞死（ATN）
```

**再灌注後**：缺氧黃嘌呤（ATP代謝產物）被氧化成黃嘌呤，產生**自由基**造成進一步細胞損傷。

### 器官保存原則

器官保存的目標是維持細胞內生理狀態。大於數毫米厚度的組織無法僅靠擴散進行有效保存，需採用以下方式：

| 保存方法 | 說明 |
|---------|------|
| **冷缺血保存** | 使用冰鹽水 Slush（0–4°C）快速冷卻；延緩細胞代謝 |
| **機械灌注** | 持續灌流保存液，維持細胞能量代謝 |
| **靜脈引流** | 防止靜脈淤血導致內皮損傷 |

> **臨床重點**
> - 冷缺血時間越長，移植腎功能延遲恢復（DGF）風險越高
> - 缺血再灌注損傷會增加移植腎的**免疫原性**，可能加速排斥反應

## 移植前額外泌尿科檢查建議

| 適應症 | 建議檢查 |
|--------|---------|
| 排尿功能障礙、反覆腎盂腎炎或逆流、超聲檢查不確定 | 逆行腎盂造影 |
| 懷疑下泌尿道癌症或計畫進行侵入性前列腺手術 | 尿液或膀胱沖洗細胞學檢查 |
| 計畫原位腎移植或超聲檢查對結石/腫塊不確定 | 逆行腎盂造影 |
| 先前曾接受環磷酰胺治療或高度刺激性排尿症狀 | 膀胱纖維化或癌症評估 |
| 腸道或胃儲器 | 逆行儲器造影 |

## 重點摘要

| 主题 | 關鍵內容 |
|------|---------|
| **心臟評估** | 超過50% ESRD患者有冠狀动脉疾病；術前需嚴格篩檢 |
| **感染篩檢** | HIV、HBV、HCV、CMV均需檢測；HIV陽性者特定條件下可移植 |
| **血栓風險** | 抗磷脂抗體陽性者需特別注意深靜脈血栓及移植腎血栓 |
| **原生腎切除** | 適應症包括：PKD囊腫過大、頑固性感染/出血/疼痛、疑似惡性腫瘤 |
| **器官保存** | 冷缺血延緩代謝；再灌注產生自由基導致進一步損傷 |
