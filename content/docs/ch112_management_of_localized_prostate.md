## 📖 導讀

本章節系統性探討**局部性攝護腺癌（Localized Prostate Cancer）**的完整管理策略。隨著**PSA 篩檢（PSA Screening）**的普及，臨床上診斷出更多早期、可治愈的攝護腺癌，但同時也面臨**過度診斷（Overdiagnosis）**與**過度治療（Overtreatment）**的嚴峻挑戰。本章詳細介紹**積極監測（Active Surveillance）**的入選標準與臨床數據、腫瘤特性評估（如 **Gleason 分數、PSA 密度、陽性核心數**等），以及各種治療選擇（根治性切除術、放射治療、積極監測）的適應症與預後比較。

## 腫瘤特性評估

### 血清 PSA 相關參數

| 參數 | 定義 | 臨床意義 |
|------|------|---------|
| **總 PSA** | 血清總 PSA 濃度 | PSA > 10 ng/mL 癌症可能性增加 |
| **PSA 速率（PSA Velocity）** | PSA 隨時間變化率 | PSA 快速上升提示更具侵襲性腫瘤 |
| **PSA 倍增時間（PSA Doubling Time）** | PSA 濃度加倍所需時間 | 短倍增時間與高風險疾病相關 |
| **PSA 密度（PSAD）** | 血清 PSA ÷ 攝護腺體積 | > 0.15 ng/mL/g 與癌症相關性增加 |
| **游離/總 PSA 比值** | Free PSA / Total PSA | 比值降低（< 25%）增加癌症可能性 |
| **攝護腺健康指數（PHI）** | 整合多種 PSA 亞型 | 提高癌症偵測特異性 |

### 切片病理學發現

| 病理特徵 | 預後價值 |
|---------|---------|
| **Gleason 分數** | 最重要之預後預測因子 |
| **陽性核心數** | 腫瘤範圍指標 |
| **腫瘤分布與體積** | 預測器官侷限性 |
| **神經周圍/淋巴血管侵犯** | 提示更具侵襲性 |
| **管狀（Ductal）、印戒細胞（Signet Ring）、神經內分泌分化** | 高度侵襲性特徵 |

> **臨床重點**
> - 單一變數的統計模型對**個體患者**之預後預測有限制
> - **Nomograms（如 Partin Table、Makarov 等）**整合多項變數，比單一參數更能預測病理分期與治療結果
> - 寬大的**信賴區間（Confidence Intervals）**限制了對個別患者決策的精確度

## 分期評估

### 低風險患者（無需常規影像學檢查）

根據 AUA 與 NCCN 指引，以下條件者**不需要常規骨骼掃描、CT 或 MRI**：

| 條件 | 閾值 |
|------|------|
| Gleason 分數 | **< 7（部分指引：< 8）** |
| 血清 PSA | **< 10 ng/mL** |
| 切片發現 | 無廣泛或高度侵襲性癌症證據 |

> **臨床重點**
> - 符合上述條件之患者，出現轉移的可能性**極低**
> - NCCN 建議低風險攝護腺癌且 PSA < 20 ng/mL、Gleason ≤ 6 者，**除非有骨骼受侵犯之跡象**，否則避免常規骨骼掃描

### 高風險患者之評估

高風險患者考慮手術治療時，應進行更完整之術前評估：

| 檢查項目 | 目的 |
|---------|------|
| **凝血功能檢查** | 手術準備 |
| **核醫骨骼掃描** | 偵測遠處轉移 |
| **腹部/骨盆腔 CT 或 MRI** | 評估原發腫瘤及淋巴結/遠處轉移 |
| **MRI（配合 DWI 與 DCE）** | 越來越廣泛地用於切片精確性與腫瘤局部評估 |
| **MRI-超聲波融合切片** | 提高切片準確性 |

> **臨床重點**
> - 單株抗體掃描、**正子造影（PET）**、**磁振波譜（MRS）**及**淋巴趨向 MRI** 目前臨床應用有限，但未來可能更具價值
> - **擴散加權成像（Diffusion-weighted Imaging, DWI）**與**動態對比增強（Dynamic Contrast Enhancement, DCE）**已成為 MRI 評估攝護腺癌的重要工具

## 積極監測（Active Surveillance）與觀察等待（Watchful Waiting）

### 兩種策略的區別

| 策略 | 定義 |
|------|------|
| **觀察等待（Watchful Waiting）** | 持續監測，直至出現需要綏解治療的轉移才開始治療 |
| **積極監測（Active Surveillance）** | 允許延遲初始治療，若有生化或組織學進展證據時再給予根治性治療 |

### 傳統 vs 現代應用

| 傳統觀點 | 現代擴展 |
|---------|---------|
| **餘命 < 10 年**且 Gleason 2-6 之男性 | 現已擴展至**年輕患者**（餘命 > 10 年）之低/中度惡性度腫瘤（Gleason ≤ 3+4=7）以延遲或避免不必要的立即治療 |

### 臨床數據

| 研究發現 | 數據 |
|---------|------|
| 符合積極監測標準之新診斷患者 | 約 **16%** |
| 選擇積極監測之患者 | 約 **10%**（另 4% 不完全符合標準但仍選擇） |
| 2011 年接受積極監測之低風險患者 | **18.6%** |
| 長期追蹤（> 30 年）之局部進展 | **41%** |
| 長期追蹤（> 30 年）之遠處轉移 | **18%** |

> **臨床重點**
> - 積極監測的候選標準與觸發治療的時間點仍在**持續驗證**中
> - 患者**焦慮情緒合併 PSA 上升**或切片結果提示進展，常是啟動治療的原因
> - 非常長期追蹤下，**局部進展與攝護腺癌特定死亡的風險顯著**

## 候選資格與「不重要癌症」預測模型

### Epstein 模型

**Epstein 及其同事**提出術前臨床與病理特徵預測「**不重要癌症（Insignificant Cancer）**」（腫瘤體積 < 0.2 mL、Gleason < 7、器官侷限性）的模型：

| 預測不重要癌症之條件 | 標準 |
|---------------------|------|
| 切片中 | 無 Gleason Pattern 4 或 5 |
| PSA 密度 | ≤ 0.1 ng/mL/g |
| 陽性子彈數 | < 3 條（總核心數至少 6 條）|
| 無核心超過 | 50% 腫瘤浸潤 |
| PSA 密度 0.1-0.15 ng/mL/g | 腫瘤長度 < 3 mm 且僅限 1 條核心 |

| 預測效能 | 數值 |
|---------|------|
| 預測「重要」癌症 | **95%** |
| 預測「不重要」癌症 | **66%**（模型限制） |
| 符合不重要癌症標準之患者比例 | 約 **16%** |

> **臨床重點**
> - 統計模型的預測效能對**群體患者**佳，但對**個體患者**仍有相當限制
> - **BRCA2 突變患者**具有更高 Gleason 分數、更晚期分期及更短存活期，**不適合積極監測**
> - **非裔美國男性**在積極監測中疾病進展風險顯著較高，且即使符合積極監測標準，手術病理學特徵亦較差

## 過度診斷（Overdiagnosis）的議題

### 過度診斷的定義

**過度診斷**指的是被診斷為攝護腺癌但**不會在患者有生之年造成症狀或死亡**。

### 估計數據

| 估算方法 | 過度診斷率 |
|---------|-----------|
| **流行病學模型（美國）** | **23-28%** |
| **手術治療患者病理資料** | **6-20%** |
| 早期文獻（部分） | 可達 **50% 以上** |

> **臨床重點**
> - **老男性**的過度診斷估計**不應推論至年輕男性**
> - 年輕男性之攝護腺癌**更可能在長期造成危害**
> - 低 PSA 閾值切片發現的癌症中，僅 **12%** 符合不重要癌症標準
> - 即使符合不重要標準，部分腫瘤為**多灶性（Multifocal）**或**非整倍體（Aneuploid）**，仍可能具臨床意義

## 切片與治療決策的複雜性

### 主要挑戰

| 問題 | 說明 |
|------|------|
| **Gleason 分數升級** | 高達 **50%** 的患者在根治切除標本上被升級 |
| **切片取樣誤差** | 重複切片存在同樣問題 |
| **纖維化風險** | 重複切片可能誘發攝護腺及其周圍組織纖維化，影響後續**神經保留手術**之可行性 |
| **發炎導致 PSA 波動** | 使 PSA 解讀更加困難 |

> **臨床重點**
> - 切片確診後的治療決策需綜合考量 **PSA、Gleason 分數與估計腫瘤體積**
> - 早期治療在腫瘤體積較小時成功率更高，且**保留勃起功能**的手術機會較大
> - 延遲治療較適合**年齡較大、餘命有限或有多重共病**的患者

## PSA 篩檢與死亡率趨勢

| 觀察 | 說明 |
|------|------|
| **PSA 普及國家的死亡率** | 趨於下降 |
| **非 PSA 篩檢國家** | 死亡率持續上升 |
| **英國 1992-2004 死亡率「下降」** | 部分因死亡歸因方式改變（PSA 時代前，轉移性攝護腺癌死於肺炎仍歸因於攝護腺癌）|

> **臨床重點**
> - PSA 篩檢對攝護腺癌特異死亡的影響仍有爭議（ERSPC 顯示淨效益，PLCO 顯示無效益）
> - 各組織之篩檢建議差異甚大，從**支持知情同意後篩檢**到**反對無症狀男性 PSA 篩檢**均有
