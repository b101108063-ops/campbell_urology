# 膀胱癌

📖 **導讀**：膀胱癌是泌尿系統最常見的惡性腫瘤之一，約佔全球癌症發病的 3%。以 **urothelial carcinoma**（泌尿上皮癌）為主，與**抽菸**和**長期膀胱刺激**密切相關。表淺性膀胱癌的預後佳，但侵襲性或轉移性膀胱癌的治療具挑戰性。

---

## 流行病學

| 統計 | 數據 |
|---|---|
| 全球發生率 | 男性第 6 常見癌症、女性第 17 常見 |
| 男:女比例 | 3-4:1 |
| 確診年齡中位數 | 73 歲 |
| 亞洲好發 | 台灣、中國男性發生率偏高 |

### 危險因子

| 危險因子 | 相對風險 |
|---|---|
| **抽菸** | 2-4 倍（最重要的危險因子） |
| 職業暴露（芳香胺） | 5-10 倍（染料、橡膠工人） |
| 慢性膀胱刺激 | 2-3 倍（導尿管、結石） |
| 寄生蟲感染（血吸蟲） | 5-10 倍（埃及血吸蟲） |
| 放射治療（攝護腺癌） | 2-4 倍 |

---

## 病理學

### 组织學分類

| 類型 | 佔比 | 預後 |
|---|---|---|
| **Urothelial carcinoma**（泌尿上皮癌） | 90-95% | 取決於分期和分級 |
| **Squamous cell carcinoma**（鱗狀上皮癌） | 2-5% | 通常為侵襲性 |
| **Adenocarcinoma**（腺癌） | 1-2% | 預後較差 |
| **Small cell carcinoma**（小細胞癌） | < 1% | 高度惡性 |

### 泌尿上皮癌的分級

| 分級 | 說明 |
|---|---|
| **Low-grade**（低惡性度） | 乳頭狀（papillary），預後佳 |
| **High-grade**（高惡性度） | 扁平（flat）、原位癌（CIS），易侵襲 |

---

## 分期（TNM Staging）

| 分期 | 腫瘤範圍 |
|---|---|
| **Ta** | 非侵襲性乳頭狀癌（只在黏膜層） |
| **Tis** | 原位癌（扁平，高惡性度） |
| **T1** | 腫瘤侵犯黏膜下層（lamina propria） |
| **T2** | 侵犯肌肉層 |
| &nbsp;&nbsp;&nbsp;**T2a** | 侵犯淺層肌肉（inner half） |
| &nbsp;&nbsp;&nbsp;**T2b** | 侵犯深層肌肉（outer half） |
| **T3** | 侵犯膀胱周圍脂肪組織 |
| **T4** | 侵犯鄰近器官（前列腺、子宮、直腸、骨盆壁） |

---

## 臨床表現

| 症狀 | 說明 |
|---|---|
| **無痛性血尿**（Painless gross hematuria） | 最常見，約 80-90% |
| 顯微血尿 | 偶爾發現 |
| 頻尿、急尿 | 膀胱刺激症狀 |
| 排尿疼痛 | 晚期或伴有感染時 |
| 排尿困難 | 腫瘤阻塞時 |

> **臨床重點**：**任何年齡的無痛性血尿都應懷疑膀胱癌**，尤其是 40 歲以上、有抽菸史者。

---

## 診斷

### 1. 尿液細胞學（Cytology）

| 特點 | 說明 |
|---|---|
| 敏感性 | 對 high-grade tumor 和 CIS 高（約 80-90%） |
| 特異性 | 高（> 95%） |
| 限制 | 對 low-grade tumor 敏感性低（< 50%） |

### 2. 膀胱尿道鏡檢查（Cystoscopy）

> **確診工具**，可在局部麻醉下進行（軟式膀胱鏡）。

| 發現 | 說明 |
|---|---|
| 乳頭狀腫瘤 | 可能是 Ta 或 T1 |
| 扁平斑塊 | 可能是 CIS |
| 廣泛性出血 | 建議做隨機切片 |

### 3. 尿液生物標記

| 標記 | 說明 |
|---|---|
| **BTA**（Bladder tumor antigen） | 敏感性 60-80% |
| **NMP22** | 敏感性 50-70% |
| **UroVysion FISH** | 可偵測染色體異常 |

### 4. 影像檢查

| 檢查 | 目的 |
|---|---|
| 超音波 | 評估上尿路（腎臟、輸尿管） |
| CT Urography | 評估整個尿路（腎臟、輸尿管、膀胱） |
| MRI | 評估局部侵襲和轉移 |

## 治療

### 非肌肉侵襲性膀胱癌（Non-Muscle-Invasive Bladder Cancer, NMIBC）

指 Ta、Tis、T1 期。

#### 經尿道膀胱腫瘤切除術（TURBT）

> **標準診斷和治療手段**。

| 項目 | 說明 |
|---|---|
| 目的 | 切除可見腫瘤 + 取得深層組織樣本 |
| 併發症 | 出血、膀胱穿孔（1-5%） |
| 術後 | 立即單次膀胱內化療（e.g., mitomycin C）可降低復發 |

#### 術後膀胱內治療（Intravesical Therapy）

| 類型 | 藥物 | 目的 |
|---|---|---|
| **化療**（Chemotherapy） | Mitomycin C、Epirubicin | 預防復發 |
| **卡介苗**（BCG） | Bacillus Calmette-Guérin | 預防復發和進展（對 high-grade 和 CIS 效果佳） |

#### BCG 治療適應症

| 適應症 | 建議 |
|---|---|
| High-grade Ta | BCG 優於化療 |
| T1 | 強烈建議 BCG |
| CIS | BCG 為標準治療 |

> **臨床重點**：**BCG 是高風險 NMIBC 的標準術後治療**，可顯著降低復發和進展風險。完整療程為 6 次初始誘導灌注 + 3 次維持灌注。

### 肌肉侵襲性膀胱癌（Muscle-Invasive Bladder Cancer, MIBC）

指 T2-T4a 期。

#### 根治性膀胱切除術（Radical Cystectomy）

> **標準治療**，男性包括膀胱、前列腺、精囊；女性包括膀胱、子宮、子宮頸、陰道前壁。

| 項目 | 說明 |
|---|---|
| 盆腔淋巴結清除 | 標準至主動脈分叉處 |
| 男性術式 | **Radical cystoprostatectomy** |
| 女性術式 | **Anterior pelvic exenteration** |
| 術前化療 | 建議（新輔助化療，cisplatin-based） |

#### 尿路改道（Urinary Diversion）

| 方式 | 說明 |
|---|---|
| **迴腸導管**（Ileal conduit） | 最常用，輸出至腹壁 |
| **可控性尿囊**（Continent cutaneous pouch） | Kock pouch、Indiana pouch |
| **原位膀胱重建**（Orthotopic neobladder） | 使用迴腸做成新膀胱，連接尿道，接近生理排尿 |

### 轉移性膀胱癌（Metastatic Bladder Cancer）

| 治療 | 說明 |
|---|---|
| **化學治療**（首選） | Cisplatin-based 化療（GC 組合：Gemcitabine + Cisplatin） |
| **免疫檢查點抑制劑** | Atezolizumab、Pembrolizumab（適用於 cisplatin 不合適或化療後） |
| **抗體藥物複合體**（ADC） | Enfortumab vedotin（EV）用於化療和免疫治療後 |
| **FGFR 抑制劑** | Erdafitinib（適用於 FGFR 基因改變者） |

---

## 追蹤

| 族群 | 追蹤方式 |
|---|---|
| **NMIBC（低風險）** | 膀胱鏡：術後 3-12 個月各一次，之後每年一次 |
| **NMIBC（高風險）** | 膀胱鏡 + 尿細胞學：每 3-6 個月一次，持續 2-3 年 |
| **MIBC（術後）** | CT、胸腔 X 光：每 6-12 個月一次 |

> **臨床重點**：**膀胱癌有很高的復發率**，NMIBC 的 5 年復發率可達 30-70%，因此長期追蹤膀胱鏡檢查是必要的。

---

## 總結

| 重點 | 內容 |
|---|---|
| **最常見類型** | Urothelial carcinoma（泌尿上皮癌） |
| **最重要的危險因子** | 抽菸 |
| **最常見症狀** | 無痛性血尿 |
| **確診工具** | 膀胱尿道鏡檢查 |
| **非侵襲性治療** | TURBT + 膀胱內 BCG/化療 |
| **肌肉侵襲性治療** | 根治性膀胱切除術 + 新輔助化療 |
| **轉移性治療** | 化學治療、免疫治療、ADC、FGFR 抑制劑 |
| **追蹤** | 膀胱鏡為主，長期追蹤復發 |
