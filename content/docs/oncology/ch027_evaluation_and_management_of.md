## 📖 導讀

**勃起功能障礙（ED）** 影響全球約 20% 的成年男性，是泌尿科最常見的性功能問題之一。本章節系統性介紹 ED 的**流行病學、風險因子、診斷評估**以及**目標導向治療（goal-directed management）** 的實證框架。臨床上 ED 不僅是局部問題，更是**全身血管健康**的指標，與心血管疾病、糖尿病及代謝症候群密切相關。

---

## 流行病學與健康政策

### 流行病學數據

| 數據 | 說明 |
|------|------|
| 全球盛行率 | 約 **20%** 成年男性受影響 |
| 美國醫療負擔 | **十大昂貴泌尿科診斷**之一 |
| 與生活品質 | 直接影響身心幸福感與整體健康 |

> **臨床重點**
> - ED 的存在本身就可能是**心血管疾病**的早期警訊，屬於「canary in the coal mine」現象。
> - ED 的治療不僅改善性生活，更與**健康維持及壽命延長**高度相關（Saigal et al, 2006）。

## 主要風險因子（Table 27-2, 27-3）

### 系統性風險因子

| 風險因子 | 多變量調整後相關性 |
|----------|-----------------|
| 心血管疾病 | 顯著增加風險 |
| 第二型糖尿病 | 顯著增加風險 |
| 良性攝護腺肥大（BPH） | 顯著增加風險 |
| 肥胖（BMI 增加） | 顯著增加風險 |
| 阻塞性泌尿道症狀（LUTS） | 顯著增加風險 |
| 吸菸（目前） | 顯著增加風險 |
| 高血壓 | 顯著增加風險 |
| 血脂異常 | 顯著增加風險 |
| 憂鬱症 | 顯著增加風險 |

> **臨床重點**
> - ED 與**代謝症候群（metabolic syndrome）** 共享相同的病理生理基礎：內皮功能障礙、氧化壓力、慢性發炎。
> - **基因型**亦影響 ED 風險，未來可能發展出基因生物標記以評估治療反應（Lippi et al, 2012）。

### 藥物相關性 ED

約 **25%** 的 ED 個案與藥物相關（Table 27-3）：

| 藥物類別 | 範例 |
|----------|------|
| 抗高血壓藥 | 噻嗪類利尿劑、非選擇性 β-受體阻斷劑 |
| 抗憂鬱藥 | 三環類、**選擇性血清素再吸收抑制劑（SSRI）** |
| 抗精神病藥 | 典型與非典型抗精神病藥 |
| 荷爾蒙藥物 | 氟他胺（Flutamide）、cyproterone acetate、LHRH analogues |
| 其他 | 組織胺 H2 受體拮抗劑、化療藥物（Cyclophosphamide, Methotrexate） |

> **臨床重點**
> - 藥物引起 ED 的因果判定需滿足：**發生率顯著高於對照組**且**有可信的生理機制支持**。
> - 藥物可能同時影響**性慾、喚起、快感與高潮**，間接妨礙勃起功能。

## 診斷評估

### 診斷標準（NIH Consensus Statement, 1992）

> 勃起功能障礙的定義為：持續或反覆出現的**無法達到或維持陰莖勃起**，以完成足以令人滿意的性交的程度。

後續共識聲明建議症狀需持續 **至少 3 個月**（創傷或手術引起的 ED 例外）。

### 評估流程（Fig. 27-2）

#### 第一階段：完整病史

| 組成 | 內容 |
|------|------|
| **性功能史** | 發病時間、持續期間、情境、嚴重程度、病因線索 |
| **醫療史** | 心血管疾病、糖尿病、血脂、血壓、荷爾蒙狀態 |
| **心理社會史** | 憂鬱、焦慮、壓力、伴侣關係 |
| **用藥史** | 所有處方藥與非處方藥 |
| **生活型態** | 吸菸、運動、體重 |

#### 第二階段：理學檢查

- 生命徵象（血壓、心率）
- 外生殖器檢查（陰莖結構、包皮、睪丸大小）
- 神經學篩檢（會陰感覺、球海綿體肌反射）
- 心血管評估（心雜音、周边脈搏）

#### 第三階段：實驗室檢查

| 檢查項目 | 目的 |
|----------|------|
| **空腹血糖、糖化血色素（HbA1c）** | 篩檢糖尿病 |
| **血脂面板** | 評估代謝風險 |
| **早晨睪固酮（總量與游離）** | 篩檢**性腺功能減退（hypogonadism）** |
| **泌乳激素（Prolactin）** | 排除高泌乳激素血症 |
| **甲狀腺功能** | 甲狀腺疾病可致 ED |
| **尿液分析** | 排除感染、血尿、蛋白尿 |

## 目標導向治療（Goal-Directed Management）

### 核心理念

**目標導向管理**由 Lue（1990）提出，強調：

- 診斷與治療應**符合個別患者的需求與期待**
- 讓患者或伴侶在充分了解所有治療選項後，**自主選擇偏好療法**
- 以**患者為中心（patient-centered）** 的框架執行

### 何時轉診專科

| 適應症 | 轉診對象 |
|--------|----------|
| 初始治療失敗 | 泌尿科 |
| 骨盆或會陰創傷史之年輕患者 | 泌尿科 |
| 陰莖畸形（如**佩羅尼氏病 Peyronie disease**、先天性彎曲） | 泌尿科 |
| 複雜內分泌疾病（如次發性性腺功能減退、腦下垂體腺瘤） | 內分泌科 |
| 頑固性憂鬱或性慾減退 | 精神科 |
| 需要血管或神經外科介入（如主動脈瘤、腰椎間盤疾病） | 血管/神經外科 |

> **臨床重點**
> - 轉診前應確保患者充分了解轉診的**理由、費用、風險與可能結果**。
> - **追蹤照護**是不可忽視的一環：研究顯示未規律追蹤的患者治療中斷率極高（Albaugh et al, 2002）。

## 治療選項概覽

### 第一線：口服藥物（PDE5 抑制劑）

| 藥物 | 起始作用時間 | 特色 |
|------|-------------|------|
| **Sildenafil（威而鋼）** | 30-60 分鐘 | 短效，飲食影響吸收 |
| **Tadalafil（犀利士）** | 30 分鐘 | 長效（可達 36 小時），不受飲食影響 |
| **Vardenafil（樂軒那）** | 30 分鐘 | 效果強，起效快 |
| **Avanafil（速效型）** | 15 分鐘 | 最新製劑，最快起效 |

> **臨床重點**
> - PDE5 抑制劑需有**性刺激**才能觸發勃起機制。
> - 禁忌症：同時使用**硝酸化合物（nitrates）**（如心絞痛藥物）會導致危及生命的低血壓。
> - 對**糖尿病患者**及**攝護腺手術後** ED 的效果較一般族群為低。

### 第二線：海綿體內注射（ICI）

**前列腺素 E1（PGE1）** 或 combination therapy（常用三聯：PGE1 + Papaverine + Phentolamine）。

### 第三線：陰莖假體植入（Penile Prosthesis）

適用於藥物治療失敗或無法使用其他治療的患者，分為：
- **可膨脹式（inflatable）**：二件式或三件式
- **半剛性（semirigid）**：可折彎式

## 追蹤照護原則

| 追蹤目標 | 內容 |
|----------|------|
| 療效確認 | 確保治療持續成功 |
| 劑量調整 | 評估是否需滴定或更換藥物 |
| 疾病再評估 | 重新檢視影響 ED 的醫療或心理因素 |
| 藥物不良反應 | 監測藥物交互作用 |
| 健康教育 | 給予患者與伴侶持續的性健康指導 |

---

## 關鍵要點摘要

- ED 盛行率約 20%，與**心血管疾病、糖尿病、代謝症候群**共享風險因子
- 完整的 ED 評估包含**性功能史、醫療史、心理社會史與實驗室檢查**
- **目標導向治療**以患者為中心，強調知情選擇與個體化治療
- PDE5 抑制劑為第一線治療，需性刺激才有效，且禁與硝酸化合物合用
- **追蹤照護**是治療成功的關鍵，不可忽視
