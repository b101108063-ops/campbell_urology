## 📖 導讀

**佩羅尼氏病（Peyronie disease, PD）** 是一種陰莖白膜（tunica albuginea）的**纖維化（fibrosis）** 疾病，導致陰莖在勃起時出現**彎曲、疼痛或變形**。傳統觀念認為此病罕見且多為自發緩解，但研究顯示其盛行率可能被嚴重低估，且與**勃起功能障礙（ED）**、**糖尿病**及**心理健康問題**高度共病。本章節系統整理 PD 的流行病學、共病關係、病理機制與治療原則。

---

## 流行病學與疾病特點

### Box 31-1 臨床要點（常被誤解的觀念）

> **臨床重點**
> - 佩羅尼氏病**並不罕見**
> - **自發緩解的可能性並不高**
> - 不僅限於**中年男性**
> - 不僅限於**白種男性**——所有種族均可能發病

### 盛行率與發生率

| 數據來源 | 數值 |
|----------|------|
| 發生率（incidence） | 0.39% - 20.3%（依篩檢族群而異） |
| 多數最新估計 | **3% - 9%** |
| 盛行率（prevalence） | 1% - 13%（主觀症狀），但**解剖學盛行率達 22%**（屍體研究） |
| 高峰發病年齡 | 約 **50 歲初頭** |
| 自發緩解 | **罕見**，多數患者疾病穩定或進行性惡化 |

> **臨床重點**
> - 自我報告症狀（13%）遠高於實際就醫人數（0.5-0.8%），顯示多數男性因尷尬而不就醫。
> - 組織病理學研究顯示：**每 100 名男性中約 22 名有至少輕度 PD**，凸顯此病的公共衛生重要性。

## 相關共病與風險因子

### 糖尿病與 PD 的雙向關聯

糖尿病與 PD 的關聯性是近年研究熱點：

| 關聯方向 | 數據 |
|----------|------|
| PD 患者中糖尿病盛行率 | **最高達 33.2%** |
| 糖尿病患者中 PD 盛行率 | **8.1% - 20.3%** |
| 糖尿病病程越長 | PD 嚴重度（彎曲角度、陰莖變形程度）越高 |
| 血糖控制越差 | PD 症狀越嚴重 |

> **臨床重點**
> - 可能的解釋：糖尿病患者因 **ED** 而注意到原本未被發現的陰莖彎曲（因勃起硬度不足時不易察覺變形）。
> - 糖尿病導致的**微血管病變與氧化壓力**可能加速白膜纖維化。
> 相反地，PD 本身造成的陰莖局部發炎與纖維化，也可能通過全身性細胞激素（cytokine）釋放加劇糖尿病相關血管損傷。

### 其他共病

| 共病 | 說明 |
|------|------|
| 高血壓 | 與年齡相關，增加組織硬化風險 |
| 高血脂 | 加速血管與組織纖維化 |
| 低睪固酮 | 與彎曲嚴重度相關（Morgentaler, 2009） |
| 攝護腺手術史 | 術後 PD 發生率約 **15.9%**（Tal et al, 2010） |

> **臨床重點**
> - **攝護腺根除術（含傳統與機器人輔助）** 後發生 PD 的風險高於一般族群，可能與術中陰莖局部創傷、神經源性後果或細胞激素釋放有關（Ciancio & Kim, 2000）。
> - 整體而言，PD 的發生隨年齡增加，與體組織彈性下降導致創傷相關損傷修復異常有關。

## 病理生理學

### PD 的發病機制

| 階段 | 變化 |
|------|------|
| **急性期** | 陰莖白膜局部**發炎與創傷**，扳機多為性交時的彎曲受力 |
| **慢性期/纖維化期** | **膠原蛋白沉積與扳機斑塊（plaque）形成**，斑塊可鈣化或維持軟組織狀態 |
| **斑塊特徵** | 主要為**順序紊亂的膠原纖維**與異常彈性纖維，破壞白膜均質結構 |

> **臨床重點**
> - **創傷（Trauma）** 似乎是 PD 的關鍵觸發因素：反覆或急性陰莖創傷在有遺傳或代謝易感性的男性身上，會激活**異常傷口癒合（abnormal wound healing）** 過程。
> - **目前無證據顯示** β-受體阻斷劑或 Phenytoin 直接引起 PD。

## 心理健康與生活品質

### PD 對心理的影響

| 影響面向 | 說明 |
|----------|------|
| 憂鬱 | **48%** 的 PD 患者有中重度憂鬱，且隨病程延長而加劇 |
| 自我形象與身體意象 | 陰莖外觀改變導致嚴重自我意識 |
| 性伴侶困擾 | 伴侣產生無助感、創傷感與親密關係失落感 |
| 社交孤立 | 疾病污名化導致退縮 |

### PDQ（Peyronie Disease Questionnaire）

Rosen 等人（2008）發展出 **PDQ**，識別出四大核心困擾領域：

| 領域 | 內容 |
|------|------|
| **身體外觀與自我形象** | 對陰莖外觀的不滿 |
| **性功能與表現** | 對勃起能力與性表現的焦慮 |
| **疼痛與不適** | 勃起時疼痛 |
| **社會污名化與孤立** | 因疾病產生的社交退縮 |

> **臨床重點**
> - 患者主觀評估的陰莖彎曲角度平均**高估客觀測量達 20 度**（54% 的患者有過度估算）。
> - 即使治療成功使患者恢復性功能，**殘餘心理困擾往往持續存在**（Gelbard et al, 1990）。
> - 出現憂鬱或焦慮跡象時，應轉診至**性治療師、心理師或精神科醫師**。

## 診斷評估

### 病史詢問要點

| 項目 | 內容 |
|------|------|
| 發病時間 | 急性或慢性 |
| 彎曲方向 | 背側、腹側、側彎 |
| 疼痛與否 | 勃起時疼痛（急性期常見） |
| 勃起功能 | 原有或新發的 ED |
| 創傷史 | 性交創傷史 |
| 共病 | 糖尿病、高血壓、血脂、用藥史 |
| 心理狀態 | 憂鬱、焦慮程度 |

### 身體檢查

- **陰莖鬆弛狀態**：觸摸白膜斑塊、評估鈣化程度
- **陰莖勃起評估**：可採用**in-office 勃起誘導測試**或患者自行拍攝勃起狀態照片
- **客觀彎曲角度測量**：以標準化方式測量勃起狀態下的彎曲程度

> **臨床重點**
> - **斑塊鈣化並非成熟或慢性疾病的指標**：超聲檢查發現鈣化僅表示曾有出血或壞死，不代表疾病已靜止。
> - 應同時評估**勃起功能狀態**，因為多數 PD 患者同時存在 ED（需兩者同時治療）。

## 治療選項

### 保守治療（急性期或不適合手術者）

| 治療方式 | 說明 |
|----------|------|
| **口服藥物** | 維生素 E（歷史使用）、秋水仙素（Colchicine）、他汀類藥物（爭議性） |
| **病灶內注射** | 膠原酶（Collagenase Clostridium histolyticum, Xiaflex）— FDA 核准 |
| **物理治療** | 陰莖牵引裝置（traction device）、負壓助勃器 |
| **PDE5 抑制劑** | 目前研究顯示有**抗纖維化（antifibrotic）** 潛力（Ferrini et al, 2006），但非主要治療 |

### 手術治療（穩定期 / 慢性期）

| 適應症 | 手術方式 |
|--------|----------|
| 嚴重彎曲（> 60-90 度）且保守治療無效 | **白膜摺疊術（Nesbit 術式）** |
| 斑塊明顯且勃起功能尚可 | **斑塊切除與修補術（plication or plaque excision with graft）** |
| 同時有嚴重 ED | **陰莖假體植入（penile prosthesis）** |

## 與攝護腺根除術的關係

| 研究 | 發現 |
|------|------|
| Tal et al, 2010 | 1011 名攝護腺根除術後患者：PD 發生率 **15.9%**，平均術後 **13.9 個月**發病 |
| Ciancio & Kim, 2000 | 11% 攝護腺切除術患者出現陰莖纖維化，其中 93% 導致陰莖彎曲 |

> **臨床重點**
> - 接受**開放或機器人輔助攝護腺根除術**的男性，PD 發生率高於一般族群。
> - 可能的機制包括：**術中局部創傷、神經源性後果、細胞激素局部釋放**，在有 PD 易感性的男性中激活異常傷口癒合路徑。

---

## 關鍵要點摘要

- PD 的盛行率可能被低估：**組織學盛行率達 22%**，但主動就醫者僅 0.5-0.8%
- **糖尿病**與 PD 有明確的雙向關聯：糖尿病患者 PD 盛行率達 8-20%，且血糖控制越差 PD 越嚴重
- **創傷**是 PD 的關鍵觸發因子，激活有遺傳或代謝易感性男性的異常傷口癒合
- **心理健康**影響深遠：48% 的 PD 患者有憂鬱，且即使成功治療仍可能有殘餘心理困擾
- 治療分為**保守治療（急性期）**與**手術治療（穩定期）**，需同時評估與處理共存的 ED
- **PDE5 抑制劑**目前認為具有抗纖維化潛力，可能對 PD 患者有益
