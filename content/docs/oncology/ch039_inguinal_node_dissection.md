# Chapter 39 Intraoperative Ultrasound and Inguinal Node Dissection

## 📖 導讀

本章節聚焦於**陰莖癌（penile cancer）**的**腹股溝淋巴結（inguinal lymph nodes）**管理，特別是**前哨淋巴結切片（Sentinel Lymph Node Biopsy, SLNB）**與**動態前哨淋巴結切片（Dynamic Sentinel Node Biopsy, DSNB）**的技術演進與臨床應用。陰莖癌的淋巴轉移模式遵循由原發腫瘤依序轉移至第一站淋巴結（腹股溝淺層）的規律，約 **20%** 臨床上無明顯淋巴結腫大的患者其實已有隱匿性轉移。本章詳細介紹了 DSNB 的技術細節、影像學超前期篩檢、以及如何降低偽陰性率，為泌尿科醫師提供陰莖癌淋巴結分期的完整參考。

---

## 陰莖癌腹股溝淋巴結管理的臨床背景

### 隱匿性轉移的流行病學

| 統計 | 數值 | 說明 |
|------|------|------|
| 臨床上無明顯淋巴結腫大的患者中存在隱匿性轉移 | **~20%** | 這意味著80%的患者接受常規雙側IFLND屬於過度治療 |
| 前哨淋巴結陽性的發現率（有DSNB中心） | **14.6%** | 74/500 個腹股溝窩，59/264 患者 |

> **臨床重點**：對所有陰莖癌患者常規執行**腹股溝淋巴結廓清術（IFLND）**會使80%無轉移的患者承受不必要的併發症。前哨淋巴結評估是解决此臨床困境的關鍵。

---

### 淋巴結評估策略

| 策略 | 目的 |
|------|------|
| **改進的預後演算法** | 根據原發腫瘤的病理與臨床特徵進行風險分層 |
| **改進的影像學技術** | 超音波導引細針穿刺細胞學（FNA） |
| **第一站淋巴結病理取樣** | DSNB / SLNB |

> **臨床重點**：目前 DSNB 已被**2009年歐洲泌尿科醫學會（EAU）指南**纳入為陰莖癌淋巴結分期的建議方法。

---

## 前哨淋巴結切片（Sentinel Lymph Node Biopsy, SLNB）

### Cabanas 法（1977年）

| 項目 | 說明 |
|------|------|
| **提出者** | Cabanas，經大量淋巴造影與解剖學研究 |
| **切口位置** | 平行腹股溝皺褶，距恥骨結節兩指寬外側、下方5 cm |
| **操作方法** | 手指由上瓣插入，向恥骨結節方向探查，即可觸及前哨淋巴結並切除 |
| **前哨淋巴結（俗稱 Cabanas node）** | 陽性的預測價值：淋巴結陽性患者中100%存在此結；此結陰性者，其他腹股溝淋巴結無轉移 |
| **重要發現** | 4%淋巴結臨床無可疑的患者中，此結為陽性 |

| Cabanas 原始報告 | 結果 |
|------------------|------|
| 前哨淋巴結切片正常者存活率 | 90% |
| 後續作者報導偽陰性率 | 18%–25% |

> **臨床重點**：Cabanas 的原始報告結果良好，但後續研究顯示偽陰性率偏高。此差異可能與早期切片技術、病理分析深度及腫瘤阻塞淋巴管導致引流改變有關。

---

## 動態前哨淋巴結切片（Dynamic Sentinel Node Biopsy, DSNB）

### 技術要素

| 要素 | 說明 |
|------|------|
| **術前淋巴閃爍造影** | 使用 technetium-99m nanocolloid |
| **術前專利藍染料注射** | 注射於原發腫瘤周圍 |
| **術中γ射線探測探頭** | 導引辨識前哨淋巴結 |
| **目的** | 精確識別個體化的淋巴引流模式 |

### DSNB 的演進與改良

| 階段 | 時間 | 機構 | 偽陰性率 | 改良內容 |
|------|------|------|----------|----------|
| **早期經驗** | 1994–2001 | NKI（荷蘭） | 19%–22% | 初始技術 |
| **成熟期** | 2001–2004 | NKI（荷蘭） | **5%** | 技術改良 |
| **多中心數據** | 混合 | NKI + SGH | **7%** | 累積經驗 |
| **SGH 最新數據** | 2004–2010 | SGH（倫敦） | **5%** | 超音波+FNA前置步驟 |

---

### 降低偽陰性率的關鍵改良

#### 1. 超音波導引細針穿刺細胞學（FNA）前置步驟

| 步驟 | 內容 |
|------|------|
| **術前腹股溝超音超檢查** | 所有候選患者術前行腹股溝超音超 |
| **FNA 對象** | 超音超顯示可疑淋巴結者 |
| **FNA 陽性** | 直接進入 IFLND，跳過 DSNB |
| **FNA 陰性** | 繼續 DSNB 流程 |

> **臨床重點**：此步驟旨在排除因**腫瘤阻塞並重新路由淋巴管**所致的偽陰性。

#### 2. 聯合染劑策略

| 染劑組合 | 檢出率 |
|----------|--------|
| 僅放射性追蹤劑 | 88.3% |
| **放射性追蹤劑 + 藍染料** | **90.1%** |

> **臨床重點**：**聯合使用放射性追蹤劑與藍染料**可提高前哨淋巴結檢出率，應作為標準做法。

#### 3. 系統性淋巴結探索

| 步驟 | 內容 |
|------|------|
| **前哨淋巴結切除後** | 系統性觸診整個腹股溝窩 |
| **目標** | 找出未 uptake 任何放射性或藍色染料的可疑淋巴結 |
| **原則** | 所有懷疑病灶均應送檢 |

#### 4. 精確病理分析

| 技術 | 說明 |
|------|------|
| **全節點包埋** | 所有淋巴結完整送檢，全埋入石蜡 |
| **連續切片** | 每 2 mm 間隔進行切片 |
| **免疫組織化學（IHC）** | 輔助標準染色 |

> **臨床重點**：**只做一個中心切面**可能漏掉微小轉移病灶。**全節點連續切片 + IHC** 是減少病理偽陰性的關鍵。

## 超音波的可疑發現（指導 FNA 時機）

以下超音超發現可提示淋巴結需要進一步 FNA 評估（Box 39-1 要點）：

| 超音波特徵 | 臨床意義 |
|-----------|----------|
| 皮質厚度增加 | 早期轉移徵象 |
| 淋巴結門結構消失 | 提示惡性侵犯 |
| 形狀變圓（原本橢圓） | 高度懷疑惡性 |
| 血流模式改變 | 腫瘤新生血管 |

---

## DSNB 時機

| 選項 | 說明 |
|------|------|
| **同步 DSNB** | 與初始確診切片（僅活檢）同期執行 |
| **分期 DSNB** | 原發腫瘤治療完成後（部分/全部陰莖切除術或保守性切除）再執行 |
| **分期 DSNB 的可行性** | 技術99m-nanocolloid 可注射於切除創口/疤痕周圍而非腫瘤周圍 |

| 分期 DSNB 數據 | 結果 |
|----------------|------|
| 前哨淋巴結顯像率 | 93% |
| 前哨淋巴結辨識率 | 100% |
| 隱匿性轉移檢出率 | 12% |

> **臨床重點**：分期 DSNB 的隱匿性轉移檢出率與同步 DSNB 相當，支持在原發腫瘤治療完成後再進行淋巴結評估的可行性。

---

## DSNB 後復發追蹤

| 項目 | 說明 |
|------|------|
| **復發定義** | DSNB 陰性後在追蹤期出現區域性淋巴結復發 |
| **追蹤期** | 所有復發均發生於術後 **15個月內** |
| **中位追蹤期** | 17.9 個月（範圍：1–69 個月） |

> **臨床重點**：建議 DSNB 術後**密集追蹤至少15個月**，以早期發現可能的區域性復發。

---

## 臨床成效

### NKI 長期追蹤資料

| 時期 | 5年癌症特定存活率（cN0患者） |
|------|--------------------------|
| 1956–1993（預防性雙側 IFLND 時代） | **82%** |
| 1994–2012（DSNB 時代） | **91%** |

> **臨床重點**：DSNB 時代的癌症特定存活率顯著提升，反映了更精確的淋巴結分期與適當治療。

---

## 學習曲線與專業培訓

| 議題 | 建議 |
|------|------|
| **可接受的偽陰性率** | 多數專家認為 **5%–10%** 可接受（考慮其降低的併發症） |
| **乳腺癌經驗借鑒** | DSNB 應由每年執行 **≥20 例** 的外科醫師執行；前20例應有經驗豐富的外科醫師協助 |
| **陰莖癌學習曲線** | 尚未有明確定義；但 pooled data（NKI + SGH）顯示前30例無偽陰性復發 |
| **專家共識** | 建議建立**轉診網絡**集中此罕見癌症的手術治療 |

> **臨床重點**：DSNB 的準確性與**外科醫師的經驗累積**密切相關。單一中心病例數少，建議區域轉診機制。

---

## DSNB 併發症

| 併發症 | 頻率 |
|--------|------|
| **總計** | 4.7%（28/592 個腹股溝窩） |
| 主要併發症 | 感染、**血清囊腫（seroma）**、**淋巴囊腫（lymphocele）**、延遲性出血 |
| **後續 SGH 報告** | 7.6%（20/264 患者）併發症；半數輕微 |

> **臨床重點**：相較於完整 IFLND，DSNB 的併發症率大幅降低，是其臨床價值的重要支撐。

---

## 總結：DSNB 實踐要點

| 要點 | 建議 |
|------|------|
| **目標偽陰性率** | **≤ 5%** |
| **必要元素** | 超音波 + FNA + 放射性追蹤劑 + 藍染料 + γ探頭導引 + 全節點 IHC |
| **術前超音超** | 所有候選患者均應執行 |
| **FNA 陽性** | 直接行 IFLND，不進入 DSNB 流程 |
| **技術標準化** | 全節點 2mm 間隔切片 + IHC |
| **追蹤期** | 至少15個月的密集追蹤 |
| **專業培訓** | 建議建立轉診網絡，集中手術經驗 |
| **多學科合作** | 泌尿科、腫瘤科、影像科、病理科共同參與 |

---

## 腹股溝淋巴結廓清術（IFLND）的適應症

| 適應症 | 說明 |
|--------|------|
| **臨床明顯淋巴結腫大** | 觸診或影像學懷疑轉移 |
| **DSNB 陽性** | 前哨淋巴結發現轉移 |
| **高風險原發腫瘤** | T1G2 以上且 DSNB 不可用或不願執行 |
| **DSNB 偽陰性復發** | DSNB 陰性後出現區域復發 |

> **臨床重點**：IFLND 是陰莖癌淋巴結轉移的金標準治療，但具有相當的手術併發症率（尤其是**淋巴水腫**與**傷口問題**），應選擇性執行。
