## 📖 導讀

本章節奠定泌尿科腫瘤學的分子基礎，從 **去氧核糖核酸（DNA）** 的結構與複製談起，逐步延伸至 **基因轉錄、蛋白質翻譛**，以及 **致癌基因（oncogene）** 與 **腫瘤抑制基因（tumor suppressor gene）** 的失衡如何驅動癌症發生。理解這些分子機制是掌握前列腺癌、膀胱癌及腎細胞癌等泌尿科惡性腫瘤發生原理的關鍵。

## DNA 結構與基本組成

### DNA 雙螺旋結構

**DNA** 是所有生物的遺傳藍圖，由以下三種成分構成：

| 成分 | 說明 |
|------|------|
| **含氮鹼基（Base）** | 嘧啶（Pyrimidine）或嘌呤（Purine） |
| **脫氧核糖（2-Deoxyribose）** | 五碳糖 |
| **磷酸基（Phosphate）** | 構成骨架 |

> **臨床重點**
> - 互補鹼基配對：**腺嘌呤（A）與胸腺嘧啶（T）** 形成 2 個氫鍵；**鳥糞嘌呤（G）與胞嘧啶（C）** 形成 3 個氫鍵。
> - **RNA** 以 **尿嘧啶（U）** 取代胸腺嘧啶（T）。

雙螺旋的兩股為**反向平行（antiparallel）**：一股為 **5′→3′** 方向，另一股為 **3′→5′** 方向。**5′ 端**與 **3′ 端**的命名來自脫氧核糖第五與第三碳原子的編號。

### DNA 複製（Replication）

複製時，雙螺旋的每一股均作為**模板（template）**，合成互補的新股。**DNA 聚合酶（DNA polymerase）** 只能從 **5′→3′** 方向添加核苷酸。

## 基因表現：轉錄與轉譯

### 轉錄（Transcription）

**轉錄**是將 DNA 資訊轉化為蛋白質的第一步：

- **RNA 聚合酶 II（RNA polymerase II）** 合成與 DNA 模板互補的 **訊息 RNA（mRNA）**
- 初始轉錄產物稱為 **前 mRNA（pre-mRNA）**，含有**外顯子（exon）**（編碼區）與**內含子（intron）**（非編碼區）

#### 前 mRNA 的三大修飾

| 修飾類型 | 內容 |
|----------|------|
| **5′ 端加帽（5′ capping）** | 保護 mRNA 並促進核糖體結合 |
| **3′ 端多腺苷酸化（3′ polyadenylation）** | 提升 mRNA 穩定性 |
| **RNA 剪接（RNA splicing）** | 移除內含子，連接外顯子 |

> **臨床重點**
> - **選擇性剪接（Alternative splicing）** 使單一基因可產生多種蛋白質，例如：**雄激素受體（AR）** 的拼接變異體在前列腺癌細胞中可無需配體即活化，導致**去勢抵抗性前列腺癌（castration-resistant prostate cancer）**。

### 轉譯（Translation）

mRNA 在細胞質的**核糖體（ribosome）** 上進行轉譯：

- mRNA 以**三核苷酸為一組的密碼子（codon）** 読み取
- 64 種密碼子對應 20 種胺基酸，密碼子具有**簡併性（degeneracy）**（多個密碼子可編碼同一胺基酸）
- 所有新蛋白質皆以**甲硫胺酸（methionine）** 開頭（起始密碼子為 **AUG**）

#### 蛋白質合成的三階段

| 階段 | 說明 |
|------|------|
| **起始（Initiation）** | 40S 核糖體與 mRNA 結合，形成起始複合物；通常為速率限制步驟 |
| **延長（Elongation）** | 核糖體依密碼子順序移動，胺基酸逐一加入肽鏈，速度最快 |
| **終止（Termination）** | 遇到終止密碼子（UAA、UAG、UGA）時，肽鏈釋放 |

#### 其他重要 RNA

| RNA 類型 | 功能 |
|----------|------|
| **轉運 RNA（tRNA）** |攜帶特定胺基酸，其反密碼子（anticodon）與 mRNA 密碼子互補配對 |
| **核糖體 RNA（rRNA）** | 佔細胞 RNA 約 80%，構成核糖體的主要結構 |

> **臨床重點**
> - **框移突變（Frameshift mutation）**：單一鹼基的插入或缺失會改變讀框，通常導致無功能蛋白質產生。
> - **點突變（Point mutation）**：單一鹼基替換可能不改變胺基酸（沉默突變），也可能造成蛋白質功能改變。

## 分子生物學名詞表（Box 19-1 精選）

| 術語 | 定義 |
|------|------|
| **等位基因（Allele）** | 基因的另一種形式 |
| **雜合子（Heterozygote）** | 攜帶兩個不同等位基因 |
| **同合子（Homozygote）** | 攜帶兩個相同等位基因 |
| **半合子（Hemizygote）** | 因染色體物質丟失僅剩一個基因拷貝 |
| **遺傳雜合性缺失（LOH）** | 基因缺失或突變導致半合子狀態，常見於癌症易感症候群 |
| **表觀遺傳（Epigenetic）** | 非基因序列改變（如甲基化、組蛋白乙醯化）影響基因表現 |
| **微小 RNA（miRNA）** | 21-23 核苷酸的單股 RNA，調控基因表現 |
| **熒光原位雜交（FISH）** | 用螢光標記探針雜交到基因組目標序列，用於定位與計數 |

## 細胞週期與癌症

### 細胞週期控制

細胞週期的精確調控依賴**細胞週期檢查點（cell cycle checkpoint）**：

- **G1/S 檢查點（限制點，R point）**：細胞決定是否進入增殖的關鍵節點
- **S 期**：DNA 合成
- **G2/M 檢查點**：確保 DNA 複製完整性
- **紡錘體檢查點**：確保染色體正確分配

> **臨床重點**
> - 許多 **致癌基因** 與 **腫瘤抑制基因** 的作用即透過干擾細胞週期檢查點與**細胞凋亡（apoptosis）** 路徑，使癌細胞持續分裂增殖。
> - **DNA 損傷檢查點** 喪失會導致基因不穩定性（genetic instability），加速癌症相關基因突變，促進致癌與疾病進展。

### 視網膜母細胞瘤蛋白（RB1）與泌尿生殖系統惡性腫瘤

**RB1 蛋白（pRb）** 是控制 G1 限制點的核心腫瘤抑制因子：

- pRb 正常情況下與 **E2F 轉錄因子** 結合並抑制其活性，阻止細胞進入 S 期
- 當細胞收到增殖信號時，**細胞週期素依賴激酶（CDK）** 磷酸化 pRb，釋放 E2F，允許 DNA 合成基因表現
- RB1 基因突變或功能喪失常見於**視網膜母細胞瘤**、**肺癌**及部分**膀胱癌**

## 關鍵要點摘要

- **DNA** 由互補鹼基對（A-T、G-C）構成雙螺旋，複製為半保留方式
- **基因表現**經歷轉錄（DNA→mRNA）與轉譯（mRNA→蛋白質）兩階段
- **選擇性剪接**使單一基因產生多樣蛋白質，與癌症治療抵抗相關
- **致癌基因**活化或**腫瘤抑制基因**失活是癌症發生兩大核心機制
- **RB1（pRb）** 是 G1 限制點的關鍵調控者，其功能喪失導致細胞週期失控
