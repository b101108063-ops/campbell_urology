# Chapter 37 Tumors of the Penis and Scrotal Pathology

## 📖 導讀

本章系統整理了**陰莖腫瘤（penile tumors）**的癌前病變、病理分類與治療原則。臨床上，**陰莖癌（penile cancer）**以**鱗狀細胞癌（squamous cell carcinoma, SCC）**最為常見，其發生與**人類乳突病毒（HPV）**感染及慢性發炎性皮膚病變密切相關。本章亦涵蓋**陰莖上皮內瘤變（penile intraepithelial neoplasia, PeIN）**、**尖圭濕疣（condyloma acuminatum）**等HPV相關病變，以及**卡波西氏肉瘤（Kaposi sarcoma）**的臨床處置。早期診斷與適當治療是改善預後的關鍵。

---

## 陰莖癌前病變概述

> **臨床重點**：約 **42%** 的陰莖鱗狀細胞癌患者有既存陰莖病變的病史。面對任何陰莖病灶，「不確定時應進行**切片檢查（biopsy）**」。

---

## HPV 非相關性癌前病變

### 皮膚角化表皮囊（Penile Cutaneous Horn）

| 項目 | 說明 |
|------|------|
| **本質** | 罕見，由既存皮膚病變（疣、痣、外傷擦傷或惡性腫瘤）上發展 |
| **外觀** | 上皮過度角化與 cornification，形成實質性突起 |
| **顯微鏡特徵** | 極度**棘皮症（acanthosis）**、**角化不良（dyskeratosis）**、**過度角化（hyperkeratosis）** |
| **HPV關聯** | 與 HPV type 16 相關 |
| **治療** | 手術切除，邊緣包括病變基部正常組織 |
| **復發風險** | 可復發；即使初始組織學為良性，後續切片也可能顯示惡性變化 |

> **臨床重點**：此腫瘤可能演變為癌，或可能是底下已存在癌症的錶現。**必須對切除後的基部進行仔細組織學評估，並進行密切追蹤**。

---

### 假上皮瘤樣 Mica 狀角化性龜頭炎（Pseudoepitheliomatous Micaceous and Keratotic Balanitis）

| 項目 | 說明 |
|------|------|
| **本質** | 罕見，龜頭上的 Mica 狀過度角化生長 |
| **顯微鏡** | 與**疣狀癌（verrucous carcinoma）**相似 |
| **治療** | 切除、**雷射消融（laser ablation）**或**冷凍治療（cryotherapy）** |
| **預後** | 易復發，可能是疣狀癌的早期表現 |
| **特殊注意** | 有報告冷凍治療後發生**陰莖纖維肉瘤（fibrosarcoma）** |

> **臨床重點**：此病變需要**積極治療與密切追蹤**。

---

### 男性**硬化性苔癬（Male Lichen Sclerosus, LS）**（Balanitis Xerotica Obliterans, BXO）

| 項目 | 說明 |
|------|------|
| **本質** | 硬化性苔癬 et atrophicus 的生殖器變異型 |
| **好發人群** | 未割包皮男性；中年男性常見，也可發生於男孩 |
| **臨床表現** | 包皮或龜頭上白色斑塊，常涉及尿道口，有時延伸至舟狀窩 |
| **症狀** | 疼痛、性交困難、搔癢、勃起疼痛、尿道阻塞 |
| **尿道口所見** | 白色、硬化、水腫；可出現龜頭糜爛、龜裂、尿道口狹窄 |
| **顯微鏡特徵** | 表皮萎縮、表皮突（rete pegs）消失、上三分之一真皮膠原均質化、淋巴細胞與組織球浸潤 |

| 統計 | 數值 |
|------|------|
| 與陰莖鱗狀細胞癌同時發現率 | 28%–50% |
| 確診為陰莖癌後續比率 | 2.3%–5.8% |

> **臨床重點**：硬化性苔癬與陰莖鱗狀細胞癌有明確關聯。**即使是治療後多年的 LS 病灶，仍有報告發生癌變**，需終身追蹤。

## HPV 相關性癌前病變與傳染性性病

### 尖圭濕疣（Condyloma Acuminatum）

| 項目 | 說明 |
|------|------|
| **病因** | **HPV type 6, 11**（低風險型） |
| **外觀** | 乳頭瘤樣、生長快速的尖峰狀病灶 |
| **好發部位** | 冠狀溝、包皮內側、尿道口 |
| **傳染性** | 高度傳染，**40%–80% 在治療後6個月內復發**（Dupin, 2004） |
| **與癌症關聯** | 已有報告尖圭濕疣惡性轉化為鱗狀細胞癌 |

#### 治療選項

| 治療方式 | 適應症/說明 |
|----------|-------------|
| **鬼臼毒素（Podophyllin）0.5%** | 小病灶，歷史悠久 |
| **三氯醋酸（TCA）** | 小病灶 |
| **Imiquimod 5% 乳膏** | 目前首選，為免疫調節劑，增強自然殺手細胞活性 |
| **干擾素（Interferon）** | 頑固性、大範圍病變 |
| **Cidofovir 1% 凝膠** | 雙盲試驗完全反應率達 47% |
| **5-氟尿嘧啶（5-FU）乳膏** | 尿道內病變，每週一次共3週 |
| **雷射燒灼** | 廣泛病變 |

> **臨床重點**：**Imiquimod**（免疫調節劑）與**Cidofovir**（抗病毒藥物）均可能影響病毒負荷量，用藥期間需追蹤。

#### HPV 疫苗

| 疫苗 | 覆蓋類型 | 批准性別/年齡 | 預防生殖器病變療效 |
|------|----------|----------------|-------------------|
| **四價疫苗（Gardasil）** | HPV 6, 11, 16, 18 | 女性9-26歲；男性9-26歲 | 65%（男性） |

> **臨床重點**：HPV 疫苗不僅可預防宮頸癌，對男性生殖器疣及陰莖癌也有預防效果。**2010年 FDA 批准用於男性**，建議儘早施打。

## 陰莖上皮內瘤變（Penile Intraepithelial Neoplasia, PeIN）

### 與 HPV 的關聯

| 亞型 | HPV 關聯 |
|------|----------|
| **Queyrat 增殖性紅斑（一型）** | 通常為 HPV 非相關 |
| **鮑文樣丘疹病（Bowenoid papulosis）（多型）** | 與 HPV-16 相關 |

---

### 鮑文樣丘疹病（Bowenoid Papulosis）

| 項目 | 說明 |
|------|------|
| **本質** | 組織學似原位癌，但臨床病程良性 |
| **年齡** | 通常在20-30歲 |
| **病灶特徵** | 陰莖皮膚或女性外陰之多彩丘疹，0.2–3.0 cm，可融合 |
| **部位特點** | 陰莖皮膚病灶多有色素；龜頭病灶多為扁平丘疹 |
| **確診** | 需**切片檢查** |
| **HPV DNA** | 標本作中發現 HPV-16 DNA，支持其致病角色 |
| **組織學** | 符合原位癌的所有組織學標準 |
| **臨床病程** | **始終良性**（Su and Shipley, 1997） |
| **治療** | 電乾燥法、冷凍治療、雷射電灼、局部5-FU乳膏、切除 |

> **臨床重點**：鮑文樣丘疹病組織學上為原位癌，但**臨床過程始終為良性**。診斷靠切片，治療以病灶去除為主，但需追蹤是否有局部復發。

---

## 陰莖原位癌（Carcinoma in Situ of the Penis）

| 別名 | 說明 |
|------|------|
| **Queyrat 增殖性紅斑** | 龜頭原位鱗狀細胞癌的經典描述（1911年 Queyrat 首創） |
| **鮑文氏病（Bowen disease）** | 陰莖軸皮膚原位癌 |

> **臨床重點**：原位癌與侵襲性癌的鑑別在於是否突破基底膜。臨床疑似原位癌時，**切片檢查**是確診與排除侵襲性癌的必要步驟。

---

## 卡波西氏肉瘤（Kaposi Sarcoma, KS）

### 歷史與本質

| 項目 | 說明 |
|------|------|
| **首次描述** | 1872年，**Kaposi** |
| **本質** | 網狀內皮系統腫瘤 |
| **外觀** | 皮膚新生血管病變：疼痛、滲血的凸出丘疹或潰瘍，帶藍紫色變色 |
| **顯微鏡特徵** | 血管形成性；內皮細胞增生；梭形細胞 |

---

### 臨床分類

| 分型 | 說明 | 病程 |
|------|------|------|
| **經典型（Classic KS）** | 無免疫缺陷證據的老年男性（東歐猶太裔或義大利裔） | 惰性，罕見致命 |
| **免疫抑制相關型** | 器官移植後免疫抑制治療者 | 降低免疫抑制劑劑量常可逆轉 |
| **非洲型（African KS）** | 年輕黑人男性 | 可為惰性或侵襲性 |
| **流行性/愛滋相關型（Epidemic/HIV-related KS）** | 愛滋病患者 | 最具侵襲性 |

> **臨床重點**：**愛滋病患者**的免疫缺陷使宿主發生卡波西氏肉瘤的風險增加 **7000倍**（Miles, 1994）。

---

### 各類型陰莖卡波西氏肉瘤的治療原則

| 分型 | 治療原則 |
|------|----------|
| **非流行性（Classic/免疫抑制型）** | 侷限性：手術切除或小範圍電子束放療；廣泛性：部分陰莖切除術 |
| **免疫抑制相關型** | 首先降低/停用免疫抑制劑；如不緩解則手術或放療 |
| **愛滋相關型** | 需全身治療（干擾素、細胞毒性化療）；優先處理基礎免疫缺陷 |

> **臨床重點**：**非流行性卡波西氏肉瘤**如僅限於陰莖，因彌散性器官受累罕見，應積極局部治療。**流行性 KS** 因與 HIV/HHV-8 相關，需多學科综合治療。

---

## 總結：陰莖腫瘤與癌前病變要點

| 病變 | 惡性潛能 | HPV 關聯 | 治療原則 |
|------|----------|----------|----------|
| **皮膚角化表皮囊** | 可惡性變化 | 有（HPV-16） | 手術切除 + 密切追蹤 |
| **假上皮瘤樣 Mica 狀角化性龜頭炎** | 可能是疣狀癌早期 | 無明確 | 積極切除/雷射/冷凍 |
| **硬化性苔癬（BXO）** | 2–6% 惡性轉化 | 無 | 藥物控制 + 終身追蹤 |
| **尖圭濕疣** | 可惡性轉化 | 有（HPV 6,11） | Imiquimod 或 Cidofovir |
| **鮑文樣丘疹病** | 組織學惡性，臨床良性 | 有（HPV-16） | 病灶去除 + 追蹤 |
| **陰莖原位癌** | 高度惡性風險 | 部分相關 | 切除或局部毀損 |
| **卡波西氏肉瘤** | 取決於類型 | HHV-8 | 侷限手術/放療；彌散全身化療 |
