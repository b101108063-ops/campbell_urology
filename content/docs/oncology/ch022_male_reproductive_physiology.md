## 📖 導讀

男性生殖系統的功能依賴**下視丘-腦下垂體-性腺軸（HPG axis）** 的精密調控。**促性腺激素釋放激素（GnRH）** 驅動腦下垂體分泌 **黃體激素（LH）** 與 **濾泡刺激激素（FSH）**，分別作用於睪丸的 **萊氏細胞（Leydig cell）** 與 **塞托利細胞（Sertoli cell）**，以維持正常的**睪固酮（testosterone）** 分泌與**精蟲生成（spermatogenesis）**。理解這些生理機制是診斷男性不孕症、性腺功能低下及年齡相關荷爾蒙變化的基礎。

---

## 下視丘-腦下垂體-性腺軸（HPG Axis）

### 促性腺激素釋放激素（GnRH）

GnRH 由下視丘**脈衝式（pulsatile）** 分泌，調控腦下垂體前葉（腺垂體）分泌 LH 與 FSH。

| 激素 | 主要功能 |
|------|----------|
| **黃體激素（LH）** | 刺激萊氏細胞合成睪固酮 |
| **濾泡刺激激素（FSH）** | 刺激塞托利細胞，支持精蟲生成 |
| **泌乳激素（Prolactin）** | 增加萊氏細胞上 LH 受體濃度，維持高睪固酮；高泌乳激素血症會抑制 GnRH 脈衝 |

### GnRH 分泌的調控因子（Table 22-1）

| 促進 GnRH 分泌（+） | 抑制 GnRH 分泌（−） |
|-------------------|-------------------|
| 吻素（Kisspeptin） | 睪固酮（Testosterone） |
| 褪黑激素（Melatonin） | 雌激素（Estrogen） |
| 瘦素（Leptin） | 抑制素（Inhibin） |

> **臨床重點**
> - **負回饋（Negative feedback）**：睪固酮與雌激素共同抑制 LH 分泌；**抑制素（Inhibin）** 與 **激活素（Activin）** 則調控 FSH 分泌。
> - LH 脈衝頻率約每 24 小時 8-16 次，反映 GnRH 釋放模式；FSH 脈衝約每 1.5 小時一次。

## 睪丸結構與血流

### 睪丸外觀與大小

- 正常睪丸容積：**15-25 mL**（Prader, 1966）
- 長度：**4.5-5.1 cm**
- 白膜（tunica albuginea）含平滑肌細胞，具收縮能力，影響血流與曲細精管液流動

### 組織學架構

| 結構 | 組成與功能 |
|------|-----------|
| **曲細精管（Seminiferous tubules）** | 產生精子的場所，人類約 600-1200 條，總長約 250 公尺 |
| **萊氏細胞（Leydig cells）** | 位於間質組織，負責**類固醇生成（steroidogenesis）**，合成睪固酮 |
| **間質組織（Interstitium）** | 佔睪丸總體積 20-30%，含血管、淋巴管、巨噬細胞、肥大細胞 |

> **臨床重點**
> - **萊氏細胞**於胚胎第 7 週開始分化， initially 由胎盤來源的 **hCG** 刺激，出生後由 **LH**接手。
> - **塞托利細胞（Sertoli cells）**構成**血睪屏障（blood-testis barrier）**，保護精子發生過程。

### 睪丸血液供應

| 血管來源 | 說明 |
|----------|------|
| **內精索動脈（Internal spermatic artery）** | 源自腹主動脈，與蔓狀叢（pampiniform plexus）靜脈相伴行，實現**逆流熱交換** |
| **輸精管动脉（Deferential artery）** | 與內精索动脉間有豐富吻合 |
| **外精索动脉（Cremasteric artery）** | 提睪肌的血供 |

> **臨床重點**
> - 正常睪丸溫度比直腸溫度低 **2-4°C**，依賴**蔓狀叢逆流熱交換**維持。
> - **精索靜脈曲張（Varicocele）**與**隱睪症（Cryptorchidism）**均因失去溫度差異而導致睪丸功能障礙。

## 萊氏細胞與塞托利細胞

### 萊氏細胞（Leydig Cells）

| 特性 | 說明 |
|------|------|
| 來源 | 間質前驅細胞分化 |
| 胚胎激活 | hCG → LH 受體 → 類固醇生成 |
| 成人主要刺激 | LH |
| 主要產物 | **睪固酮（Testosterone）** |

 LH 刺激萊氏細胞的**腺苷酸環化酶（adenylate cyclase）**，增加細胞內 **cAMP**，進而促進膽固醇轉換為** pregnenolone → 睪固酮**。

### 塞托利細胞（Sertoli Cells）

FSH 與塞托利細胞膜上的受體結合，調控：
- **曲細精管生長**（青春期启动）
- **精蟲發生（spermatogenesis）** 的維持
- **血睪屏障**的維持

## 睪固酮與精蟲生成

### 正常睪固酮分泌

- 男性每日約產生 **5 mg/day**
- 以**脈衝式、減幅振盪**模式分泌，具晝夜變異（清晨較高）
- 約 98% 與**性激素結合球蛋白（SHBG）** 或白蛋白結合，2% 為游離態（游離睪固酮為活性形式）

### 精蟲發生（Spermatogenesis）

精子在曲細精管內由**精原細胞（spermatogonia）** 依序發育為：
**精原細胞 → 初級精母細胞 → 次級精母細胞 → 精子細胞 → 精子**

FSH 與睪固酮共同調控此過程；任何一個因素受損均可導致**無精子症（azoospermia）** 或**寡精子症（oligospermia）**。

> **臨床重點**
> - **FSH** 在成人主要維持定量正常精子產生；FSH 升高可反映**塞托利細胞功能障礙**或精子輸出減少。
> - **泌乳激素**正常可維持性慾；**高泌乳激素血症**會消除 GnRH 脈衝，導致性腺功能減退。

## 年齡與 HPG 軸

### 男性更年期（Andropause / PADAM）

男性年齡增長帶來的變化包括：

| 變化 | 說明 |
|------|------|
| 睪固酮下降 | 第七十年時血漿睪固酮約年輕男性 65% |
| FSH 升高 | 老年男性平均值約年輕男性 3 倍 |
| 萊氏細胞減少 | 睪固酮合成能力下降 |
| GnRH 脈衝不規律 | 刺激效力降低 |

> **臨床重點**
> - **部分雄激素缺乏（PADAM）**：又稱男性更年期，表現為性慾減退、情緒低落、肌肉量減少、骨質疏鬆。
> - 老年男性的**睪固酮分泌晝夜變異消失**，且對 GnRH 刺激的回饋反應減弱。

## 關鍵要點摘要

- HPG 軸以**脈衝式 GnRH 分泌**為核心，LH 與 FSH 由腦下垂體依序釋放
- **負回饋**調控：睪固酮抑制 LH，抑制素抑制 FSH
- 睪丸兩大功能區：**間質（萊氏細胞→睪固酮）** 與 **曲細精管（精子生成）**
- 睪丸血流透過**蔓狀叢逆流熱交換**維持低溫環境，為精子生成必備條件
- 男性老化導致**睪固酮下降、FSH 升高、GnRH 脈衝失規律**，合稱 PADAM
