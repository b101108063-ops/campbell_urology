# Chapter 36 Complications of Urologic Cancer Treatment

## 📖 導讀

本章節聚焦於**腹腔鏡與機器人輔助後腹腔淋巴結廓清術（L-RPLND / RA-RPLND）**治療睪丸腫瘤的手術技術、適應症及併發症處理。傳統上，**後腹腔淋巴結廓清術（RPLND）**是睪丸非精原細胞瘤（NSGCT）的重要治療手段，微創技術的引入在保持腫瘤控制效果的同時，顯著降低了手術併發症率。本章詳細介紹了手術入路、**神經保留技術（nerve-sparing technique）**及術中血管損傷的處理原則。

---

## 適應症與手術時機

### 睪丸腫瘤的淋巴轉移特性

| 臨床分期 | 定義 | L-RPLND 適用性 |
|----------|------|---------------|
| **臨床分期 I（CSI）** | 無遠處轉移，僅有睪丸腫瘤 | 標準適應症 |
| **臨床分期 IIA（CSIIA）** | 後腹腔淋巴結 < 2cm | 標準適應症 |
| **臨床分期 IIB（CSIIB）** | 後腹腔淋巴結 2-5cm | 需評估 |
| **化療後殘留病灶** | 化療後小型殘留腫瘤 | 有經驗中心可考慮 |

> **臨床重點**：術前**血清腫瘤標記（serum tumor markers）**陰性是必要條件。如標記升高，應優先考慮化療而非手術。

---

## 手術演進：分期性與治療性 L-RPLND

### 早期「分期性」L-RPLND 的爭議

| 問題 | 說明 |
|------|------|
| **未進行主血管後方剝離** | 早期僅做主血管前方淋巴結取樣 |
| **主動中止條件** | 術中發現淋巴結陽性即中止手術，轉化療 |
| **理論基礎** | 認為主血管後方不存在孤立性陽性淋巴結 |
| **批評** | 繪圖研究顯示淋巴結轉移具有多灶性與對側性（Ray et al, 1974; Donohue et al, 1982） |

> **臨床重點**：「分期性L-RPLND」因可能导致过度化疗及忽略多灶性疾病，已被有經驗中心放棄。

---

### 現代「治療性」L-RPLND 的原則

**所有 NSGCT 患者的 L-RPLND 均執行與開放手術完全相同的解剖模板：**

| 原則 | 說明 |
|------|------|
| **廣泛模板（Wide template）** | 左右側均需廓清 |
| **完整切除** | 包括主動脈後方與下腔靜脈後方組織 |
| **雙側廓清** | 部分中心常規執行，部分中心僅在淋巴結陽性時執行 |
| **腫瘤學原則優先** | 不因減少併發症或保留射精功能而犧牲腫瘤切除完整性 |

> **臨床重點**：的手術模板應根據腫瘤側別與術中發現調整，切緣不應因技術限制而妥协。

---

## 機器人輔助 RPLND 的發展

### 技術背景

| 項目 | 說明 |
|------|------|
| **技術優勢** | 機器人平台提高了複雜腹腔鏡操作的精確度 |
| **已證實效益** | 增加**部分腎切除術（partial nephrectomy）**使用率（Patel et al, 2013） |
| **目前階段** | 小型病例系列，證實安全與可行性 |
| **主要障礙** | 學習曲線陡峭，需要豐富的腹腔鏡與血管手術經驗 |

---

## 術前準備

### 患者 counseling 必備內容

| 項目 | 說明 |
|------|------|
| **替代治療選項** | 開放RPLND、化療、監測 |
| **出血風險** | 可能需要輸血 |
| **鄰近器官損傷** | 肝、腸、膽囊、腎、輸尿管、胰、主要血管 |
| **姿勢相關併發症** | 骨科、神經或肺部併發症 |
| **中轉開放** | 可能因併發症或切除不完全而中轉 |
| **生育考量** | 有生育需求者術前應諮詢精子庫 |

> **臨床重點**：對有生育意願的患者，術前**精子庫（sperm banking）**諮詢是不可省略的一環。

---

### 特殊術前準備

| 準備項目 | 理由 |
|----------|------|
| **低脂飲食（術前1-2週）** | 減少**乳糜腹（chylous ascites）**風險（證據尚不確定） |
| **機械性腸道準備（前日下午）** | 排空腸道 |
| **術前一晚午夜後禁食** | 減少胃內容物 |
| **預防性抗生素** | 減少手術部位感染 |
| **下肢靜脈血栓預防裝置** | 減少深靜脈血栓（DVT）風險 |

---

## 手術技術要點

### 手術入路選擇

| 入路 | 優點 | 缺點 |
|------|------|------|
| **經腹膜入路（Transperitoneal）** | 空間大、熟悉度高、易做雙側廓清 | 需移動內臟 |
| **腹膜外入路（Extraperitoneal）** | 直接進入後腹腔 | 空間有限、雙側廓清困難 |

> **臨床重點**：大多數中心偏好**經腹膜入路**，因其提供更大的工作空間並便於必要時擴展至對側。

---

### 體位與穿刺孔配置

| 項目 | 建議 |
|------|------|
| **體位** | **仰臥位**（優於45度側臥位），便於中轉雙側廓清 |
| **墊墊保護** | 所有受壓點充分墊墊，避免神經損傷或**橫紋肌溶解（rhabdomyolysis）** |
| **カメラ孔** | 通常位於肚臍 |
| **操作孔** | 8mm 機器人孔與 12mm 助手孔 |

> **臨床重點**：的手術時間可能較長，**橫紋肌溶解**為已知併發症，術前應充分墊墊患者。

---

### 重要器械與材料

| 器械/材料 | 用途 |
|-----------|------|
| **無創抓取器** | 鈍性剝離 |
| **剪刀、鈦夾施放器** | 切割與夾閉 |
| **沖洗/吸引裝置** | 保持術野清晰 |
| **腹腔鏡撐開器（paddle retractor）** | 內側牽拉腸道 |
| **止血夾（Hem-o-lok）** | 不透射線，減少術後影像偽影 |
| **凝血酶膠（FLoSeal）** | 血管損傷輔助止血 |
| **氧化纖維素（Surgicel）** | 淋巴管渗漏填塞 |

> **臨床重點**：**超聲波超聲刀與雙極電燒**在密封大的淋巴管時可能不夠可靠，應謹慎使用。

## 「Split and Roll」技術

此技術為 RPLND 的核心剝離方法：

### 步驟分解

| 步驟 | 內容 |
|------|------|
| **1. 切開覆蓋下腔靜脈的組織** | 啟動「split and roll」 |
| **2. 十二指腸向內側反折** | 顯露**精索靜脈（spermatic vein）**殘端 |
| **3. 沿IVC「split」組織** | 向內側滾動，暴露靜脈後方空間 |
| **4. 辨識並處理腰靜脈** | 夾閉、離斷，允許後方組織分離 |
| **5. 釋放與脊柱附著** | 將組織從脊柱分離，向外側取出 |
| **6. 識別主動脈** | 同法處理主動脈前方組織至腸繫膜下動脈（IMA）水準 |
| **7. 剝離主動脈後方** | 必要時控制腰動脈以增加活動度 |
| **8. 完整移除主動靜脈間淋巴結** | 完成廓清 |

> **臨床重點**：處理腰血管時，應在主血管側留足夠殘端（長 stump），以便萬一鈦夾鬆脫時可以抓持控制。若腰血管縮回至髂腰肌，可用壓迫或深部肌肉的「8」字縫合控制。

---

## 血管損傷處理

| 損傷類型 | 第一線處理 | 進一步處理 |
|----------|-----------|-----------|
| **下腔靜脈/主動脈裂傷** | 直接壓迫 | 持續出血則進行體內縫合修復 |
| **腰血管回縮** | 壓迫 | 深部「8」字縫合於肌肉 |
| **靜脈滲漏** | 輔助止血劑（FloSeal） | 必要時縫合 |

> **臨床重點**：多數血管損傷**不需要中轉開放手術**。直接壓迫通常可控制過度出血，配合輔助止血劑可在腹腔鏡下完成修復。

---

## 神經保留技術（Nerve-Sparing）

### 必須保留的神經結構

| 結構 | 位置 | 功能 |
|------|------|------|
| **交感神經鏈（Sympathetic chain）** | 主動脈/IVC後外側 | 順行性射精 |
| **下腹神經叢（Hypogastric plexus）** | 主動脈分叉前方 | 順行性射精 |
| **節後神經纖維（Postganglionic fibers）** | 從交感鏈跨過主動脈至下腹神經叢 | 順行性射精 |

### 識別要點

- 右側：節後纖維在IVC後方最易識別，跨越主動脈前方進入下腹神經叢
- **發出點恆定位於腰靜脈附近**，因此處理腰靜脈時需特別小心
- 神經組織相較淋巴組織更緻密纖維化，有經驗者不難分辨

> **臨床重點**：神經保留技術應在術前（前瞻性）而非術後（回顧性）規劃。術中應系統性辨識並保留這些結構，以維持術後**順行性射精（antegrade ejaculation）**功能。

---

## 術後康復

| 項目 | 建議 |
|------|------|
| **鼻胃管** | 通常不需要，拔管 |
| **進食** | 手術當晚可下床活動、開始流質飲食 |
| **出院時間** | 多數患者術後第1天可出院 |
| **飲食** | 部分外科醫師建議術後低脂飲食1-2週 |

> **臨床重點**：術後**心動過速**可能因交感神經刺激所致，應注意排除其他原因（如出血、感染）。

---

## 總結

| 重點 | 內容 |
|------|------|
| **微創RPLND** | 技術要求高，應由經驗豐富的腹腔鏡外科醫師執行 |
| **完整模板** | 現代做法是完全複製開放手術的切除範圍 |
| **機器人輔助** | 安全性與可行性已獲初步證實 |
| **神經保留** | 前瞻性識別並保留交感神經鏈與下腹神經叢 |
| **血管損傷** | 多數可在腹腔鏡下處理，中轉開放非首選 |
| **個體化決策** | 根據腫瘤側別、分期、術中發現調整手術範圍 |
