## 📖 導讀

泌尿科內視鏡是泌尿科醫師最重要的工具之一，廣泛應用於診斷與治療。本章節介紹**膀胱尿道鏡**（cystourethroscope）的種類與規格、**軟式**與**硬式**內視鏡的比較適應症，以及門診內視鏡的臨床應用。內視鏡操作雖屬微創，但並非零風險；術前評估、抗生素預防、患者舒適度優化都是成功內視鏡檢查的重要環節。熟悉這些原則，是每一位泌尿科住院醫師與主治醫師的必備技能。

---

## 膀胱尿道鏡檢查的適應症

### 門診內視鏡常見適應症

| 適應症類別 | 說明 |
|-----------|-----|
| **血尿評估** | 顯微鏡下與肉眼血尿 |
| **泌尿道感染** | 反覆性泌尿道感染 |
| **下泌尿道症狀** | 阻塞性或刺激性排尿症狀 |
| **攝護腺肥大** | 阻塞症狀評估 |
| **泌尿道腫瘤監測** | **泌尿道上皮癌**（urothelial carcinoma）術後追蹤 |
| **尿道狹窄** | 診斷與治療 |
| **膀胱結石/異物** | 可在門診處理 |

> **臨床重點** 門診膀胱尿道鏡不僅是診斷工具，也可進行**淺表腫瘤切片與電燒灼**（biopsy and fulguration）、**輸尿管支架置換**，以及**選擇性輸尿管導管置入**做尿路 cytology 或逆行性腎盂造影。

## 內視鏡器械規格

### 法式尺碼（French Gauge, Fr）

> **臨床重點** **1 Fr = 1/3 mm**（周長）。膀胱尿道鏡尺碼範圍通常為 **15-26 Fr**。尺碼越大，工作通道與灌流空間越大，但患者不適感也增加。

| 尺碼應用 | 說明 |
|---------|-----|
| **15-17 Fr** | 診斷用首選，患者舒適度佳 |
| **18-22 Fr** | 治療性操作，灌流較佳 |
| **更大尺碼** | 複雜治療程序 |

## 軟式與硬式膀胱尿道鏡比較

### 硬式膀胱尿道鏡（Rigid Cystoscope）

| 特性 | 說明 |
|-----|-----|
| 光學系統 | **Hopkins rod-lens** 光學系統，影像清晰度優於光纖 |
| 灌流 | 灌流速度快，視野佳 |
| 工作通道 | 較大，可容納多樣器械 |
| 控制性 | 剛性設計，單手操作穩定性高 |
| 鏡頭角度 | 0°、12°（尿道）、25°-30°（治療常用）、70°-120°（膀胱全景） |

**橋樑（Bridge）類型：**

| 橋樑類型 | 功能 |
|---------|-----|
| 診斷橋（無工作通道） | 純視鏡檢查 |
| 治療橋（單或雙通道） | 可通過器械 |
| **Albarran 橋** | 帶控制桿，可偏轉通道內導管，利於輸尿管開口置管 |

### 軟式膀胱尿道鏡（Flexible Cystoscope）

| 特性 | 說明 |
|-----|-----|
| 尺碼 | 約 **16-17 Fr** |
| 視野角 | 約 120° |
| 尖端偏轉 | **120-210 度**，可主動控制 |
| 姿勢要求 | 不需截石位（lithotomy position） |
| 患者舒適度 | 較佳，適合門診 |

> **臨床重點** 軟式膀胱尿道鏡的主要限制是**工作通道通常只有一個**，灌流與器械通道共用。尖端偏轉方向有「同向」（intuitive）與「反向」（counterintuitive）兩種，操作前需確認型號特性。

### 比較總覽

| 特性 | 硬式內視鏡 | 軟式內視鏡 |
|-----|----------|----------|
| 影像清晰度 | 較佳（rod-lens） | 稍遜（光纖） |
| 患者舒適度 | 較差 | 較佳 |
| 器械相容性 | 多樣化 | 有限 |
| 膀胱頸/前列腺評估 | 需更換角度鏡 | 主動偏轉較方便 |
| 學習曲線 | 較陡 | 較平緩 |

## 內視鏡影像系統

### 傳統類比系統

| 組件 | 功能 |
|-----|-----|
| **CCD 晶片**（位於鏡頭） | 將光學影像轉換為電壓波形 |
| **影像處理器** | 類比電壓波形轉為數位視訊訊號 |
| **監視器** | 顯示影像 |

### 數位視訊內視鏡系統

> **臨床重點** 數位系統將 **CCD 晶片直接置於內視鏡尖端**，光學影像立即轉換為電氣訊號，無需內部光纖或外部鏡頭，影像品質更佳且無光纖損耗問題。

## 軟式膀胱尿道鏡的手術步驟

### 患者準備

> **臨床重點** 術前需取得**知情同意**、完成**尿液分析**與**尿液培養**。所有泌尿道感染必須在檢查前治療，以降低菌血症與敗血症風險。

### 進鏡技巧

#### 女性患者

- 硬式鏡：可用 sheath obturator 直接盲插
- 軟式鏡：可如 **Foley 導尿管**般直接置入，主動偏轉調整方向
- 進鏡後通常需向前上方調整方向進入膀胱

#### 男性患者

| 步驟 | 技巧 |
|-----|-----|
| 陰莖伸展 | 拉直陰莖以伸直尿道 |
| 軟式鏡握法 | 第四、五指夾住陰莖基部，拇指與食指推進 |
| 硬式鏡握法 | 五指握住陰莖 |
| 通過膜性尿道 | 囑患者放鬆（此為最不適階段） |

> **臨床重點** 通過**膜性尿道**（membranous urethra）是軟式膀胱尿道鏡檢查中男性最不適的階段。研究顯示手動加壓灌流袋可顯著降低此階段疼痛（疼痛指數 1.38 vs 3.00）。

**陰莖角度：** 進鏡時將陰莖與腹壁呈 **45-90 度角**，通過膜性尿道後向下傾斜進入膀胱。

### 系統性膀胱檢查

進入金屬尿道與前列腺尿道後需確認：
- **精阜**（verumontanum）與**攝護腺**大小
- **輸尿管間脊**（interureteric ridge）
- **膀胱三角區**（trigone）
- 膀胱黏膜完整性与血管分佈

## 患者舒適度優化

### 研究實證的舒適度提升方法

| 介入方法 | 效果 |
|---------|-----|
| **灌流袋手動加壓** | 通過膜性尿道時疼痛顯著降低（3.00→1.38） |
| **允許患者觀看監視器** | 疼痛降低（23→14 mm VAS）、術後心率降低 |
| **古典音樂** | 疼痛降低、滿意度提高、術後心率與血壓降低 |

> **臨床重點** 男性患者讓其觀看軟式膀胱尿道鏡檢查過程，可顯著降低焦慮與疼痛。這可能是因為賦予患者**控制感**與**了解感**，減少了對未知的不安。

### 尿道擴張

輕度**尿道口狹窄**可用金屬擴張器逐級擴張，目標為比預計使用內視鏡尺碼大 **2 Fr**。

## 特殊內視鏡技術

### 逆行性腎盂造影（Retrograde Pyelography）

通過內視鏡工作通道置入輸尿管導管，逆行注射對比劑顯影上泌尿道。

> **臨床重點** 對比劑過敏或無法接受靜脈注射對比劑（如腎功能不全）患者，可以此方法評估上泌尿道。

### 選擇性尿路細胞學

透過輸尿管導管沖洗上泌尿道，收集細胞學標本，提高**上泌尿道上皮癌**的偵測敏感度。

### 刷拭切片（Brush Biopsy）

> **臨床重點** 逆行性腎盂造影時可搭配**刷拭切片**取得組織學標本，用於上泌尿道狹窄的惡性腫瘤評估。

## 上泌尿道上皮癌監測

| 方法 | 臨床應用 |
|-----|---------|
| 選擇性輸尿管導管置入 | 逆行性尿路細胞學 |
| 上游灌流沖洗 | 提高細胞學敏感度 |
| 刷拭切片 | 組織學確診 |

## 內視鏡術後處置

| 項目 | 建議 |
|-----|-----|
| 術後血尿 | 常見，通常自限性 |
| 術後感染 | 術前尿液培養陽性者，術後追蹤 |
| 輸尿管支架留置 | 複雜操作後可留置，門診追蹤拔除 |
| 患者指導 | 術後多飲水，觀察排尿與疼痛變化 |
