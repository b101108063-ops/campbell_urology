# 尿路感染

📖 **導讀**：尿路感染（UTI）是泌尿科最常見的感染性疾病，從單純性膀胱炎到危及生命的急性腎盂腎炎，嚴重程度差異甚大。兒童 UTI 需特別注意，因為可能隱藏先天性泌尿道異常（如膀胱輸尿管逆流）。診斷需結合臨床症狀和尿液分析，最終以尿液培養確診。

---

## 定義與分類

### 解剖位置分類

| 類型 | 位置 | 症狀 |
|---|---|---|
| **尿道炎**（Urethritis） | 尿道 | 尿道分泌物、排尿疼痛 |
| **膀胱炎**（Cystitis） | 膀胱 | 頻尿、急尿、排尿疼痛、血尿 |
| **腎盂腎炎**（Pyelonephritis） | 腎臟 | 發燒、腰痛、噁心、嘔吐 |

### 單純性 vs 複雜性 UTI

| 類型 | 定義 |
|---|---|
| **單純性**（Uncomplicated） | 健康非孕婦女性、沒有結構或功能異常 |
| **複雜性**（Complicated） | 男性、孕婦、兒童、泌尿道結構異常、免疫抑制、導尿管相關、醫院內感染 |

---

## 流行病學

| 族群 | 終生發生率 |
|---|---|
| 女性 | 50-60% |
| 男性 | 12%（一生中） |
| 兒童 | 2-5% |

> **臨床重點**：**女性 UTI 發生率遠高於男性**，是因為女性尿道較短（約 4 cm）且開口接近肛門，細菌容易逆行性上行至膀胱。

---

## 致病菌

| 致病菌 | 佔比 | 說明 |
|---|---|---|
| **E. coli**（大腸桿菌） | 75-95% | 最常見，多為腸道菌叢逆行 |
| **Klebsiella pneumoniae** | 5-15% | 住院患者常見 |
| **Proteus mirabilis** | 5-10% | 與結石形成相關 |
| **Enterococcus faecalis** | 2-5% | 醫院感染常見 |
| **Pseudomonas aeruginosa** | 1-2% | 導尿管相關 |
| **Staphylococcus saprophyticus** | 1-2% | 年輕女性性行為後 |

---

## 發病機制

### 逆行性感染途徑
```
會陰部 → 尿道口 → 尿道 → 膀胱（ cystitis）
    ↓
進一步上行至輸尿管 → 腎臟（pyelonephritis）
```

### 致病機轉
1. **黏附因子**（Adhesins）：大腸桿菌表面的 **P fimbriae** 和 **Type 1 pili** 附著於泌尿道上皮
2. **鞭毛**（Flagella）：幫助細菌移動
3. **尿素酶**（Urease）：Proteus 產生，使尿液鹼化，促進結石形成

---

## 診斷

### 臨床症狀

| 類型 | 典型症狀 |
|---|---|
| **膀胱炎** | 頻尿、急尿、排尿困難（dysuria）、恥骨上疼痛、血尿 |
| **腎盂腎炎** | 發燒（> 38°C）、寒顫、腰痛（Costovertebral angle tenderness）、噁心、嘔吐 |

### 尿液分析（Urinalysis）

| 發現 | 意義 |
|---|---|
| **膿尿**（Pyuria）：WBC > 10/hpf | 發炎 |
| ** Bacteria**（bacteriuria） | 感染 |
| **血尿**（Hematuria） | 常見 |
| **Nitrite 阳性** | G-桿菌（如 E. coli）將 nitrates 轉化為 nitrites |
| **Leukocyte esterase** | 存在 WBC |

### 尿液培養（Urine Culture）

> **確診標準**：

| 取樣方式 | 阳性標準 |
|---|---|
| **恥骨上穿刺**（Suprapubic aspiration） | 任何菌量 |
| **導尿管取樣**（Catheterization） | ≥ 10² CFU/mL |
| **中段尿**（Mid-stream） | 女性 ≥ 10³ CFU/mL；男性 ≥ 10² CFU/mL |

### 影像檢查

| 檢查 | 適應症 |
|---|---|
| 超音波 | 懷疑結構異常、結石、腎積水 |
| CT | 懷疑腎膿瘍、複雜性腎盂腎炎 |
| DMSA scan | 評估腎盂腎炎後的腎皮質缺損 |

---

## 治療

### 膀胱炎

| 治療選項 | 療程 |
|---|---|
| **Nitrofurantoin**（呋喃妥因） | 5-7 天 |
| **TMP-SMX**（有過敏或已知感受性才用） | 3 天 |
| **Fosfomycin** | 單次劑量 |
| **Fluoroquinolones**（左氧氟沙星） | 3 天（非一線） |

> **臨床重點**：**Fluoroquinolones 不應作為單純性膀胱炎的一線用藥**（考量抗藥性和副作用）。

### 腎盂腎炎

| 病情 | 治療 |
|---|---|
| **輕度**（可口服） | 門診口服抗生素 7-14 天 |
| **中重度**（門診治療失敗、發燒 > 39°C、噁心嘔吐） | 靜脈抗生素 2-4 天後改口服 |

| 抗生素選擇 | 說明 |
|---|---|
| **Ceftriaxone** | 靜脈，广效 |
| **Ciprofloxacin** | 口服或靜脈 |
| **Piperacillin-tazobactam** | 住院患者 |
| **Carbapenems** | 抗藥性菌種考慮 |

### 復發性 UTI（Recurrent UTI）

定義：6 個月內 ≥ 2 次，或 12 個月內 ≥ 3 次。

| 預防策略 | 說明 |
|---|---|
| **低劑量預防性抗生素**（Post-coital prophylaxis） | 性行為後服用單次劑量 |
| **每日低劑量預防** | 持續 6-12 個月 |
| **陰道內雌激素**（停經後女性） | 恢復陰道菌叢 |
| **蔓越莓萃取物**（Cranberry） | 預防性輔助 |

## 特殊族群的 UTI

### 孕婦 UTI

| 特點 | 說明 |
|---|---|
| 無症狀菌尿（Asymptomatic bacteriuria） | 發生率 2-10%，需治療（避免腎盂腎炎） |
| 膀胱炎 | 需治療（安全抗生素：磷黴素、Nitrofurantoin、 Cephalexin） |
| 腎盂腎炎 | 住院靜脈抗生素 |

> **臨床重點**：**Fluoroquinolones 和 TMP-SMX 應避免用於孕婦**（TMP-SMX 為妊娠 C 類藥物，特別是早期妊娠）。

### 兒童 UTI

> **臨床重點**：**2 個月至 2 歲的發燒性 UTI 兒童，所有個案都應接受泌尿道超聲波檢查**（排除結構異常如水腎、膀胱輸尿管逆流）。

| 檢查 | 目的 |
|---|---|
| 超音波 | 評估腎臟大小、水腎、結石 |
| VCUG | 排除膀胱輸尿管逆流（VUR） |

---

## 抗藥性問題

| 抗藥性趨勢 | 說明 |
|---|---|
| **ESBL-producing E. coli** | 對所有 β-lactams 抗藥，需用 Carbapenems |
| **Fluoroquinolone resistance** | 亞洲區域抗藥率高達 30-50% |
| **UTI 門診經驗性治療** | 需參考當地抗藥性統計選擇抗生素 |

---

## 總結

| 重點 | 內容 |
|---|---|
| **最常見致病菌** | E. coli（75-95%） |
| **診斷標準** | 尿液培養確診 |
| **膀胱炎治療** | 3-7 天口服抗生素 |
| **腎盂腎炎治療** | 7-14 天療程，重度需靜脈抗生素 |
| **復發預防** | 低劑量預防性抗生素 |
| **特殊族群** | 孕婦避免 fluoroquinolones；兒童需排除結構異常 |
