# Chapter 13 Inflammatory and Pain Conditions of the Male Genitourinary Tract

## 流行病學重點 (KEY POINTS: EPIDEMIOLOGY)

> **臨床重點**
> - 18 歲以上男性中，有 **2% 至 12%** 目前有攝護腺炎症狀（prostatitis-like symptoms）
> - 男性中有 **7%** 患有慢性攝護腺炎或慢性骨盆腔疼痛症候群（chronic prostatitis/chronic pelvic pain syndrome, CP/CPPS）
> - 攝護腺炎佔男性泌尿科門診就診的 **6% 至 8%**

---

## 組織病理學 (Histopathology)

對於病理學家而言，**攝護腺炎（prostatitis）** 的定義是攝護腺實質內發炎細胞數量增加。攝護腺發炎可能見於或不明顯於被診斷為攝護腺炎、**良性攝護腺肥大（BPH）** 或**攝護腺癌（prostate cancer）** 的患者，並在多達 44% 的無明確攝護腺疾病男性屍檢組織樣本中發現。

### 發炎細胞浸潤類型

| 類型 | 位置 | 臨床意義 |
|------|------|----------|
| **淋巴細胞浸潤（lymphocytic infiltrate）** | 攝護腺腺泡旁的間質 | 最常見的發炎模式 |
| **緻密淋巴結節（dense lymphoid nodules）** | 間質中 | 反映慢性發炎程度 |
| **腺上皮內發炎細胞** | 腺體上皮及管腔內 | 可見於無症狀患者 |
| **嗜中性球及巨噬細胞** | 管腔內 | 通常與感染相關 |

> **臨床重點**
> 攝護腺發炎的強度差異很大，從散在的淋巴細胞到緻密的淋巴樣結節。

### 其他病理發現

- **Corpora amylacea**：由攝護腺分泌液沉積在脫落上皮細胞或其他刺激物周圍形成，通常與發炎無關，除非大到足以擴張或阻塞攝護腺腺體。
- **攝護腺結石（Prostatic calculi）**：可能透過阻塞中央攝護腺導管促進發炎，或提供細菌存活於宿主防禦和抗生素中的核心。
- **肉芽腫性攝護腺炎（Granulomatous prostatitis）**：以豐富組織球、淋巴細胞及漿細胞混合的緻密小葉狀發炎浸潤為特徵。常見於手術後或 **BCG 療法（bacille Calmette-Guérin therapy）** 後，系統性結核病患者則罕見。

## 微生物學 (Microbiology)

### 革蘭氏陰性尿道病原體 (Gram-Negative Uropathogens)

**急性細菌性攝護腺炎（Acute bacterial prostatitis）** 是攝護腺腺體的泛化感染，與下泌尿道感染（UTI）及全身性敗血症相關。

**慢性細菌性攝護腺炎（Chronic bacterial prostatitis）** 與復發性下泌尿道感染（如膀胱炎）相關，起因於居住在攝護腺內的局部病原菌。

| 病原體 | 感染比例 | 備註 |
|--------|----------|------|
| **Escherichia coli（大腸桿菌）** | 65%–80% | 最常見原因 |
| **Pseudomonas aeruginosa（綠膿桿菌）** | 10%–15% | 伺機性感染 |
| **Serratia species（沙雷氏菌）** | | |
| **Klebsiella species（克雷伯氏菌）** | | |
| **Enterobacter aerogenes** | | |

> **臨床重點**
> 經攝護腺切片後的急性細菌性攝護腺炎病原體，與自發性急性攝護腺炎的病原體相比，顯示不同的毒力及抗藥性模式（如對 quinolones 和 cephalosporins 的抗藥性）。

### 泌尿毒力因子 (Urovirulence Factors)

| 毒力因子 | 作用機制 |
|----------|----------|
| **P fimbriae（P 型線毛）** | 與泌尿道上皮受體結合，促進上行感染及建立深部攝護腺感染 |
| **Type 1 fimbria（第一型線毛）** | 又稱 mannose-sensitive fimbria，協助 E. coli 殖民下泌尿路 |
| **Biofilm（生物膜）** | 細菌聚集形成，保護細菌在抗生素治療後仍能存活於攝護腺 |

### 革蘭氏陽性細菌 (Gram-Positive Bacteria)

| 病原體 | 感染比例 |
|--------|----------|
| **Enterococci（腸球菌）** | 5%–10% |

> **臨床重點**
> 其他在前尿道共生的革蘭氏陽性菌角色仍有爭議。

### 難以培養的微生物 (Nonculturable Microorganisms)

傳統培養技術在識別攝護腺炎相關病原微生物方面有重大限制。細菌可能以聚集的 **biofilm（生物膜）** 形式黏附在攝護腺導管壁上，或存在於攝護腺內阻塞的導管中。

> **臨床重點**
> 研究顯示 60% 被診斷為慢性細菌性攝護腺炎的患者，在進展到 EPS 培養無菌但症狀持續後，前列腺切片培養仍顯示與初始病原菌相似的細菌陽性。

**Nanobacteria（奈米菌）** 是難以分離和培養的生物，可能與某些慢性泌尿科疾病（包括 CP）相關。

## 攝護腺宿主防禦改變 (Altered Prostate Host Defense)

### 危險因子

允許細菌殖民或感染攝護腺的危險因子包括：

| 危險因子 | 說明 |
|----------|------|
| **攝護腺內導管逆流（intraprostatic ductal reflux）** | 尿液逆流入導管 |
| **包莖（phimosis）** | 衛生問題 |
| **特定血型** | 遺傳易感性 |
| **無保護性陰莖肛交** | 病原菌引入 |
| **泌尿道感染（UTI）** | 病原菌來源 |
| **急性副睪炎（acute epididymitis）** | 鄰近感染 |
| **留置導尿管** | 醫源性 |
| **經尿道手術** | 尤其在未治療的感染尿液下 |

### 分泌功能障礙

**攝護腺分泌功能障礙** 的特徵是攝護腺分泌物成分改變：

| 減少 | 增加 |
|------|------|
| Fructose（果糖） | pH 值 |
| Citric acid（檸檬酸） | Lactate dehydrogenase-5/1 比值 |
| Acid phosphatase（酸性磷酸酶） | Ceruloplasmin（載銅蛋白） |
| Zinc（鋅）、Magnesium（鎂）、Calcium（鈣） | Complement C3 |
| Prostatic antibacterial factor（攝護腺抗菌因子） | |

> **臨床重點**
> 攝護腺抗菌因子減少可能降低攝護腺液本身的抗菌活性，而鹼性 pH 值可能阻礙某些鹼性抗菌藥物擴散進入攝護腺組織和液體。
