## 📖 導讀

外生殖器皮膚疾病涵蓋範圍廣泛，從良性發炎性皮膚病到癌前期病變皆屬此範疇。本章節系統性地介紹門診泌尿科與性病門診中最常見的外生殖器皮膚疾病，包括：**過敏性皮膚炎**、**牛皮癬**、**反應性關節炎**、**硬化性苔癬**、**扁平苔癬**、**乾癬**、**多形性紅斑**等，並涵蓋各疾病的治療原則與藥物選擇。

---

## 過敏性（濕疹樣）皮膚炎

### 過敏性皮膚炎的鑑別診斷

> **臨床重點**
> - **過敏性接觸性皮膚炎**由過敏原介導，表現為**瘙癢性皮膚病變**
> - 常見過敏原包括：**鎳**（常見於皮帶扣）、香料、防腐劑、橡膠添加劑
> - 過敏原可能同時存在於尿布、私處洗劑、藥膏中

## 牛皮癬（Psoriasis）

### 臨床特徵

- **膿皰型牛皮癬**（Pustular psoriasis）：無菌性膿皰，常伴隨**低燒**
- **尋常型牛皮癬**（Plaque psoriasis）：境界分明的紅色增厚斑塊，覆蓋銀白色鱗屑
- 生殖器部位牛皮癬常見於**陰莖**與**陰囊**

### 組織病理學

| 特色 | 說明 |
|------|------|
| 棘皮症（Acanthosis） | 表皮增厚 |
|  Munro 微膿腫 | 嗜中性球堆積於**表皮層** |
| 乳頭狀瘤病（Papillomatosis） | 真皮乳頭向上延伸 |
| 銀屑病三聯徵 |  Munro 微膿腫、殘留顆粒層、規則向下延伸的表皮突 |

### 治療選擇

| 治療方式 | 適用情況 | 注意事項 |
|----------|----------|----------|
| **外用皮質類固醇** | 輕度局部病變 | 長期使用可能導致**皮膚萎縮** |
| 局部**鈣調磷酸酶抑制劑**（Pimecrolimus、Tacrolimus） | 類固醇禁忌或需長期使用 |  |
| 窄波 UVB 光照 | 局部頑固病變 | 308 nm 準分子激光效果佳 |
| **PUVA**（口服 methoxypsoralen + UVA） | 广泛性牛皮癬 | 高劑量增加**生殖器鱗狀細胞癌（SCC）**風險 |
| 系統治療（MTX、Cyclosporine、類維生素A、TNF-α抑制劑、IL-12/23 抑制劑） | 嚴重或廣泛性疾病 |  |

> **臨床重點**
> - PUVA 治療時**強烈建議使用生殖器遮罩保護**
> - 長期 PUVA 治療與劑量依賴性生殖器 SCC 風險增加相關
> - 因此**PUVA 禁用於生殖器局部牛皮癬**

## 反應性關節炎（Reactive Arthritis）

### 舊稱：Reiter 症候群

**反應性關節炎**的典型表現為**尿道炎、關節炎、眼部病變、口腔潰瘍與皮膚病變**五聯徵，但臨床上僅約三分之一患者會出現全部表現。

### 臨床特徵

| 系統 | 表現 |
|------|------|
| 泌尿系統 | 非淋病性尿道炎（**披衣菌**或**淋病雙球菌**） |
| 腸道 | 胃腸道感染後（**Yersinia、Salmonella、Shigella、Campylobacter**） |
| 皮膚 | 龜頭與陰莖幹的**膿皰性皮疹**，可融合成波浪狀（reactive arthritis 特色） |
| 好發族群 | 男性 > 女性，兒童罕見；HIV 陽性患者更常見 |

> **臨床重點**
> - 外生殖器皮膚病變有時會被誤認為**牛皮癬**
> - 與 HLA-B27 強相關
> - 由**披衣菌**或**腸道菌種**感染誘發

## 硬化性苔癬（Lichen Sclerosus）

### 疾病特徵

**硬化性苔癬（LS）**為慢性發炎性疾病，好發於**停經前後**或**學齡前**女性，男女比例約 **1:6-10**。男性患者多為 **60 歲以上**。

### 臨床與病理表現

| 特徵 | 說明 |
|------|------|
| 發病位置 | **龜頭**與**包皮**；女性常見於外陰與肛門周圍 |
| 晚期名稱 | **乾癬性閉塞性龜頭炎**（BXO） |
| 病程 | 最終為**疤痕化疾病**，特點為組織蒼白、纖維化致結構喪失 |
| 包皮疤痕化 | 可導致**包莖**，包皮環切術通常可治癒，但可能復發於環切疤痕處 |
| BXO 併發症 | 可侵犯**陰莖尿道**導致麻煩的**尿道狹窄**；女性可致**外陰粘連、陰唇融合、陰蒂包莖、陰道阻塞** |

### 併發症

> **臨床重點**
> - LS 可造成**排尿疼痛**、**勃起疼痛**與**性交困難**
> - 約 **15-20%** 的 LS 患者有生殖器外病變
> - LS 為**癌前期病變**，與外陰癌與陰莖 SCC 相關
> - 強烈家族遺傳傾向

---

## 扁平苔癬（Lichen Planus）

### 臨床特徵

- 侵犯部位：**口腔黏膜**、**陰莖包皮**與**龜頭**
- 皮疹形態：單一與群集之**紫色丘疹**，可呈**線狀排列**
- 特有表現：**Wickham 紋**（口腔黏膜白色網狀花紋）

### 組織病理學

| 發現 | 說明 |
|------|------|
| 基底層破壞 | 特徵性所見 |
| **鋸齒狀表皮突**（Sawtooth rete ridge） | 向下延伸的表皮突呈鋸齒狀 |
| **Civatte 小體** | 凋亡之表皮細胞 |
| **親表皮性**（Eosinophils） | **不明顯**（可與其他發炎性疾病區分） |
| 無**角化不全** | 有助於與牛皮癬鑑別 |

## 多形性紅斑（Erythema Multiforme, EM）

### 臨床分類

| 類型 | 臨床特徵 | 預後 |
|------|----------|------|
| **EM minor** | 對稱固定紅斑丘疹，可發展為**靶狀病變** | 良好，自限性 |
| **EM major / Stevens-Johnson 症候群（SJS）** | 廣泛皮膚病變類似燒傷，可能致命 | 嚴重，可能需住**燒燙傷中心**或**加護病房** |

### EM minor

- 大多數由**第一型與第二型單純皰疹病毒（HSV-1、HSV-2）**誘發
- 皰疹病兆出現後 **10-14 天**出現靶狀病變
- 連續性抑制性**Acyclovir**可預防復發，但發疹後給藥無效
- 自然病程為數週內自發消退，但復發常見

> **臨床重點**
> - SJS 為**醫療急症**，治療方式與燒燙傷相似
> - 入住加護病房或燒燙傷單位可顯著降低致病率與死亡率
> - EM major 與 SJS 是否為同一疾病或不同疾病仍有爭議

## 傳染性軟疣（Molluscum Contagiosum）

- 由**痘病毒**引起
- 典型皮疹：**臍狀（umbilicated）丘疹**
- 免疫正常者：皮疹通常侷限於**生殖器**
- **HIV 陽性**或免疫抑制患者：皮疹可更廣泛分布或增大
- 可使用**刮除術**、**液態氮冷冻治療**或**雷射**移除

## 光照療法與新興療法

| 療法 | 適應症 | 備註 |
|------|--------|------|
| **窄波 UVB（308 nm）** | 局部牛皮癬、乾癬 | 無全身性光照致癌風險 |
| **PUVA** | 牛皮癬、乾癬、EM、扁平苔癬 | 高劑量有 SCC 風險，生殖器需遮罩 |
| **光動力療法（PDT）** | 尖圭濕疣（配合冷冻或 CO₂ 激光） | 對頑固性或大型尖圭濕疣有效 |
| **CO₂ 激光** | 尖圭濕疣 | 可取代手術切除 |

## 重點摘要

| 疾病 | 關鍵特徵 | 惡性風險 |
|------|---------|----------|
| 硬化性苔癬（LS） | 蒼白、疤痕化、BXO、尿道狹窄 | **癌前期病變** |
| 扁平苔癬 | 紫色丘疹、Wickham 紋、無角化不全 | 可能惡性轉化 |
| 牛皮癬 | 銀屑病三聯徵、膿皰型可伴發燒 | PUVA 增加 SCC 風險 |
| 反應性關節炎 | 五聯徵（尿道炎、關節炎、眼病、口腔潰瘍、皮膚病） | 與 HLA-B27 相關 |
| EM minor | HSV 誘發，靶狀病變 | 自限性 |
| EM major / SJS | 廣泛性黏膜皮膚病變 | 危及生命 |

> **臨床重點**
> - 所有外生殖器慢性皮膚病變皆應考慮**切片檢查**以排除惡性變化
> - LS 與扁平苔癬均為**癌前期病變**，需要長期追蹤
> - 光動力療法對頑固性尖圭濕疣是有效選擇，特別是在妊娠期
