# 17 結核桿菌與寄生蟲感染

📖 **導讀**：泌尿生殖道結核桿菌感染（Genitourinary Tuberculosis, GU TB）是肺外結核的常見形式，由結核分枝桿菌（Mycobacterium tuberculosis complex, MTBC）引起，可侵犯腎臟、輸尿管、膀胱、男性生殖道等。本章節系統性闡述 GU TB 的病理學、臨床表徵、診斷與治療，並簡要介紹其他寄生蟲感染。

---

## 流行病學

- 全球約 **1/3 人口**感染結核桿菌
- 每年約 **900 萬人**發病
- GU TB 約佔所有結核病例的 **15-20%**
- 開發中國家發生率高於已開發國家
- 末期腎衰竭約發生於 **7%** 的 GU TB 患者
- 約 **20%** 的 GU TB 同時伴有肺結核

---

## 病因與致病機制

### 病原體

**結核分枝桿菌（Mycobacterium tuberculosis complex, MTBC）**

- 抗酸染色（Ziehl-Neelsen）陽性
- 生長緩慢（倍增時間約 15-20 小時）
- 好發於氧氣豐富組織（腎皮質、肺尖）

### 感染途徑

| 途徑 | 說明 |
|---|---|
| **血行性散播** | 原發性肺部感染後，MTBC 經血流散播至腎臟（主要途徑） |
| **逆行性感染** | 膀胱 TB 可經尿道逆行感染 |
| **直接蔓延** | 鄰近器官直接侵犯（少見） |

> **臨床重點**：腎臟是血行性播種的首要目標，因腎皮質血流量豐富。感染後數年甚至數十年可無症狀，後續因免疫力改變而發病。

---

## 病理學

### 腎臟（Renals）

| 病理變化 | 說明 |
|---|---|
| **皮質膿腫** | 乾酪樣壞死形成空洞 |
| **乳頭壞死** | 結核性腎乳頭炎 |
| **腎鈣化** | 常見於長期感染（乾酪樣物質鈣化） |
| **腎功能障礙** | 慢性炎症導致腎元破壞 |

- **輸尿管**：狹窄（常見於遠端）、結節狀增厚、「串珠狀」外觀
- **膀胱**：從輸尿管口附近開始，向上蔓延；膀胱攣縮（「Thimble bladder」）

> **臨床重點**：膀胱攣縮為 GU TB 的晚期併發症，膀胱容量可小於 20 mL；在開發中國家發生率（12%）高於已開發國家（4%）。

---

## 臨床表徵

### 腎臟

| 症狀 | 說明 |
|---|---|
| **無症狀** | 早期可無任何症狀 |
| **腰痛** | 單側或雙側 |
| **血尿（hematuria）** | 顯微或巨觀血尿 |
| **膿尿（pyuria）** | 膿細胞存在但普通培養陰性（無菌性膿尿） |
| **腎功能惡化** | 雙側病變或單側嚴重病變 |

### 輸尿管

- 輸尿管狹窄導致**水腎**
- 腰痛
- 少數情况下無症狀

### 膀胱

| 症狀 | 說明 |
|---|---|
| **頻尿、尿急** | 逐漸進展 |
| **排尿困難（dysuria）** | 膀胱容量減少時出現 |
| **恥骨上疼痛** | 膀胱炎症 |
| **膀胱容量嚴重減少** | < 100 mL 時症狀顯著 |
| **「Thimble bladder」** | 嚴重攣縮，容量 < 20 mL |

### 男性生殖道

| 部位 | 臨床特徵 |
|---|---|
| **副睪（Epididymis）** | 最常見的生殖道 TB 部位（10-55%）；腫脹、硬化；34% 為雙側；可形成竇道 |
| **睪丸（Testis）** | 通常由副睪蔓延而來；摸似睪丸腫瘤 |
| **攝護腺（Prostate）** | 攝護腺結節；慢性攝護腺炎症狀但抗生素治療無效 |
| **儲精囊（Seminal Vesicles）** | 不孕（可能為首發症狀）；血精；低容量精液 |
| **輸精管（Vas Deferens）** | 增厚、結節狀疤痕（「珠狀」） |
| **陰莖（Penis）** | 極罕見；膿皰、潰疡、結節；可能與陰莖癌混淆 |
| **尿道（Urethra）** | 少見（1.9-4.5%）；可形成尿道陰囊瘻管 |

> **臨床重點**：以慢性攝護腺炎症狀就診但抗生素治療失敗者，應考慮 TB 的可能。副睪 TB 可形成結核性竇道，約 50% 患者可見此併發症。

## 診斷

### 結核菌素皮膚試驗（TST / PPD）

| 適應症 | 說明 |
|---|---|
| **HIV 阳性者** | 高風險族群 |
| **確診 TB 患者接觸者** | 追蹤接觸史 |
| **胸腔 X 光有纖維化改變** | 既往 TB 感染指標 |
| **器官移植及免疫抑制患者** | 長期使用免疫抑制劑者 |
| **高風險地區新移民** | 5 年內自高盛行區移入 |
| **靜脈藥物使用者** | 較高暴露風險 |
| **高風險機構居住者** | 監獄、護理之家、遊民收容所等 |

> **臨床重點**：判讀 TST 結果需根據受測者的風險因子，免疫抑制患者的判讀閾值更低（≥ 5 mm 即為陽性）。

### 干擾素釋放試驗（IGRAs）

| 試驗 | 方法 | 敏感性 |
|---|---|---|
| **QuantiFERON-TB Gold In-Tube (QFT-GIT)** | 全血 ELISA 測量 IFN-γ | **83%** |
| **T-SPOT.TB** | ELISPOT 測量釋放 IFN-γ 的細胞數 | **91%** |
| **傳統 TST** | 皮下注射，48-72 小時判讀 | 89% |

- IGRAs 優點：不受 BCG 疫苗影響、無需回診判讀
- T-SPOT.TB 敏感性高於 QFT-GIT

### 影像學

| 檢查 | 發現 |
|---|---|
| **腹部 X 光** | 腎臟鈣化（花瓣狀或整個腎臟） |
| **靜脈腎盂造影（IVP）** | 腎盞破壞、乳頭壞死、輸尿管狹窄（「串珠狀」） |
| **超聲波** | 腎臟萎縮或擴大、鈣化、水腎 |
| **CT** | 評估腎臟實質改變、膿腫、鈣化 |
| **膀胱尿道攝影（VCUG）** | 評估膀胱容量、攣縮 |

### 微生物學確認

| 方法 | 說明 |
|---|---|
| **抗酸染色（AFB stain）** | 快速但敏感性低 |
| **分枝桿菌培養** | 金標準；可進行藥物敏感性試驗（DST）；需 2-8 週 |
| **NAATs / PCR** | 快速確認；GeneXpert MTB/RIF 可同時檢測 rifampicin 抗藥性 |
| **組織病理學** | 顯示**乾酪樣肉芽腫（caseating granulomas）**可支持診斷 |

> **臨床重點**：在已開發國家，GU TB 診斷的首要目標是分離 MTBC 進行藥物敏感性試驗；組織學發現乾酪樣肉芽腫在培養陰性時可支持診斷。

## 治療

### 藥物治療原則

| 原則 | 說明 |
|---|---|
| **早期、聯合、用藥** | 防止抗藥性產生 |
| **標準化療方案** | 多數患者採用 6 個月療程 |
| **藥物敏感性試驗（DST）** | 指導個人化治療 |
| **監測治療反應** | 臨床症狀、尿培養、影像學 |

### 標準治療方案

| 階段 | 藥物 | 持續時間 |
|---|---|---|
| **初始強化期（2 個月）** | Isoniazid (INH)、Rifampin (RIF)、Pyrazinamide (PZA)、Ethambutol (EMB) | 8 週 |
| **持續期（4 個月）** | Isoniazid + Rifampin | 16 週 |

### 抗藥性結核

| 類型 | 定義 | 治療調整 |
|---|---|---|
| **單純 INH 抗藥** | INH 單一抗藥 | 移除 INH，加入 EMB + PZA，療程 6-9 個月 |
| **多重抗藥（MDR-TB）** | INH + RIF 抗藥 | 需含氟喹諾酮及二線注射劑，療程延長至 18-24 個月 |
| **廣泛抗藥（XDR-TB）** | MDR + 氟喹諾酮 + 至少一種注射劑抗藥 | 極難治療，預後差 |

### 手術治療

| 適應症 | 手術類型 |
|---|---|
| **腎膿瘍** | 膿腫引流或腎切除 |
| **嚴重輸尿管狹窄** | 狹窄修復、輸尿管重新植入 |
| **嚴重膀胱攣縮** | 膀胱擴大手術、尿路改道 |
| **對側腎功能正常時的無功能腎** | 腎切除 |

> **臨床重點**：GU TB 的藥物治療應與結核病專家合作；手術治療應在藥物治療穩定後進行，以減少術後併發症及促進康復。

## 寄生蟲感染概述

### 泌尿道寄生蟲感染

| 寄生蟲 | 地理分布 | 泌尿系統表現 |
|---|---|---|
| **Schistosoma haematobium（埃及血吸蟲）** | 中東、非洲 | 血尿、排尿困難、尿路阻塞 |
| **Trichomonas vaginalis** | 全球 | 尿道炎、膀胱炎（前述 STI 章節） |
| **Wuchereria bancrofti（血絲蟲）** | 熱帶地區 | 乳糜尿、淋巴系統侵犯 |

### 血吸蟲病（S血吸蟲病）

**埃及血吸蟲（S. haematobium）**：
- 傳播：淡水螺為中間宿主，尾蚴經皮膚侵入
- 病理：成蟲寄生於膀胱靜脈叢
- 診斷：尿沉渣中找到蟲卵、膀胱鏡檢
- 治療：**Praziquantel** 40 mg/kg 單次口服
- 併發症：膀胱纖維化、尿路阻塞、**鱗狀細胞癌**

> **臨床重點**：S. haematobium 感染與鱗狀細胞癌的發生密切相關，在流行區應長期追蹤。

---

## 總結

泌尿生殖道結核桿菌感染（GU TB）是肺外結核的重要形式，腎臟為血行性播種的首要部位。臨床表現多樣，包括無症狀菌尿、腰痛、血尿、膀胱症狀及男性生殖道侵犯。診斷依靠結核菌素試驗、IGRAs、影像學及微生物學確認（分枝桿菌培養、PCR）。標準治療為 INH + RIF + PZA + EMB 四合一藥物治療 6 個月；抗藥性結核需個人化調整。寄生蟲感染中，埃及血吸蟲（S. haematobium）為重要的泌尿道寄生蟲，可導致血尿、尿路阻塞及鱗狀細胞癌，Praziquantel 為主要治療藥物。
