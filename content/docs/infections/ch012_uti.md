# 12 尿路感染

📖 **導讀**：尿路感染（Urinary Tract Infection, UTI）是最常見的细菌感染，涵蓋從膀胱炎到腎盂腎炎的整個泌尿系統炎症過程。本章節系統性闡述 UTI 的定義分類、流行病學、致病機制、病原學、診斷與治療原則。

---

## 定義與分類

**尿路感染**是指細菌的致病力增加或宿主防禦機制下降時，泌尿系統受到的感染。

| 分類 | 說明 |
|---|---|
| **單純性 UTI** | 無結構或功能異常，病原菌毒性正常 |
| **複雜性 UTI** | 伴有泌尿道功能或解剖異常、留置導尿管、院內感染等（見 Box 12-1） |
| **復發性 UTI** | 短期抗菌治療後復發，分為重新感染與體內菌株復發 |
| **無症狀菌尿** | 無臨床症狀但尿培養陽性，常見於老年人 |

> **臨床重點**：複雜性 UTI 的危險因子包括：泌尿道結構或功能異常、兒童期 UTI 病史、最近使用過抗菌藥物、留置導尿管、泌尿道侵入性操作、院內感染、症狀持續超過 7 天。

---

## 流行病學

UTI 被認為是**最常見的细菌感染**。

- 美國每年超過 **700 萬次**門診就診
- 約 **100 萬次**急診就診，導致 **10 萬次**住院
- 女性一生中約 **50%** 會經歷至少一次 UTI
- 年輕女性菌尿發生率是男性的 **30 倍**
- 65 歲以上：女性至少 **20%**、男性至少 **10%** 有菌尿
- UTI 約佔所有院內感染的 **38%**，其中**導尿管相關泌尿道感染（CAUTI）**最常見

> **臨床重點**：近 30% 的女性在 24 歲前會有需要抗菌治療的症狀性 UTI。

---

## 病因與致病機制

### 感染途徑

大多數 UTI 病原菌來自腸道菌叢，經**尿道逆行**至膀胱為主要途徑。

| 途徑 | 說明 |
|---|---|
| **逆行性上升** | 病原菌經尿道上升至膀胱，再至輸尿管及腎臟（最常見） |
| **血行性散播** | 少見，正常人罕見；常見於金黃色葡萄球菌菌血症或 Candida 菌血症 |
| **直接蔓延** | 嚴重腸道感染或腹膜後膿瘍，經淋巴系統扩散 |

### 病原菌

**大腸桿菌（E. coli）**是最主要病原菌：
- 社區獲得性感染：**85%**
- 院內感染：**50%**

其他常見病原菌：

| 病原菌 | 特性 |
|---|---|
| **Proteus、Klebsiella** | 腸道桿菌科，常見於社區感染 |
| **Enterococcus faecalis** | 革蘭氏陽性球菌 |
| **Staphylococcus saprophyticus** | 約佔年輕性生活活躍女性症狀性下泌尿道感染 **10%** |
| **Klebsiella、Enterobacter、Citrobacter、Serratia、Pseudomonas aeruginosa** | 常見於院內感染 |
| **Gardnerella vaginalis、Mycoplasma、Ureaplasma urealyticum** | 見於間歇性或留置導尿管患者 |

### 毒力因子

- **第一型菌毛（Type 1 pili）**：為已確立的 UTI 毒力因子，促進細菌黏附於膀胱上皮
- **P 菌毛（P pili）**：與腎盂腎炎相關，結腸桿菌毒性增加與之相關
- **ST131 大腸桿菌**：攜帶廣效性 β-內醯胺酶（ESBL），對氟喹諾酮具抗藥性，為多重抗藥性 UTI 的重要致病原

## 病理學

### 急性膀胱炎

- 炎症主要限於膀胱黏膜
- 表現為黏膜充血、水腫及點狀出血
- 約 **50%** 的感染可延伸至上泌尿道

### 急性腎盂腎炎

- 腎實質化膿性炎症
- 膿腫形成、腎乳頭壞死
- 慢性反覆感染可導致**腎疤痕**形成

### 腎疤痕類型

- **不規則疤痕**：幼年時期逆流至腎臟不同區域，造成皮質疤痕
- **均勻萎縮**：均勻破壞所有腎元，常見於阻塞伴隨感染的兒童

---

## 臨床表徵

### 下泌尿道感染（膀胱炎）

| 症狀 | 說明 |
|---|---|
| **排尿困難（dysuria）** | 排尿時疼痛或燒灼感 |
| **頻尿（frequency）** | 排尿次數增加 |
| **尿急（urgency）** | 突然強烈需要排尿 |
| **恥骨上疼痛** | 膀胱區域不適 |
| **血尿（hematuria）** | 顯微或巨觀血尿 |

### 上泌尿道感染（腎盂腎炎）

- 發燒、寒顫
- 腰痛（單側或雙側）
- 噁心、嘔吐
- 敗血症風險

> **臨床重點**：孕婦菌尿進展至急性臨床腎盂腎炎的比率高於非孕婦，需積極治療。

## 診斷

### 實驗室檢查

| 檢查 | 臨床意義 |
|---|---|
| **尿沉渣顯微鏡檢** | 每高倍視野 > 10 顆白血球提示感染 |
| **尿培養** | 診斷金標準； Colony forming unit (CFU) > 10³/mL 考慮有意義菌尿 |
| **尿液試紙** | 亞硝酸鹽試驗（對革蘭氏陰性菌敏感）、白血球酯酶 |
| **血液培養** | 懷疑菌血症或敗血症時 |

### 影像學

- 超音波：評估腎臟大小、水腎、膿瘍
- 電腦斷層（CT）：複雜性 UTI、疑似腎膿瘍或阻塞
- 靜脈腎盂造影（IVP）：評估尿路結構異常

> **臨床重點**：再發性 UTI（每年 ≥ 3 次或半年內 ≥ 2 次）建議進一步評估，包括膀胱鏡、尿路動力學或影像學檢查。

---

## 治療

### 抗生素治療原則

| 情況 | 治療建議 |
|---|---|
| **單純性膀胱炎** | 短療程抗生素（3-7 天）：TMP-SMX、Nitrofurantoin、Fosfomycin |
| **複雜性 UTI** | 根據尿培養結果選擇抗生素；療程 7-14 天 |
| **急性腎盂腎炎** | 靜脈抗生素至退燒後改口服，總療程 14-21 天 |
| **無症狀菌尿** | 一般不需治療；孕婦、擬行泌尿外科手術者例外 |

### 預防性治療

- **持續性預防**：低劑量抗菌藥物長期使用（如 TMP-SMX 1/2 錠每週 3 次）
- **術後預防**：泌尿外科手術前給予單次劑量
- **性交後預防**：適用於性行為相關復發性 UTI

> **臨床重點**：預防性抗菌治療可降低發病率及復發菌尿的發生時間，但停止預防後感染率會恢復至治療前水平。

---

## 預後與併發症

| 併發症 | 說明 |
|---|---|
| **復發性感染** | 體內菌株復發或再感染 |
| **腎疤痕** | 需伴隨阻塞、糖尿病等危險因子才會導致進行性腎損害 |
| **敗血症** | 複雜性 UTI 可進展為菌血症及敗血症休克 |
| **腎膿瘍** | 需要引流及長期抗生素治療 |

> **臨床重點**：單純性復發性 UTI 與腎疤痕、高血壓或進行性腎功能衰竭之間**尚無明確關聯**。

---

## 總結

尿路感染是最常見的细菌感染，女性終生發生率達 50%。**大腸桿菌**為最主要病原菌，感染途徑以逆行性上升為主。臨床表徵依感染部位不同，下泌尿道感染以排尿困難、頻尿、尿急為主，上泌尿道感染則伴隨發燒、腰痛等全身症狀。診斷以尿培養為金標準，治療以短療程抗生素為主。複雜性 UTI 需積極處理以預防嚴重後遺症或死亡。
