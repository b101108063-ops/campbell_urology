## 📖 導讀

免疫學在泌尿系統腫瘤的發生、進展與治療中扮演核心角色。本章節從基礎免疫學談起，介紹先天免疫與適應性免疫的交互作用，說明**免疫編輯假說（Immune Editing Hypothesis）**如何解釋腫瘤與免疫系統的三階段互動，並詳細探討**慢性發炎與泌尿系統癌症**的關聯，以及目前最熱門的**免疫檢查點抑制劑（PD-1/PD-L1）**在膀胱癌、腎細胞癌與攝護腺癌中的臨床意義。

---

## 免疫系統概論

### 先天免疫與適應性免疫

| 免疫類型 | 特點 | 主要細胞 |
|----------|------|----------|
| **先天免疫** | 快速、非特異性、無記憶 | 巨噬細胞、樹突細胞、自然殺手細胞（NK） |
| **適應性免疫** | 特異性、有記憶 | CD4+ 輔助 T 細胞、CD8+ 殺手 T 細胞、B 細胞 |

### 細胞激素與免疫反應

| 細胞激素 | 功能 |
|----------|------|
| **IFN-α / IFN-β**（第一型干擾素） | 病毒感染細胞分泌；上調第一類 MHC 與抗原處理，使細胞更易受免疫攻擊 |
| **IFN-γ** | 誘發 **PD-L1** 表現；與良好 BCG 療效相關 |
| **IL-2** | Th1 細胞分泌；促進 T 細胞增殖 |
| **TNF-α** |  Th1 細胞分泌；與良好 BCG 療效相關 |
| **IL-4、IL-5、IL-6、IL-10** | Th2 細胞分泌；與**不良 BCG 療效**相關 |
| **IL-12** | 誘導 **Th1** 分化 |
| **IL-8、CXCL9、CXCL10** | 趨化因子；吸引免疫細胞至腫瘤微環境 |

> **臨床重點**
> - **理想的抗腫瘤免疫反應**以 **Th1 為主**（IFN-γ、IL-2、TNF-α）
> - **Th2 偏移**與 BCG 治療失敗相關
> - **CD4+ 調節性 T 細胞（Tregs）**會主動抑制適應性免疫反應

## 免疫編輯假說（Immune Editing Hypothesis）

免疫編輯假說描述腫瘤與免疫系統的三階段互動：

### 三階段

| 階段 | 說明 |
|------|------|
| **消除（Elimination）** | 早期腫瘤被免疫系統辨識並清除；先天免疫（巨噬細胞、樹突細胞）與適應性免疫共同作用 |
| **平衡（Equilibrium）** | 腫瘤與免疫系統呈動態平衡；腫瘤不再被完全消除，但進展減緩；可維持很長時間 |
| **逃脫（Escape）** | 腫瘤細胞獲得免疫逃避機制，成為臨床上可見的腫瘤 |

### 逃脫機制

| 機制 | 說明 |
|------|------|
| **腫瘤抗原下調** | 腫瘤細胞丟失被免疫系統辨識的抗原 |
| **MHC 分子下調** | 減少抗原呈現 |
| **Tregs 誘導或擴增** | 抑制抗腫瘤免疫反應 |

> **臨床重點**
> - **免疫編輯**已被列為**癌症的標誌（Hallmarks of Cancer）**之一
> - 臨床上可見的腫瘤必定已發展出逃脫免疫監視的機制
> - 此假設為**免疫檢查點抑制劑**的開發提供了理論基礎

## 慢性發炎與泌尿系統癌症

### 膀胱癌與慢性發炎

膀胱癌與慢性發炎的關聯證據最為充分：

| 發炎來源 | 致癌機制 |
|----------|----------|
| **埃及血吸蟲感染**（Schistosoma haematobium） | IARC 列為已知致癌物；流行區膀胱癌發生率高；高感染強度與**鱗狀細胞癌**表型相關 |
| 慢性泌尿道感染 | 長期發炎導致組織損傷與修復，增加致癌風險 |
| 長期留置導尿管 | 慢性刺激與發炎 |
| **Cyclophosphamide** 誘發膀胱炎 | 藥物代謝產物（acrolein）直接致癌 |

### 慢性發炎的分子機制

- **M2 型巨噬細胞**（dysfunctional macrophages）產生免疫抑制性細胞激素
- **骨髓抑制細胞（MSCs）**抑制活躍的免疫反應
- 適應性免疫向 **Th2** 方向極化

> **臨床重點**
> - 血吸蟲感染相關膀胱癌的病理型態多為**鱗狀細胞癌**（而非最常見的泌尿上皮癌）
> - 所有慢性發炎來源都是膀胱癌的危險因子

## 免疫檢查點：PD-1 / PD-L1

### 作用機制

**免疫檢查點抑制**是腫瘤逃避免疫監視的關鍵機制：

- **PD-1**（程式性死亡受體-1）：表達於**腫瘤浸潤 CD8+ T 細胞**表面
- **PD-L1**：表達於**腫瘤細胞**與**腫瘤相關巨噬細胞**表面
- 兩者結合後，顯著抑制 T 細胞的增殖與效應功能

### 適應性免疫抗性（Adaptive Immune Resistance）模型

1. 腫瘤突變產生新抗原 → 誘發 CD8+ T 細胞辨識
2. CD8+ T 細胞浸潤腫瘤並分泌 **IFN-γ**
3. IFN-γ 誘發腫瘤細胞與上皮細胞表達 **PD-L1**
4. PD-L1 與 T 細胞上的 PD-1 結合 → **抑制 CD8+ T 細胞功能**

### 膀胱癌中的 PD-L1 表達

| 研究發現 | 臨床意義 |
|----------|----------|
| 膀胱癌中 **15-35%** 患者有 PD-L1 表達 | 表達與更高腫瘤分級相關 |
| PD-L1 表達比 WHO 分級更準確預測預後 | PD-1/PD-L1 交互作用在膀胱癌進展中有功能性角色 |
| PD-L1 在 BCG 誘發的肉芽腫中高度表達 | 可能是 BCG 治療失敗的逃脫機制 |

> **臨床重點**
> - **PD-1 或 PD-L1 單株抗體**可阻斷此抑制途徑，恢复 T 細胞對腫瘤攻擊
> - 此發現直接促成了多種**免疫檢查點抑制劑**用於晚期膀胱癌的臨床試驗

## 腎細胞癌的免疫微環境

### 特點

| 特徵 | 說明 |
|------|------|
| 慢性發炎與腎癌的關聯 | 不如膀胱癌明確；僅與**吸菸**與**肥胖**等 pro-inflammatory 風險因子弱相關 |
| CD4+ T 細胞浸潤的預後意義 | 研究結果不一致 |
| CD8+ T 細胞浸潤 | 與較佳預後相關 |
| 腎癌對免疫治療的反應 | **自發性消退**罕見但在文獻中有記錄 |

---

## 攝護腺癌的免疫微環境

### 特點

| 發現 | 意義 |
|------|------|
| CD4+ 與 CD8+ T 細胞浸潤 | 存在但呈現**非活化（anergic）或抑制性**表型 |
| **調節性 CD8+ T 細胞** | 可掩蓋抗原特異性 T 細胞反應 |
| PD-1 在腫瘤浸潤 CD8+ T 細胞上表達 | 顯示 PD-1/PD-L1 軸可能限制抗腫瘤免疫 |
| 腫瘤細胞本身不表達 PD-L1 | 可能是 PD-1 抑制劑在攝護腺癌效果有限的原因 |

> **臨床重點**
> - 攝護腺癌的腫瘤微環境具有**慢性發炎**與**非產品性 T 細胞反應**雙重特徵
> - 攝護腺癌細胞不表達 PD-L1，這解釋了 PD-1 抑制劑在此癌症中效果不如膀胱癌

## Th17 細胞與 Tregs

| 細胞類型 | 分泌細胞激素 | 與腫瘤的關係 |
|----------|------------|-------------|
| **Th17** | IL-17、IL-22 | 促腫瘤與抗腫瘤的雙向角色，取決於 context |
| **Tregs** | TGF-β、IL-10 | **抑制**抗腫瘤免疫反應，促進腫瘤進展 |

---

## 重點摘要

| 主題 | 核心內容 |
|------|----------|
| 免疫編輯三階段 | **消除 → 平衡 → 逃脫** |
| 理想抗腫瘤免疫 | **Th1** 反應（IFN-γ、IL-2、TNF-α） |
| Th2 偏移後果 | BCG 治療失敗風險增加 |
| 膀胱癌與發炎 | 血吸蟲感染、慢性 UTI、導尿管、Cyclophosphamide 皆為危險因子 |
| 免疫檢查點 | PD-1（T 細胞）與 PD-L1（腫瘤/巨噬細胞）結合抑制 T 細胞功能 |
| 適應性免疫抗性 | IFN-γ 誘發 PD-L1 表達是腫瘤逃脫的關鍵機制 |
| 免疫檢查點抑制劑 | PD-1/PD-L1 抗體在膀胱癌展現顯著療效 |

> **臨床重點**
> - 免疫檢查點抑制劑開啟了**晚期膀胱癌**治療的新紀元
> - PD-L1 表達可用作為**預後指標**與**療效預測因子**
> - 了解腫瘤免疫微環境對於選擇合適的**免疫治療策略**至關重要
