# Chapter 91 Surgical Procedures for Sphincteric Incontinence in the Male

## 流行病學與病因

### 男性尿失禁（Urinary Incontinence, UI）概述

男性 UI 最常見原因為**前列腺手術**（根除性攝護腺切除術 TURP）後的**外擴約肌（external sphincter）功能障礙**。

| 病因 | 說明 |
|------|------|
| **根治性攝護腺切除術（RP）** | 最常見術後尿失禁原因，40%–45% 患者術後有不同程度膀胱功能障礙 |
| **經尿道攝護腺切除術（TURP）** | 術後 stress incontinence 較少見 |
| **放射治療** | 組織纖維化導致 sphincter 功能受損 |
| **神經性病因** | 脊髓損傷、多發性硬化症等 |
| **外傷** | 骨盆創傷後 sphincter 损伤 |

### 男性括約肌尿失禁（Sphincteric Incontinence）機制

- ** intrinsic sphincter deficiency（ISD）**：括約肌關閉壓力不足，導致 stress incontinence
- **膀胱功能障礙**（detrusor overactivity、low bladder compliance）：約佔術後尿失禁原因的 40%–45%，但作為唯一原因者極少

## 分類與評估

### 術前評估

| 評估項目 | 內容 |
|----------|------|
| **病史與排尿日誌** | 尿失禁類型（stress/urge/mixed）、頻率、嚴重度、墊片使用量 |
| **尿流動力學** | 確認膀胱容量、順應性、收縮力，排除 BOO |
| **膀胱鏡檢查** | 確認膀胱頸狹窄、括約肌殘餘功能，排除尿道狹窄 |
| **24 小時墊片重量測試** | 客觀量化尿失禁程度 |
| **血清肌酸酐 / PSA** | 術前腎功能及癌症狀態評估 |

> **臨床重點**：**2–7 天排尿日誌**可可靠評估尿失禁發作次數，並發現隱藏的 urge incontinence；僅自我報告的每日墊片使用量與實際漏尿量僅有中等相關性。

### 尿失禁分類

| 類型 | 特徵 |
|------|------|
| **Stress incontinence（應力性尿失禁）** | 腹壓增加（咳嗽、噴嚏、活動）時漏尿 |
| **Urge incontinence（急迫性尿失禁）** | 強烈尿急後無法控制漏尿 |
| **Overflow incontinence（滿溢性尿失禁）** | 膀胱過度充盈後漏尿 |
| **Mixed incontinence（混合性）** | stress + urge 混合 |

### 男性 sling 與 AUS 的機制差異

| 裝置 | 機制 |
|------|------|
| **Bone-anchored sling** | 壓迫尿道（compression），增加固定阻力 |
| **Transobturator sling（經閉孔吊帶）** | 重新定位（repositioning）而非壓迫，延長膜性尿道（membranous urethral length） |
| **Virtue quadratic sling** | 四臂設計，同時提供壓迫與提升 |
| **Artificial urinary sphincter（AUS, AMS 800）** | 2 cm 周向壓迫區（circumferential compression）， cuff 環繞膀胱頸或球部尿道 |

## 治療原則

### 男性吊帶（Male Sling）

| 類型 | 適應症 |
|------|-------|
| **Bone-anchored sling** | 輕至中度 sphincteric incontinence |
| **Transobturator sling（AdVance）** | 括約肌功能尚存的中度尿失禁 |
| **Virtue sling** | 四臂固定，壓迫 + 提升雙重機制 |

**優點**：
- 不需手動操作裝置
- 無液體滲漏風險
- 生活品質顯著改善

**缺點**：
- 不適合嚴重括約肌功能喪失者
- Detrusor hypocontractility（逼尿肌收縮力不足）者禁用（無法自行排尿）

### 人工尿道括約肌（Artificial Urinary Sphincter, AUS）

**AMS 800** 是目前最成熟的人工括約肌裝置：

| 組成部分 | 功能 |
|----------|------|
| **Cuff（袖套）** | 置於球部尿道（bulbar urethra），提供周向壓迫 |
| **Pressure-regulating balloon（PRB）** | 標準壓力 61–70 cm H₂O，平衡禁制效果與侵蝕風險 |
| **Control pump** | 置於陰囊，患者手動控制 cuff 充放液 |

**適應症**：
- 嚴重 sphincteric incontinence
- 男性吊帶失敗後
- 神經性膀胱合併 sphincter 功能障礙

**手術入路**：
- **會陰切口（Perineal approach）**：最常使用，cuff 置於球部尿道近端
- **經陰囊切口（Transscrotal approach）**：效果較差，已少用

> **臨床重點**：術前應常規評估 **逼尿肌功能**，若逼尿肌收縮力不足（hypocontractility）， AUS 或 sling 術後可能無法自然排尿，需有心理準備。

## 術後評估與失敗處理

### AUS 術後失敗的原因

| 原因 | 評估方式 |
|------|----------|
| **意外關閉（deactivation）** | 主動 cycling 確認 |
| **液體滲漏（mechanical failure）** | X 光或超聲波確認 PRB 大小變化 |
| **Cuff 侵蝕（erosion）** | Cystoscopy |
| **尿道 / 膀胱頸萎縮** | Cystoscopy + 動態觀察 cuff |
| **膀胱儲尿功能障礙** | 尿動力學檢查 |

### 持續性尿失禁的系統性評估流程

1. **cycling 測試**：排除意外 deactivation
2. **X 光 / 超聲波**：確認 PRB 大小（機械故障時 PRB 不會隨 cycling 改變大小）
3. **Cystoscopy**：排除 cuff 侵蝕、尿道狹窄、膀胱頸狹窄
4. **尿動力學**：評估膀胱儲尿功能（compliance、overactivity）

---

## 臨床重點摘要

> **臨床重點**
> - 男性尿失禁最常見於**根治性攝護腺切除術**後，術前應告知患者此為已知風險
> - **2–7 天排尿日誌**與 **24 小時墊片重量測試**是量化尿失禁程度的關鍵工具
> - **Transobturator sling** 依靠重新定位而非壓迫，適用於仍有殘餘括約肌功能的患者
> - **AUS（AMS 800）**是嚴重 sphincteric incontinence 的標準治療，可提供 2 cm 周向壓迫區
> - 術前 **逼尿肌功能評估**至關重要：hypocontractility 者不宜放置壓迫性 sling
> - AUS 術後失敗最常見原因為 **cuff 萎縮**與**機械故障**， cystoscopy 是排除侵蝕的首選檢查
> - **膀胱頸狹窄（bladder neck stenosis）**是術前應排除的重要病理，會顯著影響所有手術方式的結果
