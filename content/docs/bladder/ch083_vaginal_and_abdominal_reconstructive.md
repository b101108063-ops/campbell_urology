## 📖 導讀

**骨盆器官脫垂（Pelvic Organ Prolapse, POP）** 為影響廣大女性之功能性障礙，其根本為**骨盆底支撐結構（Pelvic Floor Support）** 之損傷。本章系統介紹**泌尿婦科解剖學**，包括**骨盆底肌肉（Levator Ani Muscle, LAM）**、**會陰膜（Perineal Membrane）**、**骨盆內筋膜（Endopelvic Fascia）** 與**陰道三層支撐系統（DeLancey's Three Levels of Vaginal Support）**。臨床上POP可分為**前壁脫垂（Cystocele）**、**後壁脫垂（Rectocele）**、**頂端脫垂（Apical Prolapse / Vaginal Vault Prolapse）** 及**複合型脫垂（Complex Vaginal Eversion）**。手術策略之選擇（前路陰道修復、腹式修復或微創修復）應根據脫垂類型、患者意願與術者經驗共同決定。

## 骨盆底解剖學

### 骨盆底肌肉（Levator Ani Muscle, LAM）

| 肌肉組成 | 功能 |
|----------|------|
| **髂尾肌（Iliococcygeus）** | 構成LAM最尾端/背側部分，形成張力支撐 |
| **恥尾肌（Pubococcygeus）** | 主要支撐來源 |
| **恥骨直腸肌（Puborectalis）** | 形成恥骨直腸懸帶，維持肛腸角度 |

**功能**：LAM為盆底主要動態支撐結構，收縮時提升並關閉泌尿生殖裂孔（Urogenital Hiatus）。

> **臨床重點**
> - LAM之損傷（如分娩、衰老、神經支配受損）為POP之主要原因
> - MRI研究顯示POP患者之LAM與耻骨直腸肌間存在明顯功能差異

### 會陰膜（Perineal Membrane）

| 特徵 | 說明 |
|------|------|
| **位置** | 泌尿生殖裂孔兩側 |
| **結構** | 三維結構，分為背側與腹側兩個區域 |
| **背側區域** | 附著於會陰體與陰道側壁，連接坐骨恥骨支 |
| **腹側區域** | 為連續之三維質量，與尿道旁及陰道旁結締組織延續 |

**會陰膜之肌肉組成（腹側區域）**：
- **壓迫尿道肌（Compressor Urethrae）**
- **尿道陰道括約肌（Urethrovaginal Sphincter）**

### 會陰體（Perineal Body）

- 會陰膜、泌尿生殖與肛門三角交界處之纖維肌肉匯聚點
- 為骨盆底支撐之關鍵中心結構

### 泌尿生殖裂孔（Urogenital Hiatus）

| 特性 | 說明 |
|------|------|
| 位置 | LAM開口，尿道與陰道由此通過 |
| 前方支撐 | 恥骨與LAM |
| 後方支撐 | 會陰體與肛門外括約肌 |

> **臨床重點**
> - 泌尿生殖裂孔擴大與下降為POP之共同解剖特徵
> - 直腸因直接附著於裂孔周圍肌肉，非通過裂孔

## 骨盆內筋膜（Endopelvic Fascia）

### 結構特徵

| 特徵 | 說明 |
|------|------|
| 位置 | 腹膜與LAM之間之纖維肌肉組織網絡 |
| 功能 | 包繞並連接膀胱、子宮、陰道、直腸至骨盆壁 |
| 組織學 | 缺乏骨骼肌筋膜之規則排列，強度與一致性具高度變異性 |
| 生物力學 | 新鮮之pubocervical fascia可縮短15–20%，術中應力需考量 |

### 續連性（Contiguity）

骨盆內筋膜為連續一體之結構，不同區域有不同名稱：

| 名稱 | 連接結構 |
|------|----------|
| **Parametrium（宮旁組織）**：寬韌帶（Broad）、主韌帶（Cardinal）、宮骶韌帶（Uterosacral） | 子宮與上段陰道 → 骨盆側壁 |
| **Paracolpium**：ATFP（Arcus Tendineus Fasciae Pelvicae）、ATLA（Arcus Tendineus Levator Ani） | 陰道 → 骨盆側壁 |

> **臨床重點**
> - 筋膜之固有變異性導致重建手術效果不一致
> - 組織癒合能力與年齡、血管狀態、吸煙與共病症密切相關

## DeLancey 陰道三層支撐系統

### Level I 支撐（頂端/懸吊型）

| 項目 | 內容 |
|------|------|
| 結構 | 主韌帶-宮骶韌帶複合體（Cardinal-Uterosacral Ligament Complex） |
| 位置 | 子宮與陰道上段2–3 cm |
| 起源 | 坐骨大孔、薦髂區域、側薦骨 |
| 方向 | 垂直走向（最長纖維） |
| 功能 | 懸吊上段陰道與，子宮 |

### Level II 支撐（中段/側向型）

| 項目 | 內容 |
|------|------|
| 結構 | 骨盆內筋膜於中段陰道處 |
| 位置 | 陰道中段 |
| 方向 | 較水平、側向附著 |
| 特徵 | 纖維較短但密度較高 |
| 延伸 | 分叉包繞膀胱（腹側葉：Endopelvic Fascia；陰道葉：Pubocervical/Perivesical Fascia） |

### Level III 支撐（遠端/融合型）

| 項目 | 內容 |
|------|------|
| 位置 | 陰道口至陰道上段2–3 cm（處女膜環 level） |
| 特徵 | 無paracolpium介入，陰道直接與尿道融合 |
| 側向 | 融入LAM內側緣 |
| 腹側 | 融入會陰膜 |

> **臨床重點**
> - Level I–III之完整理解有助於術前定位脫垂缺陷之精確位置
> - POP-Q系統（Pelvic Organ Prolapse Quantification）依此三層系統訂定標準化測量點

| 測量點 | 代表結構 |
|--------|----------|
| **Aa / Ba** | 遠端/近端前陰道壁 |
| **C / D** | 子宮頸/後穹窿（Posterior Fornix） |

## 脫垂之區域分類

### 前壁脫垂（Anterior Compartment / Cystocele）

**病因**：Level II 支撐之缺陷

| 缺陷類型 | 說明 |
|----------|------|
| **中央缺陷（Central Defect）** | 膀胱與陰道間筋膜撕裂，膀胱向陰道前壁突出 |
| **旁側缺陷（Paravaginal Defect）** | 陰道側壁與ATFP之連接斷裂 |

> **臨床重點**
> - 膀胱脫垂嚴重時可達或超出處女膜環，影響排尿功能甚至造成上泌尿道積水

### 頂端脫垂（Apical Prolapse）

**病因**：Level I 主韌帶-宮骶韌帶複合體損傷

**表現形式**：
- 子宮脫垂（Uterine Prolapse）
- 陰道穹窿脫垂（Vaginal Vault Prolapse，子宮切除術後）
- **腸膨出（Enterocele）**：Douglas窩腹膜連同小腸突入陰道

**Enterocele分類（Waters, 1956）**：

| 類型 | 病因 |
|------|------|
| 先天性（ Congenital） | 腹膜與會陰體融合失敗 |
| 推壓型（Pulsion） | 腹內壓增加（如慢性咳嗽、便祕） |
| 牽扯型（Traction） | 其他脫垂器官拉扯陰道上皮 |
| 醫源性（Iatrogenic） | 手術改變陰道軸向，或未修復Pubocervical Fascia與Rectovaginal Septum |

**統計**：完整陰道穹窿脫垂中，75%合併enterocele

### 後壁脫垂（Posterior Compartment / Rectocele）

**病因**：直腸陰道筋膜（Rectovaginal Fascia）之缺陷

| 缺陷位置 | 脫垂類型 |
|----------|----------|
| 高位（Level I） | 高位直腸膨出，常合併enterocele |
| 中段（Level II） | 側向附著於ATFR（Arcus Tendineus Fasciae Rectovaginalis）缺損 |
| 低位（Level III） | 會陰體缺陷 |

**Richardson（1993）** 首先描述直腸陰道筋膜之**特異位點缺陷（Site-Specific Defects）**

> **臨床重點**
> - 後壁脫垂修補前需確認是否有高位缺陷或隱藏之enterocele，以免術後復發

### 複合型陰道外翻（Complex Vaginal Eversion）

定義：陰道外翻合併 cystocele、rectocele 或兩者

**統計（Morley & DeLancey, 1988）**：
- 僅頂端脫垂：7%
- 頂端 + cystocele：30%
- 頂端 + rectocele：30%
- 頂端 + cystocele + rectocele：30%

### 子宮切除術後陰道穹窿脫垂

| 項目 | 數據 |
|------|------|
| 發生率 | 子宮切除術後高達18.2%（Richter, 1982） |
| 對其他腔室之影響 | 可導致其他腔室脫垂 |

> **臨床重點**
> - 子宮切除術時若未將陰道穹窿懸吊至主韌帶-宮骶韌帶複合體，日後發生穹窿脫垂之風險大增
> - 支撐結構之餘裕性（redundancy）使術後立即脫垂並不常見，但長期風險仍高

## 手術方法選擇

### 陰道修補 vs. 腹式修補

| 考量因素 | 陰道途徑 | 腹式途徑 |
|----------|----------|----------|
| **長期療效** | 復發率較高 | 較持久（Benson et al, 1996） |
| **恢復時間** | 較短 | 較長 |
| **傷口美觀** | 無腹部傷口 | 需開腹或腹腔鏡 |
| **適用性** | 年老、共病症多者 | 年輕、需高耐久性者 |
| **脫垂類型** | 前/後壁為主 | 頂端脫垂 |

> **臨床重點**
> - 腹腔鏡與機器人輔助手術之發展已縮短腹式修復之恢復時間，使更多患者可選擇較持久之修復方式
> - 最終手術選擇應結合患者之年齡、共病症、生育需求、脫垂類型與患者意願共同決定

## 術前諮詢

### 成功之定義

| 面向 | 內容 |
|------|------|
| **客觀指標** | 解剖位置糾正（如POP-Q測量改善） |
| **主觀指標** | 症狀消除（陰道腫塊感消失、de novo症狀最少化） |
| **滿意度** | 患者對整體改善之自我評估 |

### 影響患者滿意度之因素

| 研究 | 發現 |
|------|------|
| Elkadry et al (2003) | 患者滿意度與自我期望達成高度相關 |
| Kenton et al (2007) | 術前期望與就醫準備度影響術後滿意度 |

> **臨床重點**
> - 建議術前直接詢問患者：「您期望術後有什麼改變？」
> - 患者常將術後常見暫時性現象（如疼痛、導尿管攜帶、便祕、急性尿失禁）視為手術併發症，術前應充分說明
