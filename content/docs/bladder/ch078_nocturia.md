## 📖 導讀

**夜尿症（Nocturia）** 指的是為排尿之目的而於睡眠期間醒來，為**下泌尿道症狀（Lower Urinary Tract Symptoms, LUTS）** 中與全身健康最具關聯之症狀。本章探討夜尿症之流行病學、病理生理機轉與系統性評估方法。夜尿症不只是泌尿科問題，更是**代謝症候群（Metabolic Syndrome）**、**心血管疾病**、**骨折**與**早期死亡**之重要指標。治療方面強調精確分類（白天尿量過多、夜間多尿、膀胱容量降低或混合型），並依據病因給予針對性治療，包括行為療法、藥物治療與系統性疾病之控制。

---

## 定義

**夜尿症（Nocturia）**：為排尿目的而在預定睡眠期間醒來（van Kerrebroeck et al, 2002）

- **夜間（Nighttime）**：上床準備睡眠至起床準備活動之時段
- 每晚**2次或以上**之夜間排尿臨床上具有意義
- 注意：應區分「為排尿而醒來（true nocturia）」與「因醒來而順便排尿（incidental nocturnal void）」

> **臨床重點**
> - 夜尿症影響睡眠效率、慢波睡眠（Slow-Wave Sleep, SWS）與睡眠潛伏期
> - 僅10%人口為shift workers，但臨床評估時仍需注意其睡眠型態差異
> - Weiss (2009)研究：88%夜尿症患者（>2次/夜）有夜間多尿（NUV > 33% 24小時尿量）

## 臨床意義

### 夜尿症與全身健康

| 健康議題 | 證據 |
|----------|------|
| **跌倒（Falls）** | Parsons et al (2009)：夜尿症為LUTS中與跌倒最顯著相關者 |
| **髖骨骨折（Hip Fractures）** | Temml et al (2009)：≥2次/夜為年齡獨立風險因子（OR 1.36） |
| **高血壓** | Sleep Heart Health Study：睡眠<6小時或>8小時與高血壓風險增加相關 |
| **代謝症候群** | Hall et al (2008)：睡眠過短或過長者，代謝症候群風險增加≥45% |
| **冠狀動脈心臟病（<60歲男性）** | Lightner et al (2012)：調整後OR 1.36 |
| **早期死亡（≥60歲男性）** | Lightner et al (2012)：OR 1.48 |
| **第二型糖尿病** | 共同擁有相互關聯之病理生理基礎 |

> **臨床重點**
> - 髖骨骨折住院死亡率約5.3%，部分解釋夜尿症與早期死亡之關聯
> - 目前尚不清楚成功治療夜尿症是否能反轉上述健康風險

### 對睡眠結構之影響

| 睡眠參數 | 夜尿症影響 |
|----------|-----------|
| **慢波睡眠（SWS）** | 每晚排尿次數越多，SWS越少（0-1次：62分鐘；≥2次：40分鐘） |
| **睡眠片段化** | 夜間排尿越早發生，SWS補償越不足 |
| **睡眠效率** | 降低 |
| **日間嗜睡** | 增加 |

> **臨床重點**
> - 第1次排尿若發生於前兩個睡眠週期內，SWS平均僅37分鐘；若在兩個週期後，平均56分鐘（Torimoto et al, 2013, P = 0.023）
> - 這顯示「何時」排尿與「次數」同樣重要，睡前服用利尿劑之患者尤其明顯

## 系統性評估

### 頻率-尿量圖（Frequency-Volume Chart, FVC）與24小時排尿日記

**記錄項目**

| 項目 | 臨床意義 |
|------|----------|
| 每次排尿時間與尿量 | 區分true nocturia與incidental void |
| 白天尿量 | 白天尿量過多（Global Polyuria） |
| 夜間尿量（Nocturnal Urine Volume, NUV） | 夜間多尿（Nocturnal Polyuria） |
| 最大膀胱容量 | 膀胱容量減少 |
| 液體攝取量與時間 | 行為因子 |
| 夜間總睡眠時段 | 校正NUV計算 |

**夜間多尿之定義**

| 定義 | 閾值 |
|------|------|
| 傳統定義 | NUV > 33% 24小時尿量 |
| Krimpen研究（50-54歲男性） | 基線44%，追蹤6.5年後51% |
| Krimpen研究（65-69歲男性） | 基線54%，追蹤6.5年後65% |
| van Haarster & Bosch (2012)建議 | NPi > 53%（避免過度診斷） |

> **臨床重點**
> - 24小時排尿日記中，「夜間排尿」之定義需同時具「就寢意圖」與「醒來後排尿意圖」，不限絕對時間
> - Shift workers之「夜間」可能落在白天，臨床解讀時需納入考量

### 夜間多尿之生理學

**正常生理**：夜間尿量隨年齡增加
- < 25歲：NUV/total = 14%
- > 65歲：NUV/total = 34%

**抗利尿激素（Arginine Vasopressin, AVP）之角色**

| 刺激AVP釋放 | 抑制AVP釋放 |
|-------------|-------------|
| 高血清滲透壓 | 心房利鈉肽（ANP） |
| 低血容量 | 壓力感受器負回饋 |
| 血管緊張素II | |

AVP作用：
- **V1a受體**：血管收縮
- **V2受體**：促進腎臟水分再吸收 → 濃縮尿液

### 病因評估方向

| 方向 | 疾病/原因 |
|------|-----------|
| **全身性/多尿** | 糖尿病、尿崩症、藥物（鋰鹽、、四環黴素） |
| **心臟/血管** | 心臟衰竭、腎功能不全、靜脈機能不全（下肢水腫） |
| **荷爾蒙** | 夜間多尿（AVP分泌不足）、甲狀腺機能異常 |
| **阻塞性睡眠呼吸中止（OSA）** | 夜間多尿（肥胖、短頸為徵象） |
| **膀胱局部因素** | 攝護腺阻塞、OAB/逼尿肌過度活動、神經性膀胱、膀胱癌、結石 |
| **藥物** | 見BOX 78-1 |

## BOX 78-1：造成夜尿症之藥物

### 增加尿量之藥物

| 藥物 | 機轉 |
|------|------|
| **選擇性血清素再吸收抑制劑（SSRIs）** | 阻斷ADH分泌 |
| **鈣離子通道阻斷劑（CCBs）** | 增加ANP、阻斷近曲小管鈉離子再吸收 |
| **四環黴素（Tetracycline）** | 削弱ADH作用（降低cAMP） |
| **鋰鹽（Lithium）** | 減少AQP2表現 |

### 失眠與中樞神經作用

| 藥物類別 | 範例 |
|----------|------|
| 荷爾蒙 | 皮質類固醇、甲狀腺製劑 |
| 非典型抗憂鬱劑 | 某些SNRIs |
| 多巴胺促效劑 | Carbidopa |
| 抗癲癇藥物 | Phenytoin |

### 直接影響下泌尿道

| 藥物 | 說明 |
|------|------|
| Tiaprofenic acid（Surgam） | 直接刺激膀胱 |

> **臨床重點**
> - 評估夜尿症時，務必完整review患者之用藥史，包括非處方藥物與草藥製劑
> - 停用或調整可疑藥物應作為治療第一步

## FINNO研究：夜尿症危險因子

| 性別 | 危險因子 |
|------|----------|
| **男性** | 尿急、BPH、失眠、肥胖、抗憂鬱藥使用、不寧腿症候群、攝護腺癌 |
| **女性** | 肥胖、尿急、失眠、糖尿病、不寧腿症候群、冠狀動脈疾病 |

> **臨床重點**
> - Tikkinen et al (2009a)：以上任一危險因子均無法解釋超過50%之夜尿症個案，凸顯夜尿症之**多元病因**特性
> - 臨床處理應跳脫僅考慮LUT之框架，系統性評估整體健康
