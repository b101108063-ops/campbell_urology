# Chapter 88 Aging and Geriatric Urology

## 流行病學與病因

### 人口老化趨勢

- 美國 **65 歲以上**老年人口目前佔總人口約 **13%**，預計 2030 年增至 **20%**
- **85 歲以上**為成長最速區間；每天約有 **10,000 名**美國人年滿 65 歲
- 全球層面：65 歲以上人口從 2000 年的 **4.2 億**預計增至 2030 年的 **9.73 億**
- 老年族群中約 **85%** 居住於社區，僅 **15%（85 歲以上）**需要長期照護機構

### 老年泌尿系統病理

> **臨床重點**：泌尿科本質上即為老年醫學專科，除兒童泌尿外，多數泌尿科醫師超過 **65%** 的患者為老年人口。

| 疾病 | 與老化的關聯 |
|------|-------------|
| **尿失禁（UI）** | 骨盆底肌肉退化、rhabdosphincter（橫紋肌尿道擴約肌）萎縮 |
| **良性攝護腺肥大（BPH）** | 發生率隨年齡直線上升 |
| **攝護腺癌** | 主要好發於老年男性 |
| **膀胱出口阻塞（BOO）** | 與老化攝護腺直接相關 |
| **泌尿道感染（UTI）** | 免疫力下降、膀胱排空不全 |
| **骨盆腔器官脫垂（POP）** | 停經後雌激素減少，骨盆底支撐減弱 |

### 老化的生理變化

- **Homeostenosis（老年窄化）**：老化導致器官功能儲備（functional reserve capacity）下降，對感染、手術等 stress 的應對能力減弱
- **Rhabdosphincter 退化**：老年女性尿道橫紋肌組織顯著減少或消失，被結締組織取代，導致 **stress urinary incontinence（SUI）** 風險增加
- **骨盆底肌肉障礙**：許多老年女性無法在初次檢查時自發性收縮骨盆底肌肉

## 分類與臨床評估

### Charlson Comorbidity Index（CCI）

CCI 是最廣泛使用的共病評估工具，針對慢性疾病賦予分數，總分可預測死亡率。

| 分數 | 意義 |
|------|------|
| 0 | 無已知共病 |
| 1–2 | 輕度共病 |
| ≥ 3 | 重度共病，手術風險顯著增加 |

CCI 已被驗證可用於多種泌尿科疾病（如腎細胞癌）的臨床決策，幫助在老年患者中權衡監測與手術治療。

### 功能評估（Functional Assessment）

老年患者術前應評估：

| 項目 | 內容 |
|------|------|
| **日常生活活動（ADL）** | 吃飯、穿衣、如廁、沐浴等基本功能 |
| **工具性 ADL（IADL）** | 服藥、購物、理財、交通 |
| **認知功能** | Mini-Cog 測驗（時鐘繪圖 + 回憶測試）篩檢認知障礙 |
| **憂鬱篩檢** | Geriatric Depression Scale（GDS）-15 題，≥ 3 分為異常 |

### 認知功能與憂鬱

- **認知障礙**：老年泌尿科患者中常見，維生素 B12 缺乏、，甲狀腺功能低下、藥物副作用均為可逆性原因
- **憂鬱症**：並非老化的正常現象，在 UI 及泌尿生殖系統癌症患者中發生率更高，GDS 分數異常時應轉介精神科或老年科

> **臨床重點**：自我健康評估不良（poor self-reported health）是老年人死亡率的強烈負向預測因子，有時比醫師評估更具預測力。

## 診斷方式

### 老年患者特殊評估重點

| 系統 | 評估內容 |
|------|----------|
| **泌尿系統** | 尿流速（uroflowmetry）、餘尿（PVR）、尿動力學（針對複雜病例） |
| **腎功能** | 肌酸酐（Creatinine）、eGFR（預估腎絲球濾過率） |
| **共病評估** | CCI 評分、藥物盤點（polypharmacy 評估） |
| **認知 / 情緒** | Mini-Cog、GDS-15 |
| **營養狀態** | albumin、體重變化 |

## 治療原則

### 手術風險與醫療最適化

> **臨床重點**：**年齡本身不應是手術的限制因素**，共病程度較年齡對手術結果的影響更為顯著。微創手術技術的發展已大幅拓展老年患者的治療可能性。

| 策略 | 說明 |
|------|------|
| **微創手術** | 減少術後併發症、縮短恢復期 |
| **醫療最適化** | 術前控制血壓、血糖、心肺功能；停用不必要抗凝血藥物 |
| **多專科合作** | 麻醉科、老年科、心臟科共同評估高風險患者 |
| **個人化治療目標** | 根據患者預期壽命、功能狀態、生活品質期望制定治療計畫 |

### 老年泌尿科護理要點

- **泌尿道感染（UTI）**：老年患者 UTI 症狀可能不典型（無發燒但意識改變），需高度警覺
- **尿失禁**：約 **30%–50%** 老年人口受影響，應作為可治療的疾病而非老化的正常現象對待
- **攝護腺癌篩檢**：考量患者預期壽命（≥ 10 年）與共病負荷，與患者共同決策

## 臨床重點摘要

> **臨床重點**
> - 全球老年人口快速增長，泌尿科醫師需具備處理老年複雜病患的專業能力
> - **Charlson Comorbidity Index（CCI）**是標準化共病評估工具，可協助治療決策
> - **功能性評估**（認知、憂鬱、日常生活能力）應常規納入老年泌尿科患者術前評估
> - **年齡本身不是手術禁忌**，共病控制與微創技術使老年患者安全接受手術治療成為可能
> - 老年泌尿科疾病（UI、BPH、攝護腺癌、UTI）與憂鬱及生活品質下降高度相關，應全面評估
> - **自我健康評估**是強烈的預後指標，臨床應將其納入整體決策
