## 📖 導讀

**尿失禁（Urinary Incontinence, UI）**是全球最常見的泌尿科慢性病之一，影響所有年齡層女性，並對生活品質（Quality of Life, QoL）造成重大衝擊。本章節系統整理 UI 的流行病學數據、各類型的危險因子，以及**逼尿肌過度活動（Detrusor Overactivity, DO）**、**應力性尿失禁（Stress Urinary Incontinence, SUI）**與**混合性尿失禁（Mixed Urinary Incontinence, MUI）**的病理生理機轉，為後續章節的手術治療奠定基礎。

---

## 尿失禁的分類與定義

### 主要類型

| 類型 | 定義 | 典型誘因 |
|---|---|---|
| **應力性尿失禁（SUI）** | 腹壓增加（如咳嗽、打噴嚏、運動）時發生非自願性漏尿 | 尿道移動度過大、括約肌功能不足 |
| **急迫性尿失禁（Urgency UI / Urge Incontinence）** | 伴隨強烈尿意感的非自願漏尿 | 逼尿肌過度活動（DO）|
| **混合性尿失禁（MUI）** | SUI 與急迫性 UI 同時存在 | 兩種機轉並存 |
| **持續性尿失禁（Continuous UI）** | 完全無自主排尿，持續漏尿 | 尿道關閉嚴重缺陷、先天異常、瘻管 |
| **隱性尿失禁（Insensible UI）** | 患者無知覺的情況下發生漏尿 | 神經性膀胱、認知功能障礙 |
| **性交尿失禁（Coital UI）** | 性交過程中（插入、深入、射精）發生漏尿 | 膀胱頸移動度過大、DO |

> **臨床重點**
> - **隱性尿失禁**常见于糖尿病神经病变或中风后患者，常被误认为「膀胱无力」
> - **性交尿失禁**在临床上常被忽视，建议主动询问

## 膀胱儲尿與感覺功能

### 正常儲尿生理

膀胱的**儲尿期（Filling Phase）**依賴：
- **膀胱順應性（Bladder Compliance）**：膀胱容量增加時壓力維持低水平
- **逼尿肌靜止（Detrusor Relaxation）**：副交感神經抑制
- **尿道括約肌維持張力（Sphincter Tone）**：交感神經與軀體神經共同支配

### 儲尿障礙症狀

| 症狀 | 定義 |
|---|---|
| **日頻（Increased Daytime Frequency）** | 24 小時排尿次數 ≥ 8 次 |
| **夜尿（Nocturia）** | 睡眠中被尿意喚醒，每次中斷前後均有睡眠 |
| **尿急（Urgency）** | 突然、強烈的排尿欲望，難以延遲 |
| **膀胱感覺增加** | 比既往正常狀態更早出現尿意（可延遲排尿，有別於尿急）|
| **膀胱感覺減退** | 尿意出現延遲，但患者自知膀胱在充盈 |
| **膀胱感覺缺失** | 完全無膀胱充盈感與尿意 |

> **臨床重點**
> - **膀胱過度活動症（Overactive Bladder, OAB）**定義：伴隨或不伴隨急迫性尿失禁的尿急，通常伴有頻尿與夜尿
> - OAB 是**門診最常見的排尿障礙主訴**，需與 SUI 鑑別診斷

## 尿失禁的流行病學

### 評估研究的關鍵方法學因素

| 因素 | 影響 |
|---|---|
| **UI 定義** | 改變定義即導致盛行率估計差異顯著 |
| **問卷工具** | 特異性、長度、複雜度各異 |
| **評估時間框架** | 「過去一個月」vs.「過去一週」差異巨大 |
| **生活品質 vs. 症狀存在** | 以「困擾程度」定義 vs. 以「症狀存在」定義，盛行率不同 |
| **研究設計** | 病例對照（無法定義發生率）、世代研究（可計算發生率）、橫斷面（僅能計算盛行率）|

> **臨床重點**
> - **隨機對照試驗（RCT）**是評估治療結局與相對危險因子最嚴謹的設計
> - 物理演示（如尿墊試驗）確認的 UI 與僅以問卷確定的 UI，其盛行率差異可達 2–3 倍

### 全球盛行率

全球研究綜合分析（回應率 > 60% 的研究）：

- **最低報告**：2.8%（撒哈拉以南非洲年輕未產女性）
- **最高報告**：58.8%（荷蘭社區研究）
- **多數研究共識**：**25%–40%** 的成年女性有某種程度的 UI

### 類型分布

| 尿失禁類型 | 占所有 UI 的比例 |
|---|---|
| **應力性尿失禁（SUI）** | 約 50% |
| **混合性尿失禁（MUI）** | 略低於 SUI |
| **急迫性尿失禁** | 明顯少於 SUI |

> **臨床重點**
> - **年輕族群**中 SUI 占主導；隨年齡增長，各類型比例趨於接近
> - 年度**新發生率（Incidence Rate）**：1%–10%，受族群與調查工具影響極大
> - **緩解率（Remission Rate）**：每年 1%–5%；年輕女性較高，男性因尿失禁原因不同（多為術後或神經性）緩解率更高

## 危險因子

### 年齡

- 多數研究顯示 UI 與年齡**明確正相關**
- **停經（Menopause）**為一關鍵節點：停經後尿失禁報告率驟然上升
- Medicare 受益人（> 65 歲）中 **37% 報告 UI**；即使在該族群中，年齢仍為獨立危險因子

> **臨床重點**
> - 老化本身不應被視為 UI 的必然結果；但年齡是大多數研究中最強的獨立危險因子之一

### 體重與肥胖

- 肥胖顯著增加 SUI 與 OAB 風險
- **肥胖女性（BMI > 30）**接受減重手術後，UI 症狀顯著改善
- 減重 5%–10% 可帶來臨床上有意義的 UI 改善

### 懷孕與陰道分娩

| 因素 | 效應 |
|---|---|
| **陰道分娩** | 顯著增加 SUI 與 POP 風險；胎兒頭部徑線大、第二產程過長為高危 |
| **剖腹產** | 保護性效果有限；未能完全預防 UI |
| **會陰切開術（Episiotomy）** | 常規會陰切開不降低 UI 風險 |

### 吸烟

- 多項大規模研究證實**吸烟與 UI 正相關**
- 重度吸烟者的急迫性症狀比輕度吸烟者更嚴重
- 吸烟導致慢性咳嗽→增加腹壓→加重 SUI

> **臨床重點**
> - 吸烟者的 UI 發生率比非吸烟者高出 **56%**（平均尿失禁發作次數）

### 飲食因素

| 物質 | 關聯證據 |
|---|---|
| **咖啡因（特別是咖啡）** | 與急迫性 UI、OAB 症狀顯著正相關（男性資料越來越明確）|
| **碳酸飲料** | 主要與急迫性症狀相關（待驗證）|
| **人工甜味劑** | 可能與 OAB 相關（證據不足）|
| **酒精** | 各類 UI 證據不一致 |

### 內科共病

| 疾病 | 與 UI 的關聯 |
|---|---|
| **第 2 型糖尿病（DM Type 2）** | UI 盛行率可達非糖尿病女性的 **2 倍**；體重過重進一步放大風險 |
| **憂鬱症** | 顯著正相關（雙向關係）|
| **慢性肺病** | 長期咳嗽增加腹壓 |

### 藥物

可能誘發或加重 UI 的藥物：

| 藥物類別 | 機轉 |
|---|---|
| **利尿劑** | 增加尿液生成 |
| **α-受體阻斷劑** | 降低尿道阻力 |
| **抗膽鹼能藥物** | 認知障礙（老年人）→ 急迫性 UI |
| **benzodiazepines** | 鎮靜、活動能力下降 |
| **ACE 抑制劑** | 咳嗽（可能加重 SUI）|

## 逼尿肌過度活動（Detrusor Overactivity, DO）的病理生理

### 發病機制

| 機制 | 描述 |
|---|---|
| **神經性** | 中樞抑制通路受損（中風、脊髓損傷、帕金森氏症）|
| **肌源性** | 逼尿肌本身異常：受體密度增加、離子通道改變 |
| **特發性** | 無明確病因，可能與老化相關 |

### DO 與 OAB 的臨床表現

- **尿急（Urgency）**：DO 的主要症狀
- **頻尿**：逼尿肌不自主收縮增加排尿頻率
- **夜尿**：夜間 DO 活動度增加
- **急迫性尿失禁**：DO 收縮壓超過尿道阻力時發生

> **臨床重點**
> - OAB 的核心病理生理是**膀胱感覺增強**與**逼尿肌不穩定收縮**
> - OAB 患者的 QoL 損害程度與症狀嚴重程度不一定成正比；「尿急」症狀對 QoL 的影響最大

## 應力性尿失禁（SUI）的病理生理

### 兩個主要缺陷

| 缺陷 | 描述 |
|---|---|
| **尿道移動度過大（Urethral Hypermobility）** | 骨盆底支持組織薄弱，腹壓增加時膀胱頸與尿道近端移動度 > 1–2 cm |
| **固有括約肌缺陷（Intrinsic Sphincter Deficiency, ISD）** | 尿道括約肌本身关闭功能不足；最大尿道關閉壓（MUCP）常 < 20 cm H₂O |

> **臨床重點**
> - **單純 SUI**（無 ISD）患者：恥骨尿道移動度過大是主要病因，懸吊術（Sling / Burch）效果好
> - **重度 ISD**（MUCP ≤ 20 cm H₂O）：不論移動度如何，注射療法或人工括約肌（AUS）為首選
> - 臨床上 ISD 與尿道移動度過大**常同時存在**

### 尿道關閉壓測量（Urethral Pressure Profilometry）

| 指標 | 閾值 | 臨床意義 |
|---|---|---|
| **最大尿道關閉壓（MUCP）** | ≤ 20 cm H₂O | 暗示顯著 ISD |
| **腹壓漏尿壓（ALPP）** | ≤ 60 cm H₂O | 嚴重 ISD 的指標 |

> **臨床重點**
> - ALPP 對 ISD 的量化價值在文獻中仍有爭議；不應單一指標決定治療策略
> - 建議結合**臨床症狀、尿道移動度測量（Q-tip Test）與尿動力學參數**綜合判斷
