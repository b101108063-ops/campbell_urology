# Chapter 90 Bladder and Female Urethral Diverticula

## 流行病學與病因

### 定義

**Bladder diverticulum（膀胱憩室）**是指膀胱黏膜穿過肌肉層向外突出形成的囊狀結構，可為先天性或後天性。

### 病因分類

| 類型 | 機制 | 特點 |
|------|------|------|
| **先天性** | 膀胱壁局部發育缺陷，肌肉層未完整閉合 | 可能與胚系發育異常相關 |
| **後天性（獲得性）** | 長期膀胱出口阻塞（BOO）導致膀胱內壓升高，黏膜經肌肉薄弱處突出 | 約 **70%** 與 **BPH** 相關 |
| **Hutch diverticulum** | 位於輸尿管口外側上方，常見於神經性膀胱合併 VUR | 因輸尿管口周圍肌肉層發育不良 |
| **醫源性** | 膀胱切開術後肌肉層閉合不當，或輸尿管重新植入術後 | 縫合線處形成弱點 |

> **臨床重點**：後天性膀胱憩室幾乎皆與某種形式的 **膀胱出口阻塞** 或 **神經性排尿功能障礙** 有關，治療時必須同時處理根本病因。

### 臨床特徵

| 族群 | 常見表現 |
|------|----------|
| **成人男性** | 約 70% 與 BPH 相關；症狀多為非特異性（頻尿、餘尿感、下腹飽滿） |
| **成人女性** | 相對少見，多與出口阻塞相關（dysfunctional voiding、陰道脫垂、膀胱頸肥厚、尿道狹窄） |
| **兒童** | 先天性為主，常以 **泌尿道感染（UTI）** 表現 |

---

## 分類與評估

### 臨床表現

| 症狀 | 說明 |
|------|------|
| **複發性 UTI** | 憩室內尿液淤積導致细菌滋生 |
| **血尿（Hematuria）** | 憩室內慢性發炎或惡性腫瘤 |
| **排尿不完全感** | 大型憩室佔據骨盆腔空間 |
| **腹部腫塊** | 極少見，巨大憩室可能以腹部腫塊表現 |
| **腹股溝疝氣** | 憩室內容物可通過腹股溝管突出 |

### 評估工具

| 工具 | 目的 |
|------|------|
| **尿分析與尿培養** | 確認感染、膿尿、血尿 |
| **尿細胞學** | 排除惡性腫瘤 |
| **超聲波（Ultrasonography）** | 初步評估憩室數量、大小、位置 |
| **靜脈腎盂造影（IVP）** | 評估上泌尿道（hydroureteronephrosis） |
| **VCUG（排尿膀胱尿道攝影）** | 確認憩室與膀胱的連接、評估是否合併 VUR |
| **CT 或 MRI** | 評估周圍解剖結構（輸尿管位置、直腸等），確認無周邊侵犯 |
| **膀胱鏡（Cystoscopy）** | 確診並評估憩室頸部、內壁、排除惡性腫瘤 |
| **尿動力學（Urodynamics）** | 確認是否有隱藏的 BOO 或神經性排尿功能障礙 |

## 治療原則

### 手術適應症

| 適應症 | 說明 |
|--------|------|
| **復發性 UTI 藥物治療無效** | 建議憩室切除 |
| **大型憩室造成症狀** | 排尿不完全、腹部飽滿感 |
| **懷疑或確認惡性腫瘤** | 憩室內發現腫瘤 |
| **持續性膿尿** | 對抗生素治療反應不佳 |
| **上泌尿道積水** | 憩室壓迫導致 |

### 手術方式

| 方式 | 適用情況 |
|------|----------|
| **經膀胱憩室切除術（Transvesical diverticulectomy）** | 多數患者首选 |
| **憩室剝離術（Diverticular dissection）** | 與周圍組織粘連緊密者 |
| **微創腹腔鏡修復** | 技術可行但對大手術憩室具挑戰性 |

> **臨床重點**：手術時務必同時處理 **根本的膀胱出口阻塞**，否則術後復發率極高。

---

## 膀胱憩室與惡性腫瘤

| 項目 | 數據 |
|------|------|
| **憩室內惡性腫瘤發生率** | 0.8%–10%（歷史文獻） |
| **最常見病理類型** | ** Transitional cell carcinoma（TCC）**（70%–80%）；**Squamous cell carcinoma（SCC）**（20%–25%） |
| **好發年齡** | 65–75 歲 |
| **組織變化** | 45%–80% 憩室標本發現慢性發炎性泌尿道上皮改變 |

> **臨床重點**：憩室內發現 **filling defect（填充缺損）** 或其他異常時，應高度懷疑惡性腫瘤並進行活檢。

---

## 臨床重點摘要

> **臨床重點**
> - 後天性膀胱憩室約 **70%** 與 **BPH** 相關，治療時必須同時處理出口阻塞
> - 女性膀胱憩室相對少見，一旦發現應仔細評估膀胱出口（dysfunctional voiding、陰道脫垂、抗尿失禁手術後狹窄）
> - **復發性 UTI 對抗生素治療無效**是憩室切除手術的重要適應症
> - 發現膀胱憩室時，應評估 **上泌尿道積水**（約 7% 成人，兒童可達 30%）
> - 憩室內惡性腫瘤以 **TCC** 為主（約 70%–80%），發現 filling defect 應進行 cystoscopy 與活檢
> - 兒童先天性膀胱憩室常以 **UTI** 表現，且上泌尿道異常發生率較高（達 30%），需積極評估
> - 術前 **VCUG** 與 **尿動力學** 檢查對規劃手術方式與預後至關重要
