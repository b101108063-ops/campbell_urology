## 📖 導讀

尿失禁與骨盆腔器官脫垂（pelvic organ prolapse, POP）是常見的骨盆底功能障礙（pelvic floor dysfunction, PFD），嚴重影響生活品質。本章節系統性介紹完整評估流程，強調**病史（history）**與**理學檢查（physical examination）**的核心地位，並說明各項輔助檢查的臨床意義。臨床上**「膀胱是個不可靠的見證者（The bladder is an unreliable witness）」**——所有資訊必須整合才能做出準確診斷。

---

## H2 病史詢問（History of Present Illness）

### H3 尿失禁的類型與量化

** leakage characterization** 應涵蓋以下面向：

| 評估面向 | 臨床問題 |
|----------|----------|
| **發生情境** | 物理活動（壓力性）？急迫感（急迫性）？無知覺？ |
| **混合類型** | 哪一個成分困擾更大或發生更頻繁？ |
| **嚴重度量化** | 每日使用尿布/護墊數量；研究環境可用**墊重測試（pad weight testing）** |
| **排尿型態** | 日間頻率、夜間頻率；是否有阻塞症狀（hesitancy、間歇性、力道減弱、需用力） |
| **病程與誘發事件** | 妊娠、生產創傷、骨盆或脊椎手術、前列腺手術、神經損傷 |

> **臨床重點**
> - 急迫性尿失禁（urgency urinary incontinence）與**膀胱過動症（overactive bladder, OAB）**密切相關，病理生理核心是**逼尿肌過動（detrusor overactivity, DO）**
> - **墊重測試（1 小時或 24 小時）**是客觀量化尿失禁程度的標準方法，可區分為輕度（< 8 g/hr）、中度（8–50 g/hr）、重度（> 50 g/hr）
> - 阻塞症狀（hesitancy、斷續流、尿流減弱）在男性應優先排除**前列腺肥大（benign prostatic hyperplasia, BPH）**，在女性則需排除**POP**造成的尿道扭曲

### H3 骨盆腔器官脫垂症狀

POP 的常見主訴：

- 自覺陰道有物脫出（"something falling out"）
- 需用手將脫垂組織推回才能排尿或排便
- 性交不適或困難
- 慢性骨盆疼痛或沉重感

## H2 理學檢查（Physical Examination）

### H3 骨盆底肌肉評估

**骨盆底肌肉（pelvic floor muscles, PFM）** 評估方法：

1. 囑患者如同中斷尿流般收緊骨盆底
2. 觀察是否有**提肛肌（levator ani）**的對稱性收縮
3. 檢查**陰道壁（vaginal wall）**完整性與POP程度
4. 評估**會陰體（perineal body）**與**陰道口（genital hiatus）**大小

### H3 骨盆腔器官脫垂量化系統（POP-Q）

POP-Q 是國際通用的**POP分期系統**，以**處女膜（hymen）**為參考點：

| 測量點 | 定義 |
|--------|------|
| **Aa** | 陰道前壁中線，處女膜近端 3 cm |
| **Ba** | 前壁最遠端脫垂點 |
| **C** | 子宮頸或陰道穹窿最遠端 |
| **D** | 後穹窿（未切除子宫者） |
| **Ap / Bp** | 陰道後壁對應點 |
| **gh（genital hiatus）** | 陰道口大小（尿道後緣至陰道口後緣） |
| **pb（perineal body）** | 陰道口至肛門中點距離 |
| **tvl（total vaginal length）** | 將脫垂復位後測量陰道深度 |

**POP-Q 分期標準：**

| 分期 | 標準 |
|------|------|
| **Stage 0** | 所有支持點在正常位置（-3 cm），C 或 D ≤ -(tvl-2) |
| **Stage I** | 脫垂最遠端點 < -1 cm |
| **Stage II** | 脫垂最遠端點 ≥ -1 cm 且 ≤ +1 cm |
| **Stage III** | 脫垂最遠端點 > +1 cm 但 < +(tvl-2) cm |
| **Stage IV** | 脫垂最遠端點 ≥ +(tvl-2) cm（完全脫垂） |

> **臨床重點**
> - POP-Q 提供**可重現的客观測量**，優於傳統主觀分期，適用於手術前評估與術後追蹤比較
> - **Stage II 以上（脫垂超出處女膜）**通常為有臨床意義的脫垂，Stage III/IV 可能需手術修復
> - tvd 與 pb 的測量有助於評估**復發風險**與**術式選擇**（如是否需使用網膜固定）

### H3 神經學檢查

| 檢查項目 | 評估內容 | 臨床意義 |
|----------|--------------------|
| **步態（gait）** | 觀察不對稱或異常 | 上運動神經元病灶 |
| **感覺測試** | 下肢、會陰部感覺 | S2–S4 感覺分布 |
| **運動測試** | 下肢肌力 | 周邊神經或神經根損傷 |
| **球海綿體肌反射（BCR）** | 擠壓陰蒂/龜頭引發肛門收縮 | S2–S4 神經根完整性；正常男性 100%、女性 70% 可誘出 |
| **肛門括約肌張力** | 自主收縮能力 | S2–S4 運動功能 |

> **臨床重點**
> - BCR 陽性代表**薦髓（S2–S4）反射弧完整**；若缺失則需排除**馬尾症候群（cauda equina syndrome）**等神經急症
> - **認知功能（cognitive status）**與**活動能力（mobility）**是尿禁的重要影響因子；兩者受損會降低患者及時如廁的能力

## H2 藥物對下泌尿道的影響

| 藥物類別 | 代表藥物 | 對下泌尿道的影響 |
|----------|----------|-----------------|
| **抗膽鹼藥（Anticholinergics）** | 減少膀胱收縮力，可能誘發**尿滯留（urinary retention）** |
| **抗組織胺（Antihistamines）** | 增加出口阻力，可能惡化**阻塞症狀**或**OAB** |
| **α-促效劑（α-Agonists）** | 增加尿道與膀胱頸張力，可能惡化**急迫性尿失禁** |
| **利尿劑（Diuretics）** | 增加尿液生成，誘發或加重各類型尿失禁 |
| **鎮靜劑（Sedatives）** | 降低活動力與認知，影響如廁能力 |
| **鈣離子通道阻斷劑** | 減少逼尿肌收縮力，誘發**尿滯留** |
| **膽鹼酶抑制劑** | 增加膀胱收縮力，用於**逼尿肌無力（underactive bladder）**的治療評估 |

> **臨床重點**
> - 老年人**多重用藥（polypharmacy）**是尿失禁的重要可控因素；應系統性回顧所有現行藥物
> - **停經後女性**使用**系統性荷爾蒙替代治療（systemic HRT）**可能增加 SUI 風險；而**局部雌激素**對萎縮性尿道炎有明確益處

## H2 男性特有的理學檢查重點

- **陰莖檢查**：確認是否有**尿道口狹窄（meatal stenosis）**
- **前列腺指診（DRE）**：評估大小、結節、壓痛（適用於有阻塞症狀的男性）
- **站立咳嗽測試（Standing cough stress test）**：術後或懷疑**應力性尿失禁**時，站立位咳嗽觀察漏尿
- **後腹腔手術史**：如**根除性前列腺切除術（radical prostatectomy）**或**腹會陰切除術（abdominoperineal resection）**，可導致**神經性膀胱功能障礙**
