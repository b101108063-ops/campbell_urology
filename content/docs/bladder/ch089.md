# Chapter 89 Urinary Tract Fistulae

## 流行病學與病因

### 歷史背景

- **1663 年**：Hendrik von Roonhuyse 首次描述 VVF 手術修復，使用尖銳天鵝羽毛筆進行疤痕切除與對位縫合
- **1675 年**：Johann Fatio 完成第一例成功 VVF 修復
- **1838 年**：John Peter Mettauer 使用鉛線縫合完成美國首例成功修復
- **1852 年**：James Marion Sims 發表經陰道入路 silver wire 技術系列報告（其歷史爭議請見歷史章節）
- **1888 年**：Trendelenburg 報告首例經腹部 VVF 修復

### 病因分類

| 病因 | 說明 |
|------|------|
| **開發中國家** | 長時間難產（obstructed labor）導致前陰道壁、膀胱、膀胱頸及近端尿道壓迫性壞死 |
| **已開發國家** | **婦科手術**（尤其是子宫切除術）為最主要原因 |
| **放射治療** | 放射後數月至數年發生，組織品質差，修復困難 |
| **其他** | 外傷、惡性腫瘤、感染性疾病 |

### 開發中國家：Obstructed Labor Injury Complex（難產損傷複合徵）

> **臨床重點**：在開發中國家，**96.5%** 的 VVF 案例與分娩直接相關。

難產損傷複合徵包括：
- 近端尿道及膀胱頸缺損
- **Stress incontinence**
- Hydroureteronephrosis（輸尿管積水）
- 腎功能衰竭
- Rectovaginal fistula（直腸陰道瘻）
- Anal sphincter incompetence（肛門擴約肌失能）
- 子宮頸破壞、無月經、骨盆腔炎、陰道狹窄

**風險因子**（開發中國家）：
1. 年輕結婚與早孕（骨盆未成熟）
2. 營養不良導致骨骼發育不良
3. 缺乏合格產前及產科照護

### 已開發國家：婦科手術後 VVF

- 子宮切除術後 VVF 發生率約 **0.1%–0.2%**
- 英格蘭與威爾斯每年約 **140–150 例** VVF 修復手術
- **發生子宮切除術後 VVF** 最常見機制：
  1. 術中未被發現的膀胱切開傷（incidental unrecognized iatrogenic cystotomy）
  2. 電燒造成組織壞死
  3. 陰道 cuff 縫合時同時縫到膀胱
  4. 組織缺血、壞死，最終形成瘻管

## 分類與診斷

### 臨床表現

| 症狀 | 說明 |
|------|------|
| **持續性陰道漏尿** | 最常見主訴，漏尿量與瘻管大小成正比 |
| **體位性變化** | 仰臥時漏尿可能減少，坐起或站立時加劇 |
| **復發性泌尿道感染** | 因尿液持續污染陰道 |
| **會陰皮膚刺激** | 長期潮濕導致 |
| **術後表現** | 導尿管移除後立即出現，或 **1–3 週後**延遲出現 |

### 診斷方式

| 方式 | 內容 |
|------|------|
| **理學檢查** | 雙葉窺器（bivalved speculum）檢查，確認位置、大小、數量 |
| **陰道鏡（Vaginoscopy）** | 使用 flexible cystoscope 確認瘻管路徑 |
| **Methylene blue / Indigo carmine 染色試驗** | 膀胱灌注顯影劑，觀察陰道紗布是否染色 |
| **靜脈腎盂造影（IVP）** | 排除 ureterovaginal fistula（輸尿管陰道瘻） |
| **CT 或 MRI** | 評估周圍組織發炎、骨盆結構異常 |

> **臨床重點**：術後不明原因陰道漿液性分泌物應懷疑 VVF；大型或高位 VVF（陰道 cuff 位置）可能需經腹部入路修復。

## 治療原則

### 手術修復時機

| 狀況 | 建議 |
|------|------|
| **輕度發炎 / 無明顯感染** | 可考慮立即修復 |
| **顯著發炎、感染或纖維化** | 建議延遲修復（2–3 個月），先行引流與控制感染 |
| **放射後 VVF** | 需特別慎重規劃，組織品質差，修復挑戰性高 |

### 手術入路

| 入路 | 適用情況 |
|------|----------|
| **經陰道（Transvaginal）** | 多數 VVF 首選，微創、恢復快 |
| **經腹部（Transabdominal）** | 大型、高位 VVF；需要同時處理其他骨盆腔病理 |
| **Martius fat pad flap** | 使用陰唇脂肪墊作為 interpositional flap，加強修復 |

### 預防策略（Hutch, 1969）

1. 術中使用 vital dyes 即時偵測膀胱損傷
2. 膀胱進行不透水縫合
3. 適當放置膀胱外引流
4. 術後發現膀胱損傷後，避免再做陰道切口
5. 術後長期維持膀胱引流

## 臨床重點摘要

> **臨床重點**
> - **開發中國家**：VVF 主要由難產引起（96.5%），屬於_obstructed labor injury complex_的一部分
> - **已開發國家**：**子宫切除術**是 VVF 最常見原因，術中及時發現並修復膀胱損傷是預防關鍵
> - **放射後 VVF** 可於放射完成後數月至數年才出現，修復難度最高
> - **Methylene blue 染色試驗**是門診初步診斷 VVF 的簡單有效工具
> - 修復時機應根據陰道組織發炎程度決定，顯著發炎者建議延遲 2–3 個月修復
> - 術後不明陰道分泌物應提高警覺，特別是接受過婦科手術或放射治療的患者
