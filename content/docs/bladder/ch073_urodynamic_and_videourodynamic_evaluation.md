## 📖 導讀

尿路動力學（urodynamics, UDS）是評估下尿道功能障礙的**動態研究**，可客觀重現患者症狀並確認其尿路動力學根源。本章節依據**國際尿控協會（International Continence Society, ICS）**與 **AUA/SUFU 2012 指引**，系統性介紹 UDS 的適應症、核心術語、檢查方法與風險因子，並強調 UDS 必須與完整病史、理學檢查及其他檢查**整合判讀**，而非單獨作為診斷依據。

## H2 尿路動力學的臨床角色

### H3 何時需要 UDS

UDS 最具價值的臨床情境：

1. **確定造成症狀的疾病**（例如：LUTS 或尿失禁的根本原因）
2. **評估疾病對上泌尿道的潛在威脅**（例如：神經性膀胱功能障礙）

> **臨床重點**
> - UDS 在**病史、理學檢查與簡單檢查不足以確診**時最具價值；它不是所有下尿道症狀患者的一線檢查
> - UDS 在**「不自然環境」中進行**，不一定能完全複製真实生活情境；未誘發出異常並不等同「正常」
> - 應根據**患者症狀與臨床問題客製化**檢查項目，而非每次執行全套標準化流程

### H3 AUA/SFU 指引中的六大 UDS 角色

| 角色 | 臨床目的 |
|------|----------|
| **識別/排除** | 確認造成 LUTD（如尿失禁）的因素並評估其相對重要性 |
| **功能評估** | 評估尚未表現為症狀的其他 LUT 功能障礙 |
| **上泌尿道的預測** | 預測 LUTD 對上泌尿道的可能危害 |
| **治療結果預測** | 預測擬議治療的可能成效與不良反應 |
| **治療效果確認** | 確認治療效果或理解新型/實驗性治療的作用機制 |
| **失敗原因分析** | 分析先前治療失敗的原因 |

## H2 上泌尿道的尿路動力學風險因子

以下 UDS 發現代表**高風險狀態**，通常需要積極介入以防止**上泌尿道的去代償（upper tract decompensation）**：

| 風險因子 | 說明 |
|----------|------|
| **順應性受損（Impaired Compliance）** | 膀胱壁纖維化導致填充時壓力急遽上升 |
| **逼尿肌-外括約肌失弛緩（DESD）** | 神經性膀胱常見，收縮時 sphincter 不協調放鬆 |
| **逼尿肌-內括約肌失弛緩（DISD）** | 平滑肌 sphincter 在排尿時異常收縮 |
| **高壓逼尿肌過動** | 整個填充期均存在高壓力 DO |
| **逼尿肌漏尿點壓力 > 40 cm H₂O** | 上泌尿道的危險閾值 |
| **排空不良合併高儲尿壓** | 同時有出口阻塞與逼尿肌功能障礙 |

> **臨床重點**
> - **逼尿肌漏尿點壓力（detrusor leak point pressure, DLPP）> 40 cm H₂O** 是預測**膀胱輸尿管逆流（VUR）**與**上泌尿腎功能受損**的獨立危險因子
> - **DESD（Detrusor External Sphincter Dyssynergia）** 常見於**脊髓損傷（spinal cord injury）**患者，是神經性膀胱最危險的功能障礙之一，需要即時處理以防止腎功能惡化

## H2 排尿功能障礙的功能分類

### 三大類功能異常

| 類別 | 定義 |
|------|------|
| **儲尿障礙（Storage Dysfunction）** | 儲尿功能失敗 |
| **排尿障礙（Emptying Dysfunction）** | 排尿/排空功能失敗 |
| **混合障礙（Combined Dysfunction）** | 同時有儲尿與排尿問題 |

### 解剖區域分類

每類功能障礙可依**受影響的解剖區域**進一步細分：

**A. 膀胱因素：**
- **過動（Overactive）** → 儲尿障礙（DO）
- **活動不足（Underactive）** → 排尿障礙

**B. 出口因素：**
- **前列腺阻塞、膀胱頸攣縮、尿道狹窄**
- **橫紋肌括約肌失弛緩（Striated sphincter dyssynergia）**（神經性）
- **平滑肌括約肌失弛緩（Smooth sphincter dyssynergia）**（神經性）

## H2 尿路動力學核心術語（ICS 標準）

### 填充性膀胱測壓（Filling Cystometry）與膀胱感覺

| 術語 | 定義 |
|------|------|
| **生理填充率（Physiologic filling rate）** | 填充率 < 預測最大值（體重 kg ÷ 4，單位 mL/min） |
| **非生理填充率** | 填充率 > 預測最大值 |
| **首次填充感（First sensation）** | 患者首次察覺膀胱正在填充的容量 |
| **首次排尿感（First desire to void）** | 導致患者想在「下一個方便時機」排尿的感覺 |
| **強烈排尿感（Strong desire to void）** | 持續的排尿慾望，若延遲會感到不適 |
| **膀胱疼痛（Bladder pain）** | 異常，為 BPS/間質性膀胱炎的表現 |
| **急迫感（Urgency）** | 突然且強烈的排尿慾望，無法延遲 |

### 逼尿肌功能（Detrusor Function）

| 術語 | 定義 |
|------|------|
| **正常逼尿肌功能** | 填充時壓力變化極小或無，無不自主收縮 |
| **逼尿肌過動（DO）** | 填充期出現不自主逼尿肌收縮 |
| **相性 DO（Phasic DO）** | 特徵性波形，不一定導致尿失禁 |
| **終端 DO（Terminal DO）** | 單次無法制止的收縮，導致尿失禁並膀胱排空 |
| **神經性逼尿肌過動（Neurogenic DO）** | 伴隨神經學疾病的 DO（取代舊名「痙攣性膀胱」） |
| **特發性逼尿肌過動（Idiopathic DO）** | 無神經學原因的 DO（取代舊名「不穩定膀胱」） |

> **臨床重點**
> - **Cystometric capacity（膀胱測壓容量）**：患者獲准排尿時的膀胱容量；**Maximum cystometric capacity**：患者感到無法再延遲排尿時的容量
> - **urethral closure mechanism（尿道關閉機制）** 在填充期維持正向尿道閉合壓；失效時即使腹壓輕微增加也會漏尿（stress incontinence）

## H2 傳統 UDS 與動態 UDS（Ambulatory UDS）

| 特性 | 傳統 UDS | 動態 UDS（Ambulatory） |
|------|----------|------------------------|
| **填充方式** | 人工填充（生理或非生理填充率） | 自然填充（門診環境） |
| **主要優勢** | 可標準化操控與測量 | 更接近日常生理狀態 |
| **主要限制** | 非生理性設定可能誘發假象 | 活動環境難以完全控制 |
| **適應症** | 住院患者、複雜診斷 | 門診追蹤、傳統 UDS 正常的疑似症狀 |
