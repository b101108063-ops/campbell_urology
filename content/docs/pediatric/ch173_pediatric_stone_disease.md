# 173 兒童結石

📖 **導讀**：兒童尿路結石過去較少見，但近年發生率有上升趨勢。與成人不同，兒童結石的形成與**代謝異常**（如高尿鈣、甲狀旁腺機能亢進）和**泌尿道感染**密切相關。微創手術（內視鏡、體外震波）是主要的治療方式。

---

## 流行病學

| 特點 | 說明 |
|---|---|
| 發生率 | 約 1-2% 的兒童 |
| 好發年齡 | 2-10 歲 |
| 男:女比例 | 約 2:1 |
| 復發率 | 高，5 年復發率約 30-50% |

---

## 結石成分

| 成分 | 說明 | X光可見性 |
|---|---|---|
| **Calcium oxalate**（草酸鈣） | 最常見（70-80%） | 可見 |
| **Calcium phosphate**（磷酸鈣） | 與高尿鈣相關 | 可見 |
| **Magnesium ammonium phosphate**（磷酸銨鎂） | 與感染相關（struvite） | 可見 |
| **Uric acid**（尿酸） | 與高尿酸血症相關 | 不可見 |
| **Cystine**（胱氨酸） | 遺傳性胱氨酸尿症 | 微弱可見 |

---

## 病因

### 代謝因素

| 異常 | 導致結石 |
|---|---|
| **高尿鈣**（Hypercalciuria） | 鈣結石 |
| **高草酸尿**（Hyperoxaluria） | 草酸鈣結石 |
| **低尿酸**（Hypocitraturia） | 結石容易形成 |
| **胱氨酸尿**（Cystinuria） | 胱氨酸結石 |
| **高尿酸尿**（Hyperuricosuria） | 尿酸結石 |

### 結構性因素

| 因素 | 說明 |
|---|---|
| **膀胱輸尿管逆流**（VUR） | 尿液滯留、感染 |
| **後尿道瓣膜**（PUV） | 尿液滯留、感染 |
| **馬蹄腎** | 尿液滯留 |

### 環境因素

| 因素 | 說明 |
|---|---|
| 低液體攝入 | 尿液濃縮 |
| 高鈉飲食 | 增加尿鈣 |
| 維生素D過量 | 高尿鈣 |

---

## 臨床表現

| 症狀 | 說明 |
|---|---|
| **腎絞痛**（Renal colic） | 結石在腎臟或輸尿管移動時劇烈腰痛 |
| 血尿 | 可能為顯微或肉眼可見 |
| 泌尿道感染 | 結石作為感染溫床 |
| 噁心、嘔吐 | 疼痛伴隨 |
| 發燒 | 怀疑感染時需緊急處理 |

> **臨床重點**：**嬰幼兒的結石症狀可能不典型**，可能只表現為哭鬧、嘔吐、血尿或反覆泌尿道感染。

---

## 診斷

### 影像檢查

| 檢查 | 說明 |
|---|---|
| **超音波**（首選） | 無輻射、可評估水腎 |
| **KUB X光** | 初篩（但 uric acid 和 cystine 可能看不見） |
| **CT（非對比）** | 金標準，但有輻射 |
| **靜脈腎盂造影**（IVP） | 評估功能和集尿系統 |

### 實驗室檢查

| 檢查 | 目的 |
|---|---|
| 尿液分析 | 血尿、感染 |
| 尿液培養 | 排除感染 |
| 24小時尿液代謝評估 | 代謝異常 |
| 結石成分分析 | 指導預防 |

---

## 治療

### 保守治療（結石 < 5mm）
- 多喝水（每天尿量 > 1.5-2 L）
- 鎮痛（NSAIDs 如 ibuprofen）
- **Alpha-blockers**（如 tamsulosin）：促進遠端輸尿管結石排出

### 外科治療

| 方法 | 適應症 |
|---|---|
| **體外震波碎石術**（ESWL） | 腎結石和近端輸尿管結石 < 2 cm |
| **輸尿管鏡取石術**（URS） | 中遠端輸尿管結石 |
| **經皮腎造口取石術**（PCNL） | 大結石（> 2 cm）或複雜結石 |
| **開放或腹腔鏡手術** | 微創治療失敗或非常大的結石 |

### ESWL（體外震波碎石術）

| 項目 | 說明 |
|---|---|
| 成功率 | 70-90%（取決於結石大小、位置） |
| 限制 | 結石過大、胱氨酸結石（对ESWL抵抗） |
| 術後 | 可能需放置 **Double J stent** |

### URS（輸尿管鏡取石術）

> **臨床重點**：兒童的輸尿管較細，手術難度較高。**術前需放置 Double J stent 2-4 週擴張輸尿管**（已被證實可提高成功率並減少併發症）。

### PCNL（經皮腎造口取石術）

| 項目 | 說明 |
|---|---|
| 適應症 | 大結石（> 2 cm）、鹿角狀結石 |
| 優點 | 微創、結石清除率高 |
| 風險 | 出血、腎損傷 |

---

## 預防復發

| 方法 | 說明 |
|---|---|
| 多喝水 | 每天尿量 > 1.5 L/m² |
| 低鈉飲食 | 減少尿鈣排泄 |
| 正常鈣攝取 | 每天 800-1000 mg |
| 藥物 | 根據結石類型（thiazides for 高尿鈣、allopurinol for 高尿酸） |

---

## 總結

| 重點 | 內容 |
|---|---|
| **最常見成分** | Calcium oxalate（草酸鈣） |
| **首選影像** | 超音波 |
| **ESWL 適應症** | < 2 cm 結石 |
| **URS 準備** | 術前放置 Double J stent 擴張輸尿管 |
| **PCNL 適應症** | > 2 cm 結石、鹿角狀結石 |
| **復發預防** | 多喝水、低鈉、正常鈣攝取 |
