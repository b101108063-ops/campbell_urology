# 📖 章節導讀

兒童腎移植是末期腎病（End-Stage Renal Disease, ESRD）患童的最佳腎臟替代療法，隨著免疫抑制藥物的進展與外科技術的精進，移植腎存活率大幅提升。然而，兒童腎移植涉及諸多泌尿系統的特殊考量，包括移植前的膀胱與下尿路評估、移植後泌尿併發症的預防與處理，以及長期追蹤。本章節將系統性介紹這些重要課題。

> **臨床重點** 兒童腎移植的成功不僅取決於移植手術本身，更需要完善的術前評估與長期多專科追蹤（腎臟科、泌尿科、免疫科、營養科、心理科）。移植前泌尿系統評估與適當處置，可顯著降低移植後泌尿併發症的發生率。

---

## 1. 移植適應症

### 兒童腎移植的主要適應症

| 病因 | 說明 |
|---|---|
| **先天性腎發育不良（Congenital renal dysplasia）** | 最常見適應症之一 |
| **慢性腎絲球腎炎（Chronic glomerulonephritis）** | 包含 IgA 腎病、局部節段性腎絲球硬化（FSGS） |
| **溶血尿毒症症候群（Hemolytic uremic syndrome, HUS）** | 典型 HUS（非典型復發型需注意） |
| **常染色體隱性多囊腎（ARPKD）** | 兒童常見遺傳性腎病 |
| **膀胱出口阻塞（Bladder outlet obstruction）** | 導致**阻塞性泌尿病變**與腎發育不良 |
| **神經性膀胱（Neurogenic bladder）** | 脊髓發育不良導致 |
| **Wilms tumor（康復後）** | 雙側腎切除後 |

### 移植時機

- **年齡**：目前無絕對年齡限制，嬰兒（<5-10 kg）移植技術挑戰較高但可行
- **透析時間**：越早移植越好，研究顯示透析時間越長，移植腎存活率越差
- **營養狀態**：需達到理想生長曲線（體重、身高需符合標準）

---

## 2. 移植前泌尿系統評估

### 膀胱功能評估

膀胱功能正常與否，直接影響移植後併發症的發生。

| 評估項目 | 目的 |
|---|---|
| **尿路動力學檢查（Urodynamics）** | 評估膀胱容量、 compliance（順應性）、殘餘尿量 |
| **排尿性膀胱尿道造影（VCUG）** | 確認有無**膀胱輸尿管逆流（VUR）**、膀胱出口阻塞 |
| **膀胱功能障礙類型** | 低 compliance 膀胱、Dysfunctional voiding、括約肌過度活躍 |

**低 compliance 膀胱（Low compliance bladder）**：膀胱壁纖維化、容量變小、壓力升高，會對移植腎造成高壓性腎損傷。需要手術處理（如**膀胱擴大手術 augmentation cystoplasty** 使用 ileum 或 colon）後再移植。

### 下尿路感染評估

- **尿液分析與培養**：排除活動性感染
- **過去感染病史**：反覆泌尿道感染可能導致膀胱功能障礙或**膀胱輸尿管逆流**

### 性發育評估

- **性染色體分析（Karyotype）**：確認性染色體與生殖系統發育
- **內分泌功能**：性腺功能、甲狀腺功能（腎病相關甲狀腺功能減退）
- **生殖器發育**：確認外生殖器結構是否正常

### 解剖結構評估

- **腎臟與輸尿管超音超**：確認是否有殘存腎臟、輸尿管狹窄或阻塞
- **膀胱評估**：確認膀胱容量、是否有**膀胱結石**或**膀胱攣縮**

## 3. 移植後泌尿系統併發症

### 常見泌尿併發症

| 併發症 | 發生率 | 說明 |
|---|---|---|
| **尿路阻塞（Ureteral obstruction）** | 5-10% | 移植輸尿管狹窄（缺血性或技術因素）、膀胱出口阻塞 |
| **尿漏（Urine leak）** | 3-8% | 移植腎盂或輸尿管接口滲漏，常因缺血或技術因素 |
| **膀胱功能障礙** | 變異 | 低 compliance 膀胱導致移植腎高壓性腎損傷 |
| **抗排斥藥物相關腎毒性** | 常見 | **Calcineurin inhibitors**（Tacrolimus, Cyclosporine）有腎毒性 |
| **泌尿道感染（UTI）** | 15-30% | 免疫抑制狀態下感染風險增加 |
| **BK 病毒腎病（BK nephropathy）** | 5-10% | BK virus reactivation 導致移植腎功能下降 |
| **腎結石** | 1-5% | 免疫抑制導致高鈣尿症、尿酸結石 |

### 尿路阻塞的處理

| 類型 | 處理方式 |
|---|---|
| 早期阻塞（術後 <30 天） | 手術修復（redo ureteroneocystostomy 或 pyeloplasty） |
| 晚期阻塞（術後 >30 天） | 先尝试微創（內視鏡擴張、放置支架），失敗則手術 |

### 尿漏的處理

- **確診**：移植腎掃描（Mercaptoacetyltriglycine, MAG3 scan）或引流液分析（肌酐酸）
- **處理**：經皮腎造口引流 + 放置輸尿管支架；保守失敗則手術修復

> **臨床重點** 移植術後需定期監測**移植腎功能**（血清肌酐酸、eGFR）、超音超檢查、以及時偵測泌尿併發症。早期發現與介入可避免移植腎不可逆損傷。

## 4. 免疫抑制方案

### 常用免疫抑制藥物

| 藥物類別 | 代表藥物 | 機轉 | 副作用 |
|---|---|---|---|
| **Calcineurin inhibitors** | Tacrolimus, Cyclosporine | 抑制 T 細胞活化 | 腎毒性、高血壓、神經毒性 |
| **Antimetabolites** | Mycophenolate mofetil (MMF), Azathioprine | 抑制 DNA 合成 | 骨髓抑制、腸胃不適 |
| **Corticosteroids** | Prednisolone, Methylprednisolone | 廣效抗發炎、免疫抑制 | 血糖升高、骨質疏鬆、生長遲緩 |
| **mTOR inhibitors** | Sirolimus (Rapamycin) | 抑制細胞分裂 | 高血脂、傷口癒合延遲 |
| **Biological agents** | Basiliximab (IL-2R blocker) | 抑制 IL-2 誘導 T 細胞活化 | 過敏反應 |

### 標準免疫抑制療程

| 時期 | 內容 |
|---|---|
| **誘導治療（Induction）** | 高劑量皮質類固醇 + Anti-thymocyte globulin (ATG) 或 Basiliximab |
| **維持治療（Maintenance）** | Tacrolimus + Mycophenolate mofetil + 低劑量皮質類固醇 |

### BK 病毒監測

- **血漿 BK virus PCR**：每 3 個月追蹤一次
- **BK 病毒血症處理**：降低免疫抑制強度（Calcineurin inhibitor 減量或更換為 Sirolimus）

---

## 5. 長期追蹤與照護

### 追蹤項目

| 追蹤項目 | 頻率 |
|---|---|
| 移植腎功能（血 creatinine、eGFR） | 每 1-3 個月 |
| 尿液分析 | 每 3-6 個月 |
| 超音超（腎臟與膀胱） | 每 6-12 個月 |
| 免疫抑制藥物血中濃度 | 穩定後每 1-3 個月 |
| BK 病毒篩檢 | 每 3 個月（術後 2 年內） |
| 腎臟活檢（必要時） | 懷疑排斥或BK病毒腎病時 |
| 腫瘤篩檢（皮膚癌、淋巴瘤） | 每 6-12 個月 |

### 生長與發育

- 腎移植術後成功擺脫透析，生長速度會明顯改善
- **類固醇最小化**或無類固醇方案有助於生長
- 需追蹤**生長曲線**、**骨齡**、**甲狀腺功能**

---

## 重點摘要

- **適應症**：先天性腎發育不良、慢性腎絲球腎炎、溶血尿糖尿毒症症候群為最常見
- **移植前評估**：膀胱功能（compliance、殘餘尿量）、下尿路感染、性發育、解剖結構
- **泌尿併發症**：尿路阻塞、尿漏、膀胱功能障礙、免疫抑制藥物腎毒性
- **免疫抑制**：Tacrolimus + MMF + 皮質類固醇為主流；需監測 BK 病毒
- **長期追蹤**：腎功能、藥物濃度、腫瘤篩檢、生長發育
