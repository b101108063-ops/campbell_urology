## 📖 導讀

**排糞障礙（Defecation Disorders）** 是小兒泌尿科門診中經常與泌尿症狀並存的共病形態。便祕與**膀胱功能障礙（bladder dysfunction）** 之間存在明確的雙向關聯——成功治療便祕可同時改善高達 89% 之日間尿失禁與 63% 之夜間遺尿。本章節聚焦功能性便祕的**羅馬 III 診斷標準（Rome III criteria）**、**警示徵象（alarm signs/symptoms）**、身體檢查要點，以及以內科保守治療為主軸的處理原則。

---

## 流行病學與分類

### 羅馬 III 診斷標準（功能性便祕）

功能性便祕的診斷以**羅馬 III 標準**為主要依據，診斷應以完整病史與身體檢查為基礎。

| 必要條件 | 說明 |
|----------|------|
| 排便次數異常 | 每週排便 ≤2 次 |
| 大便失禁 | 每天至少一次大便失禁 |
| 主動抑制排便 | 主動忍便行為 |
| 直腸中有硬便 | 可觸及的糞便滯留 |
| 巨大糞便 | 可在直腸觸及或腹部觸及 |
| 症狀持續時間 | 至少 1 個月（需符合至少兩項） |

### Bristol 大便型態分類（Bristol Stool Form Scale）

| 分類 | 型態描述 |
|------|----------|
| Type 1 | 獨立硬塊，難以排出（如堅果） |
| Type 2 | 臘腸狀但表面不平 |
| Type 3 | 臘腸狀，表面有裂縫 |
| Type 4 | 柔軟臘腸或蛇狀，光滑軟便 |
| Type 5 | 軟塊，邊緣清晰 |
| Type 6 | 蓬鬆碎片，邊緣不規則 |
| Type 7 | 水便，無固體 |

> **臨床重點**
> - **Rome III 標準**是確診小兒功能性便祕的推薦工具
> - 診斷應以完整**病史與身體檢查**為主，不應依賴單一檢查
> - **警示徵象**或頑固性便祕應觸發針對性檢查，以排除潛在器質性疾病

## 警示徵象（Alarm Signs）與警示症狀

以下徵象出现时，应高度怀疑器质性原因：

| 警示徵象 | 可能的相關疾病 |
|----------|----------------|
| 出生後 1 個月內或胎糞延遲通過（>48 小時） | **先天性無神經節細胞症（Hirschsprung 病）** |
| 慢性或復發性呼吸道問題 | **囊狀纖維化（Cystic fibrosis）** |
| 體重減輕、生長遲緩、發育不良 | 乳糜瀉、甲狀腺功能低下、Hirschsprung 病 |
| 張力減退、發育遲緩 | 甲狀腺功能低下、唐氏症 |
| 泌尿/大便失禁超出如廁訓練年齡 | 神經性膀胱、脊髓發育異常 |
| 下肢無力、步態異常、感覺異常 | 脊髓病變（tethered cord） |
| 骶尾部凹陷、脂肪瘤、毛髮叢、臀裂偏移 | **隱性脊柱裂（Occult spinal dysraphism）** |
| 刺激後（肛門檢查或栓劑）有爆炸性排氣排便 | Hirschsprung 病、先天性巨結腸 |
| 初始排便困難早於膀胱訓練 | 器質性狹窄或功能障礙 |

> **臨床重點**
> - 胎糞延遲通過（>48 小時）為新生兒期懷疑 **Hirschsprung 病** 的重要線索
> - 伴随泌尿系統症狀的頑固性便祕需排除**隱性脊柱裂（occult spinal dysraphism）**

## 身體檢查要點

### 會陰部與骶尾部評估

- **肛門位置與外觀**（肛門前移、痔瘡、裂隙）
- **臀溝（gluteal cleft）**：偏移可能提示脊柱裂
- **骶骨凹陷（sacral dimple）**、脂肪瘤、毛髮叢
- **扁平臀部（flat buttocks）**：可能為骶骨發育不全（sacral agenesis）或 Prune-belly 症候群
- **肛門反射與球海綿體反射**：評估神經完整性

### 腹部檢查

- 有無可觸及的糞便團塊（左下腹象限）
- 腹脹程度
- 腹部肌肉張力

### 下肢檢查

- 肌力、協調性、肌肉萎縮
- 深部肌腱反射
- 步態

### Prune-Belly 症候群線索

若檢查發現**隱睪症（或曾接受雙側睪丸固定術）**、**腹壁鬆弛**及**下尿路問題**三聯症，應考慮 **Prune-Belly 症候群**，並評估是否能以腹部整形術（abdominoplasty）協助增加腹內壓以助排便。

> **臨床重點**
> - 數位直腸檢查（digital rectal examination）**非常規進行**，僅用於頑固性案例並由熟悉肛門直腸解剖異常之專業人員執行
> - 功能性便祕兒童身體檢查通常正常（體重身高正常、腹部柔軟、無神經學異常）

## 實驗室與影像學評估

### 適應症

常規腹部 X 光檢查臨床價值有限，僅建議用於：
- 疑似糞便嵌塞（fecal impaction）
- 病史與身體檢查不可靠之案例

### 對比劑灌腸（Contrast Enema）

- **Hirschsprung 病**：可見從肛門到狹窄段之前漸進性擴張的大腸，狹窄段通常位於直腸乙狀結腸交界處
- **先天性肛門直腸畸形術後**：評估解剖重建

### 脊柱超聲波 / MRI

- 適用於懷疑**隱性脊柱裂**或**脊髓束縛（tethered cord）**之案例
- 超聲波適用於出生後 3–6 個月內（椎體尚未鈣化）
- 較大兒童建議使用**腰椎 MRI**

### 直腸黏膜活檢（Suction Biopsy）

疑似 **Hirschsprung 病**時，深層吸吮切片（含黏膜下層）為確診標準：
- 發現**神經節細胞缺失**
- **肥厚性神經纖維**
- 黏膜固有層與黏膜肌層之**乙醯膽鹼酯酶活性增加**

### 肛門直腸壓力測定（Anorectal Manometry）

僅用於：
- 疑似 Hirschsprung 病
- **內括約肌失弛緩（internal sphincter achalasia）**

> **臨床重點**
> - 大多數功能性便祕兒童的輔助檢查結果均為正常
> - 肛門直腸壓力測定對功能性便祕的診斷與治療策略幫助有限

## 內科治療原則

### 治療核心：非手術優先

排糞障礙的治療以**內科保守治療**為首選，包括：

| 治療要素 | 說明 |
|----------|------|
| 行為干預 | 如廁訓練（發育年齡 ≥4 歲）、正向強化 |
| 飲食調整 | 足夠纖維與水分攝取 |
| 糞便軟化劑 | 口服軟化劑 |
| 輕瀉劑 | 刺激性或滲透性瀉劑 |
|  retrograde enemas（逆行灌腸）| 審慎使用 |

### 泌尿症狀的共病處理

Loening-Baucke（1997）的里程碑研究顯示：便祕治療成功（52%）可同時改善：
- **日間尿失禁緩解率：89%**
- **夜間遺尿緩解率：63%**
- **泌尿道感染緩解率**：顯著下降

國際兒童泌尿外科學會（ICCS）標準化委員會建議：若臨床懷疑便祕，應同時治療。

> **臨床重點**
> - 針對便祕的治療應與下尿路症狀同步進行，因為兩者常互為因果
> - 對頑固性便祕，建議會診小兒腸胃科進行多專科評估
> - 如廁訓練的去神秘化（demystification）是成功治療常被忽略的關鍵環節
