# 📖 章節導讀

**隱睪症（Cryptorchidism）** 是小男孩最常見的先天性泌尿系統異常之一，發生率約為足月新生兒的 1-4%。本章節涵蓋隱睪症的分類、診斷方法、治療時機與手術方式，並強調早期治療對生殖功能的重要性。

> **臨床重點** 隱睪症的治療時機為**6-12 個月大**前手術，最晚不超過 18 個月。延遲治療會導致睪丸組織結構破壞，增加**germ cell apoptosis（生殖細胞凋亡）**與不孕風險。睪丸在腹腔內停留時間越長，損傷越不可逆。

---

## 1. 定義與分類

### 定義

**隱睪症**是指睪丸未能正常下降至陰囊內，可發生於單側或雙側。

### 分類

| 分類 | 說明 | 佔比 |
|---|---|---|
| **可觸及型（Palpable）** | 睪丸位於腹股溝管或外環口，可經觸診摸到 | 約 80% |
| **不可觸及型（Non-palpable）** | 睪丸位於腹腔內或已缺如，觸診無法摸到 | 約 20% |

### 不可觸及型的進一步分類

| 類型 | 說明 | 佔不可觸及型 |
|---|---|---|
| **睪丸缺如（Vanishing testis）** | 胎兒期睪丸扭轉或退化，只剩睪丸與附睪残蹟 | 約 50% |
| **腹腔內睪丸（Intra-abdominal testis）** | 睪丸位於腹腔內，靠近內環口或腎下極 | 約 50% |
| **睪丸發育不全（Hypoplastic testis）** | 睪丸極小，功能極差 | 少見 |

### 鑑別診斷

| 診斷 | 說明 |
|---|---|
| **睪丸上縮（Retractile testis）** | 睪丸可被手動拉至陰囊底部，但迅速縮回腹股溝；非真正的隱睪，通常不需要手術 |
| **睪丸缺如（Anorchia）** | 真正的無睪丸，染色體正常（46,XY），超音超確認 |
| **eugonadal anorchia** | 有男性化表型但無睪丸，AMH 極低 |

## 2. 胚胎學與發病機轉

### 正常睪丸下降過程

| 時期 | 位置 |
|---|---|
| 胚胎第 7-8 週 | 睪丸在後腹膜腎臟下方形成 |
| 胚胎第 10-15 週 | 睪丸開始經由**引帶（gubernaculum）**引導下降 |
| 胚胎第 15-30 週 | 睪丸經過腹股溝管 |
| 出生時 | 睪丸應位於陰囊內 |

### 睪丸下降的調控因素

| 因素 | 作用 |
|---|---|
| **睪固酮（Testosterone）** | 促進引帶發育與睪丸下降 |
| **Insl3（Insulin-like peptide 3）** | 調控睪丸穿越腹股溝管 |
| **Müllerian Inhibiting Substance (MIS/AMH)** | 抑制女性生殖管道發育 |
| **腹內壓（Intra-abdominal pressure）** | 協助睪丸通過腹股溝管 |

### 隱睪症的危險因子

| 因子 | 說明 |
|---|---|
| **早產（Prematurity）** | 睪丸下降尚未完成即出生 |
| **低出生體重（<2,500 g）** | 發生率顯著增加 |
| **妊娠糖尿病** | 胰島素影響性腺發育 |
| **遺傳因素** | 家族史增加風險 |
| **環境内分泌干擾物** | 農藥、塑化劑暴露 |

## 3. 臨床表現與診斷

### 臨床表現

| 發現 | 說明 |
|---|---|
| **陰囊發育不良（Scrotal hypoplasia）** | 患側陰囊扁平、較小、色素較淡 |
| **單側觸診空虛** | 單側隱睪時，患側陰囊内容空虛 |
| **腹股溝腫塊** | 可觸及型隱睪可在腹股溝摸到睪丸 |
| **雙側陰囊空虛** | 雙側隱睪時，兩側陰囊内容均空虛 |

### 診斷方法

| 方法 | 說明 | 準確度 |
|---|---|---|
| **身體檢查** | 視診+觸診確認睪丸位置；檢查陰囊發育情況 | 初步篩檢 |
| **超音超（Ultrasound）** | 對可觸及型敏感度高（>90%）；對腹腔內睪丸敏感度低（30-50%） | 高（可觸及型）|
| **MRI / MRA** | 評估腹腔內睪丸 | 中等 |
| **腹腔鏡（Laparoscopy）** | 確診不可觸及型隱睪的金標準 | 確診工具 |
| **睪丸活檢** | 極少使用；僅用於確診睪丸缺如與否 |

### 不可觸及型的腹腔鏡診斷流程

1. 腹腔鏡進入腹腔
2. 確認內環口（internal ring）狀態
   - 若見**盲端血管（blind-ending vessels）**→ 確認為**vanishing testis**，終止手術
   - 若見睪丸血管進入內環口 → 確認為**腹腔內睪丸**，繼續定位與治療

## 4. 治療時機

### 治療窗口

| 年齡 | 建議 |
|---|---|
| **<6 個月** | 觀察，部分隱睪可能自行下降 |
| **6-12 個月** | 最佳手術時機（睪丸組織損傷尚可挽回） |
| **12-18 個月** | 可接受，但不宜再延遲 |
| **>18 個月** | 不建議，此時 germ cell 凋亡已相當嚴重 |

### 為什麼早期手術很重要？

| 組織變化 | 影響 |
|---|---|
| **Germ cell 凋亡（Apoptosis）** | 睪丸在腹腔內高溫環境下，生殖細胞凋亡加劇 |
| **精原細胞（Spermatogonia）減少** | 雙側隱睪若延遲治療，不孕症風險可達 30-50% |
| **睪丸萎縮（Testicular atrophy）** | 組織纖維化 |
| **睪丸腫瘤風險增加** | 隱睪患者睪丸精原細胞瘤（seminoma）風險增加 4-8 倍；手術無法完全消除風險，但可早期發現 |

> **臨床重點** 即使是**單側隱睪**，對側正常睪丸也可能受到免疫/環境因素影響，生育能力下降，因此雙側都需評估。

## 5. 手術治療

### 5.1 標準睪丸固定術（Standard Orchiopexy）

| 項目 | 說明 |
|---|---|
| **適用對象** | 可觸及型隱睪（睪丸位於腹股溝管或外環口） |
| **手術步驟** | 腹股溝切口 → 遊離精索 → 充分分離至內環口 → 將睪丸置入陰囊 → 固定 |
| **成功率** | >95% |
| **併發症** | 出血、感染、睪丸萎縮（<5%）|

### 5.2 Fowler-Stephens 睪丸固定術

| 項目 | 說明 |
|---|---|
| **適用對象** | 腹腔內高位睪丸（high intra-abdominal testis） |
| **原理** | 睪丸血管為睪丸的主要供應，切斷後依賴**側支循環（collateral blood supply）**存活 |
| **分期** | 第一期：腹腔鏡下**切斷睪丸血管（testicular vessel ligation）**；6-12 個月後第二期：將睪丸拉至陰囊並固定 |
| **成功率** | 兩期合計約 85-90% |

### 5.3 腹腔鏡輔助睪丸固定術（Laparoscopic-Assisted Orchiopexy）

| 項目 | 說明 |
|---|---|
| **適用對象** | 腹腔內睪丸 |
| **優點** | 微創、可直接確認睪丸位置與狀態、可同時進行 Fowler-Stephens 一期手術 |
| **成功率** | 與開放手術相當 |

### 5.4 睪丸切除術（Orchiectomy）

| 適用情況 | 說明 |
|---|---|
| **嚴重睪丸發育不全** | 睪丸極小（<1 mL）且無功能 |
| **高腫瘤風險** | 萎縮睪丸有高度惡性變性風險 |
| **青少年/成人隱睪** | 睪丸功能已不可挽回 |

---

## 6. 長期追蹤

| 追蹤項目 | 說明 |
|---|---|
| **睪丸大小** | 超音超測量睪丸體積，與正常側或同年齡標準比 |
| **睪丸位置** | 確認睪丸是否維持在陰囊內 |
| **青春期發育** | 評估第二性徵出現 |
| **精液分析** | 青少年後期或成年後（雙側隱睪者強烈建議）|
| **腫瘤篩檢** | 睪丸自我檢查（testicular self-examination），早期發現異常 |

---

## 重點摘要

- **分類**：可觸及型（80%）vs 不可觸及型（20%）；不可觸及型中 50% 為睪丸缺如
- **治療時機**：**6-12 個月大**前手術，最晚不超過 **18 個月**
- **Germ cell凋亡**：睪丸在腹腔內高溫環境導致不可逆損傷，延遲治療影響生育能力
- **手術方式**：標準 orchiopexy（可觸及型）；Fowler-Stephens orchiopexy（腹腔內睪丸）；腹腔鏡輔助
- **長期追蹤**：睪丸位置與大小、青春期發育、精液分析、腫瘤篩檢
