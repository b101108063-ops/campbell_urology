# 171 下尿路狀況

📖 **導讀**：兒童下尿路狀況涵蓋從功能性障礙到結構性異常。準確診斷需要結合臨床表現、尿液分析和尿路動力學檢查。治療以行為治療為優先，藥物和手術為輔。

---

## 兒童下尿路功能評估

### 病史詢問重點

| 項目 | 詢問內容 |
|---|---|
| 排尿模式 | 頻率、每次尿量、夜間排尿次數 |
| 症狀持續時間 | 急迫性、頻尿、尿失禁 |
| 排便情況 | 便祕或腹瀉（與膀胱功能相關） |
| 感染史 | UTI 頻率 |
| 出生史 | 是否早產、有無泌尿道異常 |

### 理學檢查

| 檢查 | 評估內容 |
|---|---|
| 腹部觸診 | 膀胱膨脹（尿瀦留） |
| 外生殖器檢查 | 包莖、尿道下裂、陰唇粘連 |
| 脊椎檢查 | 隱性脊柱裂（sacral dimple、毛髮斑） |
| 神經學檢查 | 會陰感覺、肛門張力 |

---

## 功能性排尿障礙（Functional Voiding Dysfunction）

### 定義
非結構性原因導致的排尿異常，與**排尿行為異常**或**骨盆底功能障礙**相關。

### 分類

| 類型 | 說明 |
|---|---|
| **Dysfunctional voiding** | 排尿時骨盆底不正常收縮 |
| **Detrusor overactivity** | 逼尿肌不自主收縮（膀胱過動） |
| **Underactive bladder** | 逼尿肌收縮力不足 |

### 診斷

| 檢查 | 說明 |
|---|---|
| **尿流速圖**（Uroflowmetry） | 評估尿流模式 |
| **EMG**（Surface electromyography） | 評估骨盆底活動 |
| **Post-void residual** | 評估膀胱排空效率 |
| **尿路動力學** | 確診的金標準 |

### 治療

| 治療方式 | 說明 |
|---|---|
| **行為治療** | 固定時間排尿、避免延遲排尿 |
| **Biofeedback** | 訓練骨盆底肌肉放鬆 |
| **抗膽鹼藥物** | 用於膀胱過動（Oxybutynin） |
| **Alpha-blockers** | 降低膀胱頸阻力（Tamsulosin） |

---

## 日間尿失禁（Daytime Incontinence）

### 病因

| 病因 | 說明 |
|---|---|
| **膀胱過動**（OAB） | 最常見，急迫性尿失禁 |
| **膀胱低complaint** | 膀胱容量小、儲尿時壓力高 |
| **Dysfunctional voiding** | 排尿時骨盆底不協調 |
| **泌尿道感染** | UTI 引起膀胱刺激 |

### 治療原則

| 病因 | 治療 |
|---|---|
| OAB | 抗膽鹼藥物 + 行為治療 |
| 低complaint膀胱 | 抗膽鹼藥物、膀胱訓練 |
| Dysfunctional voiding | Biofeedback、骨盆底復健 |

---

## 夜間遺尿（Nocturnal Enuresis）

### 分類

| 類型 | 定義 |
|---|---|
| **單一症狀性**（Monosymptomatic） | 只有夜間遺尿，無白天症狀 |
| **複雜性**（Non-monosymptomatic） | 合併白天排尿症狀 |

### 病因

| 因素 | 說明 |
|---|---|
| **夜間多尿**（Nocturnal polyuria） | 夜間尿量過多 |
| **膀胱功能障礙** | 夜間膀胱容量不足 |
| **覺醒障礙** | 睡眠過深，無法感受膀胱脹滿 |
| **家族史** | 父母有遺尿史，風險增加 |

### 治療

> **臨床重點**：首先排除白天症狀和泌尿道感染。**單一症狀性夜間遺尿**的治療以 **bedwetting alarm** 為首選（成功率 70%，但需 2-3 個月見效）；**desmopressin**（DDAVP）見效快但停藥後易復發。

| 治療 | 說明 |
|---|---|
| **Bedwetting alarm** | 首選，規律作息、睡前少喝水 |
| **Desmopressin**（DDAVP） | 快速見效，口含片或鼻噴劑 |
| **Imipramine**（三環抗憂鬱劑） | 第二線，已少用 |

---

## 總結

| 疾病 | 治療原則 |
|---|---|
| 功能性排尿障礙 | 行為治療、Biofeedback、抗膽鹼藥物 |
| 日間尿失禁 | 依病因治療（OAB、低complaint膀胱） |
| 單一症狀性夜間遺尿 | Bedwetting alarm（首選）或 Desmopressin |
| 複雜性夜間遺尿 | 同時治療白天和夜間症狀 |
