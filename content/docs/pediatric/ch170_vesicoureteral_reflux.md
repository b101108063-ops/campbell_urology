# 170 膀胱輸尿管逆流

📖 **導讀**：膀胱輸尿管逆流（VUR）是尿液從膀胱倒流回輸尿管（甚至腎臟）的現象，是兒童**最常見的泌尿系統先天異常**之一。輕度逆流可能無症狀，但重度逆流會導致逆流性腎病（reflux nephropathy），是兒童高血壓和慢性腎病的重要原因。

---

## 定義

**膀胱輸尿管逆流**（Vesicoureteral Reflux, VUR）：排尿時尿液從膀胱倒流至輸尿管（甚至腎盂、腎盞）。

---

## 流行病學

| 族群 | 發生率 |
|---|---|
| 正常兒童 | 0.4-1.8% |
| 發燒性泌尿道感染兒童 | 25-40% |
| 有泌尿道感染病史的兒童 | 30-50% |

> **臨床重點**：**泌尿道感染（UTI）是發現 VUR 的重要線索**。所有 2 個月至 2 歲的發燒性 UTI 兒童都應考慮做 VUR 評估。

---

## 分級（International VUR Grading System）

| 分級 | 描述 | 圖解 |
|---|---|---|
| **Grade I** | 逆流至遠端輸尿管，無擴張 | 輸尿管口正常 |
| **Grade II** | 逆流至腎盂，無擴張 | 腎盂可見對比劑 |
| **Grade III** | 輕度至中度擴張，輕度扭曲 | 腎盂輕度積水 |
| **Grade IV** | 中度擴張和扭曲 | 輸尿管明顯曲張 |
| **Grade V** | 嚴重擴張和扭曲，腎功能受損 | 腎盂嚴重積水 |

---

## 病理生理學

### 先天型（原發性 VUR）
- **輸尿管膀胱交界處（UVJ）瓣膜機制缺陷**
- 胚胎發育時輸尿管直走，缺乏適當的黏膜下通道長度
- 輸尿管口位置異常（lateral ectopic orifice）

### 後天型（次發性 VUR）
- **膀胱出口阻塞**（posterior urethral valve、urethral stricture）
- **神經性膀胱**（neurogenic bladder）
- **泌尿道感染**（膀胱炎導致黏膜水腫）

### 為什麼 VUR 會傷害腎臟？
1. 帶有細菌的尿液逆流至腎臟 → **急性腎盂腎炎**
2. 反覆感染 → 腎臟疤痕形成 → **逆流性腎病**
3. 腎臟疤痕 → **高血壓**、**慢性腎病**

---

## 臨床表現

| 表現 | 說明 |
|---|---|
| **泌尿道感染** | 最常見的初始表現 |
| 發燒性 UTI | 可能是唯一的臨床症狀 |
| 腰痛 | 可能為腎盂腎炎表現 |
| 高血壓 | 腎功能受損後出現 |
| 生長遲緩 | 慢性腎病表現 |

> **臨床重點**：**並非所有 VUR 都會有症狀**。輕度（Grade I-II）VUR 常無症狀，僅在因其他原因做檢查時才發現。診斷關鍵是對高風險族群（發燒性 UTI 兒童）進行系統性篩檢。

---

## 診斷

### 1. VCUG（排尿性膀胱尿道造影）

**確診工具**，也是分級的金標準。

| 發現 | 說明 |
|---|---|
| 對比劑逆流至輸尿管 | 確認 VUR 存在 |
| 擴張程度 | 判斷分級 |
| 後尿道形態 | 排除膀胱出口阻塞 |

> **臨床重點**：VCUG 是**侵襲性檢查**，需導尿管注入對比劑。建議在**急性感染控制後 2-4 週**再做，避免誘發新感染。

### 2. DMSA Scan（99mTc-DMSA Renoscintigraphy）

**評估腎臟疤痕**的金標準。

| 發現 | 意義 |
|---|---|
| 腎臟攝取功能正常 | 無疤痕 |
| 局部攝取缺損 | 腎疤痕形成 |
| 整體功能下降 | 腎發育不良或嚴重疤痕 |

### 3. 超音波（Ultrasound）

- 篩檢工具，無侵襲性
- 可評估**腎臟大小、積水程度、腎皮質厚度**
- 對 VUR 本身的敏感性低（約 30-50%）

### 4. 尿路動力學檢查（Urodynamics）

懷疑**神經性膀胱或功能障礙**時需做。

## 治療

### 治療原則

| 分級 | 策略 |
|---|---|
| Grade I-II | 保守治療（觀察 + 預防性抗生素） |
| Grade III | 保守治療為主，若失敗考慮手術 |
| Grade IV-V | 手術治療為主 |

### 1. 保守治療（Medical Management）

**目標**：預防急性腎盂腎炎，避免新疤痕形成。

| 方法 | 說明 |
|---|---|
| **低劑量預防性抗生素**（Continuous Low-dose Prophylaxis） | TMP-SMX、Nitrofurantoin |
| 規則排尿訓練 | 每 2-3 小時解尿一次 |
| 充足水份 | 每天尿量 > 1000 mL/m² |
| 定期追蹤 | 每 3-6 個月做尿液檢查 |

### 2. 手術治療（Surgical Management）

#### 內視鏡注射治療（Endoscopic Injection）

**Deflux®**（polydimethylsiloxane 微粒）注射至輸尿管口下方。

| 優點 | 缺點 |
|---|---|
| 微創、門診手術 | 成功率較傳統手術低 |
| 恢復快 | 對高 grade VUR 效果差 |
| 可重複執行 |  |

成功率：
- Grade I-II：80-90%
- Grade III：70-80%
- Grade IV-V：50-60%

#### 輸尿管再植術（Ureteral Reimplantation）

**Cohen cross-trigonal reimplantation** 為最常用術式。

| 優點 | 缺點 |
|---|---|
| 成功率高（95-98%） | 需剖腹手術 |
| 可同時處理雙側 | 恢復期較長 |
| 適用於所有分級 |  |

---

## 追蹤

| 項目 | 頻率 |
|---|---|
| 尿液檢查 | 每 3-6 個月 |
| 超音波 | 每 6-12 個月 |
| 血壓測量 | 每 6 個月 |
| DMSA（評估疤痕） |確診時 + 追蹤時 |
| VCUG | 保守治療失敗或考慮停藥前 |

> **臨床重點**：VUR 兒童的**血壓監測非常重要**。約 10-20% 的逆流性腎病兒童會發展為**高血壓**，需終生追蹤。

---

## 總結

| 重點 | 內容 |
|---|---|
| **定義** | 尿液從膀胱逆流至輸尿管/腎臟 |
| **分級** | I-V（International VUR Grading System） |
| **主要風險** | 逆流性腎病、高血壓、慢性腎病 |
| **確診** | VCUG |
| **腎疤痕** | DMSA scan |
| **治療** | 保守（預防性抗生素）或手術（內視鏡注射/輸尿管再植） |
| **追蹤** | 終生血壓和腎功能監測 |
