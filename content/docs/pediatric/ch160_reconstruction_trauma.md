# 📖 章節導讀

小兒泌尿科重建手術是為了解決先天性畸形或創傷後結構異常所造成的功能障礙。本章節系統性介紹小兒泌尿科常見的重建手術，包括手術適應症、常用組織與技術、以及術後照護要點。

> **臨床重點** 重建手術的成功不僅取決於手術技術，更取決於術前的完整評估、術式的合理選擇、以及術後的長期追蹤。多次手術史的患者，手術難度與併發症風險會顯著增加。

---

## 1. 先天性畸形重建

### 1.1 膀胱外翻重建（Bladder Exstrophy Repair）

膀胱外翻的重建為**分期手術**，各階段時機與內容如下：

| 分期 | 年齡 | 手術內容 |
|---|---|---|
| **第一期：關閉術（Primary closure）** | 出生後 24-72 小時（最佳），或 <3 個月 | 關閉膀胱與腹壁、恥骨聯合靠攏、骨盆截骨術 |
| **第二期：Epispadias 修補** | 嬰兒期/幼兒期（6-12 個月） | 重建尿道、矫正陰莖彎曲 |
| **第三期：膀胱頸重建（Bladder neck reconstruction）** | 4-5 歲或更大 | 建立控尿機制 |

**膀胱頸重建技術**：
- **Modified Young-Dees-Leadbetter** 手術
- **Kelley** 手術
- 目的：增加膀胱出口阻力，達到**乾燥（dry interval）**

### 1.2 尿道下裂修補（Hypospadias Repair）

詳見第 164 章。本章僅補充重建層面的考量。

| 考量因素 | 說明 |
|---|---|
| **先前手術失敗** | 多次修補失敗者，局部組織不足，需使用**游離黏膜移植（free mucosal graft）**或**組織工程材料** |
| **複雜型尿道下裂** | 陰囊型、會陰型可能需要**分階段手術（staged repair）** |
| **組織不足** | **口腔黏膜（buccal mucosa）**或**舌黏膜（tongue mucosa）**移植 |

### 1.3 腎臟手術

| 手術類型 | 適應症 |
|---|---|
| **腎切除術（Nephrectomy）** | 無功能腎臟（嚴重水腎、萎縮腎）、腎腫瘤 |
| **腎部分切除術（Partial nephrectomy）** | 腎臟上半部或下半部孤立功能喪失、 Wilms tumor（選擇性案例） |
| **腎盂成形術（Pyeloplasty）** | **UPJO（輸尿管腎盂連接處阻塞）**、嚴重水腎 |
| **腎移植** | 末期腎病（見第 158 章） |

**Anderson-Hynes pyeloplasty（腎盂成形術）**：
- 標準治療**腎盂輸尿管連接處阻塞（UPJO）**
- 切除病變段輸尿管與部分腎竇，重新吻合
- 成功率 >95%

## 2. 創傷後重建

### 2.1 輸尿管狹窄重建

**輸尿管狹窄（Ureteral stricture）**可因創傷、結石手術、發炎或缺血導致。

| 狹窄位置/長度 | 推薦重建方式 |
|---|---|
| **短段狹窄（<2-3 cm）** | 內視鏡擴張（balloon dilation）或狹窄切開（endoscopic incision） |
| **中段狹窄（3-5 cm）** | **輸尿管端端吻合術（ureteroureterostomy）** |
| **下段狹窄** | **輸尿管膀胱再植術（ureteral reimplantation）** |
| **長段缺損（>5-6 cm）** | **輸尿管腸道替代**（ileal ureter、colonic interposition）或**自體腎移植（autotransplantation）** |

**腸道替代輸尿管**：
- **Ileal ureter**：使用迴腸替代整段輸尿管
- **Colonic interposition**：使用結腸替代
- 需注意：腸道吸收尿液導致**高氯性酸中毒**、黏液阻塞

### 2.2 尿道狹窄重建

詳見第 157 章。本章補充重建技術：

| 狹窄類型 | 手術方式 |
|---|---|
| **短段前尿道狹窄（<2 cm）** | **尿道切開術（urethrotomy）**、狹窄切除直接吻合 |
| **長段前尿道狹窄** | **游離黏膜移植尿道重建（free graft urethroplasty）**、**帶蒂皮瓣（pedicled flap）** |
| **後尿道狹窄（骨盆骨折後）** | **端端吻合術（end-to-end anastomosis）**、**修補與吻合（excision and primary anastomosis）** |

**口腔黏膜移植（Buccal mucosa urethroplasty）**：
- 常用於**長段前尿道狹窄**或**先前手術失敗**案例
- 優點：黏膜組織再生能力強、與尿道黏膜相容性佳
- 缺點：口部術後疼痛、口腔併發症

### 2.3 膀胱重建

| 適應症 | 手術方式 |
|---|---|
| **低 compliance 膀胱** | **膀胱擴大術（Augmentation cystoplasty）**：使用 ileum 或 colon 擴大膀胱容量 |
| **膀胱攣縮（Bladder contracture）** | 切除攣縮組織 + 腸道擴大 |
| **先天性膀胱發育不全** | 膀胱擴大 + 可控性導通道建立 |

## 3. 常用組織材料

### 自體組織

| 組織 | 常用用途 |
|---|---|
| **Ileum（迴腸）** | 膀胱擴大、輸尿管替代、迴腸導管 |
| **Colon（結腸）** | 膀胱擴大、結腸替代輸尿道、可控性儲尿囊 |
| **Appendix（闌尾）** | **Mitrofanoff 導通道**（以闌尾建立可控性腹壁造口） |
| **Buccal mucosa（口腔黏膜）** | 尿道重建（游離移植） |
| **Tongue mucosa（舌黏膜）** | 尿道重建（游離移植） |
| **Omentum（大網膜）** | 覆蓋組織、促進癒合、填充死腔 |

### 生物材料與合成材料

| 材料 | 用途 |
|---|---|
| **Gore-Tex** | 修復**腹壁缺損**、**軟組織填充** |
| **Small intestinal submucosa (SIS, Strattice)** | 組織再生支架 |
| **acellular dermal matrix (AlloDerm)** | 軟組織修復、陰道重建 |

## 4. 重建手術原則

### 術前評估

| 評估項目 | 目的 |
|---|---|
| **尿路動力學檢查** | 確認膀胱功能（容量、compliance、出口阻力） |
| **影像學評估** | 靜脈腎盂造影、CT、MRI 確認解剖結構 |
| **腎功能評估** | 血清肌酐酸、eGFR、分腎功能（renal scan） |
| **腸道評估** | 若需使用腸道，術前腸道清潔、營養狀態 |
| **感染評估** | 尿液培養、排除活動性感染 |

### 術後照護

| 併發症 | 說明 |
|---|---|
| **出血** | 術後監測血紅素，必要時輸血或介入性栓塞 |
| **感染** | 傷口感染、泌尿道感染、敗血症 |
| **尿漏** | 重建介面癒合不良，需引流或手術修復 |
| **阻塞** | 輸尿管/尿道狹窄、導管阻塞 |
| **腸道併發症** | 腸阻塞、吻合口漏、黏液阻塞 |
| **代謝異常** | 腸道替代術後高氯性酸中毒、維生素缺乏 |

### 長期追蹤

| 追蹤項目 | 頻率 |
|---|---|
| 腎功能（Creatinine、eGFR） | 每 6-12 個月 |
| 超音超 | 每 6-12 個月 |
| 尿路動力學 | 每 1-2 年（依病情） |
| 膀胱鏡檢查 | 每年（膀胱外翻、腸道膀胱重建者） |
| 腫瘤篩檢 | 每 1-2 年（腸道替代膀胱者） |

> **臨床重點** 重建手術後需終身追蹤，特別是使用腸道組織進行泌尿重建的患者，因慢性黏液刺激與尿液吸收，長期有惡性腫瘤（膀胱癌、腸道癌症）風險。

---

## 重點摘要

- **分期手術**：膀胱外翻重建分三期（關閉、epispadias 修補、膀胱頸重建）
- **創傷後重建**：輸尿管狹窄依長度選擇內視鏡擴張、端端吻合或腸道替代
- **常用組織**：ileum、colon、appendix、buccal mucosa 各有其適應症與優缺點
- **術後追蹤**：腎功能、影像學、腫瘤篩檢，腸道替代者需注意代謝異常
