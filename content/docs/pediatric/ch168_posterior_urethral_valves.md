# 168 後尿道瓣膜與尿道異常

📖 **導讀**：後尿道瓣膜（PUV）是男孩專有的先天性疾病，會造成嚴重的下尿路阻塞。胎兒時期即可發現（羊水過少、水腎），新生兒期可能以泌尿系統感染或排尿虛弱來表現。若不及時處理，會導致腎功能衰竭和膀胱功能障礙。

---

## 後尿道瓣膜（Posterior Urethral Valves, PUV）

### 定義
- **只發生在男孩**的先天性後尿道瓣膜
- 瓣膜為一層薄膜狀組織，位於**精阜**（verumontanum）附近
- 造成排尿時後尿道不完全阻塞

### 流行病學
- 發生率：每 5,000-8,000 活產男嬰中有 1 例
- 是男孩**最常見的嚴重先天性泌尿道異常**

### 病理生理學
```
後尿道瓣膜 → 排尿阻塞 → 膀胱壓力升高
    ↓
膀胱肥厚（逼尿肌過度收縮）
    ↓
膀胱內壓傳遞至上尿路
    ↓
雙側水腎、輸尿管擴張
    ↓
腎功能受損（腎發育不良/逆流性腎病）
```

### 胎兒時期表現
| 超音波發現 | 說明 |
|---|---|
| **羊水過少**（Oligohydramnios） | 胎兒尿量減少 |
| 雙側水腎 | 腎臟集合系統擴張 |
| 膀胱擴張且排空不完全 | 遠端阻塞 |
| 「keyhole sign」 | 膀胱頸和後尿道擴張的超音波表現 |

> **臨床重點**：羊水過少會導致**胎兒肺部發育不良**（Potter sequence），這是 PUV 出生後最常見的死因之一。

### 新生兒/嬰兒期表現
| 症狀 | 說明 |
|---|---|
| 微弱尿流（weak urinary stream） | 典型症狀 |
| 滴尿（dribbling） | 膀胱無法完全排空 |
| 腹部腫塊 | 擴張的膀胱 |
| 泌尿系統感染 | 新生兒膿尿 |
| 陰囊水腫（scrotal edema） | 尿液外滲至陰囊 |
| 生長遲緩 | 慢性疾病 |

### 診斷

#### 排尿性膀胱尿道造影（VCUG）

> **確診工具**，是最重要的檢查。

| 發現 | 說明 |
|---|---|
| 後尿道**擴張**（dilated posterior urethra） | 阻塞近端壓力積聚 |
| 膀胱頸**肥厚**（ hypertrophic bladder neck） | 逼尿肌過度收縮 |
| 後尿道呈**鋸齒狀**（sawtooth pattern） | 瓣膜造成的造影劑通過受阻 |
| 膀胱憩室形成 | 長期高壓傳遞 |

#### 超音波（Ultrasound）

| 發現 | 說明 |
|---|---|
| 雙側水腎 | 阻塞近端 |
| 輸尿管擴張 | 傳遞性擴張 |
| 膀胱壁肥厚 | 逼尿肌過度工作 |
| 腎皮質變薄 | 腎功能受損或發育不良 |

#### 尿路動力學檢查（Urodynamics）

- 確認**膀胱低complaint**（low compliance）
- 測量**儲尿壓**（storage pressure）
- 評估**洩漏點壓**（leak point pressure）

### 治療

#### 急性期處理
1. **導尿管引流**（Foley catheter）
2. **泌尿道感染控制**（靜脈抗生素）
3. **水電解質平衡糾正**
4. **營養支持**

#### 根本治療：內視鏡瓣膜切開術

> **標準治療**，內視鏡直視下用冷刀或雷射切開瓣膜。

| 技術 | 說明 |
|---|---|
| **Y-V 瓣膜切開術**（Y-V valve ablation） | 傳統方法 |
| **雷射瓣膜消融**（Laser ablation） | 目前主流，微創精準 |

#### 手術時機
| 情況 | 處理 |
|---|---|
| 輕度阻塞、無腎功能受損 | 可等至新生兒後期做瓣膜切開 |
| 嚴重腎功能受損、水電解質失衡 | 先引流（導尿管/膀胱造口），穩定後再做 |
| 極低體重早產兒 | 先做 **vesicostomy**（膀胱造口），稍後再做確定性手術 |

#### 嚴重案例的手術選項

| 手術 | 適應症 |
|---|---|
| **Vesicostomy**（膀胱造口） | 過於虛弱無法承受瓣膜切開的新生兒 |
| **High diversion**（如 ureterostomy） | 嚴重上尿路積膿、無法控制的感染 |

### 長期併發症

| 併發症 | 說明 | 發生率 |
|---|---|---|
| **慢性腎病**（CKD） | 腎功能進行性下降 | 30-40% |
| **膀胱功能障礙** | 低 compliant bladder、dysfunctional voiding | 30-50% |
| **尿失禁** | 膀胱功能障礙導致 | 10-20% |
| **高血壓** | 逆流性腎病 | 10-20% |
| **泌尿道感染復發** | 膀胱功能障礙 | 常見 |

> **臨床重點**：即使瓣膜已成功切開，約 **30-40% 的患者**仍會發展為慢性腎病。長期泌尿科追蹤至成年是必要的。

### 追蹤

| 項目 | 頻率 |
|---|---|
| 超音波 | 每 6-12 個月 |
| 尿流速圖 | 每 1-2 年 |
| 尿路動力學（必要時） | 評估膀胱功能 |
| 血壓 | 每 6 個月 |
| 腎功能（creatinine, GFR） | 每 6-12 個月 |
| 尿液檢查 | 每 3-6 個月 |

## 尿道狹窄（Urethral Stricture）

### 定義
尿道管腔的狹窄，導致尿流受阻。

### 原因
| 原因 | 說明 |
|---|---|
| **先天性** | 罕見，如前尿道瓣膜 |
| **外傷性** | 骨盆骨折（後尿道）、會陰部鈍挫傷（前尿道） |
| **感染性** | 淋病性尿道炎（後天性） |
| **醫源性** | 導尿管、內視鏡手術後 |

### 診斷
- **逆行性尿道造影**（Retrograde urethrogram, RUG）
- **排尿性膀胱尿道造影**（VCUG）
- **尿流速圖**（Uroflowmetry）：max flow rate 降低

### 治療

| 方法 | 適應症 |
|---|---|
| **尿道擴張**（Urethral dilation） | 輕度狹窄 |
| **內視鏡尿道切開術**（Visual internal urethrotomy） | 短段狹窄（< 1-2 cm） |
| **開放性尿道重建**（Open urethroplasty） | 長段狹窄或復發性狹窄 |

---

## 總結

| 疾病 | 特色 |
|---|---|
| **後尿道瓣膜（PUV）** | 男孩專有、胎兒期羊水過少、新生兒弱尿流、VCUG確診、內視鏡瓣膜切開術治療、長期追蹤腎功能和膀胱功能 |
| **尿道狹窄** | 外傷或感染後、尿流受阻、尿道造影確診、依狹窄程度決定擴張或手術 |
