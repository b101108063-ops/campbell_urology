# 147 尿道下裂

📖 **導讀**：尿道下裂（Hypospadias）是男性最常見的先天性陰莖畸形之一，特徵是尿道開口位於陰莖腹側而非龜頭正常位置。本章節系統性介紹尿道下裂的分類、評估（包括尿道板評估）、手術適應症與時機，並重點討論目前主流的手術技術：包括**尿道板切開管狀術（TIP, Tubularized Incised Plate）**、**陰莖腹側彎曲（Ventral Curvature, VC）校正**、**分期口腔黏膜移植**與**再手術策略**。術後併發症的預防與處理（瘻管、龜頭裂開、尿道狹窄）也是本章節的核心重點。

---

## 1. 疾病概述與分類

### 定義

- **尿道下裂**：尿道開口位於陰莖腹側（從冠狀溝到會陰部之間任何位置）
- 常伴有**陰莖腹側彎曲（Ventral Curvature, VC）**與**包皮分布異常**

### 解剖分類

| 位置 | 傳統名稱 | 佔比 |
|---|---|---|
| 冠狀溝或更遠端 | **遠端型（Distal）** | ~70-80% |
| 陰莖中段 | **中段型（Midshaft）** | ~15% |
| 陰莖近端、陰囊或會陰 | **近端型（Proximal）** | ~10% |

### 依嚴重程度分類

| 類型 | 尿道開口位置 | 龜頭位置 | 包皮分布 |
|---|---|---|---|
| **輕度** | 冠狀溝遠端 | 覆蓋或輕度偏斜 | 背側多餘 |
| **中度** | 冠狀溝/冠狀溝近端 | 明顯偏斜腹側 | 背側過多、腹側缺乏 |
| **重度** | 陰莖近端、陰囊、會陰 | 嚴重偏斜 | 陰莖狀（peniform）或無覆盖 |

> **臨床重點**：近端型尿道下裂常伴有更嚴重的陰莖彎曲與尿道板發育不良，手術複雜度與併發症風險均高於遠端型。術前對尿道板（Urethral Plate）與彎曲程度的準確評估是選擇手術方式的關鍵。

---

## 2. 術前評估

### 尿道板評估

- **尿道板（Urethral Plate, UP）**：龜頭腹側的黏膜溝，是 TIP 手術的材料的基礎
- 評估重點：
  - 寬度（正常 ≥ 8-10 mm）
  - 深度與彈性
  - 是否有纖維化或疤痕

> **臨床重點**：過去認為需要深槽狀（deep groove）的尿道板才能成功執行 TIP 手術，但多項研究顯示槽的深度與手術結果無顯著相關。然而狹窄的尿道板（< 8 mm）可能增加併發症風險。

### 陰莖腹側彎曲（Ventral Curvature, VC）評估

- **人工勃起測試（Artificial Erection Test）**：陰莖去膜後注射生理食鹽水誘發勃起，測量彎曲角度
- **校正標準**：
  - **< 30°**：可接受，無需特殊處理
  - **≥ 30°**：需要校正

| 彎曲程度 | 建議處理方式 |
|---|---|
| < 30°（去膜後） | 背側摺疊術（Dorsal Plication） |
| ≥ 30° | 尿道板橫切 + 背側摺疊 |
| ≥ 30° 校正後仍 ≥ 30° | 腹側切開延長（Ventral Corporal Lengthening） |

> **臨床重點**：約 50% 的近端型尿道下裂患者在去膜與釋放陰莖海綿體腹側結構後，彎曲會自然改善至 < 30°。其餘患者需要更積極的校正策略，包括尿道板橫切或腹側白膜切開移植。

### 龜頭寬度測量

- **卡尺測量龜頭最寬處**：為評估 TIP 修復可行性的重要參數
- **< 14 mm** 的龜頭寬度與較高的龜頭裂開（glans dehiscence）風險相關

---

## 3. 手術時機

### 建議年齡

- **3 個月以上健康足月嬰兒**：可門診手術
- **早產兒**：需等至妊娠週數 56 週後評估

### 考量因素

| 因素 | 說明 |
|---|---|
| 麻醉風險 | 3-5 個月嬰兒麻醉併發症低；建議 18 個月前完成手術以減少心理影響 |
| 心理因素 | 研究顯示 18 個月前或後手術，長期心理調整無顯著差異 |
| 尿道板成熟度 | 部分外科醫師偏好延遲以獲得更大的手術操作範圍 |

> **臨床重點**：手術時機的決定應綜合考量麻醉安全、家屬意願與外科醫師的熟悉度，而非單純以年齡為唯一標準。

---

## 4. 術前雄性素刺激

### 適應症

- **龜頭寬度 < 14 mm** 且計畫執行近端型 TIP 修復的病例
- 目的：增加陰莖長度、龜頭大小與軟組織厚度

### 藥物

| 藥物 | 給藥方式 | 劑量 |
|---|---|---|
| **Testosterone Cypionate** | 肌肉注射 | 2-32 mg/kg（漸增劑量） |
| **Dihydrotestosterone（DHT）凝膠** | 局部塗抹 | 2.5% 每日塗抹至龜頭與陰莖 3 個月 |

### 對手術結果的影響

- 爭議性結果：有研究顯示術前雄性素刺激可減少併發症，也有研究顯示刺激組反而併發症增加
- Snodgrass 等人的研究發現接受術前睪固酮注射的病患：
  - 龜頭寬度平均：12 mm → 16.5 mm（注射後）
  - 未注射組：15.4 mm
  - **併發症發生率：34%（注射組）vs. 11%（未注射組）**
  - 結論：術前雄性素刺激反而增加併發症風險

> **臨床重點**：目前證據不支持常規使用術前雄性素刺激來減少併發症。若考慮使用，應謹慎評估風險收益比，並了解目前文獻的爭議性結果。

## 5. 主要手術技術

### 5.1 尿道板切開管狀術（TIP, Tubularized Incised Plate Urethroplasty）

#### 適應症

- **遠端型尿道下裂**（首選技術）
- 龜頭型、冠狀溝型、冠狀溝近端型

#### 手術步驟（遠端 TIP）

1. 測量龜頭寬度（calipers）
2. 環形切口，保留尿道板
3. **去膜（Degloving）**：背側沿 Buck's fascia，腹側保留可用的肉膜層
4. **人工勃起測試**（去膜後）；若有 < 30° 彎曲，執行背側摺疊術
5. **尿道板正中切開（Midline incision）**：於白膜表面向近端延伸，增加寬度
6. **兩層管狀化（Two-layer tubularization）**：第一層使用 subepithelial 7-0 polyglactin 間斷縫合，第二層使用 7-0 polydioxanone 連續縫合
7. **肉膜覆蓋（Barrier flap）**：背側肉膜或 **tunica vaginalis** 覆蓋新尿道
8. **龜頭成形術（Glansplasty）**：使用 6-0 polyglactin subepithelial 間斷縫合
9. 包皮修復或環切術

#### 近端型 TIP

- 與遠端型相似，但需更廣泛的**龜頭翼游離（Extended glans wings dissection）**
- 游離範圍需達陰莖海綿體兩側約 3 點鐘與 9 點鐘方向
- 可配合 **spongioplasty**（尿道海綿體成形術）覆蓋新尿道
- **Tunica vaginalis flap** 覆蓋效果優於肉膜

> **臨床重點**：近端型 TIP 的技術演變（兩層管狀化、subepithelial 縫合、tunica vaginalis 覆蓋）是大幅降低瘻管發生率的關鍵。Tunica vaginalis 覆蓋組的瘻管發生率可降至 0%。

#### TIP 結果（遠端型）

| 併發症 | 發生率 |
|---|---|
| 總併發症 | 3-15% |
| 瘻管 | 1-8% |
| 龜頭裂開 | 1-5% |
| 尿道口狹窄 | 1-4% |
| 尿道狹窄 | < 1%（遠端 TIP） |

#### 近端型 TIP 結果

- 初始併發症率高達 33-50%
- Snodgrass 等人報告技術改進後降至 **13%**
- 主要併發症：瘻管（技術改進後降至 0）、龜頭裂開（目前最常見）

### 5.2 陰莖腹側彎曲校正

#### 背側摺疊術（Dorsal Plication）

- **適應症**：校正後 < 30° 的彎曲
- **技術**：單一正中線摺疊（5-0 或 6-0 polypropylene）埋入打結
- **結果**：
  - 復發性彎曲：約 7%
  - 陰莖縮短：< 0.5 cm（成人平均 3 個摺疊）

> **臨床重點**：反覆多點摺疊會增加陰莖縮短風險。當需要多點摺疊才能校正時，應考慮其他策略（如腹側延長）。

#### 腹側延長（Ventral Corporal Lengthening）

- **適應症**：背側摺疊術後仍 ≥ 30° 的持續性彎曲
- **技術**：3-5 個橫向白膜切開（corporotomies），可能需要移植材料（如小腸黏膜下層 SIS、口腔黏膜）
- 不建議在需要執行 TIP 的近端修復中使用（因為移植床不適合游離皮瓣）

### 5.3 口腔黏膜移植（Buccal Mucosa Graft）

#### 適應症

| 情境 | 說明 |
|---|---|
| **分期修復（Staged Repair）** | 近端型尿道下裂伴隨嚴重陰莖彎曲、尿道板需切除者 |
| **再手術（Reoperation）** | 前次修復失敗、需重建尿道者 |
| **BXO 病例** | 苔蘚性硬化性閉鎖性龜頭炎 |

#### 兩期修復（Bracka / Two-Stage）

**第一期**：
- 切除所有不健康組織（通常包括整段新尿道）
- 重新建立龜頭溝（glans groove）與近端尿道切開
- 測量所需移植長度
- **口腔黏膜移植**：上唇（小範圍）或下唇（較大範圍）取得
- 移植片 quilted 縫合至白膜

**第二期**（6 個月後）：
- U 形切口沿新尿道板周邊
- 兩層管狀化（subepithelial polyglactin + polydioxanone）
- **Tunica vaginalis flap** 全程覆蓋新尿道
- 龜頭成形術與皮膚縫合

> **臨床重點**：兩期口腔黏膜修復是近端型尿道下裂或嚴重失敗病例的可靠選項。移植成功率 > 90%，但需要嚴格的術後照護與 6 個月的等待期。

#### 游離口腔黏膜結果

| 結果 | 數據 |
|---|---|
| 移植成功 | > 90% |
| 需要再次移植（contracture） | < 10% |
| 併發症（分期修復） | 15-20%（主要是龜頭裂開） |

### 5.4 包皮瓣（Preputial Flap）

#### Onlay 包皮瓣

- **適應症**：近端型尿道下裂但不接受 TIP 者
- **優點**：單期手術、使用帶血管蒂的包皮內層
- **併發症**：27-45%（瘻管、龜頭裂開、狹窄、尿道口脫垂）

#### Tubularized 包皮瓣（Byars Flap）

- **適應症**：近端型陰莖/陰囊/會陰型尿道下裂
- **缺點**：高併發症率（14-33%），包括尿道憩室（diverticulum）形成風險
- **注意**：Byars Flap 的尿道寬度若與龜頭固定阻力不匹配，容易產生遠端擴張與憩室

> **臨床重點**：包皮瓣技術的長期隨訪顯示，隨著 TIP 技術的成熟與普及，包皮瓣的使用已大幅減少。目前 TIP 技術（配合或不配合分期口腔移植）幾乎適用於所有尿道下裂類型。

## 6. 再手術（Reoperation）

### 術式選擇原則（Algorithm）

```
龜頭寬度 ≥ 14 mm + 尿道板存在且無嚴重疤痕
    → TIP 再手術

尿道板已切除但有健康皮膚條帶殘留
    → Dorsal Inlay Graft（口腔黏膜）

尿道板切除 + 嚴重疤痕/廣泛組織缺損
    → 兩期口腔黏膜修復

BXO 或近端疤痕
    → 兩期口腔黏膜修復（第一期切除所有BXO組織）
```

### TIP 再手術

| 項目 | 說明 |
|---|---|
| 適應症 | 尿道板仍存在且無嚴重疤痕 |
| 手術 | 腹側 Y 切開重新建立龜頭翼 + 正中切開 + 兩層管狀化 |
| 結果 | 併發症 12-30%（主要為瘻管、龜頭裂開） |
| 關鍵 | Tunica vaginalis flap 覆蓋顯著降低瘻管率 |

### Dorsal Inlay Graft 再手術

- **適應症**：尿道板已移除但有健康皮膚條帶
- **移植材料**：口腔黏膜（上唇或下唇）
- **結果**：約 15% 併發症率

## 7. 術後照護與併發症

### 術後用藥

| 藥物 | 目的 |
|---|---|
| **Trimethoprim-sulfamethoxazole** | 泌尿道感染預防（排尿期） |
| **Oxybutynin**（3 歲以上）| 膀胱痙攣緩解 |
| **Ibuprofen / Acetaminophen** | 疼痛控制（交替使用） |

> **臨床重點**：術後抗生素的使用有隨機對照試驗支持，顯示口服 Cephalexin 可顯著降低發燒 UTI 發生率（從 12/49 降至 3/52）。

### 主要併發症與處理

#### 瘻管（Fistula）

| 預防因素 | 處理 |
|---|---|
| Subepithelial 縫合 | 確認無遠端阻塞 |
| Barrier flap 覆蓋（tunica vaginalis 或肉膜）| 切除瘻管通道 + 兩層關閉 + 新 barrier flap |
| 兩層管狀化 | |

#### 龜頭裂開（Glans Dehiscence）

| 風險因子 | 預防/處理 |
|---|---|
| 龜頭寬度 < 14 mm | Extended glans wings dissection |
| 龜頭翼張力過大 | 遊離至 3&9 點鐘方向 |
| 組織癒合不良 | 再手術（glansplasty）|

> **臨床重點**：**龜頭裂開**是近端型 TIP 修復後最常見的併發症。預防關鍵在於充足的龜頭寬度與無張力的龜頭翼對合。Extended glans wings dissection 技術的引進已使龜頭裂開率從 20% 以上降至 1-2%。

#### 尿道口狹窄（Meatal Stenosis）

- **定義**：術後尿道口 < 8 French 且有阻塞症狀（排尿困難、發燒 UTI）
- **預防**：TIP 切口遠端限制在尿道板內，不延伸至龜頭；管狀化起點距尿道板遠端至少 3 mm
- **處理**：Direct vision meatal advancement（DVI）背側切開；若有 BXO 則需再手術

#### 尿道狹窄（Neourethral Stricture）

- 遠端 TIP 發生率 < 1%
- 近端 TIP 與海綿體遊離相關（已放棄此操作）

> **臨床重點**：近端型 TIP 修復中，若執行「尿道板與海綿體遊離」以保留尿道板，狹窄率可達 17%。此操作現已不建議使用。

#### 尿道憩室（Diverticulum）

- 主要與**皮瓣技術（Byars Flap, Tubularized flap）**相關
- 原因：遠端固定阻力與近端皮瓣彈性差異造成尿液滯留與擴張
- **預防**：避免使用大口徑、彈性差的皮瓣；維持整段新尿道口徑一致

## 8. 長期隨訪與預後

### 隨訪時間點

| 隨訪時間 | 內容 |
|---|---|
| 術後 6 週 | 傷口癒合評估、移除敷料 |
| 術後 6-8 個月 | 首次正式隨訪（遠端 TIP） |
| 術後 1 年起每年 | 近端修復者持續隨訪至青春期 |

> **臨床重點**：80% 的尿道修復併發症在術後 1 年內出現，但仍有相當比例在更晚期出現。因此建議近端修復者應長期隨訪至青春期，以評估功能結果。

### 成人結果

| 功能指標 | 發現 |
|---|---|
| 排尿症狀 | 近端型：spraying (43%)、排尿困難 (30%)、尿流偏斜 (26%) |
| 尿流速（Qmax） | 尿道下裂患者平均 21 mL/sec，低於對照組 30 mL/sec |
| 射精功能 | 近端型：26% 有射精問題（擠壓式射精、力道不足） |
| 性功能 | 數據有限；主要為病例報告 |

### 包皮保留（Preputioplasty）

- 對家屬希望保留包皮的病例，可在執行近端修復時同時進行**包皮成形術**
- **V 型切開**從包皮背側兩角向腹側低於尿道口切開
- 可配合 TIP 或分期修復

## 摘要：尿道下裂手術要點

| 原則 | 說明 |
|---|---|
| **TIP 為首選** | 遠端型首選；近端型 TIP + extended glans wings dissection 效果良好 |
| **兩層管狀化 + barrier flap** | 降低瘻管率的關鍵技術 |
| **Tunica vaginalis 覆蓋** | 優於肉膜，可使瘻管率降至 0% |
| **龜頭寬度 < 14 mm → Extended glans wings dissection** | 取代術前雄性素刺激 |
| **嚴重近端型或失敗病例 → 兩期口腔黏膜修復** | 金標準重建技術 |
| **避免尿道板與海綿體遊離** | 此操作已被證實增加狹窄風險 |
| **長期隨訪** | 近端修復需隨訪至青春期 |
