# 148 隱睪症

📖 **導讀**：隱睪症（Cryptorchidism/Undescended Testis）是男孩最常見的先天性泌尿生殖系統疾病之一，其特徵是睪丸未能正常下降至陰囊。本章節涵蓋隱睪症的流行病學與分類（先天性與後天性）、胚胎發育學基礎（INSL3、睪固酮、AMH 與引帶的角色）、遺傳與環境因素、睪丸發育與生殖細胞的病理變化、診斷方法（理學檢查、超音波、腹腔鏡）、手術適應症與時機（**睪丸固定術 Orchidopexy**），以及相關病理（睪丸發育不良、附睪畸形、引帶異常、**精索睪丸融合 Splenogonadal Fusion**、橫向睪丸異位）。

---

## 1. 疾病概述與分類

### 定義

- **隱睪症（Cryptorchidism）**：睪丸未能下降至陰囊底部，包括可觸及（palpable）與不可觸及（nonpalpable）兩大類
- ** retractile testis（收縮性睪丸）**：提睪肌反射導致睪丸上提至陰囊上方，但可在檢查時手動拉至陰囊底部；不屬於隱睪症
- **acquired cryptorchidism（後天性隱睪症）**：出生時睪丸位於陰囊，後來升至陰囊外

### 分類系統

| 類別 | 說明 |
|---|---|
| **先天性隱睪症** | 出生時即存在 |
| **後天性隱睪症** | 出生後診斷，初期曾位於陰囊 |
| **可觸及隱睪** | 睪丸可於腹股溝或陰囊上方觸及 |
| **不可觸及隱睪** | 睪丸無法於體表觸及（可能位於腹腔、腹股溝管或已萎縮） |

### 發生率

| 年齡/族群 | 發生率 |
|---|---|
| 足月新生男嬰 | 1-4% |
| 早產新生男嬰 | 可達 30% |
| 3 個月大（足月兒） | 自然下降後降至 1% |
| 1 歲時 | ~1%（自發性下降很少發生於此時段）|

> **臨床重點**：約 50-87% 在出生時診斷為隱睪的男嬰，在 3 個月大時會出現自發性睪丸下降。但若在 6 個月大後仍未下降，自發性下降的機率就大幅降低，建議進行手術干預。

## 2. 胚胎發育學

### 睪丸發育的激素調控

| 激素 | 來源 | 功能 |
|---|---|---|
| **SRY** | Y 染色體 | 啟動睪丸決定；激活 SOX9 |
| **SOX9** | 性腺支持細胞 | 睪丸細胞譜系建立 |
| **AMH（MIS）** | Sertoli 細胞 | 促使副中腎管退化 |
| **INSL3** | Leydig 細胞 | 調控第一階段下降（腹內階段）|
| **睪固酮（Testosterone）** | Leydig 細胞 | 促使中腎管發育；調控第二階段下降（腹股溝-陰囊）|
| **LH / hCG** | 腦下垂體 / 胎盤 | 刺激 Leydig 細胞分化與睪固酮分泌 |

### 睪丸下降的兩個階段

#### 第一階段：腹內下降（第 8-15 週）

| 項目 | 說明 |
|---|---|
| **主導激素** | **INSL3**（胰島素樣因子 3）|
| **目標組織** | **引帶（Gubernaculum）**|
| **作用** | INSL3 與 LGR8 受體結合，引帶增大並錨定於陰囊凹陷 |
| **結果** | 睪丸從腹腔移動至腹股溝管內口附近 |

> **臨床重點**：**INSL3** 是第一階段下降的關鍵激素。INSL3 或其受體（LGR8/RXFP2）基因剔除小鼠會出現**腹腔內隱睪症**。人類隱睪症病例中也發現 LGR8 受體基因突變。

#### 第二階段：腹股溝-陰囊下降（第 7-9 月）

| 項目 | 說明 |
|---|---|
| **主導激素** | **睪固酮** |
| **作用機制** | 促使引帶收縮；genitofemoral nerve（GFN）分泌 **CGRP** 調控引帶收縮 |
| **過程** | 腹股溝管穿透 → 陰囊下降 |
| **異常** | 睪固酮不足或雄性素阻抗 → 隱睪症 |

### 激素缺乏與隱睪症的對應關係

| 激素/因子 | 缺乏結果 |
|---|---|
| **INSL3** | 腹內隱睪（第一階段失敗）|
| **睪固酮 / 雄性素受體** | 腹股溝-陰囊下降失敗 |
| **AMH / AMH 受體** | 副中腎管不退化（Persistent Müllerian Duct Syndrome）；不直接影響下降 |

## 3. 病因學：遺傳與環境因素

### 遺傳因素

- **家族聚集性**：兄弟中發生率為一般族群的 3-5 倍
- **自體顯性遺傳（不完全外顯）**為最常見的遺傳模式
- **復發風險比（Recurrence Risk Ratio）**：
  - 同卵雙胞胎：10.1
  - 兄弟：3.5
  - 子女：2.3

> **臨床重點**：隱睪症的遺傳基礎被認為是**多基因-多因素**的複雜模式。候選基因包括 INSL3、LGR8、AR、SRY、SOX9、AMH 等，但單一基因突變只能解釋少數病例。

### 環境內分泌干擾物質（EDCs）

| 物質 | 效應 |
|---|---|
| **DES（己烯雌酚）** | 動物實驗與人類研究均顯示與隱睪症相關 |
| **鄰苯二甲酸酯（Phthalates）** | 動物實驗顯示抑制類固醇生成；人體研究結果不一致 |
| **雙酚 A（BPA）** | 動物實驗顯示影響生殖細胞發育；人體數據有限 |

- **肛殖距離（Anogenital Distance, AGD）**：為胎兒雄性化作用的生物標記；縮短的 AGD 與隱睪症、尿道下裂及多種生殖發育異常相關

> **臨床重點**：雖然環境內分泌干擾物質（EDCs）在動物實驗中顯示對生殖發育的影響，但目前的人體流行病學證據尚不足以確認單一 EDC 與隱睪症的因果關係。隱睪症的發生更可能是遺傳易感性與環境因素共同作用的結果。

## 4. 病理變化

### 睪丸發育不良（Testicular Maldevelopment）

- **生殖細胞減少**：隱睪症的**精原細胞（spermatogonia）**數量自嬰兒期後開始減少
- **Gonocyte → Spermatogonia 轉化延遲**：正常新生兒約 1.5 個月時 gonocyte 轉化為 spermatogonia；隱睪症中此轉化延遲
- **Ad Spermatogonia（成人暗型精原細胞）**減少或消失：為精子生成潛能的指標
- **Sertoli 細胞與周節狀肌樣細胞（Peritubular Myoid Cells）**發育異常

| 細胞組成 | 變化 |
|---|---|
| **精原細胞** | 數量減少；成熟延遲 |
| **Sertoli 細胞** | 形態異常；成熟延遲 |
| **間質細胞** | 間質纖維化增加 |

> **臨床重點**：隱睪症的睪丸發育不良在嬰兒早期即可出現，且與睪丸位置異常本身有關，而非僅僅是延遲手術的後果。這支持**早期手術介入（6-12 個月大）**的理論基礎。

### 對側睪丸

- 研究顯示約 22-95% 的隱睪症患者其對側（已下降）睪丸也顯示出生殖細胞減少
- 說明隱睪症可能是一**雙側性病理過程**，即使只表現為單側異常

---

## 5. 睪丸大小與生長

| 發現 | 臨床意義 |
|---|---|
| 隱睪在出生時即較小 | 反映宮內發育異常 |
| 隱睪在術後生長速度仍低於對側 | 位置異常對睪丸生長有持續影響 |
| **9 個月大手術**的術後生長優於 **3 歲手術** | 早期干預對睪丸發育更有利 |

> **臨床重點**：Kollin 等人的前瞻性隨機研究顯示，**9 個月大**接受睪丸固定術的男孩，其術後睪丸生長優於 3 歲才接受手術者，支持 AAP 與 AUA 指南建議的手術時機（**6 個月大後**）。

## 6. 相關病理

### 附睪畸形（Epididymal Anomalies）

| 發生率 | 16-75%（報導差異大）|
|---|---|
| **類型** | 頭/尾部與睪丸融合不全；附睪延長/迴旋；閉鎖 |

- 附睪畸形的嚴重程度與隱睪位置相關：位置越高，附睪異常越常見

### 引帶異常

- 引帶與睪丸的連接可能異常
- 可能導致**橫向睪丸異位（Transverse Testicular Ectopia）**

### 遺傳性腺囊腫與囊狀水腫

- 隱睪症中**睪丸附件（Appendix Testis）**扭轉的風險增加

### Splenogonadal Fusion

| 項目 | 說明 |
|---|---|
| **定義** | 脾臟組織與性腺或精索的纖維性融合 |
| **分類** | 連續型（有索帶連接脾臟與睪丸）55%；非連續型 45% |
| **隱睪症發生率** | 30%（在 splenogonadal fusion 個案中）|
| **臨床意義** | 可能被誤認為睪丸腫瘤；需避免不必要的睪丸切除 |
| **治療** | 確認診斷；可同時進行睪丸固定術 |

### 橫向睪丸異位（Transverse Testicular Ectopia）

| 項目 | 說明 |
|---|---|
| **定義** | 兩側睪丸位於同一側陰囊或腹股溝管 |
| **分類** | 單獨發生（40-50%）或伴隨 **Persistent Müllerian Duct Syndrome（PMDS）** |
| **常見表現** | 腹股溝疝氣 + 對側不可觸及睪丸 |
| **治療** | 睪丸固定術；PMDS 病例可能需要經中隔（transseptal）技術 |

### 隱睪症與惡性腫瘤

- 隱睪症患者**睪丸生殖細胞腫瘤**風險增加 2.8-8 倍
- **精原細胞瘤（ seminoma）**是最常見的組織類型
- **睪丸固定術（Orchidopexy）**可降低（但不能完全消除）腫瘤風險
- 早期手術（6-12 個月大）可能對腫瘤預防有益

## 7. 診斷與評估

### 理學檢查

| 步驟 | 說明 |
|---|---|
| **觸摸位置** | 陰囊、腹股溝管（由上內骨脊向下唇移動觸摸）、恥骨上區 |
| **手動誘發** | 單手沿同側腹股溝管向下的持續壓力 + 對側手觸摸 |
| **分類** | 可觸及 vs. 不可觸及 |
| **注意** | 需與**收縮性睪丸（Retractile Testis）**區分：收縮性睪丸可在檢查時手動拉至陰囊底部 |

> **臨床重點**：理學檢查是確診隱睪症的**首要步驟**，但檢查者間與檢查者內的變異相當大。即使是有經驗的檢查者，完全一致的判斷也只有約 13.5% 的機率。

### 不可觸及睪丸的評估

| 檢查 | 說明 |
|---|---|
| **腹腔鏡（Laparoscopy）** | 確認腹腔內睪丸位置的金標準 |
| **超音波** | 非侵入性；對腹腔內睪丸敏感性低 |
| **MRI** | 對軟組織解析佳；但幼兒需鎮靜 |

| 腹腔鏡發現 | 臨床意義 |
|---|---|
| 睪丸位於腹腔/腹股溝管（"peeping"）| 需手術固定 |
| 輸精管/精索血管盲端（無睪丸）| **Vanishing Testis（萎縮性睪丸）** |
| 無血管/無結構 | 需擴展腹腔探查 |

### Vanishing Testis（睪丸消失症候群）

| 項目 | 說明 |
|---|---|
| **發生率** | 不可觸及睪丸的 15-40% |
| **病因** | 宮內睪丸扭轉（推測）|
| **病理** | 殘留的精索盲端；無可識別的睪丸組織 |
| **處理** | 腹腔鏡確認；若有可觸及的陰囊殘餘（nubbin）且對側睪丸肥大 → 陰囊探查；否則腹腔鏡確認 |
| **對側固定** | 建議（理論上避免對側扭轉風險）|

### DSD 篩檢

- **雙側不可觸及睪丸**的男孩：需評估是否有**性發育障礙（DSD）**
- 建議：染色體分析（Karyotype）+ 術前專科會診

## 8. 治療

### 觀察（自然下降）

| 族群 | 建議 |
|---|---|
| **新生兒** | 觀察至 6 個月大（糾正胎齡）|
| **6 個月大後仍未下降** | 建議手術 |

> **臨床重點**：自發性下降很少發生在 6 個月大之後（不考慮胎齡）。早產兒的時間軸應順延至約 6 個月的**糾正胎齡**。

### 手術時機（AUA/AAP 指南）

| 建議 | 說明 |
|---|---|
| **確診隱睪症後，6 個月大起（糾正胎齡）** | 標準建議 |
| **不建議遲於 1-2 歲** | 組織病理變化在此之前已存在；延遲手術對睪丸發育與腫瘤預後均有不利影響 |

### 睪丸固定術（Orchidopexy）

#### 可觸及隱睪的手術（標準腹股溝途徑）

| 步驟 | 說明 |
|---|---|
| **切口** | 低位橫向切口（蘭格線），位於恥骨結節外上方 |
| **腹股溝管暴露** | 切開腹外斜肌筋膜；注意避免傷及髂腹股溝神經 |
| **確認睪丸** | 確認於腹股溝管/陰囊上方；搜索 SIP（淺表腹股溝囊）|
| **游離精索** | 切斷引帶；打開內精索筋膜；游離至內腹股溝環 |
| **處理囊膜** | 若有**開放性腹膜鞘突（PPV）** → 縫扎 |
| **腹股溝環切開** | 進一步游離腹膜後方的輸精管與血管 |
| **陰囊切口** | 橫向切開；建立皮下囊（subdartos pouch）|
| **睪丸通過** | 建立從腹股溝至陰囊的隧道；將睪丸通過置入 |
| **固定** | 縫合固定至陰囊皮下組織 |
| **關閉** | 可吸收線縫合 |

#### 不可觸及睪丸的手術

| 睪丸位置 | 技術 |
|---|---|
| **腹腔內（距內環 < 2-3 cm）**| **Fowler-Stephens 睪丸固定術**（第一期或第二期）|
| **腹股溝管內 ("peeping")** | 腹股溝探查；可能可標準固定 |
| **無法觸及但確認萎縮** | 腹腔鏡/腹股溝探查；確認後可不切除殘餘 |

#### Fowler-Stephens 技術

| 方式 | 說明 |
|---|---|
| **第一期（微創）** | 夾閉精索血管（血流測試）；6-12 個月後第二期固定 |
| **第二期** | 將睪丸與側支循環一起固定至陰囊 |
| **單一期** | 對低位腹腔睪丸，可直接固定（需有良好側支循環）|

> **臨床重點**：Fowler-Stephens 技術的原理是利用睪丸的側支循環（提睪肌血管、輸精管血管）在精索主要血管被阻斷後提供替代血流。但側支循環的建立差異大，第二期手術可確保睪丸存活。

#### 睪丸固定術結果

| 結果 | 數據 |
|---|---|
| 成功率（觸及性隱睪）| > 95% |
| 睪丸萎縮率 | < 1%（可觸及）/ 5-10%（腹腔內 Fowler-Stephens）|
| 睪丸固定術後睪丸生長 | 取決於手術時機；早期手術生長更佳 |

## 9. 後天性隱睪症

| 項目 | 說明 |
|---|---|
| **定義** | 出生時睪丸位於陰囊，後來升至陰囊外 |
| **發生率** | 不完全確定；估計 1-4% |
| **典型年齡** | 8-11 歲診斷 |
| **位置** | 多為低位（淺表腹股溝囊 SIP 最常見）|
| **囊膜狀態** | 多數為關閉狀態 |
| **病因假說** | 可能是輕度的先天性隱睪；或因身體生長導致睪丸-陰囊距離相對增加 |
| **自然史** | 可出現自發性下降（尤其在青春期前）|

> **臨床重點**：後天性隱睪症的處理原則與先天性相似，建議在確診後觀察一段時間（至青春期前），若未自發性下降再考慮手術。

## 10. 隱睪症與性發育障礙（DSD）

- **隱睪症與 DSD 的共同發生**：隱睪症，特別是近端型尿道下裂伴隨的隱睪，需考慮 DSD 的可能
- **Klinefelter 症候群（47,XXY）**：約 < 2% 的隱睪症男孩中發現
- **Kallmann 症候群**：低促性腺激素性腺功能低下症
- **Leydig 細胞發育不全**

| 建議 | 說明 |
|---|---|
| **雙側隱睪 + 尿道下裂** | 強烈建議染色體分析 |
| **所有隱睪症嬰兒** | 建議術前常規評估是否有 DSD |

## 摘要：隱睪症治療要點

| 項目 | 建議 |
|---|---|
| **手術時機** | 6 個月大（糾正胎齡）確診後，建議不遲於 1-2 歲 |
| **標準固定術** | 可觸及隱睪：腹股溝途徑 + 陰囊固定 |
| **腹腔內不可觸及睪丸** | 腹腔鏡確認；Fowler-Stephens（第一期或第二期）|
