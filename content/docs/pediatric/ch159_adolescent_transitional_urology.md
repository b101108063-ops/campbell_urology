# 📖 章節導讀

**過渡期泌尿科（Transitional Urology）** 是小兒泌尿科與成人泌尿科之間的橋樑，專注於從兒童期過渡到成人期的泌尿系統疾病管理。本章節將介紹過渡期護理的重要性、需要長期追蹤的常見疾病、青少年特有的泌尿問題，以及社會心理層面的支持需求。

> **臨床重點** 良好的過渡期照護（Transition Care）可顯著降低青少年泌尿系統疾病患者在成年期的併發症發生率與再手術率。過渡期不是「結束兒科照護」，而是「開始成人自主管理」的過程。

---

## 1. 過渡期護理的概念

### 定義

**過渡期護理（Transition）** 是指將青少年從**以家長為中心的小兒醫療體系**，逐漸轉移至**以患者本人為中心的成人醫療體系**的系統性過程。

### 為什麼過渡期泌尿科很重要？

| 原因 | 說明 |
|---|---|
| **疾病延續性** | 许多小兒泌尿疾病（如神經性膀胱、膀胱外翻）會延續至成年 |
| **併發症風險** | 青少年期疏於追蹤，成年後可能出現腎功能惡化、尿路結石、泌尿系統惡性腫瘤 |
| **自主管理需求** | 成年後需自我導尿、藥物管理，沒有家長協助時更容易出錯 |
| **生育與性功能** | 青少年後期需評估生育能力與性功能 |

### 理想的過渡期模式

- **多專科團隊**：小兒泌尿科醫師、成人泌尿科醫師、腎臟科醫師、內分泌科醫師、心理師、社會工作者
- **漸進式轉移**：非突然中斷，而是 1-2 年的過渡期
- **患者教育**：疾病知識、自我照護技能、藥物遵從性
- **轉移文件**：完整的病史、手術紀錄、用藥清單、追蹤計畫

## 2. 需要過渡期追蹤的主要疾病

### 2.1 神經性膀胱（Neurogenic Bladder）

**脊髓發育不良（Spina Bifida）** 是最常見的致病原因。

| 青少年期/成年期問題 | 說明 |
|---|---|
| **腎功能惡化** | 膀胱高壓導致**膀胱輸尿管逆流（VUR）**與逆流性腎病 |
| **尿路感染（UTI）** | 免疫抑制＋尿瀦留增加感染風險 |
| **尿路結石** | 長期導尿、脫水、高鈣尿症 |
| **性功能障礙** | 男性：勃起功能障礙、射精異常；女性：性交困難 |
| **生育問題** | 男性：精子數量減少；女性：妊娠需高風險產科照護 |
| **尿失禁** | 持續性或進展性尿失禁影響生活品質 |

**過渡期重點**：確認**尿路動力學**狀態、腎功能（creatinine、eGFR）、自我導尿技術、膀胱腸道管理計畫。

### 2.2 膀胱外翻（Bladder Exstrophy）

膀胱外翻為**先天性腹壁缺損**，膀胱裸露於腹壁外，歷經新生兒期重建手術。

| 重建手術階段 | 內容 |
|---|---|
| **新生兒期關閉（Primary closure）** | 出生後 24-72 小時內關閉膀胱與腹壁 |
| **Epispadias 修補** | 嬰兒期或幼兒期修補 |
| **膀胱頸重建（Bladder neck reconstruction）** | 青少年期（約 4-5 歲）進行 |

**青少年/成人期問題**：
- **尿失禁**：即使手術後，仍可能有壓力性尿失禁或持續性尿失禁
- **性功能**：陰莖彎曲（chordee）、性交困難
- **生育能力**：男性可能需要輔助生殖技術；女性可懷孕但需剖腹產
- **膀胱癌風險**：膀胱黏膜長期暴露於刺激物，膀胱癌風險增加（需定期膀胱鏡追蹤）

### 2.3 尿路改道（Urinary Diversion）

因膀胱癌、根治性膀胱切除術、先天性異常（如膀胱外翻）所施行的尿路改道。

| 尿路改道類型 | 說明 |
|---|---|
| **迴腸導管（Ileal conduit）** | 最常見，Bricker 手術；尿液經由腹壁造口排出 |
| **可控性尿路改道（Continent diversion）** | 使用腸道建立可控制之儲尿囊（如 Indiana pouch） |
| **原位新膀胱（Orthotopic neobladder）** | 以腸道重建新膀胱，排尿從原有尿道 |

**青少年期問題**：
- **造口護理**：自我照護技能、造口周圍皮膚炎
- **代謝異常**：腸道吸收尿液導致**高氯性酸中毒（hyperchloremic metabolic acidosis）**
- **維生素 B12 缺乏**：迴腸切除後（>20-25 cm）可能發生
- **尿路結石**：儲尿囊內結石形成
- **惡性腫瘤風險**：儲尿囊黏膜長期慢性炎症，泌尿系統上皮癌風險升高

## 3. 青少年特有的泌尿系統問題

### 3.1 白天尿失禁與夜間遺尿

- **過渡期延續**：若兒童期尿失禁未完全緩解，青少年期仍可能持續
- **評估**：尿路動力學檢查、膀胱功能、排尿習慣
- **治療**：行為治療、骨盆底肌肉訓練、藥物（抗膽鹼藥物、desmopressin）

### 3.2 泌尿道感染

| 特殊考量 | 說明 |
|---|---|
| **性行為相關 UTI** | 女性青少年：性行為後 UTI 風險增加（"honeymoon cystitis"） |
| **頻繁感染影響生活品質** | 影響學業、社交活動 |
| **抗生素抗藥性** | 頻繁使用抗生素導致抗藥性菌株產生 |

### 3.3 尿路結石

青少年尿路結石與成人不同，需注意：
- **先天性代謝異常**：胱胺酸尿症（cystinuria）、高草酸尿症（hyperoxaluria）
- **結構異常**：輸尿管狹窄、膀胱出口阻塞
- **藥物相關**：蛋白酶抑制劑（indinavir）、carbonic anhydrase inhibitors

## 4. 社會心理支持

### 青少年面臨的心理挑戰

| 挑戰 | 說明 |
|---|---|
| **自尊心與身體形象** | 尿路改道造口、疤痕、陰莖外觀異常影響自我形象 |
| **性功能焦慮** | 擔心性伴侶反應、性功能障礙 |
| **生育能力擔憂** | 對未來生育能力的焦慮 |
| **社交隔離** | 因尿失禁、頻繁上廁所而回避社交場合 |
| **學業與職業影響** | 頻繁就醫干擾學業，成年後可能影響職業選擇 |

### 支持資源

| 資源 | 內容 |
|---|---|
| **心理師/精神科** | 青少年心理問題、性功能諮詢 |
| **社會工作者** | 協助資源連結、就業輔導 |
| **病友團體** | 同儕支持、經驗分享 |
| **性教育** | 性傳染病預防、避孕、性功能障礙處理 |

> **臨床重點** 過渡期護理的成功關鍵在於「以患者為中心」的溝通，了解每位青少年患者的獨特需求與生活情境，鼓勵他們參與自身照護的決策。

---

## 重點摘要

- **過渡期護理**：從小兒到成人泌尿科的系统性轉移，需多專科團隊合作
- **主要疾病**：神經性膀胱（脊髓發育不良）、膀胱外翻、尿路改道
- **青少年問題**：腎功能惡化、性功能障礙、生育問題、尿失禁、尿路結石
- **社會心理**：自尊心、性功能焦慮、社交隔離、學業/職業影響
- **過渡期重點**：患者教育、自我管理技能、心理支持、完整的轉移文件
