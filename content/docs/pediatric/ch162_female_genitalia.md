# 📖 章節導讀

女性生殖器異常涵蓋從青春期到成年期的多種先天與後天結構異常。本章節系統性介紹**Müllerian 發育異常**、**陰道隔膜**、**處女膜異常**、以及**陰唇粘連**等常見疾病的流行病學、病理機轉、臨床表現與治療原則。

> **臨床重點** 女性生殖器異常的處理，需根據患者的年齡、症狀嚴重度、性功能需求與生育計劃，採取個人化治療策略。對於無症狀的先天性異常，建議延遲手術，等患者足夠大能理解並參與決策。

## 1. 子宮與陰道發育異常（Müllerian Anomalies）

### 1.1 先天性陰道發育不全
（Müllerian Agenesis / Mayer-Rokitansky-Küster-Hauser Syndrome, MRKH）

| 項目 | 說明 |
|---|---|
| **定義** | 先天性子宮與陰道上部發育不全或缺如，染色體為 46,XX，性腺（卵巢）功能正常 |
| **發生率** | 約 1/4,500 女性新生兒 |
| **臨床表現** | 原發性閉經（從未有月經）、正常乳房與陰毛發育、正常女性外觀 |
| **伴隨異常** | 30-50% 伴有腎臟異常（單側腎發育不全最常見）、10-15% 伴有脊椎異常 |

**診斷**：
- **身體檢查**：外生殖器正常，陰道短淺或缺如
- **超音超**：確認無子宫或子宫發育不良
- **MRI**：詳細評估骨盆腔結構

**治療**：
| 方法 | 說明 |
|---|---|
| **非手術：陰道擴張（Vaginal dilation）** | 使用 Progressive vaginal dilators，75-90% 成功率；需每日使用 20-30 分鐘，維持 6-12 個月 |
| **手術：陰道重建（Vaginoplasty）** | McIndoe 手術（使用 split-thickness skin graft）、Vecchietti 手術（機械性拉出）、或腸道陰道成形術（Sigmoid vaginoplasty） |

### 1.2 甲狀腺功能減退相關（Müllerian 發育不全）

甲狀腺功能減退可導致 **Müllerian duct 發育停滯**，但多為暫時性，甲狀腺治療後可能改善。

### 1.3 子宮異常（Müllerian Anomalies）

| 分類（VFAC分類） | 類型 | 說明 |
|---|---|---|
| **Class I** | 子宮發育不全（Agenesis/hypoplasia） | 子宮缺如或極小 |
| **Class II** | 單角子宫（Unicornuate uterus） | 一側 Müllerian duct 發育不全 |
| **Class III** | 雙角子宫（Bicornuate uterus） | 子宮底部凹陷 >1 cm |
| **Class IV** | 隔膜子宫（Septate uterus） | 子宮內有縱隔，由纖維或肌肉組成 |
| **Class V** | 雙子宫（Didelphys uterus） | 雙側 Müllerian duct 完全未融合 |

**臨床意義**：
- **生育影響**：隔膜子宫（Class IV）流產率最高，可考慮手術切除縱隔（metroplasty）
- **雙角子宫（Class III）**：孕期流產率升高，但手術修復仍有爭議

## 2. 陰道隔膜（Vaginal Septum）

### 2.1 橫向陰道隔膜（Transverse Vaginal Septum）

| 項目 | 說明 |
|---|---|
| **發生率** | 約 1/30,000-1/80,000 |
| **發生位置** | 陰道上部（65%）、中部（25%）、下部（10%） |
| **病理** | 胚胎期 Müllerian duct 與泌尿生殖竇連接失敗 |
| **分類** | 完全性（無孔道）vs 不完全性（有孔道） |

**臨床表現**：
| 情況 | 症狀 |
|---|---|
| **青春期前** | 通常無症狀 |
| **青春期** | 經血滯留（hematocolpos）、週期性腹痛（無月經流出）、陰道積血、子宮內膜異位 |
| **成年後** | 性交困難、痛經、不孕 |

**診斷**：
- 身體檢查（陰道短淺或見盲端）
- 超音超（陰道近端積血）
- MRI（確認隔膜位置與厚度）

**治療**：
- **手術切除隔膜**：游離並切除隔膜組織，術後放置陰道模具（vaginal stent）防止再粘連
- **不完全性隔膜**：可先嘗試內視鏡切開

### 2.2 縱向陰道隔膜（Longitudinal Vaginal Septum）

| 項目 | 說明 |
|---|---|
| **病因** | 常與雙子宫（didelphys）或雙角子宫（bicornuate）共存 |
| **臨床表現** | 通常無症狀，可能導致性交困難或衛生棉使用不便 |
| **治療** | 無症狀者不需治療；有症狀者可手術切除隔膜 |

## 3. 處女膜異常（ Hymenal Anomalies）

### 3.1 處女膜閉鎖（Imperforate Hymen）

| 項目 | 說明 |
|---|---|
| **定義** | 處女膜完全無孔洞，月經血無法流出 |
| **發生率** | 約 1/1,000-1/10,000 女性 |
| **臨床表現** | 月經初潮時（11-15 歲）出現週期性下腹痛、無月經流出、陰道積血（hematocolpos）、腹部腫塊 |

**臨床表徵**：
| 發現 | 說明 |
|---|---|
| 藍紫色陰道膨出（blue dome cyst） | 經血積聚於陰道內 |
| 陰道積血（hematocolpos） | 陰道內充滿陳舊性血液 |
| 子宮積血（hematometra） | 血液逆流至子宫 |
| 腹痛、便秘 | 骨盆腔腫塊壓迫 |

**診斷**：
- 身體檢查（見藍紫色處女膜膨出）
- 超音超（確認陰道、子宮積血，排除其他異常）

**治療**：
- **手術切開（hymenotomy）**：十字切開或環形切除處女膜組織
- 術後：溫水坐浴、陰道擴張（防止再粘連）
- 預後良好，正常月經功能恢復

> **臨床重點** 處女膜閉鎖是少數需**緊急手術**的先天性異常之一，因為月經積血可能導致，子宮內膜異位與骨盆腔粘連。

### 3.2 處女膜過厚（ Thickened Hymen）

- 處女膜厚度 >3-4 mm，可能導致性交困難
- 治療：手術切除部分處女膜組織

### 3.3 微小孔處女膜（Microperforate Hymen）

| 項目 | 說明 |
|---|---|
| **定義** | 處女膜有極小孔洞，月經血可少量流出 |
| **臨床表現** | 經血排出不順暢、衛生棉使用困難、性交時疼痛 |
| **治療** | 手術切開或切除部分處女膜 |

## 4. 陰唇粘連（Labial Adhesions）

| 項目 | 說明 |
|---|---|
| **定義** | 小陰唇粘連融合，覆蓋陰道口與尿道口 |
| **好發年齡** | 6 個月至 6 歲（高峰 1-2 歲） |
| **發生率** | 1-2% 的女孩 |
| **病因** | 雌激素不足（嬰兒期雌激素低）、局部慢性發炎、尿布疹 |

**臨床表現**：
| 症狀 | 說明 |
|---|---|
| 無症狀 | 多數輕度粘連無症狀 |
| 排尿困難 | 尿液滯留、排尿時哭鬧 |
| 泌尿道感染 | 尿液滯留增加 UTI 風險 |
| 陰道分泌物 | 粘連下方積存分泌物 |

**治療**：

| 程度 | 治療方式 |
|---|---|
| **輕度（<5 mm 粘連）** | 觀察；局部塗抹 **estrogen cream**（每日 2 次，2-4 週）+ 輕柔分開 |
| **中度** | **皮質類固醇 cream**（betamethasone 0.05%）每日塗抹 |
| **重度或復發** | **手術分離（surgical lysis）**：局部麻醉下用止血鉗分離 |

**術後護理**：
- 局部塗抹雌激素或皮質類固醇軟膏防止再粘連
- 術後 1-2 週開始
- 每日輕柔分開陰唇清潔

## 5. 其他女性生殖器異常

### 5.1 陰唇發育不良（Labial Hypoplasia/Aplasia）

| 異常 | 說明 |
|---|---|
| **小陰唇缺如** | 先天性缺如或發育不全，通常無功能影響 |
| **大陰唇粘連** | 罕見，可手術修復 |

### 5.2 陰蒂肥大（Clitoromegaly）

| 病因 | 說明 |
|---|---|
| 先天性腎上腺增生（CAH） | 見第 161 章 |
| 胎兒期雄激素暴露 | 母體使用雄激素藥物 |
| 特發性 | 無明確病因 |

**治療**：陰蒂縮小術（clitoroplasty），通常與性別認定手術同時進行

### 5.3 泄殖腔畸形（Cloacal Malformation）

| 項目 | 說明 |
|---|---|
| **定義** | 陰道、尿道、肛門共同開口於一個竇道 |
| **臨床表現** | 單一會陰開口、糞便與尿液混合排出 |
| **治療** | 多期手術重建：泄殖腔切開 → 泌尿生殖道分離 → 肛門重建 |

---

## 重點摘要

- **MRKH 綜合徵**：先天性陰道發育不全，46,XX，正常卵巢功能，原發性閉經；治療以陰道擴張為主
- **陰道橫隔膜**：經血滯留、週期性腹痛，手術切除治療
- **處女膜閉鎖**：月經初潮時緊急手術（hymenotomy）
- **陰唇粘連**：小女孩常見，estrogen cream 或手術分離
- **泄殖腔畸形**：複雜多期手術重建
