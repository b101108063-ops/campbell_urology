# 150 性發育障礙

📖 **導讀**：性發育障礙（DSD）涵蓋一大類先天性染色體、性腺及解剖性別發育異常的疾病，其診斷和治疗涉及多專科團隊合作。本章節系統性介紹DSD的病因學、評估流程及內科管理原則，涵蓋從基因調控到臨床表型的完整譜系，強調精確診斷對指導治療決策的重要性。

## 定義與分類

### 2006年芝加哥共識分類

| 分類 | 定義 | 範例 |
|---|---|---|
| **47,XXY** | 性染色體DSD | 克氏症候群（Klinefelter syndrome） |
| **46,XY** | 46,XY DSD |  partial gonadal dysgenesis |
| **46,XX** | 46,XX DSD | 卵巢過早發育不全 |
| **卵睪型DSD（Ovotesticular DSD）** | 同時存在卵巢及睪丸組織 | - |
| **46,XX男性（XX male）** | 具男性表型但染色體為46,XX | SRY基因易位 |

## 遺傳學基礎

### 性別決定的關鍵基因

| 基因 | 功能 | 臨床意義 |
|---|---|---|
| **SRY** | 睪丸決定因子（TDF），啟動SOX9表達 | 突變導致XY性逆轉；SRY存在於大多數XX男性中 |
| **SOX9** | 維持Sertoli細胞分化 | 突變導致骨骼發育不良及性逆轉 |
| **WT1** | 腎臟及性腺發育 | 突變導致WAGR、Denys-Drash、Frasier症候群 |
| **NR5A1（SF1）** | 性腺及腎上腺發育 | 突變導致性腺發育不全及腎上腺功能不全 |
| **NR0B1（DAX1）** | 反向調控SOX9 | 劑量效應導致XY性逆轉 |
| **WNT4** | 卵巢發育途徑 | 突變導致XX性逆轉及掌蹠角化過度 |
| **RSPO1** | 卵巢發育途徑 | 突變導致XX性逆轉及掌蹠角化過度 |
| **FOXL2** | 顆粒細胞發育 | 突變導致 blepharophimosis-ptosis-epicanthus inversus症候群 |

> **臨床重點**：性別決定是一個複雜的基因調控網絡，涉及**SRY-SOX9軸**的活化（睪丸發育）與**DAX1/WNT4/β-catenin**途徑的抑制（卵巢發育）。任何影響這些途徑的基因突變都可能導致DSD。

### SRY的作用機制

1. SRY蛋白為**轉錄因子**，通过與DNA結合並彎曲DNA結構
2. SRY作用於**原始性腺ridge的支持細胞（supporting cells）**
3. 這些細胞最終分化为**Sertoli細胞**並形成睪丸索（testicular cords）
4. 已發現超過**50種SRY突變**與XY女性（XY female）相關，多數位於DNA結合區（高移動性組[HMG]盒結構域）

> **臨床重點**：SRY是大多數**46,XX男性**的致病原因。這些患者通常攜帶含有SRY的Y染色體片段，證實了SRY在睪丸發育中的核心角色。

## 染色體性別的評估

### 關鍵遺傳學要點

| 發現 | 臨床意義 |
|---|---|
| **SRY的發現**（Sinclair等，1990） | 首次定位人類TDF，為單拷貝雄性特異性序列 |
| **SRY突變** | 超過50種突變與XY性逆轉相關 |
| **XX男性中SRY** | 大多數XX男性攜帶Y染色體片段（含SRY） |

## 性腺發育

### 原始生殖細胞（PGCs）的遷移

| 發育階段 | 時間 | 事件 |
|---|---|---|
| PGCs起源 | 第3週 | 出現在卵黃囊後壁 |
| 遷移開始 | 第5週 | 沿卵黃囊壁遷移至性腺ridge |
| 到達性腺 | 第6週 | 1000-2000個PGCs抵達性腺芽（gonadal blastema） |

### 睪丸與卵巢的分化

| 結構 | 睪丸發育 | 卵巢發育 |
|---|---|---|
| **性腺索** | 睪丸索形成（6-7週），Sertoli細胞分化 | 卵巢索形成 |
| **Germ cells** | 分化為精原細胞（gonocytes） | 分化為卵母細胞（oogonia） |
| **間質細胞** | 萊氏細胞分化（8-9週） | 卵泡膜細胞（theca cells）分化 |
| **激素分泌** | MIS + 睪固酮 | 雌激素 |

> **臨床重點**：在妊娠**前6週**，性腺ridge、生殖細胞、內部管道及外部生殖器在**46,XY和46,XX胚胎中均為雙向潛能（bipotential）**。SRY的表達與功能是啟動睪丸發育途徑的關鍵開關。

## 激素與性別分化

### 抗穆勒氏管激素（MIS/AMH）

| 特性 | 說明 |
|---|---|
| **來源** | Sertoli細胞（7-8週開始分泌） |
| **化學性質** | 轉化生長因子β（TGF-β）家族成員 |
| **基因位置** |  chromosome 19 |
| **功能** | 局部作用，導致穆勒管退化 |
| **作用機制** | 可能主要作用於**間質細胞（mesenchyme）**，而非上皮細胞 |

### 睪固酮的合成與作用

| 階段 | 說明 |
|---|---|
| **開始分泌** | 妊娠約9週（萊氏細胞形成後） |
| **分泌高峰** | 13週（血清及睪丸內濃度達峰） |
| **限速酶** | 3β-羥基類固醇脫氫酶，胎兒睪丸中濃度為其他組織的50倍 |
| **作用一** | 維持沃爾夫管（Wolffian ducts），形成輸精管、副睪、儲精囊 |
| **作用二** | 經**5α-還原酶**轉化為DHT，導致外生殖器雄性化 |

> **臨床重點**：MIS是男性性分化所必需的**兩種激素之一**（另一種為睪固酮），於**妊娠7-8週**開始分泌後即開始作用。若MIS或其受體缺陷，穆勒管結構（輸卵管、子宮、上段陰道）將持續存在。

### 穆勒管與沃爾夫管的命運

| 結構 | 男性（正常） | 女性（正常） | 男性（異常） |
|---|---|---|---|
| **穆勒管** | 退化（MIS作用） | 發育為輸卵管、子宮、上段陰道 | 持續存在（MIS缺乏或阻抗） |
| **沃爾夫管** | 發育為附睪、輸精管（睪固酮作用） | 退化 | 退化不良 |

## 外部生殖器的發育

### 男性化過程

| 週數 | 發育事件 |
|---|---|
| **7-8週** | 穆勒管退化（對雄性而言） |
| **8-10週** | 泌尿生殖竇（urogenital sinus）開始分化 |
| **10週** | 生殖結節（genital tubercle）與肛褶距離增加 |
| **12-13週** | 陰莖形成，尿道皺褶從後向前融合，泌尿生殖膨隆形成陰囊 |
| **前列腺形成** | 尿道周圍由泌尿生殖竇分化 |

### 泌尿生殖竇的分化

| 結構 | 男性 | 女性 |
|---|---|---|
| **前列腺** | 由泌尿生殖竇分化 | 退化 |
| **尿道球腺** | 由泌尿生殖竇分化 | 退化 |
| **陰道下部** | 泌尿生殖竇（與穆勒管共同形成陰道） | 泌尿生殖竇 |

> **臨床重點**：外生殖器的雄性化依賴**系統性睪固酮分泌及其在局部的DHT轉化**。這解釋了為何**5α-還原酶缺乏症**患者尽管有正常睪固酮分泌，外生殖器仍呈現女性或模糊表型（因無法有效進行DHT轉化）。

## 卵巢發育與功能

### 卵巢的特點

| 特性 | 說明 |
|---|---|
| **主要功能** | 與睪丸不同，卵巢以**外分泌功能**為主（產生卵子） |
| **顆粒細胞** | 需要**兩個X染色體**才能正常分化形成保護層 |
| **Germ cells** | 在胚胎卵巢中進行旺盛的有絲分裂，於20週時達到約**2000萬個** |
| **細胞選擇** | 只有約30%的Germ cells（約200萬個）被「拯救」形成原始卵泡，其餘退化 |

### 卵巢發育的遺傳控制

- 目前尚未發現專門決定卵巢發育的基因
- 可能需要**X染色體某區域的雙拷貝**（解釋45,XO Turner症候群的卵巢發育不全）
- DSS關鍵區（Xp21）重複可能導致XY男性向女性性逆轉

> **臨床重點**：與睪丸不同，卵巢的發育似乎是被動的——在缺乏SRY及其下游途徑時，默認發育為卵巢。**45,XO Turner症候群患者**的條索狀性腺（streak gonads）正是因為缺乏X染色體劑量效應而無法維持正常卵巢發育。

## 相關基因症候群

### WT1與腎臟-性腺發育

| 症候群 | 臨床特點 | 腎臟表現 | 性腺/生殖器表現 |
|---|---|---|---|
| **Denys-Drash症候群** | WT1突變 | 威爾姆氏腫瘤（Wilms tumor）、腎衰竭 | 性腺發育不全、性腺母細胞瘤 |
| **Frasier症候群** | WT1突變（剪接位點） | 腎病症候群、腎功能衰退 | 條索狀性腺、XY性逆轉 |
| **WAGR症候群** | 11p13缺失 | 威爾姆氏腫瘤 | 泌尿生殖系統異常、性腺母細胞瘤 |

> **臨床重點**：**WT1基因突變**可同時影響腎臟及性腺發育，說明這兩個器官在胚胎發育早期的相关性。Denys-Drash和Frasier症候群代表了同一基因突變的**不同臨床表現譜系**，差異主要源於突變類型及對RNA剪接的影響。

### RSPO1與XX性逆轉

| 發現 | 說明 |
|---|---|
| **突變位置** | 義大利家族性掌蹠角化過度（PPK）與XX女性向男性性逆變共同分離 |
| **突變類型** | 單核苷酸框移突變（家族性）；缺失突變（散發性） |
| **機制** | RSPO1為WNT4/β-catenin途徑的配體，突变导致卵巢發育途徑抑制不足 |

## 評估流程

### 新生兒DSD初步評估

| 步驟 | 內容 |
|---|---|
| **1. 病史** | 家族史、母親孕期暴露、母親營養 |
| **2. 體檢** | 陰莖/陰蒂大小、尿道/陰道口位置、睪丸是否存在、腹股溝腫塊 |
| **3. 染色體分析** | 標準核型分析（至少200個分裂象） |
| **4. 超聲波** | 評估內部生殖結構（卵巢、子宮、睪丸位置） |
| **5. 激素檢測** | LH、FSH、睪固酮、DHT、AMH |
| **6. 基因檢測** | 根據臨床表現選擇性進行SRY、NR5A1、AR等基因檢測 |

> **臨床重點**：DSD的評估应遵循**從病史到基因的系統流程**，並在多專科團隊（內分泌、泌尿外科、心理團隊）的框架下進行。性別分配的决定需要综合考虑病因、解剖結構、治療效果及家庭社會因素。

### 激素刺激試驗

| 試驗 | 方法 | 結果解讀 |
|---|---|---|
| **hCG刺激試驗** | hCG注射後測量睪固酮 | 無反應提示無睪丸組織或睪丸功能嚴重受損 |
| **ACTH刺激試驗** | 測量腎上腺類固醇前驅物 | 區分腎上腺皮質功能不全的原因 |
| **GnRH刺激試驗** | 測量LH/FSH反應 | 評估下視丘-腦下垂體-性腺軸功能 |

## 內科管理原則

### 性别分配的决定因素

| 因素 | 考量 |
|---|---|
| **病因學** | 是否為單基因突變、染色體異常 |
| **解剖結構** | 內外生殖器發育程度 |
| **手術治療可能性** | 重建手術的複雜度及效果 |
| **生育潛力** | 是否有可能保留生育功能 |
| **心理社會因素** | 家庭文化背景、長期心理適應 |

### 長期追蹤

| 監測項目 | 頻率 |
|---|---|
| **生長發育** | 每3-6個月 |
| **激素功能** | 每年或根據臨床需要 |
| **腎臟功能** | 每1-2年（有WT1突變者） |
| **心理社會支持** | 持續性 |

> **臨床重點**：DSD的管理是一个**長期的、多學科的過程**，不僅限於新生兒期或兒童期的診斷和初始治療。持續的心理支持、賀爾蒙監測及適時的手術介入都是整體照護的重要組成部分。
