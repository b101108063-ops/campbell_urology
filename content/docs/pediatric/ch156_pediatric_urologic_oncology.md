# 📖 章節導讀

小兒泌尿科腫瘤雖然整體發生率低於成人，但因其獨特的病理生理學與治療考量，在臨床實務中佔有重要地位。本章節將介紹三種最常見的小兒泌尿生殖道惡性腫瘤——**Wilms tumor**、**Neuroblastoma**、以及 **Rhabdomyosarcoma**——涵蓋其流行病學、病理分類、臨床表現、分期系統與治療原則。

> **臨床重點** 小兒泌尿科腫瘤的治療強調多專科團隊合作（外科、腫瘤科、放射科、病理科），手術切除為核心，化療與放療為輔助，五年整體存活率已大幅提升至 80-90%（早期個案）。

---

## 1. Wilms Tumor（腎母細胞瘤）

**Wilms tumor**，又稱**腎母細胞瘤**，是兒童最常見的腎臟惡性腫瘤，約佔所有小兒腎臟腫瘤的 **85%**，發生率約為每百萬名兒童中 7-10 例，好發年齡為 **2-5 歲**，男女比例約略相等。

### 病理學

- 起源於腎臟胚胎性間葉細胞，属**腎胚細胞瘤**（nephroblastoma）家族
- 約 5-10% 與先天性異常相關，如 **WAGR syndrome**（Wilms tumor, Aniridia, Genitourinary anomalies, mental Retardation）、**Beckwith-Wiedemann syndrome**、**Denys-Drash syndrome**
- 最常見的組織學類型為**favorable histology**（好預後型），預後佳；**anaplastic histology**（間變型）預後較差

### 臨床表現

| 症狀/發現 | 說明 |
|---|---|
| 無痛性腹部腫塊 | 最常見，多由家長意外觸摸發現 |
| 顯微血尿（microscopic hematuria） | 約 20-30% 出現 |
| 高血壓 | 因腫瘤產生 renin，約 30-40% 血壓升高 |
| 腹痛 | 腫瘤快速生長時 |
| 發燒、體重減輕 | 晚期表現 |

### 分期系統（NWTSG / COG）

| 分期 | 描述 |
|---|---|
| Stage I | 腫瘤局限於腎臟，可完全切除（90%存活率） |
| Stage II | 腫瘤超出腎臟但可完全切除 |
| Stage III | 腫瘤殘存於腹膜內（非完全切除或有淋巴結轉移） |
| Stage IV | 遠處轉移（肺、肝、骨、腦） |
| Stage V | 雙側腎臟 Wilms tumor |

### 治療原則

- **手術治療**：根治性腎切除（radical nephrectomy）為標準
- **化學治療**：Vincristine + Actinomycin D（Stage I-II）；Stage III-IV 加用 Doxorubicin、Cyclophosphamide、Etoposide
- **放射治療**：主要用於 Stage III 或腹膜後復發
- **雙側 Wilms tumor**：強調保留腎單位的保守手術

> **臨床重點** 化療前需確認組織病理學分類；間變型（anaplastic）需要更強化的化療療程，且對放射治療反應較差。

## 2. Neuroblastoma（神經母細胞瘤）

**Neuroblastoma**起源於**交感神經系統**的胚胎性神經嵴細胞，是小兒最常見的顱外實體腫瘤，發生率約每百萬名兒童 10-12 例，好發於 **2 歲以下**，約 50% 確診時已有轉移。

### 起源與分布

- **肾上腺髓質**（50%）
- **後腹膜交感神經節**（25%）
- **縱隔**（20%）
- **頸部、交感神經鏈**（5%）

### 病理與分子標記

- 為**胚胎性腫瘤**，可自發性退化（spontaneous regression，尤其嬰兒型）
- **N-myc (MYCN) amplification**：預後不佳指標（>10 copies 為預後不良）
- **Diploid DNA content** 較 tetraploid 預後差
- 分泌 **catecholamines**，尿中 **VMA（vanillylmandelic acid）** 與 **HVA（homovanillic acid）** 升高

### 臨床表現

| 類型 | 症狀 |
|---|---|
| 局部型 | 腹部腫塊、疼痛；胸部型可能造成 Horner syndrome |
| 轉移型 | 眼眶周圍瘀青（raccoon eyes）、顱骨轉移、發燒、骨痛 |
| 嬰兒型 | 皮下結節（blueberry muffin rash）、肝臟轉移 |

### 分期（INSS）

| 分期 | 說明 |
|---|---|
| Stage 1 | 局部，可完全切除 |
| Stage 2A | 局部，無法完全切除 |
| Stage 2B | 局部，同側淋巴結轉移 |
| Stage 3 | 跨中線或有遠處淋巴結轉移 |
| Stage 4 | 遠處轉移（骨、骨髓、淋巴結等） |
| Stage 4S | 嬰兒（<1歲），侷限原發但有肝臟/皮膚/骨髓轉移（特殊預後良好組） |

### 治療原則

- **低風險組**：手術切除 alone，觀察
- **中風險組**：手術 + 化療（Cyclophosphamide + Doxorubicin + Vincristine）
- **高風險組**：大劑量化療 + 自體骨髓移植 + 13-cis-retinoic acid 維持治療
- **MIBG（metaiodobenzylguanidine）掃描**與放射性碘-131-MIBG治療可用於復發或頑固型

> **臨床重點** 嬰兒型 Stage 4S 預後極佳，多數可自發性退化，治療以支持性照護為主，強烈化療應避免。

## 3. Rhabdomyosarcoma（橫紋肌肉瘤）

**Rhabdomyosarcoma**是起源于**橫紋肌母細胞**的軟組織肉瘤，為小兒泌尿生殖道最常見的軟組織肉瘤，佔所有兒童軟組織肉瘤的 5-8%。

### 好發部位

| 部位 | 說明 |
|---|---|
| 膀胱 | 最常見泌尿系統原發部位 |
| 前列腺 | 男孩常見 |
| 陰道、子宮 | 女孩常見 |
| 睪丸旁（paratesticular） | 男孩第二常見 |
| 會陰、肛門周圍 | 晚期局部侵犯 |

### 病理亞型

| 亞型 | 預後 | 說明 |
|---|---|---|
| **Embryonal**（胚胎型） | 較好 | 最常見（60-70%），好發於泌尿生殖道，典型為息肉狀（botryoid）或硬化型（sclerosing） |
| **Alveolar**（腺泡型） | 較差 | 常見於四肢、軀幹，常有 **PAX3-FOXO1** 或 **PAX7-FOXO1** 融合基因 |
| **Pleomorphic**（多形性） | 差 | 少見，主要見於成人 |
| **Spindle cell** | 尚可 | 青少年陰囊/陰莖常見 |

### 分期（IRS Group）

| 分組 | 描述 |
|---|---|
| Group I | 完全切除，無顯微殘留 |
| Group II | 切除後有顯微殘存（IIA）或區域淋巴結轉移（IIB）或兩者（IIC） |
| Group III | 不完全切除，腫瘤殘留 >50% |
| Group IV | 確診時已有遠處轉移 |

### 治療原則

- **手術**：廣泛切除（wide excision），但泌尿生殖道者需考量器官保留
- **化學治療**（VAC 療程）：
  - **V**incristine
  - **A**ctinomycin D
  - **C**yclophosphamide
- **放射治療**：用於局部控制，特別是 Group II/III
- 膀胱/前列腺型：先化療縮小腫瘤，再進行**保留膀胱的手術**（bladder-sparing approach）

> **臨床重點** 泌尿生殖道橫紋肌肉瘤的治療目標是根治腫瘤同時保留膀胱功能。約 60-70% 患者可達到長期無病存活，腺泡型預後顯著較差。

---

## 三種腫瘤治療原則總整理

| 腫瘤 | 首選手術 | 化療藥物 | 放療角色 | 五年存活率 |
|---|---|---|---|---|
| Wilms tumor | 根治性腎切除 | Vincristine, Actinomycin D, Doxorubicin | 輔助（Stage III+） | 90%（早期） |
| Neuroblastoma | 盡量切除 | Cyclophosphamide, Doxorubicin, Cisplatin | 姑息/残留 | 50-70%（整體） |
| Rhabdomyosarcoma | 廣泛切除（盡量保留器官） | VAC regimen | 局部控制 | 60-80% |

---

## 重點摘要

- **Wilms tumor**：最常見小兒腎臟腫瘤，典型無痛性腹部腫塊，手術+化療為主
- **Neuroblastoma**：交感神經系統胚胎瘤，尿中 VMA/HVA 升高，婴儿型有自發退化可能
- **Rhabdomyosarcoma**：泌尿生殖道最常見軟組織肉瘤，胚胎型預後較好，治療強調保留器官功能
