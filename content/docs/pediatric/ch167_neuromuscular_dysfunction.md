# 📖 導讀

兒童下尿路神經肌肉障礙涵蓋一大類因神經系統疾病或損傷導致的膀胱功能障礙，臨床上稱為**神經性膀胱**（Neurogenic bladder）。這些疾病可能導致嚴重的上尿路損傷，包括**腎功能衰竭**、**膀胱輸尿管逆流**及**尿路感染**等併發症。早期診斷與積極管理對於保護腎臟功能、維持生活品質至關重要。本章節系統性介紹兒童神經性膀胱的常見病因、神經學分類、臨床評估及長期管理原則。

---

## 1. 常見病因

### 神經系統發育異常

| 病因 | 說明 | 發生率 |
|-----|------|--------|
| **脊髓發育不良**（Spina Bifida） | **最常見原因**，包括脊髓脊膜膨出 | 約 0.1-0.2% 活產 |
| 脊髓拴繫（Tethered cord） | 脊髓粘連限制移動 |
| 脊柱裂 | 各種類型的脊柱閉合不全 |

### 神經系統損傷

| 病因 | 說明 |
|-----|------|
| **脊髓損傷**（Spinal cord injury） | 創傷性或非創傷性 |
| 腦癱（Cerebral palsy） | 腦部運動功能障礙 |
| 脊髓炎 | 感染或發炎導致脊髓損傷 |

> **臨床重點**：**脊髓發育不良**（特別是**脊髓脊膜膨出**）為**兒童神經性膀胱**的**最常見原因**。約 **60-80%** 的脊髓脊膜膨出患者會出現某種程度的膀胱功能障礙。

---

## 2. 神經性膀胱的神經學分類

### 解剖學與神經生理學基礎

膀胱功能受**自主神經系統**（交感神經、副交感神經）及**體神經系統**（陰部神經）的複雜調控：

| 神經支配 | 來源 | 功能 |
|---------|------|------|
| **副交感神經** | 脊髓骶段（S2-S4） | 逼尿肌收縮 |
| **交感神經** | 胸腰段（T10-L2） | 逼尿肌放鬆 |
| **體神經** | 陰部神經（S2-S4） | 外括約肌收縮 |

### Upper Motor Neuron Lesion（上位運動神經元病變）

> **臨床重點**：**上位運動神經元病變**（病變位於**骶髓以上**）導致**痙攣性膀胱**（Spastic bladder），特徵為逼尿肌**過反射**及**逼尿肌-括約肌共濟失調**（DSD）。

#### 病理生理

| 病變位置 | 病理變化 | 臨床表現 |
|---------|---------|---------|
| 腦部 | 無法抑制膀胱收縮 | 尿急 |
| 胸腰段以上 | 交感神經抑制中斷 | 逼尿肌過反射 |
| 骶髓以上 | DSD | 排尿困難、尿急 |

#### 臨床特徵

| 症狀 | 說明 |
|-----|------|
| **尿急**（Urgency） | 突然强烈的排尿衝動 |
| **頻尿**（Frequency） | 每日排尿次數增加 |
| **急迫性尿失禁**（Urge incontinence） | 無法控制的逼尿肌收縮 |
| **排尿困難** | DSD 導致排尿阻力增加 |
| **殘餘尿增多** | 括約肌無法正確放鬆 |

#### 逼尿肌-括約肌共濟失調（Detrusor-Sphincter Dyssynergia, DSD）

| DSD 特徵 | 說明 |
|---------|------|
| 定義 | 逼尿肌收縮時，括約肌不自主收縮 |
| 發生率 | 上運動神經元病變中 30-50% |
| 危險性 | 高膀胱壓力導致上尿路損傷 |
| 後果 | 膀胱壁肥厚、膀胱憩室、逆流 |

### Lower Motor Neuron Lesion（下位運動神經元病變）

> **臨床重點**：**下位運動神經元病變**（病變位於**骶髓以下**）導致**弛緩性膀胱**（Flaccid bladder），特徵為逼尿肌**無反射**及**尿瀦留**。

#### 病理生理

| 病變位置 | 病理變化 | 臨床表現 |
|---------|---------|---------|
| 骶髓（S2-S4） | 逼尿肌失去神經支配 | 逼尿肌無反射 |
| 骨盆神經 | 神經傳導中斷 | 膀胱容量增大 |
| 括約肌 | 失去神經支配 | 括約肌張力降低 |

#### 臨床特徵

| 症狀 | 說明 |
|-----|------|
| **尿瀦留**（Urinary retention） | 無法有效排空膀胱 |
| **溢出性尿失禁**（Overflow incontinence） | 膀胱過度充盈後漏尿 |
| **大量殘餘尿** | 可達數百毫升 |
| **排尿無力** | 尿流微弱或間斷 |
| **感覺減退** | 膀胱膨脹感消失 |

## 3. 併發症

> **臨床重點**：**神經性膀胱**若未適當治療，可能導致**上尿路不可逆損傷**。其中**尿路感染**、**膀胱輸尿管逆流**及**腎功能損傷**是最重要且常見的併發症。

| 併發症 | 發生率 | 臨床意義 |
|--------|--------|---------|
| **尿路感染**（UTI） | 60-80% | 反覆感染、發燒、腎臟疤痕 |
| **膀胱輸尿管逆流**（VUR） | 30-50% | 腎臟疤痕、高血壓 |
| **腎功能損傷** | 20-30% | 慢性腎病、腎衰竭 |
| **尿路結石** | 10-20% | 疼痛、感染阻塞 |

### 感染與逆流的惡性循環

```
神經性膀胱 → 高壓膀胱 → 膀胱輸尿管逆流 → 腎臟疤痕 → 腎功能減退
     ↓
  尿瀦留 → 尿路感染 → 結石形成 → 阻塞
```

## 4. 臨床評估

### 基本評估

| 評估項目 | 臨床意義 |
|---------|---------|
| 詳細病史 | 神經系統疾病史、症狀持續時間 |
| 理學檢查 | 會陰部感覺、肛門張力、陰莖/陰蒂功能 |
| 尿液檢查 | 排除感染、評估腎功能 |
| 超音波 | 膀胱壁厚度、腎臟形態、残餘尿量 |

### 進階檢查

| 檢查項目 | 適應症 |
|---------|---------|
| **尿路動力學檢查** | 確診神經性膀胱類型 |
| **尿道膀胱鏡檢查** | 評估膀胱頸功能 |
| **核醫腎功能掃描** | 評估分腎功能 |
| **排泄性膀胱尿道造影**（VCUG） | 評估逆流程度 |

> **臨床重點**：**尿路動力學檢查**為評估**神經性膀胱**的**金標準**，可確定：
> 1. 膀胱容量與順應性
> 2. 逼尿肌功能（反射或無反射）
> 3. 括約肌功能（協調或DSD）
> 4. 膀胱出口阻力

## 5. 管理原則

### 核心原則：上尿路保護

> **臨床重點**：**上尿路保護**是**神經性膀胱管理**的**最重要目標**。維持**低儲尿壓**（< **40 cmH2O**）是預防腎臟損傷的關鍵。

| 目標 | 數值 | 臨床意義 |
|-----|------|---------|
| 儲尿壓 | < 40 cmH2O | 避免上尿路損傷 |
| 殘餘尿 | < 50 ml（或 < 10% 容量） | 避免尿瀦留 |
| 尿流壓 | < 60 cmH2O | 避免出口阻力過高 |

### Clean Intermittent Catheterization（CIC）

> **臨床重點**：**Clean Intermittent Catheterization（CIC）**為管理**神經性膀胱**的**基石**，適用於**弛緩性膀胱**、**高殘餘尿**及**DSD**患者。

| CIC 特性 | 說明 |
|---------|------|
| 原理 | 定期導尿排空膀胱 |
| 頻率 | 每 3-4 小時一次 |
| 目的 | 維持低膀胱壓力、減少殘餘尿 |
| 併發症 | 感染（可減少）、創傷 |
| 生活品質 | 多數患者可正常生活 |

**CIC 執行原則**：
1. 導尿前洗手，使用清潔技術
2. 選擇適當尺寸的導尿管
3. 記錄每次導尿量
4. 定期追蹤尿培養

### 藥物治療

#### 抗膽鹼藥物（Anticholinergics）

> **臨床重點**：**抗膽鹼藥物**用於治療**膀胱過反射**，降低逼尿肌不自主收縮的頻率和強度。

| 藥物名稱 | 劑量 | 副作用 |
|---------|------|--------|
| **Oxybutynin** | 0.1-0.2 mg/kg，每日2-3次 | 口乾（30%）、便秘（10%）、嗜睡 |
| **Solifenacin** | 5-10 mg，每日一次 | 口乾、便秘 |
| **Tolterodine** | 1-2 mg，每日2次 | 口乾、頭痛 |

| Oxybutynin 使用注意 | 說明 |
|-------------------|------|
| 起始劑量 | 2.5 mg，每日2次 |
| 調整方式 | 每週調整 |
| 最大劑量 | 5 mg，每日3次 |
| 監測 | 定期評估膀胱超音渡變化 |

### 定期追蹤

| 追蹤項目 | 頻率 | 臨床意義 |
|---------|------|---------|
| **腎功能檢查**（Cr, BUN） | 每 3-6 個月 | 監測腎臟功能 |
| **腎臟超音渡** | 每 6-12 個月 | 評估腎臟形態、水腎 |
| **尿路動力學檢查** | 每 1-2 年 | 評估膀胱功能變化 |
| **尿培養** | 發燒或症狀時 | 早期發現感染 |

---

## 6. 手術治療選項

| 手術方式 | 適應症 | 目的 |
|---------|--------|------|
| **膀胱擴大術**（Augmentation cystoplasty） | 低順應性膀胱、高壓膀胱 | 增加容量、降低壓力 |
| **尿道懸吊術** | 括約肌功能不全 | 預防漏尿 |
| **人工括約肌植入** | 括約肌嚴重功能不全 | 恢復禁尿功能 |
| **可控性尿路改道** | 無法自行排尿且CIC失敗 | 建立排尿通道 |

---

## 總結

| 主題 | 關鍵要點 |
|-----|---------|
| **常見病因** | **脊髓發育不良**（spina bifida）最常見 |
| **上位運動神經元病變** | **痙攣性膀胱**，逼尿肌過反射、**DSD** |
| **下位運動神經元病變** | **弛緩性膀胱**，逼尿肌無反射、尿瀦留 |
| **併發症** | **尿路感染**、**膀胱輸尿管逆流**、**腎功能損傷**、**尿路結石** |
| **管理基石** | **Clean Intermittent Catheterization（CIC）** + 抗膽鹼藥物 |
| **核心目標** | **上尿路保護**，維持低儲尿壓（< 40 cmH2O） |
