# 📖 章節導讀

男性外生殖器異常是小兒泌尿科最常見的手術性疾病之一。本章節系統介紹**尿道下裂（Hypospadias）**、**陰莖彎曲（Chordee）**、**包莖（Phimosis）**與**嵌頓包莖（Paraphimosis）**的病理機轉、分類、臨床表徵與治療原則。

> **臨床重點** 男性外生殖器異常的手術時機通常在**6-18 個月大**之間，此時陰莖大小足以進行手術，且患者對手術記憶較少、康復较快。手術前需確認性別分化正常（46,XY），必要時進行染色體或內分泌評估。

---

## 1. 尿道下裂（Hypospadias）

### 定義

**尿道下裂**是指尿道口開口於陰莖腹側正常位置以下的先天性異常，常伴隨**包皮過多（hooded foreskin）**與**陰莖彎曲（Chordee）**。

### 發生率與流行病學

| 項目 | 數值 |
|---|---|
| 發生率 | 約 1/300 男孩 |
| 好發種族 | 白種人 > 黑人 > 亞洲人 |
| 危險因子 | 低出生體重、早產、妊娠糖尿病、試管嬰兒（IVF）|

### 病理機轉

- 胚胎期**泌尿生殖溝（urogenital groove）**閉合失敗
- 雄激素（Testosterone）作用不足或時機異常
- 組織纖維化導致陰莖腹側彎曲

### 分類（依尿道口位置）

| 分類 | 尿道口位置 | 發生率 | 手術難度 |
|---|---|---|---|
| **冠狀溝型（Glandular/Coronal）** | 冠狀溝邊緣 | 50-55% | 低 |
| **冠狀溝下型（Subcoronal）** | 冠狀溝以下陰莖背側 | 20-25% | 低 |
| **陰莖型（Penile）** | 陰莖體部 | 15-20% | 中 |
| **陰莖陰囊型（Penoscrotal）** | 陰莖與陰囊交界 | 5-10% | 高 |
| **會陰型（Perineal）** | 會陰部 | 3-5% | 最高 |

### 臨床表現

| 發現 | 說明 |
|---|---|
| 尿道口位置異常 | 開口於陰莖腹側或會陰部 |
| 包皮分佈異常 | 包皮僅覆蓋陰莖背側，腹側缺如 |
| 陰莖彎曲（Chordee）** | 陰莖腹側纖維組織束帶，勃起時彎曲更明顯 |
| 排尿方向異常 | 尿流方向不向前，易弄濕褲子 |

### 手術時機

| 建議年齡 | 說明 |
|---|---|
| **6-12 個月** | 多數專家建議的手術窗口 |
| **12-18 個月** | 仍屬理想，可在此期間安排 |
| **>18 個月** | 可進行但需注意心理影響 |

### 手術技術

| 技術名稱 | 說明 |
|---|---|
| **TIP（Tubularized Incised Plate）尿道重建術** | 將尿道板切開後包繞成管；為**遠端型尿道下裂（distal hypospadias）**首選 |
| **Mathieu 手術（Flip-flap）** | 龜頭瓣膜翻轉修補；用於輕度遠端型 |
| **Duckett 手術（Transverse preputial island flap）** | 使用包皮瓣游離移植；用於**近端型（proximal hypospadias）** |
| **Staged repair** | 兩期手術；第一期矫正陰莖彎曲 + 尿道重建；第二期龜頭整型 |

**TIP 手術步驟**：
1. 置入導尿管
2. 環形切開包皮，游離龜頭板
3. 切開尿道板中央（深達白膜）
4. 將尿道板包繞導尿管縫合成管
5. 游離包皮並覆蓋新尿道
6. 龜頭整型（glanuloplasty）

> **臨床重點** 成功的手術需要：無張力尿道重建、筆直陰莖、新尿道與陰莖軸線一致、對稱的包皮覆蓋。術後需放置導尿管引流 5-7 天。

### 術後併發症

| 併發症 | 說明 |
|---|---|
| **尿瘻（Urethrocutaneous fistula）** | 最常見（5-15%）；尿道癒合不良導致尿液從新尿道滲出 |
| **尿道狹窄（Urethral stricture）** | 新尿道口或吻合口狹窄 |
| **尿道囊腫/憩室（Diverticulum）** | 尿道壁薄弱突出 |
| **復發性陰莖彎曲** | 彎曲矫正不完全 |
| **龜頭外觀不佳** | 切口癒合疤痕 |

## 2. 陰莖彎曲（Chordee）

### 定義

**陰莖彎曲**是指陰莖海綿體白膜腹側（偶爾為背側）出現**纖維組織帶**，導致陰莖在勃起時向腹側或背側彎曲。

### 與尿道下裂的關係

| 關係 | 說明 |
|---|---|
| **伴隨尿道下裂** | 約 50% 的尿道下裂患者有輕度以上的陰莖彎曲 |
| **不伴隨尿道下裂** | 單純型陰莖彎曲稱為**先天性陰莖彎曲（Congenital penile curvature）** |

### 臨床表現

| 發現 | 說明 |
|---|---|
| 陰莖勃起時彎曲 | 彎曲角度 >15-20 度具有臨床意義 |
| 腹側纖維組織束帶 | 觸診可摸到堅硬纖維帶 |
| 排尿功能通常正常 | 單純型陰莖彎曲排尿不受影響 |

### 治療

| 彎曲程度 | 治療方式 |
|---|---|
| **輕度（<30 度）** | 觀察；僅物理矫正或不需要治療 |
| **中度至重度（>30 度）** | 手術矫正：切除腹側纖維組織 + 陰莖筆直化（straightening） |

**手術方式**：
- **Nesbit 手術**：背側橢圓形切除白膜 + 褶疊縫合（plication）
- **陰莖彎曲矫正術**：游離并切除腹側纖維組織帶，同時進行白膜延長或縮短

## 3. 包莖（Phimosis）

### 定義

**包莖**是指包皮無法完全推開露出龜頭的狀態，可分為**生理性**與**病理性**。

### 生理性 vs 病理性包莖

| 類型 | 說明 |
|---|---|
| **生理性包莖** | 所有新生男嬰皆有；包皮與龜頭自然粘連，隨年齡逐漸分離；正常現象 |
| **病理性包莖（Pathologic phimosis）** | 包皮疤痕化、纖維化、無法推開；因慢性發炎、外傷、導尿管刺激 |

### 臨床評估（Brown 評分）

| 分數 | 包皮可推開程度 |
|---|---|
| 0 | 完全無法推開 |
| 1 | 僅能看到尿道口 |
| 2 | 露出部分龜頭 |
| 3 | 完全露出龜頭但有勒緊帶 |
| 4 | 完全露出龜頭，無勒緊 |

### 治療原則

| 程度/情況 | 治療方式 |
|---|---|
| **生理性包莖（0-3 分）** | 觀察至 5-6 歲；每日溫水浸泡 + 輕柔推開 |
| **病理性包莖（0-2 分）** | **皮質類固醇軟膏**（0.05-0.1% betamethasone）塗抹，每日 2 次，4-6 週；70-80% 有效 |
| **保守治療失敗** | **包皮環切術（Circumcision）** 或 **包莖整形術（Preputioplasty）** |

### 包莖整形術（Preputioplasty）

| 項目 | 說明 |
|---|---|
| **原理** | 在包皮狹窄處做縱切横縫，擴大包皮口，同時保留包皮 |
| **優點** | 保留包皮完整性，符合美學與宗教文化需求 |
| **適應症** | 輕至中度包莖 |
| **成功率** | >90% |

> **臨床重點** 不建議強制推開包皮進行「強力復位」，可能導致包皮撕裂、出血與疤痕形成，反而加重包莖。

## 4. 嵌頓包莖（Paraphimosis）

### 定義

**嵌頓包莖**是指包皮被推開後，**無法復位（reduce）**回覆蓋龜頭，導致包皮勒緊在龜頭冠狀溝近端，造成陰莖水腫、靜脈回流受阻，若不及時處理可能導致組織壞死。

### 病因

| 原因 | 說明 |
|---|---|
| 醫療處置後未復位 | 導尿、膀胱鏡、陰莖檢查後忘記復位 |
| 自慰或性行為 | 推開包皮後未即時復位 |
| 包皮環切術後 | 術後水腫 |

### 臨床表現

| 發現 | 說明 |
|---|---|
| 包皮勒緊在冠狀溝近端 | 明顯可見勒痕 |
| 陰莖頭水腫 | 龜頭變色（暗紅或紫） |
| 疼痛 | 程度依嵌頓時間 |
| 靜脈回流受阻 | 嚴重時龜頭蒼白，提示組織缺血 |

### 治療

| 方法 | 步驟 |
|---|---|
| **緊急復位（Manual reduction）** | 兩拇指放在龜頭上，兩手食指、中指放在勒緊包皮近端，持續加壓同時將包皮往下推；若水腫嚴重，用兩手拇指按壓龜頭使水腫液推向冠狀溝遠端，減少體積後復位 |
| **復位失敗或延遲就醫** | **背側切開（dorsal slit）**：在勒緊處背側切開鬆解張力；待水腫消退後再行**包皮環切術** |

**復位後處置**：
- 口服抗生素預防感染
- 陰莖加壓包紮減少水腫
- 避免再次推開包皮 48-72 小時

## 5. 其他男性外生殖器異常

### 5.1 陰莖發育不全（Micropenis）

| 項目 | 說明 |
|---|---|
| **定義** | 陰莖長度 <2.5 個標準差，低於同年齡平均值 |
| **病因** | 內分泌異常（睾固酮不足）、性腺發育不全、染色體異常 |
| **治療** | 早期（前 3 個月）補充**睾固酮**（每月注射 25 mg testosterone enanthate，共 3 個月）|

### 5.2 陰莖缺如（Aphallia）

| 項目 | 說明 |
|---|---|
| **定義** | 陰莖完全缺如，罕見（發生率 1/10,000,000） |
| **治療** | 性別重置手術（性別認定為女性）+ 陰道重建；或陰莖重建手術 |

### 5.3 先天性陰莖扭轉（Congenital Penile Torsion）

| 項目 | 說明 |
|---|---|
| **定義** | 陰莖沿軸線異常扭轉（通常向左）|
| **治療** | 輕度可觀察；>30 度扭轉需手術矫正（detorsion + 固定）|

---

## 重點摘要

- **尿道下裂**：尿道口位於陰莖腹側；分類（遠端/近端）；**TIP 手術**為遠端型首選
- **陰莖彎曲**：常伴隨尿道下裂；>30 度需手術矫正（Nesbit 手術）
- **包莖**：生理性可觀察至 5-6 歲；病理性用皮質類固醇軟膏或手術
- **嵌頓包莖**：緊急復位；失敗則背側切開
- **手術時機**：6-18 個月大為理想窗口
