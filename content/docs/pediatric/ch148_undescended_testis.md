# 148 隱睪症

📖 **導讀**：隱睪症是男嬰最常見的先天性泌尿生殖系統疾病之一，其病因涉及複雜的胚胎發育過程，特別是**睪丸引帶（gubernaculum）**的發育及**胰島素樣因子3（INSL3）**和**睪固酮**的調控。本章節涵蓋隱睪症的病因學、診斷、自然病程及治療原則，強調早期診治對保護生育能力的重要性。

## 胚胎學與病因學

### 睪丸發育的關鍵調控基因

| 基因 | 功能 |
|---|---|
| **SRY**（性別決定區Y基因） | 觸發睪丸發育，活化SOX9表達 |
| **SOX9** | 維持 Sertoli 細胞分化 |
| **NR5A1（SF1）** | 協助SRY作用，促進性腺發育 |
| **AMH**（抗穆勒氏管激素） | 由Sertoli細胞分泌，導致穆勒管退化 |
| **FGF9** | 促進Sertoli細胞增殖 |

### 睪丸激素分泌

**萊氏細胞（Leydig cells）**的發育可分為三個階段：
1. **增殖分化期**：妊娠7-14週
2. **成熟期**：至18週
3. **退化期**：24週後至分娩

| 激素 | 來源 | 功能 |
|---|---|---|
| **睪固酮（Testosterone）** | 萊氏細胞 | 維持沃爾夫管、促進外生殖器雄性化 |
| **INSL3** | 萊氏細胞 | 調控睪丸引帶發育，負責**引帶階段（cranial ligament phase）**的睪丸下降 |
| **hCG** | 胎盤 | 刺激14-16週雄激素分泌高峰 |
| **AMH** | Sertoli細胞 | 導致穆勒管退化 |

> **臨床重點**：**INSL3和睪固酮**是睪丸下降的兩大關鍵激素。動物實驗顯示，Insl3、Rxrpf2或雄激素受體（AR）基因缺陷會導致隱睪症，人類研究亦證實雄激素合成或作用異常與隱睪症相關。

## 睪丸下降的解剖學過程

### 下降階段

| 階段 | 時間 | 事件 |
|---|---|---|
| **引帶階段** | 妊娠10-15週 | INSL3主導，gubernaculum增厚縮短 |
| **腹股溝管通過階段** | 妊娠15-25週 | 睪丸通過腹股溝管 |
| **陰囊固定階段** | 25週後 | 睪丸進入陰囊，引帶退化 |

### 重要解剖結構

**Gubernaculum（睪丸引帶）**：
- 人類胎兒中，引帶在通過腹股溝管後**遠端游離**
- 陰囊由生殖皺褶在**二氫睪固酮（DHT）**作用下發育形成
- 提睪肌（cremaster muscle）的神經肌肉調控對睪丸下降有重要作用

> **臨床重點**：大多數人類胎兒睪丸在**妊娠27週後**才完全進入陰囊，在27週前睪丸仍可位於腹股溝管內。這解釋了為何早產兒隱睪症的發生率較足月兒高。

## 診斷

### 體檢要點

| 睪丸位置 | 描述 |
|---|---|
| **腹部睪丸** | 位於腹腔內 |
| **腹股溝管內睪丸** | 可在腹股溝觸及但無法推至陰囊 |
| **高腹股溝睪丸** | 位於外環附近 |
| **陰囊上睪丸** | 可部分推入陰囊但迅速回縮 |
| **可回縮睪丸（retractile）** | 可順利推入陰囊並停留， 並非真正的隱睪症 |

> **臨床重點**：**可回縮睪丸**不同於真正隱睪症，其特點是檢查時可被手法推送至陰囊底並維持，可能是提睪肌反射活躍所致，不需要手術治療。

### 輔助檢查

| 檢查 | 適應症 |
|---|---|
| 超聲波 | 觸診無法確定的病例，評估睪丸位置及大小 |
| 腹腔鏡 | 高度懷疑腹部睪丸，或需要明確診斷 |
| 激素檢測 | 考慮無睪症（anorchia）時，檢測hCG刺激後睪固酮反應 |

## 自然病程

### 自發性下降

| 研究 | 自發下降率（至3個月大） |
|---|---|
| 多項前瞻性研究 | **50-87%** |
| 丹麥vs芬蘭研究 | 68% vs 45% |
| 高位腹股溝睪丸 | 50%（至1歲） |
| 高位陰囊睪丸 | 87.5%（至1歲） |

> **臨床重點**：出生時診斷的隱睪症中，**50-87%在3個月大前可自發下降**。因此，建議在出生後6個月大前完成確診評估，手術治療則通常在6-12個月大時進行。

### 再次上升（Reascent）

- 發生率：約 **10-22%**
- 好發時間：1-5歲之間

### 獲得性隱睪症

**定義**：出生時睪丸位置正常，後續因睪丸與附睪分離（testis-epididymis dissociation）或陰囊發育異常而出現睪丸上升。

## 治療

### 手術時機

| 建議 | 理由 |
|---|---|
| **6-12個月大** | 此時睪丸已無自發下降可能，手術並發症風險最低 |
| **不宜晚於18-24個月大** | 避免對睪丸生精功能造成不可逆損傷 |

> **臨床重點**：延遲治療會增加**睪丸組織學損傷**的風險，包括精原細胞（spermatogonia）減少及間質纖維化。建議在**嬰兒6-12個月大**之間安排手術，最遲不應超過**24個月大**。

### 手術方式

| 睪丸位置 | 手術方式 |
|---|---|
| 腹股溝可觸及 | **睪丸固定術（orchiopexy）** - 腹股溝切口，游離精索，將睪丸固定於陰囊內 |
| 腹腔內 | **腹腔鏡睪丸固定術（Fowler-Stevens腹腔鏡）** 或分期手術 |
| 觸診無法發現 | 腹腔鏡探查確診後決定 |

### 手術原則

1. **充分游離精索**，確保無張力降至陰囊
2. **保留睪丸血供**，避免損傷精索血管
3. **保護輸精管（vas deferens）**
4. 同期處理**腹股溝疝氣（indirect inguinal hernia）**若存在

> **臨床重點**：隱睪症手術的核心原則是**在無張力情況下將睪丸固定於陰囊內**。術中需充分游離精索，但應避免過度電燒或分離，以免影響睪丸血供。

## 生育能力考量

### 組織病理學變化

隱睪症睪丸的組織病理學發現：
- **精原細胞減少或缺失**
- **間質纖維化**
- **萊氏細胞減少**
- 這些變化**隨年齡增長而加重**

### 治療目標

- 早期手術（6-12個月大）可**減緩或預防**這些病理變化
- 但即使早期手術，部分患者仍可能面臨**生精功能受損**

> **臨床重點**：隱睪症的治療目標不僅是將睪丸降至陰囊，更重要的是**保護睪丸的生育能力**。手術時機越晚，睪丸組織的不可逆損傷越嚴重。
