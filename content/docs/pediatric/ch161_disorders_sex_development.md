# 📖 章節導讀

**性發育障礙（Disorders of Sex Development, DSD）** 涵蓋染色體、性腺或解剖性別發育之先天性異常，是小兒泌尿科、內分泌科與遺傳醫學的重要交領域。本章節介紹 DSD 的分類、發病機轉、診斷流程、性別認定考量與治療原則，強調多專科團隊（Multi-disciplinary Team, MDT）合作的重要性。

> **臨床重點** DSD 的診斷與性別認定（gender assignment）需要高度敏感的溝通技巧與完整的家族遺傳諮詢。任何決策都應以**患者最佳利益**為核心，避免標籤化與污名化，給予家庭充分的資訊與時間。

---

## 1. 定義與分類

### DSD 統一定義（共識 2006，Chicago）

| 傳統名稱 | DSD 分類 |
|---|---|
| 雌雄同體（Hermaphroditism） | **46,XX DSD**、**46,XY DSD**、**性腺發育異常** |
| 偽雌雄同體（Pseudohermaphroditism） | 併入上述分類 |
| 性腺發育不全（Gonadal dysgenesis） | **性腺發育異常** |

### 三大分類

#### 1.1 46,XX DSD（原本為女性，具有男性化表型）

| 病因 | 說明 |
|---|---|
| **先天性腎上腺增生（Congenital Adrenal Hyperplasia, CAH）** | 最常見原因（90%），**21-hydroxylase deficiency** 最常見，皮質醇與醛固酮不足，腎上腺雄激素過量 |
| 胎兒期母體雄激素暴露 | 母體使用雄激素藥物、卵巢/腎上腺腫瘤 |
| 胎兒甲狀腺功能減退 | 罕見 |

**21-hydroxylase deficiency CAH** 特點：
- 皮質醇缺乏 → 腎上腺危象（adrenal crisis）、鈉流失
- 醛固酮缺乏 → 低鈉高鉀
- 雄激素過量 → 女性胎兒外生殖器男性化（陰蒂肥大、陰唇融合）

#### 1.2 46,XY DSD（原本為男性，具有男性化不足表型）

| 病因 | 說明 |
|---|---|
| **5-alpha Reductase deficiency** | 無法將睾酮轉化為雙氫睾酮（DHT），外生殖器呈女性或曖昧 |
| **Partial Androgen Insensitivity Syndrome (PAIS)** | 雄激素受體功能部分減退，外生殖器曖昧 |
| **Complete Androgen Insensitivity Syndrome (CAIS)** | 雄激素受體完全不作用，外觀為女性，但無月經 |
| **Leydig cell hypoplasia** | 睾酮製造缺陷 |
| **性腺發育異常（Gonadal dysgenesis）** | 睪丸發育不全 |

**CAIS 臨床特徵**：
- 染色體：46,XY
- 外觀：女性表型
- 無月經（原發性閉經）
- 乳房發育正常（睾酮經芳香酶轉化為雌激素）
- 無腋毛、陰毛稀疏
- 陰道短淺或缺如
- 睪丸位於腹股溝或腹腔（性腺活檢確認）

#### 1.3 性腺發育異常（Gonadal Dysgenesis）

| 類型 | 說明 |
|---|---|
| **Complete Gonadal Dysgenesis (Swyer syndrome)** | 46,XY，性腺為條索狀（streak gonads），表型為女性，子宮與輸卵管的發生需要 Y 染色體部分基因（如 SRY） |
| **Mixed Gonadal Dysgenesis (MGD)** | 一側為條索狀性腺，另一側為睪丸（或卵睪）；常見鑲嵌型核型如 45,X/46,XY |
| **Partial Gonadal Dysgenesis** | 性腺功能部分保留，外生殖器程度不一的曖昧 |
| **True Hermaphroditism（卵睪性別不分）** | 同時具有卵巢與睪丸組織（約 60% 為 46,XX，30% 為 46,XX/46,XY 鑲嵌型） |

## 2. 診斷流程

### 2.1 初步評估

| 評估項目 | 目的 |
|---|---|
| **詳細病史** | 家族史、死產史、新生兒死亡、母親藥物暴露 |
| **身體檢查** | 外生殖器評分（Quigley score）、性腺是否可觸及、有無子宫 |
| **染色體分析（Karyotype）** | 確認染色體性別（30 個細胞分析） |
| **SRY 基因檢測** | 確認 Y 染色體性決定區 |

### 2.2 內分泌評估

| 檢查 | 說明 |
|---|---|
| **17-hydroxyprogesterone (17-OHP)** | CAH 篩檢（21-hydroxylase缺乏） |
| **Androstenedione、DHEA、睾酮、DHT** | 雄激素合成路徑評估 |
| **AMH（Anti-Müllerian Hormone）** | 評估性腺功能；CAIS 時升高 |
| **LH、FSH** | 性腺功能評估；CAIS 時升高 |
| **hCG 刺激試驗** | 評估睪丸間質細胞（Leydig cell）功能 |

### 2.3 影像學檢查

| 檢查 | 說明 |
|---|---|
| **骨盆腔超音超** | 評估子宫、卵巢/睪丸結構 |
| **MRI** | 更精確評估性腺位置（腹腔內、盆腔） |
| **泌尿系統超音超** | 評估腎臟結構（CAH、Denys-Drash 綜合徵常合併腎臟病變） |

### 2.4 性腺活檢

- 染色體分析無法確診時，可考慮**腹腔鏡性腺活檢**
- 目的：確認性腺組織類型（卵巢、睪丸、或卵睪）
- 注意：**性腺切片可能增加腫瘤（性腺母細胞瘤）風險**，需審慎評估

## 3. 性別認定（Gender Assignment）

### 原則

| 原則 | 說明 |
|---|---|
| **以患者最大利益為中心** | 考慮生活質量、心理健康、身體功能 |
| **避免標籤化** | 不使用貶義詞，尊重家庭文化與價值觀 |
| **透明溝通** | 與家庭充分分享資訊，共同參與決策 |
| **延遲非緊急手術** | 除非有醫療必要，否則等患者夠大能表達意願 |
| **長期心理支持** | 遺傳諮詢、心理評估與支持 |

### 各類 DSD 的性別認定建議（現行指南）

| 診斷 | 建議 | 說明 |
|---|---|---|
| **CAIS（完全型）** | 女性 | 建議女性養育，外觀女性，青春期乳房發育正常 |
| **PAIS（部分型，帶男性化表型）** | 男性（多數） | 外生殖器男性化程度高時，建議男性；需早期手術干預 |
| **5-alpha reductase deficiency** | 男性（多數） | 許多患者成年後轉變為男性性別identity |
| **MGD（Mixed gonadal dysgenesis）** | 多數為男性 | 取決於外生殖器結構與性腺功能 |
| **CAH（嚴重男性化）** | 女性 | 早期手術切除男性結構 |

> **臨床重點** 2015 年後的國際共識越來越傾向於**延遲非緊急手術**，並由患者本人成年後自行決定性別。手術決定不應僅由醫師或家長單方面決定。

## 4. 治療

### 4.1 內分泌治療

| 疾病 | 治療 |
|---|---|
| **CAH** | 皮質類固醇替代（氫化可的松、氟氫可的松）|
| **CAIS/PAIS** | 青春期後補充雌激素（維持乳房發育、骨質健康） |
| **5-alpha reductase deficiency** | 青春期後補充睾酮（促進男性化） |

### 4.2 手術治療

| 手術 | 適應症 |
|---|---|
| **陰蒂縮小術（Clitoroplasty）** | 嚴重陰蒂肥大（Prader III-IV），影響生活品質 |
| **陰唇整型術（Labioplasty）** | 陰唇融合、影響日常生活或衛生 |
| **陰道重建（Vaginoplasty）** | 陰道缺如或狹窄，影響性交或月經流出 |
| **性腺切除術（Gonadectomy）** | CAIS/PAIS/MGD 中有腫瘤風險的性腺（性腺母細胞瘤風險增加）|
| **睪丸固定術（Orchiopexy）** | PAIS/MGD 中睪丸在腹腔內或腹股溝 |

**陰道重建時機**：
- 傳統觀點：青春期前早期手術
- 現代觀點：**建議等患者足夠大，能參與決策**，多數患者青春期後才需手術
- 技術：**Vecchietti 手術**（機械性陰道形成）、**McIndoe 手術**（使用口腔黏膜或皮膚移植）、**Daniels 手術**（使用乙狀結腸）

### 4.3 長期追蹤

| 追蹤項目 | 內容 |
|---|---|
| **生長發育** | 身高、體重、生長曲線、骨齡 |
| **內分泌功能** | 腎上腺功能、性腺功能、骨質密度 |
| **腫瘤篩檢** | 性腺超音超、腫瘤標記（AFP、β-hCG、CA125）|
| **心理社會支持** | 心理健康、性功能、生活質量 |

---

## 重點摘要

- **DSD 分類**：46,XX DSD（CAH 最常見）、46,XY DSD（PAIS、CAIS、5α-reductase deficiency）、性腺發育異常（Swyer、MGD）
- **診斷流程**：染色體分析 → 內分泌評估 → 影像學 → 性腺活檢（必要時）
- **性別認定**：多專科團隊+家庭共同決策，延遲非緊急手術
- **手術時機**：建議等患者夠大能參與決策，嚴重陰蒂肥大或陰道狹窄可早期處理
- **長期追蹤**：生長發育、骨質密度、腫瘤篩檢、心理支持
