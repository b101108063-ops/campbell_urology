# 📖 章節導讀

排便障礙（Defecation Disorders）與泌尿系統功能密切相關，尤其在兒童群體中，**便秘**與**膀胱功能障礙**常同時存在，形成所謂「**腸道-膀胱功能障礙**（Bowel-Bladder Dysfunction）」的臨床表徵。本章節介紹兒童排便障礙的評估、診斷與治療，以及其與泌尿系統的交互影響。

> **臨床重點** 排便障礙與泌尿系統症狀常常相互影響。慢性便秘導致直腸糞便滯留，進而刺激膀胱、造成膀胱功能障礙（如白天尿失禁、頻尿）。因此，評估兒童泌尿症狀時，必須同時評估排便情況；反之亦然。

---

## 1. 正常排便生理與發育

### 正常排便過程

| 階段 | 機制 |
|---|---|
| **糞便形成** | 結腸吸收水分，糞便儲存於直腸 |
| **排便反射** | 直腸擴張 → 內肛門括約肌反射性鬆弛 → 糞便進入肛管 |
| **随意性排便** | 外肛門括約肌與骨盆底肌自主放鬆，腹壓增加，糞便排出 |
| **肛門直腸抑制反射（RAIR）** | 直腸擴張時內括約肌反射性鬆弛；先天性巨結腸症此反射消失 |

### 正常排便頻率

| 年齡 | 正常排便頻率 |
|---|---|
| 新生兒（0-3 個月，母乳餵養） | 每日 5-40 次（質軟）|
| 新生兒（0-3 個月，配方奶） | 每日 1-7 次 |
| 2 歲以下 | 每日 1-3 次至每 2 日 1 次均屬正常 |
| >4 歲 | 同成人，每日 3 次至每 3 日 1 次 |

## 2. 兒童便秘（Pediatric Constipation）

### 定義（Rome IV 標準）

| 診斷標準（需存在 ≥2 項，時間 ≥1 個月） | 說明 |
|---|---|
| 每週排便 <3 次 | |
| 每週至少 1 次大便失禁（encopresis） | |
| 有主動忍便姿勢或刻意抑制排便行為 | |
| 排便疼痛或困難 |
| 直腸有巨大糞便塊 | |
| 巨大糞便阻塞馬桶 |

### 發病機轉與分類

| 分類 | 說明 |
|---|---|
| **功能性便秘（Functional constipation）** | 最常見（90-95%），無結構或器質性病因；與排便習慣、飲食、心理因素相關 |
| **器質性便秘（Organic constipation）** | 結構異常（肛門閉鎖、狹窄）、內分泌/代謝異常（甲狀腺功能減退、糖尿病）、神經性（脊髓病變、先天性巨結腸症）|

### 先天性巨結腸症（Hirschsprung Disease）

| 項目 | 說明 |
|---|---|
| **定義** | 腸道神經節細胞（ganglion cells）先天性缺如，導致腸道持續痙攣、無法鬆弛 |
| **發生率** | 約 1/5,000 活產新生兒 |
| **常見部位** | 直腸、乙狀結腸 |
| **臨床表現** | 出生後 24-48 小時無胎糞排出、腹脹、嘔吐 |
| **確診** | 直腸肛門抑制反射（RAIR）消失；直腸黏膜活檢確認缺乏神經節細胞 |
| **治療** | 手術切除無神經節細胞段 + 拉出術（pull-through procedure）；如 Swenson、Soave、Duhamel 手術 |

### 便秘對泌尿系統的影響

| 影響機制 | 結果 |
|---|---|
| **直腸糞便壓迫膀胱** | 膀胱容量減少、頻尿 |
| **骨盆底肌肉協調異常** | 排尿困難、Dysfunctional voiding |
| **尿液滯留** | 泌尿道感染（UTI）|
| **糞便逆流至尿道/膀胱** | 復發性泌尿道感染 |
| **糞便嵌塞** | 膀胱出口阻塞症狀 |

> **臨床重點** 臨床上遇到**復發性泌尿道感染**或**白天尿失禁**的兒童，必須常規評估排便情況。若發現便秘，應優先處理便秘，因為便秘控制後，泌尿症狀往往也會改善。

## 3. 評估與診斷

### 3.1 臨床評估

| 項目 | 內容 |
|---|---|
| **病史** | 排便頻率、糞便性狀（布里斯托分類）、大便失禁、忍便行為、腹痛 |
| **飲食評估** | 纖維攝取量、液體攝取量 |
| **身體檢查** | 腹部（糞便塊）、肛門（位置、糞便、裂隙、疤痕）、脊椎（隱性脊柱裂、神經學檢查）|
| **排便日誌（Defecation diary）** | 記錄 7-14 天的排便、尿尿、喝水時間與症狀 |

### 3.2 實驗室檢查

| 檢查 | 目的 |
|---|---|
| 甲狀腺功能（TSH、Free T4） | 排除甲狀腺功能減退 |
| 電解質、血糖 | 排除電解質異常、糖尿病 |
| 血清钙 | 排除高血鈣 |
| 腹腔 X 光 | 評估糞便淤積程度（尤其在無法進行直腸檢查時）|

### 3.3 特殊檢查

| 檢查 | 適應症 |
|---|---|
| **肛門直腸測壓（Anorectal manometry）** | 評估內外肛門括約肌功能、先天性巨結腸症確診 |
| **排糞造影（Defecography）** | 評估直腸肛門角、直腸脫垂、腸套疊 |
| **腸道傳輸試驗（Transit study）** | 區分出口阻塞型與慢傳輸型便秘 |
| **MRI 脊椎檢查** | 排除脊髓病變（如 tethered cord）|

## 4. 治療

### 4.1 功能性便秘的治療原則

| 治療層面 | 內容 |
|---|---|
| **家屬教育** | 了解便秘機轉、排便訓練的重要性 |
| **飲食調整** | 增加纖維攝取（水果、蔬菜、全穀類）；每日液體 50-100 mL/kg |
| **排便行為訓練** | 固定時間坐馬桶（飯後 15-30 分鐘，促進胃結腸反射）；每次 5-10 分鐘 |
| **藥物治療** | 軟化糞便、刺激排便 |

### 4.2 藥物治療

| 藥物類別 | 代表藥物 | 機轉 | 說明 |
|---|---|---|---|
| **糞便軟化劑** | Docusate sodium（DSS）| 降低糞便表面張力 | 安全性高 |
| **渗透性瀉劑** | Polyethylene glycol（PEG, Miralax）| 促進水分分泌至腸道 | 一線藥物；兒童劑量 0.4-0.8 g/kg/日 |
| **渗透性瀉劑** | Lactulose | 渗透作用 | 可長期使用 |
| **刺激性瀉劑** | Senna、甘油栓（ Glycerin suppository）| 刺激腸道蠕動 | 短期使用；長期使用可能影響腸道功能 |
| **礦物油（Mineral oil）** | | 潤滑糞便 | 6 個月以下嬰兒禁用（誤吸風險）|

**PEG（Miralax）用藥原則**：
- 起始劑量：0.4 g/kg/日
- 依排便情況調整劑量（每 2-3 天增加 0.2 g/kg）
- 維持劑量：0.4-0.8 g/kg/日，維持至少 2 個月
- 糞便軟化後，漸進式減量

### 4.3 大便失禁（Encopresis）的處理

| 項目 | 說明 |
|---|---|
| **定義** | 非故意性地將糞便排入衣物（≥4 歲）|
| **原因** | 慢性便秘導致糞便淤積、肛門括約肌鬆弛失控 |
| **處理原則** | 與便秘治療相同；加強行為訓練；必要時使用內掛（anal plug）|
| **心理支持** | 大便失禁對兒童心理影響大，需避免責罰 |

### 4.4 外科治療（少數）

| 適應症 | 手術類型 |
|---|---|
| 器質性便秘保守治療失敗 | 結腸切除術（如改良 Duhamel 手術治療先天性巨結腸症）|
| 出口阻塞型保守失敗 | 手術處理直腸脫垂、肛門狹窄 |

## 5. 腸道-膀胱功能障礙（Bowel-Bladder Dysfunction）

### 定義

**腸道-膀胱功能障礙**是指便秘與膀胱功能障礙同時存在，兩者相互影響，形成惡性循環。

### 臨床表徵

| 表現 | 說明 |
|---|---|
| **白天尿失禁** | 直腸糞便壓迫膀胱 |
| **頻尿、緊迫性尿失禁** | 膀胱過動（OAB）|
| **復發性泌尿道感染** | 尿液淤積、排尿不完整 |
| **排尿困難** | 骨盆底肌肉協調異常（Dysfunctional voiding）|

### 治療原則

| 步驟 | 內容 |
|---|---|
| **第一步** | 優先治療便秘（PEG + 飲食調整）|
| **第二步** | 固定時間排尿（每 2-3 小時一次）|
| **第三步** | 骨盆底肌肉訓練（Pelvic floor physiotherapy）|
| **第四步** | 抗膽鹼藥物（如 Oxybutynin）治療膀胱過動 |
| **第五步** | 行為與心理支持 |

> **臨床重點** 治療腸道-膀胱功能障礙的順序：**先腸後膀胱**。若只治療膀胱症狀而忽略便秘，往往療效不佳且容易復發。

---

## 重點摘要

- **功能性便秘**：兒童最常見；Rome IV 診斷標準；飲食行為調整 + PEG 為一線治療
- **先天性巨結腸症**：腸道神經節細胞缺如；RAIR 消失確診；手術切除治療
- **便秘與泌尿系統**：慢性便秘導致膀胱功能障礙、頻尿、UTI；評估泌尿症狀時需同時問診排便
- **大便失禁**：非故意性糞便排出，與便秘治療相同，避免責罰
- **腸道-膀胱功能障礙**：先治療便秘，後治療膀胱症狀
