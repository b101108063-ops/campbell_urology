## 📖 導讀

小兒腎上腺腫瘤以**神經母細胞瘤（neuroblastoma）**為最常見的惡性腫瘤，其臨床表徵多變，從無症狀團塊到轉移性疾病均可見。本章節系統整理神經母細胞瘤的**病理特徵**、**分期系統（INSS）**、**風險分層**，以及以**外科手術**為核心的治療策略，並說明**ganglioneuroma** 與神經母細胞瘤的差異。

---

## 病理學與分類

### 神經母細胞瘤

原始神經嵴腫瘤，起源於交感神經系統的未分化細胞。依據組織學特徵可分為三級：

| 組織學分級 | 特徵 |
|-----------|------|
| **良好型（favorable histology）** | 節細胞（ganglion cells）分化佳，間質豐富 |
| **不良型（unfavorable histology）** | 未分化或低分化，壞死廣泛 |

Shimada 分級系統可獨立預測預後（Shimada et al, 1984）。

### Ganglioneuroma

為完全分化的良性腫瘤，常見於**年齡較大的孩童**及**後縱膈**或**腹膜後**，少數起源於腎上腺。腫瘤常生長至巨大才出現症狀（因鄰近結構壓迫或脊椎延伸）。

> **臨床重點**
> - 與神經母細胞瘤不同，**Ganglioneuroma** 的存活率不受切除範圍影響，手術僅用於有顯著症狀者
> - 廣泛切除可能造成不必要的手術風險，應避免

## 臨床表徵與轉移模式

### 初始症狀

| 表現 | 說明 |
|------|------|
| 腹部疼痛或可觸及團塊 | 最常見 |
| 骨或關節疼痛 | 轉移性疾病的表現 |
| 眼眶瘀青（periorbital ecchymosis） | 眼眶周圍轉移 |
| 胸部病灶 | 咳嗽或呼吸困難 |

胸椎旁病灶（paravertebral lesions）可直接延伸進入**椎管**，導致**脊髓壓迫**之神經功能缺損。

### 腫瘤發生位置

| 位置 | 頻率 |
|------|------|
| 腹部（原發） | 65% |
| 腎上腺 | 嬰幼兒稍高 |
| Zuckerkandl 器官（骨盆腔神經母細胞瘤） | 4% |

外部壓迫膀胱和直腸可導致**尿瀦留**及**便祕**。

> **臨床重點**
> - 70% 患者在診斷時已有**遠處轉移**
> - 脊髓壓迫是急需外科或放射科處理的急症

## 副腫瘤症候群

| 症候群 | 機制 | 臨床表現 |
|--------|------|---------|
| **Catecholamine 分泌過量** | 嗜鉻細胞瘤樣症狀 | 陣發性高血壓、心悸、臉部潮紅、頭痛 |
| **VIP 分泌** | 血管活性腸肽分泌 | 嚴重水樣腹瀉、低血鉀 |
| **Opsoclonus-myoclonus 症候群**（嬰兒肌肉陣攣性腦病） | 抗神經母細胞瘤抗體攻擊神經組織 | 肌陣攣、眼球游走性運動（共濟失調） |

> **臨床重點**
> - **Opsoclonus-myoclonus** 雖然 oncologic 預後佳，但 70–80% 的孩童會有長期神經功能損傷，包括學習障礙及發育遲緩
> - ACTH 或類固醇為主要治療，可选 IVIG 或 cyclophosphamide

## 實驗室評估

### 尿液兒茶酚胺代謝物

| 項目 | 敏感度 |
|------|--------|
| **VMA**（vanillylmandelic acid） | 90–95% 患者升高 |
| **HVA**（homovanillic acid） | 同上 |

治療後這些代謝物濃度會下降，可用於偵測**腫瘤復發**及**治療反應**。

### 骨髓評估

建議取 **2 個骨髓穿刺**及 **2 個骨髓切片**，以提高轉移偵測率。骨髓浸潤廣泛時可見貧血。

## 影像學評估

| 影像工具 | 臨床應用 |
|---------|---------|
| **X光** | 偵測鈣化團塊 |
| **CT** | 評估原發腫瘤局部範圍及血管侵犯；可偵測腎實質侵犯 |
| **MRI** | 評估椎管內延伸；明確major vessels與腫瘤之關係 |

> **臨床重點**
> - MRI 為評估**脊椎管內延伸**的首選工具
> - CT 可顯示腎實質侵犯，但 MRI 更能精確評估腫瘤與大血管的關係

## 分期系統：INSS（國際神經母細胞瘤分期系統）

### 表 155-1 國際神經母細胞瘤分期系統

| Stage | 描述 |
|-------|------|
| **1** | 局部腫瘤，完整切除，無顯微殘留；同側淋巴結陰性 |
| **2A** | 局部腫瘤，不完整切除；同側淋巴結陰性 |
| **2B** | 局部腫瘤（可完整或不完整切除）；同側區域淋巴結陽性；對側淋巴結陰性 |
| **3** | 無法切除的單側腫瘤跨中線*，或局部單側腫瘤合併對側淋巴結侵犯 |
| **4** | 任何原發腫瘤合併遠處轉移（淋巴結、骨、骨髓、肝、皮膚等） |
| **4S** | 局部原發腫瘤（1/2A/2B），轉移僅限於皮膚、肝、骨髓（<1歲，<10%腫瘤浸潤） |

> \*中線定義為脊椎柱。跨越中線需腫瘤浸潤至或超越對側脊椎柱。

## 風險分層

### 表 155-2 神經母細胞瘤風險組分類

| 風險組 | 特性 | 治療策略 |
|--------|------|---------|
| **低風險** | 嬰兒（<1歲），4S期，Favorable biology | 積極觀察 ± 有限化學治療 |
| **中風險** | 各年齡，Stage 2/3/4 | 多模態治療（化療 + 手術） |
| **高風險** | >18 個月，Stage 4，MYCN放大，不良生物標記 | 強化多模態治療 |

---

## 預後因子

| 因子 | 影響 |
|------|------|
| **年齡** | <18 個月預後佳；>18 個月復發風險增加 |
| **分期** | Stage 1/2/4S：75–90% OS；Stage 4：19–30% 兩年無病存活率 |
| **MYCN 放大** | 高度惡性，復發風險顯著增加 |
| **腫瘤位置** | 非腎上腺原發者預後較佳 |
| **DNA 指數** | >1.0 為良好預後指標 |

> **臨床重點**
> - Stage 4S 的良好預後與其腫瘤幾乎均具有有利生物標記有關
> - 具有 MYCN 放大且廣泛轉移的病童應被歸類為高風險，須接受強化多模態治療

---

## 治療策略

### 手術治療原則

| 情境 | 建議 |
|------|------|
| **Stage 1** | 完整切除後密切追蹤，不需輔助治療 |
| **Stage 2** | 即使不完全切除預後仍佳；放療僅用於復發且化療無效者 |
| **Stage 3** | 術前化療可顯著降低腎切除的風險 |
| **Stage 4S** | 原發腫瘤切除非強制；侷限症狀時才考慮手術 |

> **臨床重點**
> - 化療對 Stage 4S 的 90% 患者有效，手術並非必要
> - 術前化療對 Stage 3 或腎臟/腎血管周圍腫瘤，可降低 40% 以上的腎切除率（Shamberger et al, 1998）

## 本章重點摘要

| 議題 | 核心要點 |
|------|---------|
| **腫瘤分類** | 神經母細胞瘤（惡性）vs. Ganglioneuroma（良性，手術選擇性） |
| **分期** | INSS 1–4 和 4S；Stage 4S 專指嬰兒的肝/皮膚/骨髓轉移 |
| **預後因子** | 年齡、分期、MYCN 放大與否為最重要的獨立預後因子 |
| **風險分層** | 低/中/高風險決定治療強度；嬰兒 4S 期多為低風險 |
| **Opsoclonus-myoclonus** | 預後佳但神經後遺症常見，需長期復健與追蹤 |
