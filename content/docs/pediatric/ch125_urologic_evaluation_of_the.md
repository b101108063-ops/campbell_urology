# CH125 小兒泌尿科評估：陰莖、尿道與生殖器症狀

## 📖 導讀

小兒泌尿科門診常見的陰莖與外生殖器症狀包括**嵌頓包莖（paraphimosis）**、**包莖（phimosis）**、**尿道下裂（hypospadias）**以及**鞘膜積液（hydrocele）**等。本章節系統整理各年齡層男孩陰莖症狀的評估與處理原則，涵蓋從新生兒時期的包皮護理建議到青少年時期的睪丸腫瘤辨別。對於兒童泌尿科醫師而言，正確區分生理性與病理性包皮問題，並掌握何時應積極介入，是日常臨床工作的核心能力。

---

## 男性陰莖與尿道症狀

### 包莖（Phimosis）與嵌頓包莖（Paraphimosis）

#### 包莖的生理與病理之分

| 類型 | 年齡 | 特徵 | 處理 |
|------|------|------|------|
| **生理性包莖** | < 2–3 歲嬰兒 | 包皮與龜頭粘連為正常發育現象 | **不應強行退縮**，保持清潔即可 |
| **病理性包莖** | 訓練如廁後的兒童 | 包皮纖維化、無法退縮 | 先嘗試**低劑量類固醇軟膏**（1-2療程），失敗後考慮**包皮環切術** |

> **臨床重點**
> - 2–3 歲以下男孩嘗試手動退縮包皮**應避免**，此舉可能造成創傷與疤痕
> - 病理性包莖的治療：第一線為**低劑量類固醇軟膏**（如 0.05% betamethasone），1–2 療程無效則行包皮環切術

---

#### 嵌頓包莖（Paraphimosis）

嵌頓包莖為**包皮退縮後無法復位**而卡在冠狀溝近端，是泌尿科急症。

| 項目 | 內容 |
|------|------|
| 定義 | 包皮狹窄環卡在冠狀溝近端，靜脈回流受阻 |
| 處理原則 | **立即**手動復位 |
| 麻醉需求 | 兒童通常需要** lidocaine 陰莖阻斷**與鎮靜 |
| 併發症 | 若未處理，長期嵌頓可導致**陰莖壞死** |

> **臨床重點**
> - 嵌頓包莖是需要**立即關注**的急症
> - 復位失敗或反覆發作應考慮急診或儘速手術干預

---

### 尿道下裂（Hypospadias）

| 項目 | 內容 |
|------|------|
| 定義 | 尿道口位於陰莖腹側非正常位置 |
| 評估時機 | **新生兒期**即應啟動評估 |
| 父母需求 | 多數父母希望儘早與外科醫師諮詢，即使為輕度尿道下裂 |
| 手術時機 | 通常於新生兒期或嬰兒期完成修復 |

---

### 包皮環切術後併發症

| 併發症 | 表現 | 處理原則 |
|--------|------|---------|
| **環切術後狹窄環（Cicatrix）** | 包皮環縮窄，形成 trapped penis | 塗抹**凡士林** 4–6 週，或類固醇軟膏，若排尿正常可延後至 4–6 個月手術修補 |
| **尿道口狹窄（Meatal stenosis）** | 環切術後 6 個月出現 | 門診**局部麻醉下尿道口切開術（meatotomy）** |

> **臨床重點**
> - 環切術後狹窄環導致 trapped penis，只要排尿正常，手術修補可延後至 4–6 個月齡
> - 尿道口狹窄是包皮環切術後最常見的遠期併發症之一

## 青少年陰莖症狀

### 陰莖異常勃起（Priapism）

| 項目 | 內容 |
|------|------|
| 定義 | 疼痛性陰莖持續勃起 |
| 病因 | **陰莖海綿體缺血**，可進展為纖維化 |
| 高風險族群 | **鐮刀型紅血球疾病**患者；75% 在 20 歲前首次發作 |
| 急性處理（>4 小時） | 海綿體抽吸 + **擬交感神經藥物**鞘內注射 |
| 口服藥物 | **terbutaline** 或 **pseudoephedrine**：急性缺血性陰莖異常勃起**不建議使用** |

> **臨床重點**
> - 疼痛可能暗示陰莖海綿體缺血，延誤治療可導致**陰莖纖維化**
> - 所有兒童疼痛性陰莖異常勃起都應**立即評估**

## 女童外生殖器症狀

### 陰道內團塊的鑑別診斷

| 診斷 | 特徵 | 處理 |
|------|------|------|
| **良性尿道旁囊腫（Paraurethral cyst）** | 無痛性 | 觀察 |
| **處女膜皮膚標籤（Hymen skin tag）** | 良性 | 觀察 |
| **尿道脫垂（Urethral prolapse）** | 甜甜圈狀充血團塊，常見於非裔美國女童 | **局部雌激素軟膏**；若排尿正常可保守治療 |
| **無孔處女膜（Imperforate hymen）** | 月經無法排出，骨盆腔疼痛 | 手術切開 |
| **輸尿管囊腫脫垂（Prolapsed ureterocele）** | 可阻塞膀胱出口 | 手術處理 |
| **陰道橫紋肌肉瘤（Vaginal rhabdomyosarcoma）** | 罕見但惡性 | 進一步影像學與切片 |

> **臨床重點**
> - **尿道脫垂**常見於年輕非裔美國女童，表現為接觸性出血的甜甜圈狀團塊
> - **無孔處女膜**若不及時處理，，子宮逆流排水可能導致**內膜異位症與不孕**

---

### 小陰唇粘連（Labial Adhesions）

| 項目 | 內容 |
|------|------|
| 發生率 | 常見，多為無症狀 |
| 有症狀表現 | 陰道刺激（尿液滯留）、頻尿、急尿 |
| 治療 | 局部**雌激素軟膏**；或門診局部麻醉下分離 |
| 嚴重粘連 | 可能與**先天性腎上腺增生（CAH）**、性腺發育不全或泄殖腔畸形相關 |

> **臨床重點**
> - 糞便滯留幾乎總是伴隨尿液滯留，兩者皆為**排空障礙**的表現
> - 陰道 rhabdomyosarcoma 可能以**陰道出血**為表現，需高度警覺

---

## 排尿功能障礙的評估

### 日夜間遺尿（Enuresis）的處理原則

| 狀況 | 處理建議 |
|------|---------|
| **夜間遺尿（ nocturnal enuresis）** | 5 歲前不建議積極治療；若兒童本人不在意，藥物或警鈴治療優勢有限 |
| **日間遺尿或白天頻尿** | 需更積極評估，常暗示**排空不完全或頻繁** |
| **日夜間遺尿 + 頻尿** | 與**泌尿道感染（UTI）**和**膀胱腸道功能障礙（BBD）**密切相關 |

### 排尿功能障礙的紅旗症狀

| 症狀 | 可能的病因 |
|------|---------|
| 正常排尿之間的連續漏尿（女童） | **異位輸尿管（Ectopic ureter）** |
| 排尿困難、遲疑、慢或微弱尿流、餘尿感 | **隱性脊柱裂（Occult spinal dysraphism）**、**後尿道瓣膜（PUV）** |
| 排尿疼痛與滯留 | **後尿道瓣膜**或**膀胱腫瘤（如 rhabdomyosarcoma）** |

> **臨床重點**
> - **膀胱出口阻塞**症狀（stranguria、retention）是深入病因評估的重要警訊
> - 排尿功能評估第一步：**尿流速測定（uroflow）**、**餘尿測定（PVR）**、**腎臟與膀胱超聲**

## 青春期前睪丸與副睪腫瘤

| 腫瘤類型 | 比例（青春期前） | 備註 |
|---------|--------------|------|
| **畸胎瘤（Teratoma）** | 最常見（48%） | 74% 為良性 |
| **橫紋肌肉瘤（Rhabdomyosarcoma）** | 第二常見 | 高度惡性 |
| **表皮樣囊腫（Epidermoid cyst）** | 常見良性 | — |
| **卵黃囊瘤（Yolk sac tumor）** | 15% | 2歲高峰，75% 為惡性 |
| **生殖細胞瘤（Germ cell tumor）** | 少見 | — |

> **臨床重點**
> - 青春期前睪丸腫瘤中，**74% 為良性**
> - 2 歲以內的腫瘤：惡性比例高（75%），以**卵黃囊瘤**最常見
> - **白血病與淋巴瘤**亦需列入陰囊團塊的鑑別診斷

## 重點總結

| 主題 | 核心要點 |
|------|---------|
| 生理性 vs. 病理性包莖 | < 2–3 歲不強行退縮；病理性包莖先類固醇軟膏，失敗後手術 |
| 嵌頓包莖 | 泌尿科急症，需立即手動復位 |
| 尿道下裂 | 新生兒期即應啟動評估與父母諮詢 |
| 環切術後併發症 | 狹窄環→凡士林或類固醇；尿道口狹窄→門診meatotomy |
| 陰莖異常勃起 | 立即評估，缺血可致陰莖纖維化 |
| 女童陰道團塊 | 尿道脫垂→雌激素；無孔處女膜→手術，預防內膜異位症 |
| 排尿障礙 | Uroflow + PVR + 超聲為一線評估；stranguria/retention 是紅旗 |
| 青春期前睪丸腫瘤 | 畸胎瘤最常見（良性），2歲前以卵黃囊瘤惡性比例最高 |
