# 147 尿道下裂

📖 **導讀**：尿道下裂是男性嬰兒常見的先天性泌尿生殖系統畸形，其特徵為尿道開口位於陰莖腹側而非遠端龜頭。本章節涵蓋尿道下裂的手術時機、術前準備、併發症處理，特別是關於**陰莖彎曲（ventral curvature, VC）**的評估與手術矫正原則。臨床上，非症候群性尿道下裂不需常規進行尿路影像檢查，手術時機建議於嬰兒3個月大後進行。

## 定義與流行病學

尿道下裂是指尿道開口位於陰莖腹側正常位置以下的任何位置，同時伴有**包皮短缺（preputial deficiency）**——包皮在腹側缺失，背側則可能過多形成「帽狀」外觀。

> **臨床重點**：非症候群性尿道下裂（nonsyndromic hypospadias）無論嚴重程度，均**不建議常規進行尿路影像檢查**（超聲波或排泄性膀胱尿道造影），因其發現異常的臨床意義有限。

## 術前評估

### 尿路影像檢查的必要性

多項回顧性研究顯示：
- 腎臟超聲波檢查異常率約 **18%**，但臨床上有意義的發現（如水腎）僅 **1-4%**
- 排泄性膀胱尿道造影發現**膀胱輸尿管逆流（VUR）**的比例約 **4%**

| 檢查項目 | 異常率 | 需手術治療比例 |
|---|---|---|
| 腎臟超聲波 | 18% | 12% |
| 排泄性膀胱尿道造影 | 4% (VUR) | - |

> **臨床重點**：尿道下裂修復手術本身**不需要常規術前尿路影像檢查**，除非合併其他臨床表徵提示上泌尿系統異常。

## 手術時機

**最佳手術年齡**：嬰兒 **3個月大或以上**，身體健康、足月分娩者，可作為門診手術進行。

### 影響手術時機的因素

1. **麻醉風險**：3-5個月大嬰兒的麻醉併發症發生率低（支氣管痙攣約2%），早產兒需等到妊娠週數滿56週後才能進行門診手術
2. **心理社會因素**：美國小兒科學會建議18個月前完成手術，以減少心理壓力
3. **尿道修復併發症與年齡的關係**：各研究結果不一致，部分顯示年齡增加併發症上升，但亦有大規模研究質疑年齡是否為獨立風險因子

> **臨床重點**：手術時機的選擇應综合考量麻醉風險、心理因素及可能的併發症差異。**3個月大**是目前多數專家認可的最小手術年齡。

## 術前雄激素刺激治療

### 理论基础

**雄激素（Androgens）** 可增加陰莖長度及龜頭周徑，效果在停藥後可能持續一段時間。

### 臨床證據

| 研究 | 發現 |
|---|---|
| Bush等（2013） | 龜頭寬度**<14mm**時尿道修復併發症顯著增加 |
| Kaya等（2008）隨機試驗 | 術前使用**局部二氫睪固酮（DHT）**可降低併發症（治療組1/37 vs對照組9/38，p=0.01） |
| Bush等 | 術前補充睪固酮後，併發症發生率反而**增加**（34% vs 11%，p<0.0001） |

### 治療方案

- **初始劑量**：Testosterone cypionate 肌肉注射 **2 mg/kg**，注射2-3次
- **劑量調整**：若龜頭寬度未達標，可漸進式增加劑量（最高至 **32 mg/kg**）
- **目標**：龜頭寬度達到 **15mm或以上**

> **臨床重點**：術前雄激素刺激治療的臨床效益仍有爭議。文獻報告結果不一致，且多为主觀選擇患者、經驗性治療方案，並缺乏客觀終點。建議審慎評估後再決定是否使用。

## 新生兒包皮環切術中發現尿道下裂

### 處理原則

| 情況 | 建議 |
|---|---|
| 發現隱藏性尿道下裂但包皮正常 | 可繼續進行包皮環切術 |
| 懷疑為**megameatus intact prepuce** variant | 建議避免包皮環切，因可能需要包皮作為修復材料 |
| 已有包皮環切病史 | 修復手術的尿道併發症與無環切病史者相當 |

> **臨床重點**：若新生兒包皮外觀正常，**不應因為懷疑隱藏性尿道下裂而停止包皮環切術**。研究顯示正常包皮的環切術中發現隱藏性尿道下裂的機率很低，且不影響修復結果。

## 陰莖彎曲（Ventral Curvature, VC）的術中評估與處理

### 發生率

研究顯示近端型尿道下裂中：
- **19%** 無明顯彎曲
- **31%** 彎曲角度 < 30度
- **50%** 彎曲角度 **> 30度**

### 人工勃起試驗（Artificial Erection Test）

**技術方法**：
- 使用 **23號蝴蝶針** 插入單側陰莖海綿體
- 注入生理食鹽水直至勃起達成
- 不使用止血帶，避免影響彎曲程度的判斷

> **臨床重點**：術中人工勃起試驗是評估陰莖彎曲的標準方法。**生理食鹽水注射**較血管活性藥物更為簡便可靠，無需特殊藥物配製。

### VC < 30度的處理

**背側摺疊術（Dorsal Plication）**：
- 在彎曲最明顯處做**縱向Buck筋膜切開**
- 使用 **5-0或6-0聚丙烯縫線**進行單一中部摺疊
- 縫線打結埋入，術中重複勃起測試確認拉直效果

**復發率**：7%（文獻報告）

### VC > 30度的處理流程

1. **第一步**：陰莖脫套（degloving）、腹側Dartos組織分離、釋放海綿體附著
2. **第二步**：若彎曲仍 > 30度，進行**尿道板（urethral plate）橫斷**
3. **第三步**：重新進行人工勃起測試
   - 若彎曲 **< 30度**：行背側摺疊術
   - 若彎曲仍 **> 30度**：行**腹側海綿體橫切術（ventral corporotomies）**，可配合或不配合移植

> **臨床重點**：海綿體橫切術（3處橫切）是我們首選的**腹側延長技術**，不同於單一橫切加移植的方式。選擇此方法可以保留更多尿道修復選項（尤其是**尿道切開板修復術/TIP urethroplasty**的可行性）。

### 背側摺疊術要點

| 項目 | 說明 |
|---|---|
| 適應症 | 陰莖彎曲 < 30度 |
| 縫線材質 | 聚丙烯（polypropylene）5-0或6-0 |
| 縫合位置 | 中線海綿體隔（midline septum） |
| 併發症 | 陰莖縮短 < 0.5cm（成人系列） |
| 復發率 | 約7% |

> **臨床重點**：不建議對 > 30度的彎曲使用**多重摺疊術**，因其結果可能無法維持至成年。我們首選對 > 30度的持續彎曲進行海綿體橫切術，以確保效果持久。

## 縫線材料與修復結果

**Guarino等（2009）** 隨機對比兩種縫線：
- **Polyglytone（快速吸收）** vs **Polydioxanone（慢速吸收）**
- 修復後2年追蹤：**兩組瘻管發生率無顯著差異**（8% vs 12%）

結論：目前無證據顯示縫線材質會影響尿道修復結果。

> **臨床重點**：修復結果主要取決於手術技術、龜頭大小及陰莖彎曲程度，而非縫線材質的選擇。
