# 📖 導讀

兒童下尿路功能障礙是兒童泌尿科最常見的臨床問題之一，涵蓋從簡單的**夜間遺尿**到複雜的**神經性膀胱**等多種疾病。這些障礙不僅影響兒童的生活品質，更可能對泌尿系統造成長期的結構性傷害。早期識別、準確診斷與適當治療，對於維護腎臟功能及生活品質至關重要。本章節重點介紹兩大主題：**白天尿失禁**（Daytime urinary incontinence）與**夜間遺尿**（Nocturnal enuresis），包括其流行病學、病因、診斷方法及治療原則。

---

## 1. 白天尿失禁（Daytime Urinary Incontinence）

### 定義與流行病學

**白天尿失禁**定義為白天清醒時無法控制排尿，導致不自主漏尿。發生率隨年齡變化：

| 年齡 | 白天尿失禁發生率 |
|-----|----------------|
| 4-6 歲 | 約 10-15% |
| 7-12 歲 | 約 5-10% |
| 12 歲以上 | 約 2-5% |

> **臨床重點**：**白天尿失禁**在 4 歲以上兒童即屬**異常**，不應被視為正常發育過程的一部分。若未適當治療，可能影響兒童**社交**、**心理發展**及**學校表現**。

### 病因分類

| 病因類型 | 說明 |
|---------|------|
| **膀胱過動**（OAB） | **最常見原因**，逼尿肌不自主收縮 |
| 膀胱容量減少 | 先天性或後天性 |
| 功能性排尿障礙 | 骨盆底肌肉協調異常 |
| 泌尿道感染 | 膀胱炎刺激 |
| 結構異常 | 後尿道瓣膜、膀胱頸狹窄 |

### 膀胱過動（Overactive Bladder, OAB）

**膀胱過動**為**白天尿失禁**的**最常見原因**，特徵為逼尿肌的不自主過度收縮。

| 症狀 | 臨床表現 |
|-----|---------|
| **尿急**（Urgency） | 突然强烈的排尿衝動 |
| **頻尿**（Frequency） | 每日排尿次數 > 8 次 |
| **急迫性尿失禁**（Urge incontinence） | 尿急後無法控制的漏尿 |
| 夜尿 | 可能伴随夜间遗尿 |

> **臨床重點**：診斷**膀胱過動**需排除**泌尿道感染**、**結構異常**及其他神經性疾病。**尿流速圖**和**尿路動力學檢查**可協助確診。

### 診斷評估

#### 基本評估

| 檢查項目 | 臨床意義 |
|---------|---------|
| 病史詢問 | 排尿習慣、症狀持續時間 |
| 排尿日誌 | 記錄排尿時間、頻率、漏尿次數 |
| 尿液檢查 | 排除泌尿道感染 |
| 超音波 | 評估膀胱壁厚度、残餘尿量 |

#### 進階檢查

| 檢查項目 | 適應症 |
|---------|---------|
| **尿流速圖**（Uroflowmetry） | 評估排尿型態 |
| **殘餘尿量測定**（Post-void residual） | 確認是否為阻塞或神經性 |
| 尿路動力學檢查 | 複雜病例 |

> **臨床重點**：**尿流速圖**可區分**阻塞型**與**功能型**排尿障礙；**殘餘尿量**測定對於評估膀胱排空功能至關重要。超音波可評估**膀胱壁厚度**，膀胱壁增厚提示長期膀胱高壓狀態。

### 治療原則

#### 第一線：行為調整

| 治療方式 | 具體建議 |
|---------|---------|
| 定时排尿 | 每2-3小時按時排尿 |
| 避免刺激飲食 | 減少咖啡因、辛辣食物 |
| 水分管理 | 避免一次大量飲水 |
| 骨盆底肌肉訓練 | 学习抑制尿急 |

#### 第二線：藥物治療

> **臨床重點**：**抗膽鹼藥物**（Anticholinergics）為治療**膀胱過動**的主要藥物，作用機制為阻斷逼尿肌上的**M3毒蕈鹼受體**，降低逼尿肌收縮頻率。

| 藥物名稱 | 劑量 | 副作用 |
|---------|------|--------|
| **Oxybutynin** | 0.1-0.2 mg/kg，每日2-3次 | 口乾、便秘、嗜睡 |
| **Solifenacin** | 5-10 mg，每日一次 | 口乾、便秘 |
| **Tolterodine** | 1-2 mg，每日2次 | 口乾、頭痛 |

| Oxybutynin 注意事項 | 說明 |
|-------------------|------|
| 起始劑量 | 2.5 mg，每日2次 |
| 調整方式 | 每週調整劑量 |
| 最大劑量 | 5 mg，每日3次 |
| 常見副作用 | 口乾（30%）、便秘（10%） |

## 2. 夜間遺尿（Nocturnal Enuresis）

### 定義與分類

**夜間遺尿**又稱**夜尿症**（Bedwetting），定義為夜間睡眠時不自主排尿。根據臨床特徵分為：

| 類型 | 定義 | 特點 |
|-----|------|------|
| **單一症狀性夜間遺尿**（Monosymptomatic） | 僅有夜間尿失禁，無白天症狀 | 預後較好 |
| **複雜性夜間遺尿**（Non-monosymptomatic） | 合併白天尿失禁或其他泌尿症狀 | 需要更詳細評估 |

> **臨床重點**：區分**單一症狀性**與**複雜性夜間遺尿**非常重要。**單一症狀性夜間遺尿**的治療相對單純，而**複雜性夜間遺尿**需排除其他下尿路功能障礙。

### 流行病學

| 年齡 | 發生率 |
|-----|--------|
| 5 歲 | 約 15-20% |
| 7 歲 | 約 10% |
| 10 歲 | 約 5-7% |
| 15 歲以上 | 約 1-2% |

- 男女性別比例：男孩約為女孩的 2-3 倍
- 自然緩解率：每年約 15% 未治療者可自然緩解

### 病因

| 病因類型 | 說明 |
|---------|------|
| **夜間多尿**（Nocturnal polyuria） | 夜間抗利尿激素分泌不足 |
| **膀胱容量不足** | 功能性膀胱容量過小 |
| **覺醒障礙** | 睡眠過深，無法感知膀胱膨脹 |
| **遗传因素** | 父母有夜間遺尿病史者，風險增加 |

### 診斷評估

| 評估項目 | 臨床意義 |
|---------|---------|
| 詳細病史 | 症狀開始時間、頻率、家族史 |
| 排尿日誌 | 記錄日間及夜間尿量 |
| 尿液檢查 | 排除泌尿道感染及糖尿病 |
| 超音波 | 評估膀胱容量及結構 |

> **臨床重點**：**排尿日誌**為評估**夜間遺尿**的重要工具，應記錄連續 48 小時的排尿時間與尿量，以區分**夜間多尿**與**膀胱容量不足**。

### 治療原則

#### 單一症狀性夜間遺尿的治療

> **臨床重點**：**Bedwetting alarm**（遺尿警報器）為**單一症狀性夜間遺尿**的**首選治療**，**成功率達 70%**，且復發率低。

##### Bedwetting Alarm（遺尿警報器）

| 特性 | 說明 |
|-----|------|
| 作用機制 | 偵測尿液後發出警報，訓練觉醒反應 |
| 使用方式 | 睡前放置，偵測到尿液後叫醒兒童 |
| 成功率 | **約 70%** |
| 復發率 | 低（< 10%） |
| 治療時間 | 通常 2-3 個月 |
| 前提條件 | 兒童年齡 > 6-7 歲，能配合 |

**使用原則**：
1. 設定固定起床時間（如凌晨 1 點）叫醒兒童排尿
2. 逐漸延長警報觸發時間
3. 持續使用至連續 14 天無夜間遺尿
4. 避免懲罰，以正向鼓勵為主

##### Desmopressin（DDAVP）

> **臨床重點**：**Desmopressin**（DDAVP）為**合成抗利尿激素**，可快速見效，但**停藥後易復發**，適用於需要快速控制症狀的場合（如睡眠活動、露營）。

| Desmopressin 特性 | 說明 |
|-------------------|------|
| 作用機制 | 減少夜間尿量 |
| 給藥方式 | 睡前鼻腔噴霧或口服 |
| 見效速度 | **快速**（數天內見效） |
| 停藥後復發率 | **高**（約 60-70%） |
| 適用場合 | 需要快速控制、短期使用 |

| 藥物劑量 | 說明 |
|---------|------|
| 鼻腔噴霧 | 10-40 mcg，睡前 |
| 口服 | 0.2-0.4 mg，睡前 |
| 起始劑量 | 較低劑量開始 |
| 調整 | 根據療效調整 |

#### 複雜性夜間遺尿的治療

> **臨床重點**：**複雜性夜間遺尿**需先治療**日間泌尿症狀**（如**膀胱過動**），待白天症狀穩定後再處理夜間症狀。

| 治療順序 | 說明 |
|---------|------|
| 第一步 | 治療白天泌尿症狀（抗膽鹼藥物） |
| 第二步 | 白天症狀穩定後，加入夜間治療 |
| 第三步 | Bedwetting alarm 或 Desmopressin |

## 3. 診斷工具總整理

| 檢查項目 | 用途 | 適應症 |
|---------|------|--------|
| **尿流速圖**（Uroflowmetry） | 評估排尿型態 | 懷疑阻塞或功能異常 |
| **殘餘尿量測定**（PVR） | 評估膀胱排空功能 | 懷疑尿瀦留 |
| 超音波 | 評估膀胱壁厚度及結構 | 常規評估 |
| 尿路動力學檢查 | 完整膀胱功能評估 | 複雜病例 |

> **臨床重點**：多數**白天尿失禁**和**單一症狀性夜間遺尿**可通過詳細**病史**、**排尿日誌**及**基本檢查**（尿液、超音波）做出診斷。**尿路動力學檢查**僅用於**保守治療失敗**或**複雜病例**。

---

## 總結

| 主題 | 關鍵要點 |
|-----|---------|
| **白天尿失禁** | **膀胱過動（OAB）**最常見，治療：**行為調整** + **抗膽鹼藥物（Oxybutynin、Solifenacin）** |
| **單一症狀性夜間遺尿** | **Bedwetting alarm**首選（成功率70%），或 **Desmopressin**（快速見效但易復發） |
| **複雜性夜間遺尿** | 需先治療白天泌尿症狀，再處理夜間問題 |
| **診斷工具** | **尿流速圖**、**殘餘尿量**測定、超音波評估膀胱壁厚度 |
