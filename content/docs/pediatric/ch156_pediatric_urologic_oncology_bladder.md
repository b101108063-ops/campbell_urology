## 📖 導讀

**横紋肌肉瘤（Rhabdomyosarcoma, RMS）**是小兒最常見的軟組織肉瘤，而泌尿生殖系統是其好發部位之一。本章節聚焦於膀胱與前列腺原發之 RMS，系統整理其**病理學與分子生物學**（特別是 **PAX-FOXO1 融合基因**）、**分期系統**、**風險分層**，以及從傳統根治手术到現代**器官保存策略**的治療演進。

---

## 病理學分類

### 組織學亞型

| 亞型 | 特徵 | 預後 |
|------|------|------|
| **胚胎型（Embryonal）** | 最常見；膀胱主要組織類型；鏡下似7–10週胎兒橫紋肌 | 良好（85–90% 存活率） |
| **葡萄狀肉瘤（Botryoid）** | 變異型，呈息肉樣「葡萄串」外觀，起源於中空器官 | 良好 |
| **梭形細胞（Spindle cell）** | 常見於副睪丸區 | 良好 |
| **腺泡型（Alveolar）** | 第二常見；好發於青少年四肢；似10–21週胎兒橫紋肌 | 較差（轉移率高） |
| **未分化型（Undifferentiated）** | 最少見；分化程度最低 | 不佳 |

> **臨床重點**
> - 膀胱/前列腺病灶以**胚胎型**為主；腺泡型在膀胱/前列腺罕見
> - 腺泡型 RMS 可分為 **PAX-FOXO1 融合基因陽性**與**陰性**兩種生物亞型，融合陽性預後明顯較差

## 分子生物學：PAX-FOXO1 融合基因

### 染色體易位與基因重排

| 染色體易位 | 融合基因 | 發生率（腺泡型 RMS） |
|-----------|---------|---------------------|
| t(2;13) | **PAX3-FOXO1** | 最常見 |
| t(1;13) | **PAX7-FOXO1** | 較少見 |

約 **80%** 的腺泡型 RMS 為融合基因陽性。

### 臨床意義

| 融合基因型 | 事件自由存活（EFS） | 整體存活（OS） |
|-----------|---------------------|----------------|
| PAX3-FOXO1 陽性 | 最差 | 最差 |
| PAX7-FOXO1 陽性 | 中等 | 較 PAX3 好 |
| 融合基因陰性 | 佳（與胚胎型相近） | 佳 |

> **臨床重點**
> - PAX3-FOXO1 融合陽性腺泡型 RMS 的 EFS 及 OS 均顯著低於胚胎型及融合陰性腺泡型
> - 未來 COG 研究將以融合基因狀態作為風險分層的分子基礎
> - **Myogenin** 免疫染色可區分腺泡型（強陽）與胚胎型（弱/陰）

## 術前 TNM 分期系統（IRS Group Pretreatment）

### BOX 156-1 術前 TNM 臨床分期

| 分期 | 條件 |
|------|------|
| **Stage 1** | 良好部位（favorable site），無轉移 |
| **Stage 2** | 不良部位（unfavorable site），小腫瘤，淋巴結陰性，無轉移 |
| **Stage 3** | 不良部位，較大腫瘤或淋巴結陽性，無遠處轉移 |
| **Stage 4** | 任何部位，有遠處轉移 |

**良好部位**：眼眶、非顱底頭頸部、男性副睪丸、女性生殖道（陰道、外陰、子宮、子宮頸）

**不良部位**：所有其他部位（包含**膀胱與前列腺**）

---

## 術後臨床分組（Postoperative Clinical Group）

### BOX 156-2 術後分組

| Group | 描述 |
|-------|------|
| **I** | 局部疾病，完全切除 |
| **II** | 顯微殘留（Gross完全切除但顯微下有殘留）；或區域淋巴結侵犯但完全切除 |
| **III** | 不完全切除或切片後有gross殘留 |
| **IV** | 遠處轉移 |

## 風險分層

### 表 156-2 RMS 風險分層

| 風險組 | 特性 |
|--------|------|
| **低風險** | 良好部位，Group I/II/III |
| **中風險** | 不良部位（如膀胱/前列腺），Group III；或區域淋巴結侵犯 |
| **高風險** | 遠處轉移（Stage 4）或 PAX-FOXO1 融合陽性腺泡型 |

> **臨床重點**
> - 膀胱/前列腺 RMS 最常被歸入**中風險組**
> - 隨著器官保存策略的普及，多數膀胱/前列腺 RMS 從 Group I 變為 Group III（因先行切片而非切除）
> - 患者年齡為獨立預後因子：<1 歲及 >10 歲的存活率較差

## 多模態治療的演進

### IRS I–IV 的治療里程碑

| 研究 | 年代 | 治療策略 | 結果 |
|------|------|---------|------|
| **IRS I** | 1972–1978 | 根治手術 + 輔助化療 | OS 78%，但手術相關併發症顯著 |
| **IRS II** | 1979–1984 | 新輔助化療 + 放療 | OS 80%，但膀胱保存率僅 25% |
| **IRS III** | 1985–1992 | 含 doxorubicin、cisplatin、etoposide + 放療 | OS 83%，膀胱保存率提升 |

### 現代膀胱保存策略

| 策略 | 內容 |
|------|------|
| **先期化療（Primary chemotherapy）** | VAC 療程（Vincristine + Actinomycin D + Cyclophosphamide）為核心 |
| **部分膀胱切除術** | 僅切除受腫瘤侵犯的膀胱壁，保留膀胱功能 |
| **根治手術** | 化療無效或腫瘤進展時的最後手段 |

> **臨床重點**
> - 化療 alone 可使 10% 的患者達到無復發存活
> - 避免放療的方案：復發率較高，但 OS 相近（化療搶救效果好）
> - 過去 20 年膀胱/前列腺 RMS 的 OS 無顯著改善，需新的治療策略或精準風險分層

## 手術併發症與功能性結果

### 出口阻塞與尿路引流

| 併發症 | 處理策略 |
|--------|---------|
| **尿路出口阻塞** | 置入導尿管或恥骨上引流（suprapubic tube） |
| **輸尿管阻塞** | 逆行放置輸尿管導管；若失敗則以**經皮腎造口（percutaneous nephrostomy）**替代，後續再轉換為內部導管 |

### 延遲重建

- 部分病人在初始尿路引流後接受**延遲泌尿重建**
- 使用結腸段製作**暫時性導管**，後續再重構為**可控式腹壁造口（continent cutaneous stoma）**
- 延遲**正位（orthotopic）膀胱重建**的經驗有限，結果令人失望（Padua 經驗）

## 本章重點摘要

| 議題 | 核心要點 |
|------|---------|
| **病理學** | 膀胱/前列腺以胚胎型為主；腺泡型預後較差（與 PAX-FOXO1 融合基因相關） |
| **分子診斷** | PAX3/PAX7-FOXO1 融合基因陽性的腺泡型 RMS 侵襲性更強；myogenin 免疫染色為實用標記 |
| **分期** | 膀胱/前列腺屬「不良部位」；多數患者屬 Group III（先行切片） |
| **治療** | 以 VAC 新輔助化療為核心；器官保存為首要目標；根治手術保留至化療失敗 |
| **獨立預後因子** | 年齡（<1歲或>10歲預後差）、分期、Group、PAX-FOXO1 融合狀態 |
| **尿路引流併發症** | 出口阻塞用導尿管；輸尿管阻塞用逆行支架或經皮腎造口 |
