# 137 膀胱輸尿管逆流

📖 **導讀**：本章節探討**膀胱輸尿管逆流（Vesicoureteral Reflux, VUR）**的流行病學、遺傳學、胚胎學及臨床意義。VUR 為尿液從膀胱逆流至輸尿管甚至腎臟的疾病，與**泌尿道感染（UTI）**、腎臟疤痕形成及高血壓等併發症密切相關。近年研究對 VUR 的自然病程、抗生素預防的角色及傳統手術適應症提出新觀點。

## 定義與分類

**膀胱輸尿管逆流（VUR）**是指尿液從膀胱逆行流入輸尿管甚至腎盂的病理狀態。VUR 的自然病程具有以下特點：
- 可自行緩解（spontaneous resolution）
- 或因**膀胱功能異常（abnormal bladder dynamics）**而持續存在

### 分級表格

| 等級 | 描述 |
|---|---|
| **I** | 逆流至輸尿管下半段，未達骨盆 |
| **II** | 逆流至腎盂，無擴張 |
| **III** | 輕度至中度擴張，輕度積水 |
| **IV** | 中度擴張及積水，乳頭形狀消失 |
| **V** | 重度擴張及積水，乳頭形狀消失 |

> **臨床重點**：高grade reflux（IV-V級）最常與**腎臟閃爍掃描（renal scintigraphic）**異常相關，即使無感染病史，小腎臟伴全域功能降低可能暗示**輸尿管芽（ureteric bud）**發育異常。

## 病因與病生理

### 發生率與危險因子

根據文獻統計：
- 有 UTI 的兒童：VUR 發生率約 **30%**
- 無感染的兒童：VUR 發生率約 **17%**
- 嬰兒出現 UTI：VUR 發生率可達 **70%**（Baker et al, 1966）
- 產前水腎嬰兒：VUR 發生率 **15-38%**

**Table 137-1: UTI 病患中 Reflux 發生率**

| 年齡 | 男性 | 女性 |
|---|---|---|
| 0-1 歲 | 較高 | 較低 |
| 1-5 歲 | 中等 | 中等 |
| >5 歲 | 較低 | 較高 |

### 性別差異

- **嬰兒期**：男孩較多（男女比可達 6:1）
- **較大兒童**：女性較多（85%）
- 未割包皮的男性嬰兒患 UTI 風險是已割包皮者的 **12 倍**

### 種族差異

- **非洲裔兒童**：VUR 發生率約為白人的 **1/10**（10倍低）
- 非洲裔兒童 VUR 緩解速度較快（P < .005）
- 10 歲後種族間發生率趨於相等

> **臨床重點**：種族差異可能與**抗逆流機制（antireflux mechanism）**在白人中的成熟延遲有關，而非絕對發生率差異。

## 遺傳學與家族傾向

### 家族篩檢

- **兄弟姐妹**：VUR 發生率約 **32%**（meta-analysis）
- **原發性 VUR**：可能低至 **7%**
- 呈現**自體顯性遺傳（autosomal dominant）**模式傾向

### 基因研究

| 基因/模型 | 發現 |
|---|---|
| **GDNF-RET** | 在小鼠中強烈參與 UVJ 形成；過表現 RET 導致 30% VUR 發生率（野生型僅 4%） |
| **Uroplakin III** | 剔除小鼠出現 VUR；但人類族群中未發現結構變異 |
| **AGTR2、ACE** | 與 VUR 的關聯尚未證實 |
| **全基因組掃描** | 最大規模研究未發現主要基因座（major gene loci） |

> **臨床重點**：雖然動物模型顯示明確的遺傳機制，但人類 VUR 可能為**多基因（polygenic）**機制，不應假設所有逆流兄弟姐妹的皮質異常均為後天獲得。

## 胚胎學：輸尿管膀胱交界處（UVJ）

### Y 形發育模型

胚胎發育中，**輸尿管芽（ureteric bud）**與**中腎管（wolffian duct）**的形成可比喻為 Y 形結構：

```
    輸尿管芽 ←┐
              ├─→ 中腎管遠端（Y 的莖）→ 泌尿生殖竇（膀胱）
  中腎管（vas/射精通管）←┘
```

### 關鍵時序調控

| 情況 | 機制 | 結果 |
|---|---|---|
| **過早出芽** | 輸尿管芽過早達到泌尿生殖竇，導致過度旋轉 | 輸尿管口位於高位及外側，壁內長度不足 → **逆流** |
| **過晚出芽** | 輸尿管芽延遲達到泌尿生殖竇，旋轉不足 | **異位輸尿管（ectopic ureter）**，位置偏遠端 |

Mackie 等人（1975）提出的「**芽位理論（bud position theory）**」說明輸尿管口位置與抗逆流機制的關係。

## 臨床表徵

### 產前線索

- **產前水腎（antenatal hydronephrosis）**：產前超聲檢查發現水腎的嬰兒，產後 VUR 檢出率達 **38%**（Zerin et al, 1993）
- 水腎閾值越低，產後 VUR 檢出率越高

### 臨床表現

- **泌尿道感染（UTI）**：兒童 UTI 中約 30% 發現 VUR
- **發燒性 UTI**：應高度懷疑 VUR
- **高血壓**：成人 VUR 與高血壓相關（19% 發生率）
- **腎臟疤痕**：與反覆感染及高grade reflux 相關

> **臨床重點**：**無感染的 VUR 臨床意義存疑**——VUR 本身可能為正常變異，僅在易感 UTI 的族群中才具臨床重要性。

## 診斷

### 影像學檢查

| 檢查 | 用途 |
|---|---|
| **排尿性膀胱尿道攝影（VCUG）** | 診斷 VUR 的標準檢查，可分級 |
| **腎臟膀胱超聲（RBUS）** | 評估腎臟形態、水腎、疤痕 |
| **腎臟閃爍掃描（DMSA/Scan）** | 評估腎功能及疤痕 |
| **產前超聲** | 篩檢產前水腎 |

### 篩檢建議

- **兄弟姐妹篩檢**：兄弟姐妹 VUR 發生率較高（32%），但缺乏前瞻性研究支持全面篩檢
- **不建议盲目进行大规模筛查**：皮質異常可能為發育性而非後天性

## 治療

### 治療原則

| 情況 | 治療策略 |
|---|---|
| **低grade reflux（I-II）** | 保守觀察，自發緩解率高 |
| **中grade reflux（III）** | 抗生素預防，密切追蹤 |
| **高grade reflux（IV-V）** | 手術介入可能性高 |
| **反覆 UTI** | 積極治療 |

### 手術適應症（傳統觀點）

- 高grade reflux
- 腎臟疤痕進行性惡化
- 抗生素預防下仍反覆感染
- 膀胱功能異常

> **臨床重點**：近年研究對傳統手術適應症提出質疑——VUR 的管理（抗生素使用、膀胱攝影侵入性、手术适应症）正在被重新檢視。

## 總結

**膀胱輸尿管逆流（VUR）**是小兒泌尿科常見疾病，其特點包括：

1. **流行病學多變**：發生率因年齡、性別、種族及感染狀態而異
2. **性別差異明顯**：嬰兒期男孩為主，較大兒童以女孩為主（85%）
3. **種族差異顯著**：非洲裔兒童發生率明顯較低
4. **遺傳傾向**：兄弟姐妹發生率達 32%，可能為多基因遺傳
5. **胚胎基礎**：輸尿管芽發育時序決定 UVJ 抗逆流功能
6. **臨床管理待更新**：傳統手術適應症正在被重新審視

> **臨床重點**：VUR 的評估應個體化，年幼兒童、有發燒性 UTI 病史、高grade reflux 或有腎臟疤痕者需積極追蹤與治療。
